## 摘要
现代视觉-语言-动作（VLA）策略已具备广泛的操作技能，但通常仅基于当前观测或短固定长度历史生成每个动作块。然而，真实世界的操作往往是非马尔可夫的，要求机器人从长期交互历史中保留并推理任务相关信息以决定下一步动作。为应对这一挑战，我们提出HyMeS，一种混合学习框架，利用编码代理的推理与记忆管理能力来引导马尔可夫VLA完成记忆依赖型操作。具体而言，HyMeS通过基于梯度的模仿学习学习底层运动技能，同时编码代理通过启发式学习获得高层记忆管理策略，即根据 rollout 反馈迭代更新可执行的启发式系统。此外，我们通过多阶段完成验证来闭合引导与执行之间的回路，该验证利用本体感觉信号和多帧VLM判断更新记忆。与端到端的记忆增强VLA相比，HyMeS仅需针对可复用的运动技能提供演示，而无需为每个依赖历史的任务配置提供演示，从而实现了数据高效的组合泛化。在RoboMemArena上，HyMeS将平均累计成功率从52.5%提升至66.2%，平均任务成功率从41.3%提升至60.1%，相比pi0.5；同时在累计成功率上超过PrediMem 4.5个百分点，在任务成功率上超过14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

## 2. 方法论

### 2.1 核心思想
- **HyMeS（Hybrid Memory Steering）** 将任务学习拆分为两个互补部分：
  - **权重空间**：VLA 通过梯度型模仿学习获得低层运动技能；
  - **代码空间**：编码代理（coding agent）通过启发式学习，从 rollout 反馈中迭代更新可执行的启发式程序，获得高层记忆管理策略。
- 关键洞察：**技能存于权重，记忆存于代码**。VLA 参数在记忆策略开发与评估期间保持固定，无需记忆相关的权重更新。

### 2.2 系统与关键变量
- 可执行程序：**P = (C, V, U)**，包含约束选择规则 C、事件验证规则 V、记忆更新规则 U。
- 符号记忆状态：**sₜ = (plan, ρₜ, Bₜ, Nₜ, Fₜ)**，其中 ρₜ 为当前计划阶段，其余变量记录任务绑定、重复事件计数和持久交互状态。
- 闭环执行流程：
  - Rₜ = C(sₜ, oₜ, ℓ) （选择可微约束）
  - aₜ = Steer(π_θ*, Rₜ, oₜ, ℓ) （约束引导动作生成）
  - eₜ = V(o_Wₜ, a_Wₜ; sₜ) （阶段完成事件验证）
  - sₜ₊₁ = U(sₜ, eₜ, oₜ) （记忆更新）

### 2.3 运动技能学习（权重空间）
- 基于 flow-matching 目标微调预训练 VLA（如 π0.5）：
  - 插值 a_τ = (1−τ)ε + τa；
  - 优化速度场：θ* = argmin E[||v_θ(a_τ, τ|o, ℓ) − (a − ε)||²]。
- 该阶段只学习演示中的接触丰富运动行为，完成后权重冻结。

### 2.4 记忆策略学习（代码空间）
- 编码代理根据候选程序 P⁽ⁿ⁾ 的 rollout 符号执行轨迹 ξₙ 与基准阶段裁决 bₙ 对比，定位失败阶段、诊断约束或验证规则问题，并编辑程序：P⁽ⁿ⁺¹⁾ = Edit(P⁽ⁿ⁾, ξₙ, bₙ)。
- 该学习过程**不使用梯度或专家动作标签**，从执行反馈中迭代优化软件而非神经网络参数。
- 评估阶段程序 P* 冻结，不再修订。

### 2.5 记忆条件动作引导
- 活动阶段 ρₜ 选择可微约束，例如到达阶段：R_reach = −‖ee(a) − Γ_target(sₜ), oₜ‖²。
- 约束注入 flow-matching 速度场：v̂ = v_θ*(a_τ, τ|oₜ, ℓ) + λₜ∇_aτ R_ρₜ(a_τ, oₜ; sₜ)。
- 采用 sigmoid 衰减调度 λₜ，在接近交互区域时减弱引导，让学到的运动策略主导接触丰富的执行。

### 2.6 多模态阶段完成验证（PACE）
- **Proprioception-And-Completion-driven stagE-switching (PACE)** 使用两类互补证据：
  - **本体感觉证据**：检测动作相关运动模式，并通过符号锁存保留持久事件；
  - **视觉证据**：Qwen3-VL-8B 基于当前阶段和最近至多 5 帧 RGB 图像判断完成情况。
- 完成事件触发条件：最近 w 次查询中至少有 k 次通过（实验中 w=5, k=3），有效抑制孤立错误。

## 3. 实验设计

### 3.1 仿真基准：RoboMemArena
- 使用**修正后的 12 任务协议**，共 **160 个 episode**，覆盖四类记忆能力：
  - **转移（Transferring）**：3 个任务，每个 10 episodes；
  - **计数（Counting）**：3 个任务，每个 10 episodes；
  - **序列执行（Sequence）**：2 个任务，每个 20 episodes；
  - **遮挡（Occlusion）**：4 个任务，每个 15 episodes。
- 修正了可能产生假阳性的成功检查，排除了可通过观测捷径解决或主要由运动技能失败主导的任务。

## 6. 主要结论与发现

### 6.1 仿真主要结果
- 在相同策略权重下，HyMeS 将 **CSR 从 52.5% 提升至 66.2%**，**TSR 从 41.3% 提升至 60.1%**，均优于 π0.5。
- HyMeS 超过 PrediMem **4.5 个 CSR 点**和 **14.5 个 TSR 点**，表明其更有效地将中间进展转化为完整任务成功。
- 最大 TSR 增益出现在**计数**（+30.0）、**转移**（+26.6）和**序列**（+22.5）任务上。
- **遮挡是最难类别**：PrediMem 在遮挡场景低于反应式 π0.5（CSR 38.3% vs. 50.4%），说明不可靠的记忆可能误导执行；HyMeS 在 CSR 上匹配 π0.5（50.6%）并在 TSR 上提升 7.0 点。

### 6.2 真实机器人结果
- 总体 TSR 从 **25.7% 提升至 57.1%**（π0.5 vs. HyMeS）。
- 各任务增益：Observe-and-Pick-Up +50.0 点（2/10→7/10）、Number-Guided Button Pressing +26.7 点（7/15→11/15）、Put-Back Block +20.0 点（0/10→2/10）。

### 6.3 消融结论
- Rollout 启发式学习将 CSR 和 TSR 分别提升 **8.5 和 18.4 点**，验证了执行反馈作为记忆策略学习信号的有效性。
- 单一模态验证均导致性能下降：仅视觉降低 CSR/TSR 16.0/21.7 点，仅本体感觉降低 8.8/8.4 点；**多模态互补证据使阶段转换更可靠**。

### 6.4 其他发现
- 演示预算随**可复用运动技能**数量扩展，而非历史依赖任务配置数量；
- 符号记忆在每一步可读，可精确定位失败源于记忆更新、运动执行还是事件验证。

## 7. 优点

- **创新的混合学习范式**：将运动技能和记忆策略分离到权重空间与代码空间，避免端到端记忆增强所需的大量历史相关演示。
- **数据效率高**：仅需可复用运动技能的演示，新记忆配置通过编辑代码实现，无需重新收集演示。
- **可检查性与可解释性**：符号记忆状态显式可读，失败可精确定位到具体环节（记忆、执行或验证）。
- **双向闭环耦合**：记忆通过约束引导影响动作生成，同时执行反馈（本体感觉 + VLM 视觉）传回更新记忆，优于单向推理时引导方法。
- **策略权重冻结**：记忆能力的获得不依赖任何记忆相关的权重更新，保留预训练策略的原有技能。
- **多模态验证的工程设计**：PACE 利用本体感觉和视觉双证据流 + 多帧投票机制，有效抑制孤立错误。
- **在真实机器人上验证**：不仅限于仿真，还通过 SO-101 物理机器人验证了实际可行性。

## 8. 不足与局限

- **符号状态表示范围有限**：当前方法仅适用于历史可被紧凑符号状态表示的任务；更开放式的指令和更长视野操作需要分层、多模态记忆表示。
- **接触丰富执行仍受限**：正确记忆状态和约束并不保证成功执行。失败分析显示，预抓取位姿的瞄准偏差、抖动造成的额外按压等运动层面问题仍会终结任务。
- **遮挡场景视觉验证可靠性差**：在遮挡条件下，多帧 VLM 完成验证的证据最不可靠，HyMeS 的 TSR 提升有限（平均 47.0%）。
- **推理延迟与成本**：周期性 VLM 查询和编码代理调用增加了每 episode 的推理延迟和计算开销，论文未报告具体成本量化。
- **真实实验样本量小**：SO-101 上仅 35 次试验，Put-Back Block 任务仅有 2 次成功，统计置信度有限。
- **环境敏感性**：真实场景中环境光照变化会降低底层视觉运动策略的鲁棒性，影响整体成功率。
- **算力信息缺失**：未报告 GPU 型号、数量、训练时长等资源消耗，难以评估方法的计算成本可负担性。
