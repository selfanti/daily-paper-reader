## 摘要
长视界工具使用代理必须对用户目标、领域策略、工具调用、模拟器状态以及延迟的可验证奖励进行推理。强化学习（RL）自然适合这种场景，但多轮在线轨迹生成长上下文，而模型特定的注意力层可能需要自定义掩码和学习到的汇点归一化。我们提出了SINKFLEX-RL，一个用于双控制工具使用环境中强化学习的模块化训练系统。该系统结合了兼容Gymnasium的环境封装器、类似VERL的轨迹数据流、无需独立价值模型的组相对策略优化，以及一个感知汇点的FlexAttention路径，旨在在因果和滑动窗口掩码下保持模型特定的汇点缩放。在初步的Tau2Bench零售运行中，验证奖励（mean@1）从训练早期的0.25上升到观察训练窗口后期的0.44，而训练分数和轨迹奖励代理指标也呈上升趋势。在固定配置的内存基准测试中，优化的注意力路径在4096个token时将峰值VRAM从28.06GB降至22.52GB，减少了19.7%，并在8192个token配置下使用25.53GB运行，而急切基线则内存不足。这些结果说明了集成环境接口、RL数据流和注意力内核设计对于内存可行的长视界代理训练的价值。

## Abstract
Long-horizon tool-using agents must reason over user goals, domain policies, tool calls, simulator state, and delayed verifiable rewards. Reinforcement learning (RL) is a natural fit for this setting, but multi-turn on-policy rollouts create long contexts, while model-specific attention layers may require custom masks and learned sink normalization. We present SINKFLEX-RL, a modular training system for RL in dual-control tool-use environments. The system combines a Gymnasium-compatible environment wrapper, a VERL-style rollout dataflow, group-relative policy optimization without a separate value model, and a sink-aware FlexAttention path designed to preserve model-specific sink scaling under causal and sliding-window masks. In a preliminary Tau2Bench retail run, validation reward (mean@1) rises from 0.25 early in training to $0.44$ later in the observed training window, while training-score and trajectory-reward proxies also trend upward. In a fixed-configuration memory benchmark, the optimized attention path reduces peak VRAM from 28.06GB to 22.52GB at 4096 tokens, a $19.7\%$ reduction, and runs the measured 8192-token configuration using $25.53$~GB where the eager baseline runs out of memory. These results illustrate the value of integrating environment interfaces, RL dataflow, and attention-kernel design for memory-feasible long-horizon agent training.

### 一、核心问题与整体含义（研究动机与背景）

- **研究问题**：长视界（long-horizon）工具使用型语言模型代理在交互式环境中执行任务时，需要同时推理用户目标、领域策略（SOP）、工具调用、模拟器状态，并只能从延迟的、程序化可验证的奖励中获取学习信号。强化学习（RL）天然适配此类问题，但存在显著的系统性瓶颈。
- **核心矛盾**：多轮在线策略采样（on-policy rollout）产生极长上下文（如对话轮次、工具调用序列、环境观测），导致注意力机制的显存开销随序列长度呈二次增长；当序列长度达到 8192 token 时，传统 eager 注意力在训练配置下直接内存溢出（OOM）。
- **附加挑战**：生产级大模型（如 MoE 架构）的注意力层可能包含**自定义掩码、滑动窗口限制、学习型 sink（attention sink）参数**等模型特定机制，现成的融合注意力内核（如 FlashAttention）的固定接口无法直接支持这些机制在可微分训练路径中的完整前后向传播。
- **整体定位**：论文将长视界智能体 RL 视为**系统集成问题**，而非单纯算法问题或内核问题，主张环境接口、RL 数据流、注意力内核三者的协同设计是决定训练内存可行性（memory feasibility）的关键。

### 二、方法论：核心思想与关键技术细节

论文提出 **SINKFLEX-RL** 模块化训练系统，包含四个核心组件：

#### 1. Gymnasium 兼容环境包装器
- 将 τ2-Bench 等双控制（dual-control）环境封装为统一的 `reset/step` 接口。
- 在 `step` 时，将模型输出路由到三类处理程序之一：自然语言回复、工具调用或终止信号，随后推进用户模拟器和状态后端。
- 设计目标：将基准特有的用户模拟、工具行为和校验逻辑与训练器解耦，支持未来接入更多可执行环境。

#### 2. VERL 风格 Rollout 数据流
- 采样工作节点（rollout worker）负责完整的智能体循环：格式化观测 → 从当前策略采样 → 解析动作 → 调用环境 → 追加转移至轨迹缓冲区，直至终止或达到最大轮次上限。
- 训练器仅接收 token 级对数概率、动作掩码、轨迹奖励和元数据，不直接依赖基准特有的解析或工具实现。

#### 3. 组相对策略优化（GRPO），无需独立价值模型
- 给定提示 $x$ 和一组 $G$ 条从旧策略采样的轨迹，计算组归一化优势：

$$\hat{A}_i = \frac{R_i - \mu(R_{1:G})}{\sigma(R_{1:G}) + \epsilon_A}$$
- 重要性采样比率为 $\rho_{i,t}(\theta) = \frac{\pi_\theta(y_{i,t}|x, y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t}|x, y_{i,<t})}$。
- 损失为截断的 PPO/GRPO 目标：$J_{i,t}(\theta) = \min\left(\rho_{i,t}(\theta)\hat{A}_i,\ \text{clip}(\rho_{i,t}(\theta), 1-\epsilon_c, 1+\epsilon_c)\hat{A}_i\right)$，并附加 KL 正则项 $\beta D_{KL}(\pi_\theta \| \pi_{ref})$。
- 关键设计：去掉独立的 critic/value 网络，显著降低显存与实际开销（沿用 DeepSeekMath 的记忆驱动动机）。

#### 4. 感知 Sink 的 FlexAttention 路径（核心创新）
- **零值 Sink 等价性**：设 $s_\eta$ 为学习型 sink logit，值向量 $v_{sink}=0$，则显式拼接 sink token 的注意力输出在数学上等价于：
$$O_{sink} = \alpha_{sink} O_{std},\quad \alpha_{sink} = \sigma(\ell - s_\eta)$$
其中 $\ell = \log\sum_i \exp(q\cdot k_i)$ 为 log-sum-exp 统计量。该等价性使系统无需显式物化 sink token，而是通过输出缩放实现同等效果。
- **掩码组合**：$M_{b,h,q,k} = \mathbb{1}[k \leq q] \land \mathbb{1}[q - k \leq w \lor k < p]$，其中 $w$ 为滑动窗口大小，$p$ 为始终可见的前缀位置数。掩码被编译为块稀疏结构，完全掩码的块可跳过计算。
- **梯度传播**：通过链式法则处理数据依赖的 sink 缩放，使梯度经 $\alpha_{sink}$ 和 $\ell$ 正确回传至 Q、K、V 及 sink 参数 $\eta$。使用 `torch.compile` + AOTAutograd 生成前后向代码，避免物化 $O(n^2)$ Jacobian。
- **内存优化**：①使用 `torch.compile`/Inductor 融合逐点算子；②块掩码在 batch 和 head 维度上广播复用，避免重复存储。

### 三、实验设计

#### 实验一：初步零售域策略训练（τ2-Bench）
- **Benchmark**：τ2-Bench 零售领域（dual-control 环境，含用户模拟器、工具 API、领域 SOP 约束）。

### 六、主要结论与发现

1. **策略学习信号有效**：在单次 τ2-Bench 零售运行窗口内，验证奖励（mean@1）从 0.25 提升至 0.44，训练分数和轨迹奖励代理同步上升（0.18 → 0.40/0.39），表明集成管线能接收到有用学习信号。
2. **内存可行性显著改善**：在 4096 token 时峰值显存从 28.06 GB 降至 22.52 GB（-19.7%）；8192 token 时基线 OOM，而优化路径仅用 25.53 GB 完成，消除了长序列训练的内存失败。
3. **核心主张收窄且明确**：环境接口、RL 数据流与注意力内核的集成可以有效改善长视界代理训练的内存可行性；但不宣称算法优越性、广泛泛化能力、精确实现等价性或端到端速度提升。

### 七、优点与亮点

- **系统级集成视角**：将环境封装、RL 数据流、注意力内核三方面整合为统一系统，而非孤立优化某一环节，具有工程实用价值。
- **数学等价性推导精妙**：零值 sink 等价性（$O_{sink} = \sigma(\ell - s_\eta) O_{std}$）避免了显式物化 sink token，同时保持训练路径可微，是简洁且优雅的理论贡献。
- **模型兼容性优先**：通过 FlexAttention 可编程接口保留模型特定的掩码、sink 缩放等语义，而非强制套用固定内核，对生产模型适配有现实意义。
- **诚实且克制的表述**：论文对“初步结果”“无统计显著性”“仅测峰值显存”等限制有明确声明，结论范围界定严谨，不存在过度宣称。

### 八、不足与局限

- **实验覆盖不足**：仅单任务（零售域）单次运行，未在 τ2-Bench 其他域（如航班、银行）、其他模型规模或架构上验证；无消融实验，无法区分各组件（环境包装器、GRPO、FlexAttention、sink 缩放）各自的贡献。
- **数据采集方式粗糙**：训练曲线数据来自仪表盘截图目测估算，非结构化标量导出，影响可复现性和精确性。
- **缺少关键验证**：未提供优化路径与 eager 参考路径的前向/后向数值等价性测试，无法完全排除语义偏差；仅测峰值显存，未测吞吐量、延迟、训练总时间或加速器利用率。
- **无算法对比**：未与 PPO（带 critic）、其他 RL 算法或其他注意力实现进行公平对比，无法说明 GRPO 本身在该任务中的相对优势。
- **外部效度有限**：仅适用于具有程序化可验证奖励的受控环境；对开放域任务需引入奖励模型或人类反馈，通用性未验证。
- **部署安全性未评估**：伦理声明明确指出系统训练出的智能体可调用工具和更新环境状态，需在部署前评估策略合规性、用户欺骗、不安全工具使用、隐私泄露和模拟器过拟合等风险，当前仅验证系统可行性。
- **长上下文声称受限**：当前评估止于 8192 token，论文承认更长目标工作负载虽构成设计动机，但未在实验中覆盖。
