## 摘要
尽管记忆在大模型智能体中广泛部署，但关于什么是记忆或何时最优，尚未有统一的形式化解释。本文朝这一目标迈出第一步。核心思想是：记忆是基，知识是它的张成，可回答性是一个覆盖问题：智能体存储从材料中提取的事件；一个生成算子将任何事件集转化为其蕴含的知识；当且仅当张成中的某个单个条目覆盖查询时，该查询可回答。然后，最优记忆是容量受限下期望覆盖的最大化器，其价值沿着效用-容量前沿曲线变化，这是可比较记忆系统的共同尺度。接下来，我们考虑记忆中的噪声，并讨论在噪声下覆盖与精确度的问题：记忆可能存储虚假声明，因此写入策略必须推断其存储内容的真实性。借鉴生物记忆的类比，生物记忆通过持续的经历不断形成，我们在一个覆盖多个级别的序列MDP中形式化了持续智能体记忆问题，其中记忆是状态，写入是动作，查询时结算的效用是驱动学习的延迟奖励。为了使框架具体化，我们在荷马的《奥德赛》上实例化它，将前沿、压缩区域以及覆盖与精确度的偏差转化为具体数字。最后，我们将现有系统置于框架内，使“记忆有多好”变得可衡量，并将构建和学习智能体记忆的开放问题重新表述为具体的研究问题。

## Abstract
Despite the wide deployment of memory in large-model agents, there is no unified formal account of what a memory is or when it is optimal. This paper takes a first step toward this account. The central idea is that memory is a basis, knowledge is its span, and answerability is a coverage problem: an agent stores events extracted from a material; a generation operator turns any event set into the knowledge it entails; and a query is answerable exactly when some single item in the span covers it. The optimal memory is then the capacity-constrained maximizer of expected coverage, and its value traces a utility--capacity frontier, the common yardstick on which memory systems can be compared. Next, we consider noise in the memory and discuss coverage versus precision under it: a memory may store false claims, so the write policy must infer the truth of what it stores. Drawing an analogy with biological memory, which is formed continuously through ongoing experience, we formalize the continual agent-memory problem in a sequential MDP that covers multiple levels, where memory is the state, writing is the action, and the utility settled at query time is the delayed reward that drives learning. To make the framework concrete, we instantiate it on Homer's \emph{Odyssey}, turning the frontier, the compression zone, and the divergence of coverage from precision into concrete numbers. Finally, we position existing systems within the framework, making ``how good is a memory'' measurable and recasting the open problems of constructing and learning agent memory as concrete research questions.

### 2. 论文提出的方法论

**核心思想：记忆是基（basis），知识是张成（span），可回答性是覆盖（coverage）问题。**

- **事件与材料（Definition 2.1）**：事件 e 是关于材料的原子陈述（事实、偏好、规则、反思），材料 D 是长信息源，E_D 是材料包含的事件集。
- **知识与生成算子（Definition 2.2）**：生成算子 Φ: 2^E → 2^N 将事件集映射为其蕴含的知识集；单个事件是退化的知识项（E ⊂ N）。
- **记忆定义（Definition 2.3）**：记忆 M_D ⊆ E_D，是材料事件的子集（基）；张成 R_MD = Φ(M_D) 是智能体实际可调用的知识。
- **可回答性与覆盖效用（Definitions 2.4–2.6）**：知识项 n 的回答集 Q(n) = {q : ans(n,q)=1}；**单条目支持假设（Assumption 2.1）**——每个查询由单个知识条目回答，推理组合被推入生成算子 Φ。覆盖效用 u(q, M_D) = 1[q ∈ ∪_{n∈Φ(M_D)} Q(n)]，期望效用即随机查询被记忆张成覆盖的概率。
- **最优记忆与效用-容量前沿（Definitions 3.1）**：容量约束 S 下的最优记忆 M*_D(S) = argmax E[u(q, M_D)]，前沿 U*_D(S) 为最优期望覆盖。前沿在 S ≥ |E_D| 时饱和于全上下文基线，压缩区（compression zone）是记忆真正起作用的区间。
- **复杂度刻画（Proposition 3.3）**：
  - 当 Φ **可分解**时，问题归约为加权最大覆盖（NP-hard），贪心算法有经典的 (1 − 1/e) 近似保证。
  - 当 Φ **不可分解**（存在跨事件协同）时，目标是单调集合函数但未必子模（Remark C.2 构造了边际收益增长的例子），贪心保证失效。
- **噪声记忆（Section 4）**：区分声明（claims，候选事件，可能为假）与事件（真声明），好张成 R_good = Φ(M_D ∩ E_D)；定义精确度效用 u_prec；**水膨胀度（water-inflation degree）** Δ(π) = E[u_cov − u_prec] 度量报告质量中有多少来自虚假声明。
- **渐进式问题设置分类（Section 5.1，Table 1）**：
  - Level 0：单材料单查询（一次压缩/检索，退化情况）
  - Level 1a：单材料多查询，p_D 已知（一次性最优记忆）
  - Level 1b：单材料多查询，p_D 未知（顺序写入，逐步逼近 M*_D(S)）
  - Level 2：多材料多查询（可迁移写入规则 π）
- **序列记忆 MDP（Definition 5.2）**：记忆 M_{m,t} 是状态，写入动作 π_write(M_{m,t}, D_m, q_{m,t}, a_{m,t}) 更新记忆，查询时结算的效用 u(q_{m,t}, M_{m,t}) 是延迟奖励；每次 episode 抽取新材料 D_m ~ p(D)。这暴露了信用分配（credit assignment）与探索-利用权衡（trust estimation）两个核心学习难题。
- **代理级记忆目标（Definition 5.1）**：π* = argmax E_{D~p(D)}[Σ_{t=1}^{T_D} E_{q_t~p_D} u(q_t, π(D))]，即学习一个跨材料泛化的可迁移写入规则。

### 6. 论文的主要结论与发现

- **记忆的形式化定义**：记忆是材料事件的子集（基），其张成（生成算子产生的知识）是智能体实际可调用的内容。
- **最优记忆与共同尺度**：最优记忆是容量约束下最大化期望覆盖的记忆，其值沿效用-容量前沿变化；前沿饱和于全上下文基线，界定压缩区，为所有记忆系统提供统一比较标尺（size–utility 平面上的点，前沿下方差距即策略损失）。
- **复杂度结论**：可分解生成算子下最优记忆是加权最大覆盖（NP-hard，贪心 (1−1/e) 近似）；跨事件协同使目标失去子模性，贪心保证失效——"协同正是击败贪心论证的东西"。
- **噪声下的覆盖与精确度分离**：水膨胀度 Δ(π) 量化虚假声明对报告质量的贡献；优化 u_cov 的策略继承膨胀；写入策略必须从查询结算信号中推断声明真实性 τ，形成信用分配问题。
- **记忆写入是学习问题**：查询分布未知使写入必须顺序学习，序列 MDP 将记忆作为状态、写入作为动作、查询结算作为延迟奖励，统一了 Level 1 和 Level 2 的设置。
- **现有系统定位**：领域内方法的主要差异在于生成、写入、读取、推理组件的选择；框架使异构系统可比较。

### 7. 优点

- **填补空白**：首次为智能体记忆提供统一形式化定义，使"记忆是什么"、"什么是最优记忆"从模糊的日常用语变成精确定义的数学对象。
- **简洁优美的核心隐喻**："记忆是基、知识是张成、可回答性是覆盖"将记忆问题与经典数学结构（线性代数中的基/张成）和经典优化问题（最大覆盖、集合函数最大化）连接起来，概念传达极具解释力。
- **分析深度**：对复杂度有细致刻画——可分解 vs 非可分解、子模 vs 非子模的区分给出了问题的精确困难边界；前沿饱和命题（Proposition 3.2）和全上下文基线提供了实证锚点。
- **噪声处理**：覆盖/精确度分离和水膨胀度概念抓住了 LLM 记忆实践中"幻觉虚高"的真实痛点。
- **统一视角**：将分散的记忆系统（图、树、分层页面、参数记忆）和评测设置（长上下文、多会话、跨任务）整合进单一框架，并用 MDP 把写入问题转化为可学习问题。
- **诚实与严谨**：论文明确承认假设（单调性、单条目支持）的近似性及其实践中的失败模式（冲突注入导致非单调），不回避局限。

### 8. 不足与局限

- **单条目支持假设**：排除回答时推理（answer-time reasoning），所有组合推理必须预先物化在 Φ 中；真实智能体常需联合多个条目回答问题，这类场景在框架外。
- **覆盖 ≠ 正确性**：框架优化的是信息可用性而非回答正确性；当推理器（reasoner)不可靠或被误导性记忆引导时，覆盖与端到端质量会发散，框架结果不适用。
- **对生成算子的假设仅近似成立**：单调性假设在真实 LLM 提取中最多局部成立；可分解性是特殊情形；框架记录了这些失败模式但未解决。
- **表示无关的局限**：容量以事件数 |M_D| ≤ S 计数，但真实记忆付出的是 token 或存储代价，与表示相关的权衡（如压缩或参数记忆的动机）被搁置。
- **缺乏实证验证**：只有一个手工实例，没有在真实数据上验证前沿的可计算性、贪心策略的实际损失、或水膨胀度在现有系统中的测量；"记忆增强系统相比全上下文节省 90% token"等证据是引用的外部研究而非本文实验。
- **前沿计算的可行性未知**：对真实规模的 p_D 和 Φ，U*_D(S) 本身可能计算不可行（NP-hard），论文未讨论估计前沿的算法策略。
- **应用范围有限**：框架主要面向"从材料中提取事件"的显式符号记忆，对参数化记忆（MemoryLLM、Titans 等）仅承认其存在于框架之外，未深入整合。
