## 摘要
具身智能体越来越多地被用来弥补端到端策略模型留下的差距。然而，智能体路径尚未在物理执行中实现闭环学习：现有框架在很大程度上仍然是开环的，在执行过程中遵循固定技能，并且只在回合结束后进行反思。这种事后反思无法在执行进行时控制执行，因为物理交互需要决策以超出当今大型智能体模型所能达到的频率来跟踪快速变化的机器人-环境状态。我们提出了Zetta，一种闭环具身框架，它在线演化基于代码的运行时评论者和恢复技能，同时保持基础策略冻结。通过三个时间尺度分离的循环，Zetta提供了动作频率治理、执行级评论者-恢复建议以及验证门控的技能更新。与Z-Infra（一种将智能体逻辑与异构执行资源解耦的执行基础设施）一起，Zetta在我们当前的执行预算下，在LIBERO-Pro和RoboCasa上取得了最先进的成功，达到90.8%和93.6%，推理速度提升11.1倍；成功随着自我探索经验持续扩展；学到的技能零样本迁移，并且出现了清晰的机器人“顿悟时刻”。这些结果表明，闭环框架的自进化为可靠的物理智能开辟了一条扩展路径。

## Abstract
Embodied agents are increasingly used to close the gap left by end-to-end policy models. Yet the agentic path has not realized closed-loop learning in physical execution: existing harnesses remain largely open-loop, following fixed skills during rollout and reflecting only after an episode completes. Such post-hoc reflection cannot govern execution as it unfolds, because physical interaction requires decisions to track rapidly changing robot-environment states at a frequency beyond today's large agentic models. We present Zetta, a closed-loop embodied harness that evolves code-based runtime critics and recovery skills online while keeping the base policy frozen. Through three timescale-separated loops, Zetta provides action-frequency governance, rollout-level critic-recovery proposal, and validation-gated skill updates. Together with Z-Infra, a rollout infrastructure decoupling agent logic from heterogeneous execution resources, Zetta achieves state-of-the-art success on LIBERO-Pro and RoboCasa under our current rollout budget, reaching 90.8% and 93.6%, with an 11.1x inference speedup; success continues to scale with self-exploration experience; learned skills transfer zero-shot, and clear robotic "Aha Moments" emerge. These results show that closed-loop harness self-evolution opens a scaling path for reliable physical intelligence.

## 1. 核心问题与研究动机

### 1.1 背景
- 物理智能（Physical Intelligence）的发展有两条路径：
  1. **端到端策略模型**：如 VLA（Vision-Language-Action）和 WAM（World-Action Model），依赖大规模演示数据训练；但物理数据稀缺、部署分布变化大、小错误在长程任务中会级联放大，距离真实世界可靠执行仍有差距。
  2. **具身智能体（Embodied Agent）路径**：利用大语言模型编排策略模型、代码、工具和控制原语，试图通过环境的自我探索实现学习。
- 然而，现有具身智能体**harness（框架/鞍具）大多是开环的**：执行一旦开始，智能体不会根据持续变化的机器人-环境状态实时调整决策，而是遵循固定技能或预规划轨迹，只在回合结束后进行反思。

### 1.2 核心问题
- **物理交互需要毫秒级决策**，而大型智能体模型（LLM 级）无法在此频率上实时推理。
- 现有的**事后反思（post-hoc reflection）**存在固有缺陷：
  - 无法在执行中实时验证反思是否正确；
  - 对整条轨迹的信用分配困难；
  - 事后分析缺乏故障时刻的精确状态；
  - 总结出的经验难以复用，也难以适应真实世界动态变化。
- 核心问题因此是：**如何构建一个能在执行中实时治理物理过程、同时从失败中持续自我进化的闭环具身框架？**

## 2. 方法论

### 2.1 核心思想
- **在保持基础策略模型完全冻结（∇θ = 0）的前提下，在线演化一个可学习的 harness**：
  - **H = {C, R, T}**：
    - **C（Runtime Critic）**：高频监测函数，扫描轨迹并生成结构化证据提案 P_t = ⟨e_t, σ̂_t⟩（e_t 为可审计失败证据，σ̂_t 为建议执行模式）；
    - **R（Recovery Playbook）**：针对不同因果失败机制的结构化恢复策略库；
    - **T（Heterogeneous Toolset）**：可执行工具集合（如规划器、抓取检测器、恢复模块），可在演化中被生成、实例化、选择与精炼。
- 设计双智能体治理架构：

  - **离线演化智能体（A_evo）**：分析失败数据，生成候选修补，迭代更新 H。

### 2.2 三时间尺度闭环（三个循环）
1. **批评者治理的动作循环（Loop 1）**：以动作频率执行已学习的 critic，必要时调用相应恢复技能，实现闭环执行；
2. **Rollout 批量候选优化循环（Loop 2）**：对每次迭代的失败轨迹进行聚类与因果诊断，提出候选 critic 和恢复策略；借鉴 SkillOpt/EmbodiSkill 的思路，在代码空间中做有界、稳定的类似 SGD 的更新；
3. **验证门控的技能更新循环（Loop 3）**：只接纳能提升成功率且能在 rollout 间泛化的候选，随后加入技能记忆库。

### 2.3 演化流程三阶段

## 6. 主要结论与发现

1. **闭环 harness 自进化是可行的扩展路径**：在基座策略完全冻结的情况下，Zetta 在 LIBERO-Pro 达到 90.8%（宏观平均），RoboCasa 达到 93.6%，显著超过纯 VLA 基线。
2. **成功率随演化迭代持续提升**：LIBERO-Pro Goal-T 31.0% → 92.5%，Goal-S 38.0% → 89.0%；RoboCasa 18 任务宏观平均 73.56% → 93.56%（+20.00 个百分点）。
3. **技能可零样本迁移**：PnP-Stove 演化出的预抓取、重抓取、稳定放置技能迁移到 PnP-Sink/Cabinet/Toaster，宏观平均 64% → 84%；TurnOffStove 技能迁移到开关类任务，64% → 80%。
4. **存在“Aha 时刻”**：早期修复停滞（如 10% → 15%），一旦识别关键物理瓶颈（如抓取保持、末端对齐），成功率突跳（如 15% → 95%，5% → 90%），表明智能体获得了可复用的具身智能而非任务特定的轨迹调整。
5. **基础设施增益显著**：Z-Infra 使吞吐量从 1.7 提升到 35.1 episodes/min（20.6×）；推理延迟相对于 RPent 降低 91%（11.1× 加速）。
6. Zetta 在每个任务-设置对上均不差于基线（32 个提升、8 个持平），无需额外 VLA 训练。

## 7. 优点

- **问题定义清晰**：明确指出现有 harness 的开环缺陷，并给出形式化定义（H = {C, R, T}、三循环、权威层级）。
- **最小干预原则**：自上而下分层诊断保证修补作用于最小有效层，避免过度参数化修补破坏 VLA 的语义泛化。
- **工程基础设施创新**：Z-Infra 将智能体逻辑与异构资源解耦，用环境/模型工作器池、批处理推理、模型分片与量化解决了具身 rollout 的资源异构与执行动态性两大难题。
- **验证协议严格**：历史回归 + 严格隔离的 held-out 评估 + 数据隔离再分类策略，防止过拟合与数据泄露。
- **实验叙事完整**：从最终精度、缩放曲线、零样本迁移、Aha 分析到系统性能，多层次验证闭环演化的价值。
- **优雅处理频率鸿沟**：用代码级 critic 在动作频率治理、用 LLM 在离线离线频率反思，巧妙地绕开大模型无法实时推理的限制。

## 8. 不足与局限

- **缺乏真实世界验证**：全部实验在仿真中进行；从仿真到真实的 gap 是公认的核心挑战，论文也将其列为未来工作（“sim-to-real gap”）。
- **演化成本未量化**：未报告每轮演化所需的计算资源、时间与 token 成本；作为“自进化”系统，离线 A_evo 的 LLM 调用开销被刻意省略（仅在在线 rollouts 中强调低延迟）。
- **依赖任务语义知识**：milestone（μ₁…μ_goal

#（续）

…）的定义需要研究者手工指定，无法自动生成，限制了系统的全自动扩展能力。论文声称“自我进化”，但进化的方向与里程碑定义仍依赖于人工任务分解知识，并非完全自主。

- **方法在代码空间中演化**：虽然避免了直接修改 VLA 权重以保持语义稳定，但批评者与恢复策略均以代码形式演化；这意味着演化后的 harness 在跨环境迁移时需要重新适配，代码修补的抽象层级难以自动跨任务复用。此外，对代码空间做“类似 SGD 的更新”本质上是一种有针对性的程序搜索，其搜索空间与收敛性缺乏理论保证。

- **系统复杂度高**：双智能体架构（A_orch + A_evo）、分层因果诊断、critic 治理、VLA 重入合约、异构 rollout 基础设施等多组件协同工作，复现门槛较高。论文未提供各组件间接口的足够细节，也未发布代码或检查点（截至论文发表状态不明确），第三方难以独立验证。

- **基线对比有限**：虽然对比了纯 VLA 基线和 RPent，但未与同期的其他自进化具身框架在同一任务套件上做直接比较（如 ENPIRE、ASPIRE、EmbodiSkill 等）。由于各方法使用不同的基座策略、任务与评估协议，跨论文对比的结论仍不够稳健。

- **概率性成功率的方差问题**：论文用平均成功率作为主要指标，但某些任务在 50 个种子上可能呈现高方差（如 LIBERO 最终评估仅 20 个种子），论文未报告逐任务置信区间或方差，可能高估某些“Aha”突破的显著性。

- **无负面结果讨论**：论文没有报告任何失败案例或演化未能改善的任务；对“为什么某些任务只需要 8 个回合持平”以及“哪些任务类型不适合该框架”缺乏系统分析。

## 9. 潜在改进方向

- **真实机器人验证**：将 Zetta 迁移到真实机械臂操作平台，验证 harness 在真实物理引擎、感知噪声与执行误差下的鲁棒性与重入合约的可靠性。
- **自动里程碑生成**：利用 VLM 或 LLM 从任务描述中自动推断里程碑序列，减少手工任务分解依赖，推动全自动自我进化。
- **跨环境泛化机制**：研究如何将演化出的 critic 与 playbook 以跨仿真器、跨机器人的可移植形式表达（如技能库 + 适配器），并用元学习或检索增强在部署时快速适配。
- **理论分析**：对代码空间演化的收敛性、验证门控的置信度、以及历史回归对分布偏移的敏感度给出理论或半理论分析，增强方法可信度。
- **更系统的基线对比**：在同一基座策略、同一任务集上对比 ENPIRE、ASPIRE 等自进化框架，明确 Zetta 的边际贡献。
- **成本-收益分析**：量化每轮演化所需的 GPU 小时、LLM token 数以及 human-in-the-loop 时间，给出自进化方法相对于纯数据/训练方法的帕累托前沿。

## 10. 总体评价

Zetta 提出了一种**务实的混合架构**——不试图让大模型实时推理，也不试图更新 VLA 权重，而是通过一个**可演化的环境-critical 治理层**将 VLA 的鲁棒感知/操作与 LLM 的长程推理无缝衔接。该方案在仿真基准上取得了显著且一致的成功率提升，并且用严格隔离的评估协议证明了演化收获的可泛化性。其核心贡献在于将“事后反思”升级为“执行中治理 + 离线结构化演化”的双闭环范式，并将这一范式落实为完整的工程系统（Z-Infra）。

尽管在真实世界验证、基线丰富度、演化成本透明度和完全自主性方面仍存在明显不足，但 Zetta 为具身智能体如何从“推理者”进化为“自进化执行者”提供了一个清晰且可复现的路线图。尤其值得肯定的是，它严格坚持了**基座模型冻结**的原则，将自我进化置于外部的代码/技能空间，这与当前大模型时代“不轻易改动模型权重、通过外部工具与环境交互实现能力扩展”的主流趋势高度契合。

**一句话总结**：Zetta 是一个在仿真中已被验证有效的闭环自进化具身框架，它通过批评者治理、恢复手册与异构工具集的在线演化，在不更新 VLA 权重的前提下实现了显著的成功率提升，但距离真实世界的自主进化和完全无监督的自适应仍有相当距离。
