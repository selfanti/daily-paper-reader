## 摘要
从经验中学习对于开发能力强大、自我改进的大型语言模型（LLM）智能体至关重要。现有方法通常通过反思、记忆、规则或技能从累积的轨迹中提取知识。然而，现实环境中的智能体不断遇到新任务，往往只有一次改进机会。这些执行过程产生丰富但高度嘈杂的上下文，将广泛有用的经验与特定任务的细节纠缠在一起。关键的是，先前的工作很少在复杂的现实世界任务上验证其有效性，或隔离改进的根本驱动因素。为解决这些空白，我们形式化了在线工具集学习，其中冻结的智能体通过跨顺序任务持续更新结构化工具集来改进。这一形式化使我们能够通过所提出的Evo-Harness系统地研究关键的自我改进因素。其核心是上下文到工具集技能编译，将嘈杂的单次执行提炼为可复用的技能工具集，用于跨领域和主题级适应。为了证明单次技能编译的有效性，我们在五个现实基准（TerminalBench2、SWE-bench、CL-Bench、-bench、WebArena-Infinity）上进行了评估。我们广泛的分析证明了Evo-Harness的有效性，并提供了对LLM智能体如何有效即时学习的原理性理解。我们的代码可在https://github.com/A-EVO-Lab/a-evolve/tree/release/evo-harness获取。

## Abstract
Learning from experience is critical for developing capable, self-improving large language model (LLM) agents. Existing methods typically extract knowledge from accumulated trajectories via reflection, memory, rules, or skills. However, agents in realistic environments continuously encounter novel tasks, often offering only a one-shot opportunity to improve. These executions yield rich but highly noisy contexts, entangling broadly useful lessons with task-specific artifacts. Critically, prior works rarely validate their effectiveness on complex real-world tasks or isolate the underlying drivers of improvement. To address these gaps, we formulate online harness learning, where a frozen agent improves by continually updating a structured harness across sequential tasks. This formulation enables a systematic study of key self-improvement factors through our proposed Evo-Harness. At its core, context-to-harness skill compilation distills noisy, single-shot executions into reusable skill harnesses for cross-domain and topic-level adaptation. To demonstrate the efficacy of one-shot skill compilation, we evaluate across five realistic benchmarks (TerminalBench2, SWE-bench, CL-Bench, -bench, WebArena-Infinity). Our extensive analysis demonstrates the effectiveness of Evo-Harness and provides a principled understanding of how LLM agents can effectively learn on the fly. Our code is available at https://github.com/A-EVO-Lab/a-evolve/tree/release/evo-harness.

## 1. 论文的核心问题与整体含义

LLM 智能体在现实环境中会持续遇到新任务，每次执行通常只有一次性的改进机会，而执行过程产生的上下文噪音极高——有用的经验与任务特定细节、部分失败、工具痕迹纠缠在一起。现有经验学习方法（反思、记忆、规则、技能）主要依靠累积轨迹进行离线学习，在真实在线单次任务流中面临三大挑战：

- **噪声大**：真实执行上下文混杂任务特定伪影，难以直接提炼可复用知识；
- **单次机会**：每个任务通常只执行一次，没有多次试错/离线重放的机会；
- **验证不足**：现有方法很少在复杂真实任务上系统验证有效性，也未隔离改进的根本驱动因素。

为此，论文形式化定义了**在线 harness 学习**：一个冻结（参数不更新）的智能体，通过持续更新一个结构化的外部可复用指南（harness，论文中实例化为技能集合），在顺序到达的任务流上实现自我改进。核心问题是：**如何将单次、有噪声的执行上下文编译为对未来任务有指导意义的技能指南？**

整体意义在于：将自进化智能体研究从聚合成功率比较，推向对"智能体如何产出、组织、迁移和应用可复用经验"的机制性理解。

## 2. 论文提出的方法论

### 2.1 核心思想：上下文到harness技能编译
Evo-Harness 将执行上下文（输入、动作轨迹、结果、反馈）通过**反思（Reflection）**与**进化（Evolution）**两阶段，编译为结构化的技能 harness，在后续任务执行前被检索注入到 solver 上下文中，从而引导规划、行动、验证和恢复。

### 2.2 形式化框架（在线任务批次流）

- 维护外部 harness H_i（结构化指南条目集合），不修改 solver 参数；
- 对每个任务，从 harness 中检索有限条目的子集 S_{i,j}（预算为 b），注入任务上下文后由冻结 solver执行；
- 执行失败或负反馈时，solver 对执行上下文进行反思，产出候选记忆：r = (lesson, trigger, evidence, scope_hint)；
- evolver 接收候选记忆与当前 harness，执行 ADD / MERGE / REVISE / SKIP 操作，更新 harness。

### 2.3 两级技能设计

- **跨任务模式（Cross-task patterns）**：跨多个任务比较提取共享的操作结构，适合可迁移的一般性指导；
- **任务类型程序（Task-type procedures）**：保留针对特定任务格式、接口或领域的局部操作知识，在任务内部形成局部手册。

### 2.4 算法流程（文字描述）

1. 对每个批次，当前 harness 检索注入后由 solver执行任务；
2. 对每个失败/负反馈的执行，通过 Reflect 生成候选记忆；
3. 批次结束后，分别调用 CompileTaskType（任务类型级编译）与 CompileCrossTask（跨任务级编译）；
4. 将编辑结果合并回更新后的 harness。单任务批次（|B_i|=1）退化为纯任务类型更新，模块化设计便于系统研究各组件贡献。

## 6. 论文的主要结论与发现

1. **Evo-Harness 在所有五个基准上一致优于 No-Evolve 与所有经验/记忆/技能基线**（例如 CL-Bench 34.02 vs 最强基线 XSkill 31.44；TerminalBench-2 73.03 vs 66.29），验证了在线技能编译的有效性；
2. **外部经验复用并非自动有益**：多个基线在某些基准上低于 No-Evolve，说明检索或进化的指导可能噪音过大、过于具体或与 solver 不匹配；
3. **通用与主题技能的作用因任务而异**：CL-Bench（异构推理）偏重主题/任务类型技能（Topic Only 33.70 vs General Only 30.28）；SWE-bench（仓库级调试）更依赖通用技能（General Only 66.67 vs Topic Only 64.33）；两者互补，完整方法最优；
4. **跨模型与跨任务迁移可行**：由 Claude Sonnet 在训练集上进化的技能，迁移到 Opus 4.7 测试集上仍带来显著提升（68.8→73.4）；在线更新进一步优于纯迁移（75.0）；
5. **solver 能力决定了进化收益**：对于能力强的 Opus solver，跨模型进化甚至优于同模型进化（Cross 76.0 > Same 75.3）；但对于能力较弱的 Sonnet solver，进化反而带来退化（55.3/55.7 < No-Evolve 58.0），说明技能收益依赖于 solver 能否理解并遵循指导；
6. **反馈的grounding（客观锚定）至关重要**：LLM 自生成反馈在 CL-Bench 和 SWE-bench 上均低于 No-Evolve（29.54→27.96；63.67→61.67），说明无外部证据支持的自评会引入误导性更新；使用环境信号的 Minimal/Standard 反馈可靠得多。在 CL-Bench 上标准（详细诊断）反馈更优，在 SWE-bench 上极简（通过/失败）反馈反而略好——过细的错误信息可能使 harness 过度拟合特定失败。
