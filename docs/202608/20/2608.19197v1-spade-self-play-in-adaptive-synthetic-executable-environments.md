## 摘要
持续自我改进需要不断扩展的、自生成的、多样化的自适应目标池。对于语言代理而言，现有的训练环境池（手工策划、静态合成或冻结验证器）在学习者扩展时保持目标分布固定。我们提出SPADE（自适应合成可执行环境中的自博弈），一个自博弈强化学习框架，其中单个LLM扮演两个角色：一个环境设计器，负责编写完整的、长视界训练环境，以可执行代码的形式，带有OpenAI Gym风格的reset()/step()接口；以及一个推理代理，学习在这些环境中行动。每个环境都是状态化的多轮环境（包含状态转移、奖励函数和验证代码），因此一个接口即可涵盖推理问题和多步骤智能体工具使用。推理代理的遗憾通过其在有/无特权提示下的奖励差距来估计；在优化这一遗憾信号时，环境设计器学会将环境定位在代理能力的边缘，同时保持其可行性。通过大量实验，我们发现了几个对成功至关重要的组件：将环境设计器基于从大型预训练语料库中采样的文档，并为其提供累积的环境记忆。将规模扩展到300亿参数的模型，SPADE在八个保留的数学、科学、代码和推理基准上平均比最强的固定环境基线提高+5.3，在BFCL-v4多轮上将工具使用设置提升+5.7，在ACEBench-Agent上提升+13.9；在游戏设置中，相对于最强基线的优势随模型规模增长。通过使环境设计本身成为可学习组件，SPADE向开放式自我改进迈出了坚实的一步。

## Abstract
Continuous self-improvement requires an ever-expanding pool of self-generated, diverse, adaptive goals. For language agents, existing training environment pools (hand-curated, statically synthesized, or frozen-verifier) keep the goal distribution fixed as the learner scales. We introduce SPADE (Self-Play in Adaptive Synthetic Executable Environments), a self-play RL framework in which a single LLM plays two roles: an Environment Designer that writes complete, long-horizon training environments as executable code with an OpenAI Gym-style reset()/step() interface, and a Reasoning Agent that learns to act in them. Each is a stateful, multi-turn environment (state transitions, reward functions, and verification code), so one interface spans reasoning problems and multi-step agentic tool use. The Reasoning Agent's regret is estimated using the gap between its reward with and without privileged hints; in optimizing this regret signal the Environment Designer learns to target environments at the edge of the agent's capabilities while keeping them feasible. Through extensive experimentation, we find several components critical to success: grounding the Environment Designer on documents sampled from a large pretraining corpus, and giving it an accumulated environment memory. Scaling to 30B-parameter models, SPADE improves over the strongest fixed-environment baseline by +5.3 on average across eight held-out math, science, code, and reasoning benchmarks, and lifts the tool-use setting by +5.7 on BFCL-v4 multi-turn and +13.9 on ACEBench-Agent; on the games setting, the margin over the strongest baseline grows with model scale. By making environment design itself a learnable component, SPADE takes a concrete step toward open-ended self-improvement.

## 1. 论文的核心问题与整体含义

**研究动机：** 智能体 AI 的能力提升越来越依赖"从经验中学习"（interacting with environments and rewards），而非仅靠预训练。然而，高质量人类文本是有限资源，训练环境的供给成为智能体进步的瓶颈。

**核心问题：** 现有的训练环境池（人工策划、静态合成、或使用冻结验证器）在智能体能力提升时，目标分布保持固定不变化。智能体一旦穷尽该环境池，进步便会停滞。这阻碍了持续自我改进（open-ended self-improvement）的实现。

**SPADE 的整体含义：** 提出了一个自博弈强化学习框架，让同一个 LLM 同时扮演两个角色：
- **环境设计器（Environment Designer）**：编写完整的、长视界的可执行训练环境（Python 代码，Gym 风格的 `reset()`/`step()` 接口）；
- **推理代理（Reasoning Agent）**：在这些生成的环境中学习行动。

该设计使环境分布能够随智能体能力提升而共同演化，环境设计本身成为可学习的组件，为开放式自我改进提供了具体路径。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想：双角色自博弈 + 代码即环境

- 单个 LLM `πθ` 通过角色特定系统提示（`role=D` 与 `role=A`）在两个角色间切换。
- **代码即环境的表示方式**：每个环境都是一个完整的 MDP，以 Python 类实现 Gym 风格接口，统一了单回合推理问题（一步到终端奖励）和多回合智能体任务（顺序交互与转移动力学）。
- 因为任何可计算的 MDP 都可以用程序表达，环境设计器可以在无界环境空间中生成环境，而非受限于手工设计参数化空间。

### 2.2 基于 Hint 的遗憾奖励（Hint-Based Regret Reward）

- 环境设计器为每个环境生成一个特权提示（hint）h（例如部分解决方案草图或关键结构观察）。
- 设计器的奖励定义为：

\[
r_D(e) = \bar{r}_A(e|h) - \bar{r}_A(e)
\]

即体验器在有/无提示两种情况下的平均收益差距。三种情形：
- **高遗憾**：有提示可解、无提示不可解 → 处于学习前沿的环境；
- **低遗憾（两臂都成功）**：已掌握的环境；
- **低遗憾（有提示也失败）**：不可解的环境。

这实现了 PAIRED 的 minimax regret 目标，无需单独的反方（antagonist）。附录 B 中证明了在理想化假设下，纯纳什均衡时每个有效环境上的无提示最优性成立。

### 2.3 语料库接地（Corpus Grounding）与环境记忆（Environment Memory）

- **语料库接地**：每轮环境设计器条件下，采样自大型预训练语料库（游戏设置：10k 数学 + 5k 科学文档，来自 DCLM 和 MegaScience；工具使用设置：15k 代码文档，来自 Nemotron 预训练代码语料）。防止生成器 mode collapse（"隐形皮带"效应）。
- **环境记忆**：保留之前生成的环境缓冲区，附有遗憾分数和技能标签，防止环境设计器重新提出已掌握的环境，并作为高遗憾种子。

### 2.4 稳定双角色联合训练

- 按角色独立标准化优势（advantage）；
- 对较少出现的环境设计器轨迹进行上采样；
- **延迟设计器更新** k 个 rollout，并使用截断重要性采样（truncated importance sampling）修正离策略梯度；
- 不对称裁剪范围（ε_low=0.2, ε_high=0.28）；
- 环境设计器奖励为**下限为零的遗憾**（权重 0.4）与**平坦顶部难度锚**（权重 0.6，目标胜率带 [0.4, 0.6]）的混合。

## 6. 主要结论与发现

1. **游戏设置**：SPADE 在 30B-A3B 上将八个基准套件的平均值从基础模型的 50.2 提升至 58.3（+8.1），超过最强固定环境基线（Fixed-env RLVE）5.3 个点，且收益在静态分布饱和后仍保持。
2. **工具使用设置**：在 30B-A3B 上 ACEBench-Agent +13.9、BFCL v4 multi-turn +5.7（4B 时 +10.3），且在该两个基准上超越了专用数据合成系统。
3. **规模效应**：SPADE 的增益随模型规模增长（4B +5.2 → 8B +5.7 → 30B-A3B +8.1），而 Fixed-env GRPO 在各规模下均停留在约 +1.2。
4. **课程多样性**：6 技能课程比 2 技能课程带来更大收益（58.3 vs 53.7），说明课程广度驱动增益。
5. **语料库接地的作用**：Vendi/ n 多样性分数从 0.68（全配置）降至 0.04（无语料库），证明语料库接地是多样性的关键来源；无语料库运行时 41 次连续生成同一迷宫任务。
6. **环境设计器训练的作用**：随着训练推进，设计器生成的环境在代码层面变得更难——物理环境中在开场中给出公式的比例从 25% 降至 5%，奖励粒度从 3.7 级提高到 5.8 级。
7. **推理代理行为演化**：从"前置推导"（step 0）→"假设-测试-修正"（step 200）→"先收集证据再推导"（step 300），且保持长格式推导能力。
8. **消融结论**：完全自适应配置优于所有部分与冻结设计器控制；冻结自博弈设计器 + 移除记忆会使模型低于未训练基线（40.5 vs 50.2）。

## 7. 优点

1. **新颖的框架设计**：首次将环境设计本身作为 RL 训练的可学习组件引入 LLM 后期训练，实现环境与智能体共同演化（co-evolution）。
2. **代码即环境表示**：以 Gym 风格 Python 代码统一了单回合推理与多回合智能体任务，环境空间无界（任何可计算 MDP 均可表达）。
3. **基于 Hint 的遗憾奖励**：简洁而有理论支撑（附录 B 的均衡分析），避免了纯对抗设计器导致的环境不可解和纯合作设计器导致的奖励膨胀问题，并具有可解释性（图 4 清晰展示了有/无提示下的行为差异）。
4. **语料库接地**：有效解决了自博弈中信息对称性和模式崩塌的核心问题，实验中以详实证据（Vendi 分数）验证了其必要性。
5. **完整的大规模训练配方**：包括环境验证、奖励黑客防御、延迟更新 + 重要性采样等稳定性技术，验证了 30B+ 尺度上的可行性。
6. **全面而深入的实验**：两个场景 × 三个规模 × 多组消融 + 跨模型族验证 + 丰富的定性分析（生成环境示例、逐轮轨迹、环境质量指标）。
7. **潜力与可扩展性**：框架适用于广泛的任务类别，且与记忆系统、超智能体（HyperAgents）等方向互补。

## 8. 不足与局限

1. **计算资源未披露**：论文没有报告 GPU 数量、训练时长、总体算力开销，限制了成本评估与复现。
2. **复杂度受基础模型能力约束**（正文承认）：环境设计器无法产生超过其基础模型上下文表达能力的环境，即可达环境复杂度受模型规模和生成预算限制。
3. **人类设计的优化器**：两个角色的学习规则仍是固定的人类编写的 RL 算法（GRPO），SPADE 不修改自身的学习规则。
4. **缺乏形式最优性**：基于 PAIRED 的最小遗憾动机，但未证明产生最优课程；评估基准测量固定任务性能，而非开放式推理增长。
5. **实验公平性受限**：在表 2 中，与外部系统（AgentScaler 等）的比较涉及训练数据、预算、基础模型和评估协议的多重差异；部分消融控制同时改变多个因素，难以单独归因。
6. **小规模骨干的信号噪声**：4B 和 8B 上 hint 遗憾在训练中长时间为负（有限样本估计误差），但仍保持增益，说明小规模下信号质量不佳。
7. **工具使用基准增益不均匀**：τ2-bench 增益（+3.6）明显小于另外两个基准（+5.7 和 +13.9），跨基准的泛化效果分布不均。
8. **基线可能过弱**：Fixed-env GRPO 在 30B 上平均仅 +1.2，与 SPADE 的 +8.1 相比差异显著，但其静态环境质量、数量是否与动态生成环境的计算成本对齐，值得进一步审视。
9. **现实世界应用的考量**：生成环境与真实环境的语义差距（sim-to-real gap）未被评估；环境验证主要依靠语法/可执行性检查 + 规则验证，对真实世界复杂性的模拟有限。
