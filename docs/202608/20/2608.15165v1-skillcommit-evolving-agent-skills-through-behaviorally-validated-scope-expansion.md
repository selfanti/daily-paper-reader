## 摘要
大型语言模型（LLM）智能体可以通过将历史经验转化为可复用的程序性知识，在不更新参数的情况下持续改进。然而，现有方法通常基于语义相似性或LLM判断来整合经验，这可能会合并表面上相关但行为上不兼容的策略，从而降低性能。为解决这一问题，我们提出了SkillCommit，一种在线技能演化框架，能够持续将经验转化为层次化的可复用技能库。每个新经验最初被保留为实例特定的补丁，保留其在局部上下文中经过验证的行为。随着相关技能的积累，SkillCommit将那些共享共同行为机制的技能抽象为更高级别的技能。具体而言，对于每个传入的技能，基于嵌入的检索首先识别候选相关技能。跨实例回放和基于LLM的机制检查确定这些技能是否能在不同案例间迁移，并是否共享共同的基本机制。通过两项检查的候选技能会被抽象为更高级别的技能，并且仅当该高级技能保留所有组成技能的已验证行为时才会被提交。在RuleArena、OpenExempt和KOR-Bench上的实验表明，SkillCommit在不同领域始终能提升智能体的性能。此外，学习到的技能可跨模型规模和系列迁移，实现跨模型的经验迁移。

## Abstract
Large language model (LLM) agents can continually improve without parameter updates by converting historical experience into reusable procedural knowledge. However, existing methods often consolidate experience based on semantic similarity or LLM judgments, which may merge superficially related but behaviorally incompatible strategies and thereby degrade performance. To address the issue, we propose SkillCommit, an online skill evolution framework that continuously transforms experience into a hierarchical library of reusable skills. Each new experience is initially preserved as an instance-specific patch, retaining the behavior validated in its local context. As related skills accumulate, SkillCommit abstracts those sharing a common behavioral mechanism into higher-level skills. Specifically, for each incoming skill, embedding-based retrieval first identifies candidate related skills. Cross-instance replay and an LLM-based mechanism check determine whether these skills transfer across cases and share a common underlying mechanism. Candidates that pass both checks are abstracted into a higher-level skill and committed only if it preserves the validated behavior of all constituent skills. Experiments on RuleArena, OpenExempt and KOR-Bench demonstrate that SkillCommit consistently improves agent performance across diverse domains. Moreover, the learned skills transfer across model scales and families, enabling cross-model experience transfer.

- **核心问题**：大型语言模型（LLM）智能体可将历史经验转化为可复用的程序性知识（技能），从而在不更新模型参数的情况下持续提升性能。然而，现有技能演化方法在整合经验时，普遍依赖语义相似性或LLM的主观判断，这可能导致**表面相关但行为上不兼容**的策略被错误合并，最终造成性能下降。
- **深层矛盾**：论文指出，语义相似的补丁可能编码相互冲突的策略，而表述不同的补丁可能共享相同的底层机制。因此，仅靠语义匹配无法保证行为兼容性，技能演化需要超越表面相似性的标准。
- **整体含义**：SkillCommit主张将技能库的构建视为一系列**行为验证的范围扩展**（behaviorally validated scope expansion），即每一个更广泛的行为主张（如多个补丁可抽象为一个更高级技能）都必须通过重放（replay）获得实证支持，从而保证可靠、可演化的技能学习。

### 2. 论文提出的方法论
- **核心思想**：以“行为验证”贯穿技能演化的全流程，强调技术必须兼顾局部有效性与可泛化性，避免抽象化过程中丢失已验证的行为能力。
- **技术细节与算法流程**（共三阶段）：
  - **阶段一：反馈引导的补丁归纳（Feedback-Guided Patch Induction）**
    - **补丁生成**：当执行器在源实例失败后，教师模型依据失败轨迹、正确答案和教师参考轨迹，生成一条包含行为约束、决策规则或可检查步骤的候选补丁。
    - **源重放验证**：候选补丁由同一冻结执行器在源实例上重放；只有成功解决该实例的补丁才能被采纳为“源验证的实例特定补丁”。若失败，将带着新的回放轨迹与验证反馈返回教师模型，重新生成，最多迭代 K=3 次。实验显示，88.0% 的失败实例可在 3 次内获得有效补丁。
  - **阶段二：行为兼容性分组（Behavioral Compatibility Grouping）**
    - **候选检索**：基于嵌入的余弦相似度检索相关的高层技能（Top R=4）或残余补丁，仅用作缩小候选范围，不直接作为合并依据。
    - **跨实例重放**：对检索到的技能 p 与当前补丁 qt，进行交叉重放：将 p 在 qt 的源实例上验证，同时将 qt 在 p 覆盖的实例上验证，得到行为兼容性得分 C(p, qt) = [ρ(p, xt) + Σρ(qt, xj)] / (1 + |W(p)|)，得分 ≥ γ 才通过行为兼容筛选。
    - **机制评估**：由模式作者（LLM）进一步判断 p 和 qt 是否可解释为共享同一程序性机制。二者都通过则支持合并或扩展。
  - **阶段三：源保留整合（Source-Preserving Consolidation）**
    - **候选技能归纳**：从兼容补丁组或扩展技能中生成高层技能，包含 when（适用条件）、repair（程序性指导）和 avoid_when（排除条件）。诱导时不准许访问原始问题、答案或来源信息，以强制进行机制级抽象。
    - **全范围源重放**：候选技能需在全部源实例上重放，确认其保留了每个组成技能已验证的行为。
    - **提交与分裂**：若全部通过则提交（Commit）；若仅部分通过则分裂（Split），并限制范围后再次验证；否则拒绝（Reject）。所有版本与重放结果均保留用于审计。
