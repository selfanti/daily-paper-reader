## 摘要
随着智能体任务复杂度的增长，LLM智能体越来越依赖经验记忆来跨任务复用程序性知识。有效的记忆设计必须共同解决存储什么、如何组织和检索记忆，以及记忆如何演化的问题。现有系统仅部分地处理了这些问题：它们将轨迹、见解或工作流存储为孤立条目，丢弃了子任务和可复用技能之间的组合关系；通过忽略关系信号的平面嵌入相似性进行检索；并且在维护记忆时不利用其关系结构。我们提出HyperSkill，一个基于超图的记忆框架，它同时改进了这三个方面。HyperSkill将记忆表示为具有两种节点类型（子任务步骤和可复用技能）的超图，其中每条超边连接来自单个轨迹的子任务和技能。双路径检索同时查询子任务和轨迹层面，通过跨检索轨迹的共现对技能进行排序。周期性的结构感知维护会修剪低效用节点，并通过质量加权传播合并冗余技能。在xBench、GAIA和WebWalkerQA上，使用GPT-4o和Qwen3-30B-A3B，HyperSkill优于十种记忆基线，在GAIA上获得高达+11.51的提升，在WebWalkerQA上获得+11.18的提升。

## Abstract
As agentic tasks grow in complexity, LLM agents increasingly rely on experiential memory to reuse procedural knowledge across tasks. Effective memory design must jointly address what to store, how memory is structured and retrieved, and how memory evolves. Existing systems tackle each only partially: they store trajectories, insights, or workflows as isolated entries, discarding compositional relationships among subtasks and reusable skills; retrieve by flat embedding similarity that ignores relational signals; and maintain memory without leveraging its relational structure. We propose HyperSkill, a hypergraph-based memory framework that jointly improves all three. HyperSkill represents memory as a hypergraph with two node types, subtask steps and reusable skills, where each hyperedge links the subtasks and skills from a single trajectory. Dual-path retrieval queries both subtask and trajectory levels, ranking skills by co-occurrence across retrieved trajectories. Periodic structure-informed maintenance prunes low-utility nodes and merges redundant skills via quality-weighted propagation. Across xBench, GAIA, and WebWalkerQA with GPT-4o and Qwen3-30B-A3B, HyperSkill outperforms ten memory baselines, yielding gains of up to +11.51 on GAIA and +11.18 on WebWalkerQA.

## 2. 论文提出的方法论

### 2.1 核心思想
- 将经验记忆构建为超图 \(G = (V, E)\)，其中：
  - **节点** \(V = V_u \cup V_s\)：子任务节点（捕获任务的组合工作流结构）与技能节点（捕获可跨任务迁移的执行策略，含正例策略与错误模式）；
  - **超边** \(e_j = (V_j, d_j, \ell_j, \gamma_j)\)：每条超边对应一条轨迹，将子任务节点集 \(V_{uj}\)、技能节点集 \(V_{sj}\)、原始任务描述 \(d_j\)、提炼的教训 \(\ell_j\) 和效用分数绑定在一起。
- 每个节点/超边都有动态**效用分数**，结合成功率与步数效率：
  \[
  \gamma(\cdot) = \beta \cdot \frac{\sigma(\cdot)}{\nu(\cdot)} + (1-\beta) \cdot \left(1 - \frac{\bar{T}(\cdot) - T_{\min}}{T_{\max} - T_{\min}}\right)
  \]

### 2.2 双路径超边检索（从子任务到轨迹）
- **子任务路径**：先用 LLM 将当前任务分解为子任务集 \(P_0\)，编码后检索 top-\(k_u\) 个子任务节点，再通过节点的关联超边扩展出候选轨迹集合 \(E_{\text{sub}}\)，可发现表面任务描述不同但流程结构相似的轨迹；
- **轨迹路径**：直接用任务描述 \(d_q\) 匹配超边嵌入 \(h_e = \phi(d_e \| \ell_e)\)（任务描述与蒸馏教训拼接），得到 top-\(k_e\) 条超边 \(E_{\text{traj}}\)，捕获高层语义相似的轨迹；
- **融合**：\(E^* = E_{\text{sub}} \cup E_{\text{traj}}\)，两路径互补，蒸馏教训 \(L_q\) 作为轨迹层上下文提供。

### 2.3 技能检索（从轨迹到技能）
- 候选技能池为 \(R_s = \bigcup_{e \in E^*} V_s^e\)；
- **共现排序**：按技能在检索到的超边中出现的次数 \(\kappa(v) = |\{e \in E^* \mid v \in V_e\}|\) 排序，平局时用嵌入相似度打破，选出 top-\(k_s\) 技能作为执行指导；
- 执行时上下文为 \((S_q, L_q)\)，配合滑动窗口历史；完成后提取新技能并做**插入时去重**（相似度超阈值即合并），新超边加入图。

### 2.4 记忆演化（周期性维护）
- **质量驱动剪枝**：删除被检索足够多次但效用低于阈值的节点：
  \[
  V \leftarrow V \setminus \{v \mid \nu(v) \ge N_{\min} \land \gamma(v) < \tau_{\text{prune}}\}
  \]
- **结构感知合并**：仅对技能节点进行。先构建质量加权共现矩阵：
  \[
  W_{ij} = \min(\gamma(v_i), \gamma(v_j)) \cdot \sum_{e: v_i,v_j \in V_e} \frac{1}{|V_e|}
  \]
  再进行 L 步对称传播得到结构嵌入 \(\tilde{Z} = S Z\)，相似度超过 \(\delta_{\text{merge}}\) 的技能对由 LLM 合并为更高级的技能，超边成员关系全部重新指向新节点。

## 7. 优点

## 8. 不足与局限
