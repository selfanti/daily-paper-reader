## 摘要
跨会话持久化的LLM智能体会积累存储记忆，这些记忆的有效性因内容类型而异，但现有记忆架构将所有记忆视为同等持久，并系统性用过时事实污染检索到的上下文。我们证明，每种记忆的、类型条件化的时间衰减（一种西部灌丛鸦情景记忆特性）可以被操作化为外部LLM智能体记忆存储中的自动分类系数π_i，从而产生ScrubJay-MEM：每条记忆被编码为联合绑定的“何物—何地—何时”元组，带有估计易逝性π_i和效用时间范围τ_i，通过查询自适应评分检索，并在每次更新时以O(1)次LLM调用进行回溯性修订。我们引入了时间泛化测试（TGT），这是一个带有保留间隔留出法和泛化差距（GenGap）指标的基准测试。在TGT上，ScrubJay-MEM是唯一具有实质性正GenGap（+0.108）的基于检索的系统；在MemoryAgentBench EventQA-64k上，在LLM骨干下，其F1比Mem0提高+2.66，比Qwen3-Embedding-4B提高+3.09。衰减消融使GenGap缩小5.7倍，证明类型条件化衰减是取得该结果的必要条件。在更强的骨干下收益减小，并在事实整合任务中反转，将贡献限定为对易逝事实的时间推理。

## Abstract
LLM agents that persist across sessions accumulate stored memories whose validity varies enormously by content type, yet existing memory architectures treat all memories as equally persistent and systematically contaminate retrieved context with outdated facts. We show that per-memory, type-conditioned temporal decay, a property of western scrub jay episodic memory, can be operationalized as an auto-classified coefficient $π_i$ in an external LLM-agent memory store, yielding ScrubJay-MEM: each memory is encoded as a jointly-bound What--Where--When tuple with an estimated perishability $π_i$ and utility horizon $τ_i$, retrieved by query-adaptive scoring, and revised retroactively at $O(1)$ LLM calls per update. We introduce the Temporal Generalization Test (TGT), a benchmark with held-out retention intervals and a Generalization Gap (GenGap) metric. On TGT, ScrubJay-MEM is the only retrieval-based system with substantially positive GenGap ($+0.108$); on MemoryAgentBench EventQA-64k it improves F1 by $+2.66$ over Mem0 and $+3.09$ over Qwen3-Embedding-4B under a llm backbone. A decay ablation collapses GenGap by $5.7\times$, establishing type-conditioned decay as necessary for the result. Gains narrow under stronger backbones and reverse on fact-consolidation tasks, scoping the contribution to temporal reasoning over perishable facts.

## 1. 核心问题与研究动机

- **背景问题**：跨会话持久化的 LLM 智能体会不断积累存储记忆，但不同内容类型的记忆其有效性差异巨大。例如，用户职业信息可能数年有效，而会议室安排可能几小时后即失效。现有记忆架构将所有记忆视为同等持久，导致检索上下文被过时事实系统性污染。
- **关键洞察**：从西部灌丛鸦（western scrub jay）的缓存行为获得启示——这种鸟在缓存食物时不仅记住"是什么、在哪里"，还记住"什么时候"，并能据此推断食物的易腐性（如蠕虫易腐烂、花生耐久）。这种集成的 What–Where–When（WWW）记忆痕迹对时间具有鲁棒性，是现有 LLM 智能体记忆系统所缺乏的。
- **现有方案的不足**：简单的统一时间衰减（对所有记忆施以相同折扣）无效，因为不同记忆类型的衰减速率本质不同；二元的短期/长期划分也无法覆盖至少四种可区分的衰减速率；且易腐性并非静态——原本稳定的记忆在情境转变后可能变得时间敏感。
- **核心诉求**：需要一个逐记忆的（per-memory）、类型条件的（type-conditioned）、可追溯修订的（retroactively revisable）衰减机制——这是现有智能体记忆系统尚未组合实现的特性。

## 2. 方法论：ScrubJay-MEM

### 2.1 核心思想
借鉴灌丛鸦情景记忆的四项认知机制，转化为计算组件：

| 生物学发现 | 认知机制 | ScrubJay-MEM 组件 |
|---|---|---|
| WWW 集成 | 绑定式情景痕迹 | 集成式记忆单元（EMU） |
| 易腐性感知 | 物品特定衰减 | 效用函数 U |
| 追溯性修订 | 痕迹参数更新 | 追溯性上下文整合（RCI） |
| 前瞻性缓存 | 预期性加载 | 前瞻性记忆缓冲区（PMB） |

### 2.2 关键技术细节

**（1）Episodic Memory Unit（EMU）**：每条记忆编码为 4 元组 m_i = ⟨wWHAT_i, wWHERE_i, (t_i, τ_i), π_i⟩。WHAT 为语义内容嵌入，WHERE 为任务上下文嵌入，t_i 为创建时间戳，τ_i 为估计效用期限，π_i ∈ (0,1] 为易腐性系数（π≈1 表示易逝，π≈0 表示稳定）。通过固定凸融合生成绑定向量：h_i = 0.55·wWHAT_i + 0.35·wWHERE_i + 0.10·σ(wWHAT_i ⊙ wWHERE_i)，并对前两个坐标添加对数尺度的时间位置偏移。

**（2）Perishability-Aware Utility**：效用函数为 U(m_i, t_q) = V_i · exp(−π_i · (t_q − t_i)/τ_i)。衰减率类型条件化：稳定知识（π≈0.05）、程序性知识（π≈0.2–0.4）、任务特定推理（π≈0.5–0.7）、临时交互（π≈0.8–1.0）。π 和 τ 由 LLM-prompt 分类器自动估计（含关键词启发式后备），无需训练。

**（3）自适应 WWW 检索**：检索得分为四因子加权：S = α_q·sim(WHAT) + β_q·sim(WHERE) + γ_q·U(m_i,t_q) + δ_q·Φ(m_i,G)。权重 [α, β, γ, δ] 查询自适应，通过关键词触发的偏置逻辑（如"recent/latest"上调 γ，"what/which"上调 α）结合嵌入范数和时间间隔生成。

**（4）时间超图（Episodic Hypergraph）**：三类边——语义、上下文、时间共现，混合权重 wS=0.40、wC=0.30、wT=0.30。图奖励通过一跳消息传递 Φ(m_i,G) = Σ e_ij·S(m_j,q,t_q)·U(m_j,t_q) 传播，链接到已衰减记忆的边自动降权。

**（5）Retroactive Contextual Integration（RCI）**：新信息到达时，仅需 O(1) 次 LLM 调用解析更新量 (ΔV, Δπ, Δτ)，对阈值 θ_RCI 以上亲和力的受影响记忆执行轻量向量更新（±0.15–0.20 学习率）。Proposition 1 证明每次更新有界且 WHAT 嵌入对目标证据产生压缩映射（Lipschitz 常数 (1−η_w·α_in)）。

**（6）Prospective Memory Buffer（PMB）**：任务执行前预加载 top-K 最可能需要的记忆，实现两阶段检索——先搜缓冲区（O(K)），未命中再搜全库（O(N)）。Proposition 2 证明随任务编码器质量提高，期望检索成本趋近 O(K)。

**（7）附加机制**：面向未来的编码（询问 LLM"何时有用"并拼接至原记忆后嵌入）；会话结束时基于效用阈值 ϵ 和图连通性阈值 ϵ_G 进行值加权记忆整合与剪枝。

## 3. 实验设计

### 3.1 Benchmark 与数据集

**（1）MemoryAgentBench EventQA-64k**：最贴近实际的任务，5 个长上下文（中位数 64K tokens）、每个 100 题、共 500 个查询，考验智能体从时间有序事件序列中检索和推理的能力。使用官方评分器（EM、F1、sEM、ROUGE-L，无 LLM 陪审团）。

**（2）Temporal Generalization Test（TGT，自建）**：受 Clayton 等人的灌丛鸦保留间隔实验启发。20 个实例、每实例 96 条记忆（四类易腐性各 24 条）、66 个查询 × 5 个保留间隔（I1 即时、I2 短期、I3 中期（未见）、I4 长期、I5 超长期（未见）），共 1,320 个查询。I3 测试内插、I5 测试外推。核心指标为泛化差距 GenGap = Acc(I2) + Acc(I4) − 2·Acc(I3)，衡量系统在未见间隔上的表现是否低于已见间隔的线性内插预期。

### 3.2 对比方法

- **EventQA-64k**：BM25、A-MEM、Contriever、Qwen3-Embedding-4B、Mem0（所有系统共享 llama3.1:8b 骨干和 nomic-embed-text 嵌入）。
- **TGT**：10 个系统，涵盖随机（B0）、纯 LLM 无检索（B1）、词法（B2: BM25）、稠密（B3）、混合（B4: BM25+稠密 RRF）、稠密+统一 recency（B5）、RAG-vanilla（B6）、RAG-temporal（B7: 带时间提示）、ScrubJay-MEM（无衰减）、ScrubJay-MEM（完整）。

### 3.3 设置

- TGT 使用 qwen3:30b-instruct 作为生成模型，nomic-embed-text（768 维）嵌入，llama3.2:3b（跨模型家族）作为答案正确性判定者以避免自我偏好偏差，top-k=10，单种子 42。
- 质量审计：修复了答案泄漏、池复用、查询重复等问题后发布。

## 5. 实验数量与充分性

- **EventQA-64k**：5 个系统对比 × 2 种骨干（llama3.1:8b 和 qwen3:30b-instruct），共 10 组实验。
- **TGT**：10 个系统对比 × 5 个保留间隔 × 20 个实例 × 66 查询，共 1,320 查询。附带按类型 × 间隔的逐格分解、TGS 排行榜、staleness 与 combined 双维度分析。

- **充分性评估**：整体实验设计较为充分。TGT 作为控制诊断，构造严谨（含泄漏预防、去重、有效性调度）；正反两面验证（何处有效、何处无效均报告）体现了客观性。但 TGT 仅单种子（42），未报告方差；RCI 和 PMB 组件未做独立消融（论文承认只隔离了衰减一项）。

## 6. 主要结论与发现

1. **EventQA-64k（llama3.1:8b 骨干）**：ScrubJay-MEM 取得 F1=61.58、EM=41.00，超越 Mem0（F1 +2.66、EM +5.00）和 Qwen3-Embedding-4B（F1 +3.09、EM +4.40），为最强系统。
2. **TGT 泛化**：ScrubJay-MEM 是唯一 GenGap 显著为正（+0.108）的基于检索的系统；所有平坦检索基线 GenGap ≤ −0.022。次优检索基线（混合 RRF）仅 −0.054，差距 16.2 个百分点。
3. **机制确认**：去除类型条件衰减使 GenGap 缩小 5.7× 而其他指标不变，证明衰减是泛化的必要机制；统一 recency 基线（B5）甚至比无时间模型基线（B3）更差，直接反驳"单一全局衰减率足够"的猜想。
4. **作用边界**：在更强骨干（qwen3:30b）下，稠密检索反超 ScrubJay-MEM（Contriever F1=78.68 vs. ScrubJay-MEM 72.82）；在事实整合任务（Factconsolidation）中，类型条件衰减反而有害（F1 低于稠密/词法基线 14–18 分），因为这些任务要求过期事实保持可见。
5. **效率-能力权衡**：RAG-temporal 在 raw combined accuracy 上最高（67.2%），但 GenGap 为负（−0.018），其时间能力源于推理时的逐查询 LLM 推理而非架构属性；ScrubJay-MEM 在检索级计算成本下达到 LLM 级的过时判断准确性。

## 7. 优点

- **生物启发的可解释架构**：四个机制均映射到具体的认知学观察，非纯工程拼凑。π_i 作为可检查架构参数，优于作为 LLM 文本属性的隐式时间有效性。
- **理论保证**：Proposition 1（RCI 每次更新有界 + WHAT 压缩）和 Proposition 2（PMB 亚线性检索）提供了形式化的效率与稳定性保障。
- **自建基准的严谨性**：TGT 设计包含答案泄漏预防（FORBIDDEN ANSWER CONTENT）、无放回目标选择、跨模型家族评判、程序化质量审计（9 项标准全部通过）、Trivial baseline 地板测定，有效支撑机制性结论。
- **必要的消融隔离**：5.7× GenGap 坍缩配合非 GenGap 指标几乎不变，干净地识别出关键机制。
- **诚实的边界报告**：主动报告 stronger backbone 下优势消失和 Conflict-Resolution 上表现反转，而非选择性呈现有利结果；支持"易逝事实时序检索器"的精准定位。

## 8. 不足与局限

### 实验覆盖方面
- TGT 为 LLM 自然化的受控合成基准（虚构名字/槽值词汇表），外部效度限于同分布对话日志，不覆盖真实用户数据。
- 仅单一种子（42），未报告跨种子的方差/置信区间。
- TGT 中 ScrubJay-MEM 的 Combined accuracy（37.1%）显著低于 RAG 类系统（62.7–67.2%），论文承认原始精度不是其优势。
- 四个 RCI/PMB 组件未做独立消融——论文仅隔离了衰减项，其他三个原语的独立贡献未量化。
- 合成数据"已知有效性调度"与架构共享相同四类 π 范围，虽通过无衰减消融部分缓解，但机制性主张与基准存在类别原语共享的风险。

### 偏差风险方面
- LLM 判定者即使跨家族（llama3.2:3b 评判 qwen3 生成），仍存在潜在判定偏差。
- 检索基线（B2–B5）直接以 top-1 记忆文本作为答案，而 RAG/ScrubJay 有额外机制，检索系统间的可比性受限于分层设置。

### 应用限制方面
- **伦理风险**：π_i 自动分类可能将用户医疗、财务、安全关键内容误标为易逝而静默遗忘。论文建议生产部署中将 π_i 视为建议性而非决定性，敏感类记忆门控需要显式保留策略。
- **骨干依赖**：受益集中在资源受限的部署场景（小 LLM 骨干），大模型可通过推理自行补偿时间朴素检索器。
- **任务窄化**：在事实整合/冲突消解任务中类型条件衰减会压制任务所需记忆，故定位为"易逝事实的时序检索器"而非通用记忆系统；需要与平坦检索器（用于整合任务）和提示级时间推理（用于高容量骨干系统）互补使用。
