## 摘要
多智能体强化学习（MARL）是解决复杂协作任务的强大框架，但它严重依赖于定义良好的全局奖励函数。设计这样的奖励具有挑战性，尤其是在具有异构智能体的系统中，因为单一的标量目标可能无法捕捉多样化的行为。在本文中，我们提出了多智能体偏好集成学习（MAGPIE），通过智能体特定的偏好建模来应对这些挑战。每个智能体由专门的专家通过偏好信号进行评估，从而无需全局评估。我们从理论上证明，优化这些去中心化的偏好会收敛到纳什均衡策略。为了将局部偏好整合为连贯的全局目标，我们从偏好数据构建智能体特定的奖励模型，并通过单调聚合机制将它们组合起来。我们进一步证明，优化这个聚合奖励模型等同于训练纳什均衡策略。在基准多智能体任务和顺序生产线任务上的大量实验表明，MAGPIE实现了与经过奖励工程设计的基线相当的性能，展示了其在精确奖励工程不可行的场景中促进策略学习的潜力。

## Abstract
Multi-agent reinforcement learning (MARL) is a powerful framework for solving complex collaborative tasks, but it relies heavily on well-defined global reward functions. Designing such rewards is challenging, especially in systems with heterogeneous agents, where a single scalar objective may fail to capture diverse behaviors. In this paper, we introduce Multi-AGent Preference-Integrated lEarning (MAGPIE), which addresses these challenges through agent-specific preference modeling. Each agent is evaluated by a dedicated expert through preference signals, eliminating the need for global evaluation. We theoretically prove that optimizing these decentralized preferences converges to a Nash equilibrium policy. To integrate local preferences into a coherent global objective, we construct agent-specific reward models from preference data and combine them via a monotonic aggregation mechanism. We further prove that optimizing this aggregate reward model is equivalent to training the Nash equilibrium policy. Extensive experiments on benchmark multi-agent tasks and a sequential production line task show that MAGPIE achieves performance comparable to reward-engineered baselines, demonstrating its potential to facilitate policy learning in scenarios where precise reward engineering is impractical.

## 1. 核心问题与研究动机

- **背景与动机**
  - 多智能体强化学习（MARL）依赖良好定义的全局奖励函数，但在异构智能体系统中（各智能体角色、观测和行动空间不同），设计单一标量奖励既困难又容易失效。
  - 偏好强化学习（PbRL）利用人类对轨迹段的比较反馈来指导策略学习，避免了手工奖励设计，但直接扩展到多智能体环境存在三大局限：
    1. **全局评价负担过重**：人类评估整支团队的联合行为在智能体数量和异质性增加时变得越来越困难，容易产生认知过载和噪声；
    2. **隐含的同质性假设**：现有方法常通过比较不同智能体的行为贡献来评价个体，这在异构系统中无意义或产生误导；
    3. **对真实奖励的依赖**：一些方法在训练中仍需要真实奖励作为辅助信号，削弱了 PbRL 消除奖励工程的初衷。
- **核心问题**：能否在不依赖全局奖励工程的前提下，利用去中心化的、智能体特定的偏好信号来引导异构多智能体系统达到全局最优的协作策略？

## 2. 方法论：MAGPIE 框架

### 2.1 核心思想

MAGPIE（Multi-AGent Preference-Integrated lEarning）将复杂的全局评估分解为多个可行的局部评估：每个智能体配备一个**专属的教师（teacher）**，该教师仅评价该智能体的个体行为与协作贡献，提供智能体特定的偏好信号。然后通过训练独立奖励模型并采用**单调聚合机制**融合为全局奖励，使标准 MARL 算法可以直接使用。

### 2.2 理论框架

- **假设体系（Assumptions 1–7）**：
  - A1–A2：每个智能体存在定义良好且可获取的偏好，满足对称性、一致性和传递性；
  - A3：存在有界真实全局奖励函数；
  - A4：局部偏好与全局回报严格一致（局部改善 ⇒ 全局改善）；
  - A5：每个智能体存在与教师偏好一致的潜在局部奖励函数；
  - A6：全局奖励可表示为局部奖励的连续可微函数 F；
  - A7：局部改进对其他智能体的负面冲击不会超过该改进本身。
- **关键定理**：
  - **Theorem 1**：在有限状态-动作空间和足够长的轨迹段（H→∞）条件下，基于智能体特特定偏好迭代更新策略可收敛到纳什均衡（Algorithm 1，概念性框架）；
  - **Theorem 2**：若学习的局部奖励模型与教师偏好完全对齐，则最大化聚合奖励（局部奖励之和）所得联合策略是真实奖励下的纳什均衡；
  - **Theorem 3**：通过 Bradley-Terry 模型 + 交叉熵损失学习奖励模型，在充分偏好数据下可一致收敛到真实局部奖励（至多差一个仿射变换），并提供了有限样本误差界（含 Rademacher 复杂度）；
  - **Theorem 4**：有限样本下，学到的策略构成 **ϵ-纳什均衡**，且 ϵ = O(1/√N)，当 N→∞ 时收敛到精确均衡；
  - **Theorem 5**（附录）：在随机采样条件下，分析 Q 函数更新过程的 ODE 收敛性，证明算法几乎必然收敛到最优策略。

### 2.3 奖励建模技术细节

- **偏好预测器**：基于 Bradley-Terry 模型构建，偏好概率通过 softmax 形式与局部奖励的折扣和关联；
- **损失函数**：偏好损失（交叉熵）+ 正则化项（惩罚局部偏好与全局聚合回报不一致的情况），总损失为两者加权和：
  - L = L_pref + λ·L_reg
- **奖励聚合**：采用加性单调聚合函数：
  - r̂(s, A) = Σᵢ r̂ᵢ(s, A)
- **两个实用技术**：
  1. **连续偏好采集**：在策略学习过程中周期性使用最新轨迹新增偏好数据，提高奖励模型在相关状态-动作区域上的准确性；
  2. **经验重标记**：奖励模型更新后，用最新全局奖励重新标记回放缓冲区中的历史转移，提升样本效率。

### 2.4 算法流程（Algorithm 2，以 QMIX 为骨干）

1. 初始化各智能体的 Q 函数、奖励模型和重放缓冲区；
2. 在每个环境步骤中，各智能体基于局部观测选取动作，执行联合动作，用当前聚合奖励模型计算奖励并存储转移；
3. 每隔 K 步，从回放缓冲区采样 M 对轨迹段，向各智能体的教师查询偏好，存入偏好缓冲区并更新各奖励模型；
4. 更新全局奖励并重新标记所有历史转移；
5. 使用 QMIX 的标准损失函数更新局部 Q 函数和混合网络，迭代直至收敛。

## 8. 不足与局限

- **理论假设较强**：
  - 假设教师的偏好具有传递性和一致性，在真实人类评估中可能不成立；
  - A4 要求局部偏好与全局回报严格一致，但实际中教师往往只能通过局部观测判断；
  - A7（局部改进不损害全局）在存在强竞争关系或负外部性时可能被违反；
  - Theorem 1 依赖无限长度轨迹段，实际中只能近似。
- **实验与真实场景的差距**：
  - 偏好全部由自动化规则生成，没有真实人类教师的实验，无法反映人类判断的噪声和不一致性；

  - 智能体规模较小，超大规模（如几十到上百个智能体）下的扩展性未知。
- **对齐问题**：Theorem 3 只保证学习到的奖励模型与真实奖励相差一个仿射变换（α > 0, β），而不同智能体的 α 和 β 可能不同，简单求和可能引入偏差；
- **安全性**：正则化项只是软约束，无法从机制上保证局部偏好更新不会损害全局目标，在安全敏感场景中仍有风险；
- **训练稳定性**：偏好数据质量低或覆盖率不足时，奖励模型可能误导策略学习，论文对此未做充分分析。
