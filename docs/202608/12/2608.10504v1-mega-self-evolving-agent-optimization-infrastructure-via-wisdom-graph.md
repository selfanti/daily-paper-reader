## 摘要
随着编码智能体越来越多地处理实现工作，核心挑战从构建单个智能体转向构建一个能够系统性地改进它们的基础设施。当前的方法要么在优化智能体系统时没有积累可迁移的知识，要么积累了知识却不对其进行组合推理，并且缺乏一种让知识通过运行证据自我进化的机制。MEGA（Meta Evaluation-Grounded Adaptation，基于元评估的自适应）作为一个自我进化的基础设施弥补了这些不足：每个优化周期都会产生持久资产，对这些资产的组合推理指导后续优化，而运行证据则不断完善已积累的智慧以及支配它的推理。第一层通过行为模式聚类和经验性A/B验证，从智能体会话中提炼出可复用的智慧，将每个过程转化为持久资产。第二层将这些资产分解为类型化智慧图（Wisdom Graph）中的原子PCR（Primary-Context-Resultant，主-上下文-结果）单元，并通过演绎、溯因和归纳推理来扩展隐含关系；随后，它通过组合检索组装特定于上下文的执行计划，从而揭示仅靠嵌入相似性无法获得的桥接知识。第三层在异构智能体工作流（代码节点、LLM调用和使用工具的智能体）上执行多智能体协同优化，通过消除数据方差的受控评估，将改进效果归因于特定的策略变更。从第三层反馈的证据驱动了管理智慧构成的策展策略和跨运行积累的优化轨迹的自我进化。最终结果是，在这样的基础设施中，优化智能体系统与进化指导优化的知识是同一个过程。

## Abstract
As coding agents increasingly handle implementation, the central challenge shifts from building individual agents to building an infrastructure that systematically improves them. Current approaches optimize agent systems without accumulating transferable knowledge, accumulate knowledge without compositional reasoning over it, and lack a mechanism for that knowledge to self-evolve through operational evidence. MEGA (Meta Evaluation-Grounded Adaptation) addresses these gaps as a self-evolving infrastructure: each optimization cycle produces durable assets, compositional reasoning over those assets guides subsequent optimization, and operational evidence refines both the accumulated wisdom and the reasoning that governs it. Layer 1 distills reusable wisdom from agent sessions through behavioral-pattern clustering and empirical A/B validation, transforming each process into a durable asset. Layer 2 decomposes these assets into atomic PCR (Primary-Context-Resultant) units within a typed Wisdom Graph and performs deductive, abductive, and inductive reasoning to expand implicit relations; it then assembles context-specific execution plans through compositional retrieval that surfaces bridging knowledge unreachable by embedding similarity alone. Layer 3 performs multi-agent collaborative optimization over heterogeneous agent workflows (code nodes, LLM calls, and tool-using agents), attributing improvement effects to specific strategy changes through controlled evaluation that eliminates data variance. Evidence fed back from Layer 3 drives the self-evolution of both the curation strategies that govern wisdom composition and the optimization trajectories accumulated across runs. The result is an infrastructure in which optimizing an agent system and evolving the knowledge that guides optimization are one and the same process.

随着编码智能体日益承担实现工作，智能体开发的核心挑战已从"构建单个智能体"转向"构建一个能系统性改进智能体的基础设施"。然而，现有智能体开发自动化方法存在三个结构性局限：

- **局限一：优化不积累知识，记忆无法单独解决问题**——无状态自动化循环（如 Ralph Loop）只重复执行而不从先验周期中学习；提示词和工作流优化器（GEPA、DSPy、AFlow 等）可以在单项目内显著改进系统，但成功优化的"原因"——何种策略在何种条件下有效——仍是非结构化、不可迁移的。新项目开始时，策略搜索从零重启。
- **局限二：存储的知识缺乏组合推理能力**——技能库（Voyager、Memento-Skills）存储了程序性知识，却无法推理"哪些技能应组合、以什么顺序、在什么条件下"。现有的技能编排框架（AgentSkillOS、SkillNet）尽管引入了层级组织和类型化关系图，但组合单元仍是完整技能，既不能将技能分解为原子子单元，也不执行逻辑推理来发现隐式关系。论文借 Press et al. 的"组合性鸿沟"（compositionality gap）形式化了这一问题。
- **局限三：未经运行验证的知识无法自我改进**——即使实现了组合推理，没有反馈回路（优化证据验证组合是否实际有效）的知识仍然是悬空的。未经证实的和过时的知识会与有效知识一同累积，导致检索质量逐渐退化。

**论文的核心含义**：MEGA 是第一个将三种能力——优化时积累知识、对知识进行组合推理、通过运行证据自我进化——统一到单一基础设施中的架构。其关键设计理念是："优化智能体系统"与"进化指导优化的知识"是同一过程。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

MEGA 采用三层循环架构，核心公式为：**W(t) = L1(T(t) ∪ T3(t−1)), Π(t) = L2(W(t), E(t−1)), E(t), T3(t) = L3(Π(t))**——其中 W 为智慧资产，Π 为执行计划，E 为证据，T3 为 Layer 3 产生的执行会话。该循环确保优化输出重塑引导未来优化的知识。

### 2.1 Layer 1：基于会话的智慧生成（Session-based Wisdom Generation）

将原始会话轨迹提炼为可复用的智慧资产，而非简单存储日志。核心技术流程：

- **隐私过滤前置**：客户端侧先进行密钥掩码和路径匿名化，再进入管线。
- **两阶段聚类**：第一阶段用嵌入相似度的贪心分配进行域预聚类；第二阶段在各域内用 **BIRCH**（Balanced Iterative Reducing and Clustering using Hierarchies）算法进行行为模式发现。BIRCH 使用聚类特征（CF）元组 (N, LS, SS)，通过可加的 O(1) 合并操作实现单遍 O(n) 处理，无需预指定 k 值，用半径阈值 T 判断新样本归属。
- **LLM 综合与结构化过滤**：对聚类生成的候选进行哈希精确去重（O(n)）、LLM 冲突检测、跨会话嵌入相似度去重。
- **行为 A/B 验证**：对每个候选智慧生成测试套件，在治疗组（注入智慧）和对照组（基线）下并行执行，实证测量**性能提升**（准确率提升）和**令牌效率**（成本变化）两个 ROI 轴，据此决定接受/拒绝。
- **三阶质量门控**：结构过滤 + 自评估打分（加权调和平均，独立解析交叉验证防自膨胀）+ 行为 A/B 验证。

### 2.2 Layer 2：智慧推理与策展（Wisdom Reasoning and Curation）

Layer 2 是整个架构的核心推理基座，具体包括：

- **安全筛查**：所有进入图的资产需通过指令级威胁（提示注入、工作流劫持）和执行级威胁（数据外泄、破坏性命令）的双类污染筛查。

- **PCR 原子分解与角色流式节点池**：每个智慧资产分解为原子 **PCR 三元组** ω = (vP, vC, vR, m)，其中 vP 为核心动作（Primary）、vC 为应用条件（Context）、vR 为预期结果（Resultant）、m 为实现细节（Method）。子技能间的前置条件、互斥、条件分支和回退关系建模为带类型边。每个边携带双重因果分数 **σ(e) = (S(e), N(e)) ∈ [0,1]²**，分别表示充分性（存在源节点时目标节点跟随的程度）和必要性（无源节点时目标节点不太可能发生的程度）。角色流式节点池允许同一概念在不同三元组中充当不同角色，自然生成跨技能连接并降低节点数。

- **PCR 推理（三种经典推理模式）**：
  - **演绎（Deduction）**：当 P→C 和 C→R 存在时，传递推断 P→R，乘法分数衰减使远程推断更保守。
  - **溯因（Abduction）**：当 P→R 和 C→R 共享同一结果时，若 C→R 的必要性分数足够高，则逆推 P→C 的隐藏前置关系，用贝叶斯后验估计综合结果覆盖率、因果强度和语义相关度。
  - **归纳（Induction）**：当多个 P 同时连接到相同的 C 和 R 时，用超几何检验判断共现是否超越偶然性，在统计显著时推断 C→R 边。
  
  三种推理迭代应用，边只增不减，各阶段有各自的接受阈值（演绎用最小因果强度+对数惩罚，溯因用贝叶斯后验界，归纳用超几何显著性检验），直至到达不动点。

- **PCST 组合检索**：将检索形式化为无向图投影上的**奖赏收集斯坦纳树（Prize-Collecting Steiner Tree, PCST）**问题：**T∗ = argmax [Σv∈V(T) π(v;q) − Σe∈E(T) c(e)]**，其中 π(v;q) 为与查询相关度成正比的奖赏，c(e) 为与因果弱度成正比的成本。非种子节点——即与查询相似度低但作为种子间连接必不可少的节点——构成**桥接知识**。PCST 不做单一类型检索，而是跨异构智慧类型的混合子图组装。

- **子图到执行的转化**：PCST 输出的推理子图被转化为带排序的计划工件：技能节点→执行候选，策略节点→门控规则和优先级约束，策展模式→拓扑约束和依赖排序，轨迹→保守/探索分支的初始偏置。输出 Π(q) 不是 top-k 列表，而是带有分配执行规则的图线性化。

- **ROI 驱动智慧策展（自进化机制）**：
  - 预测效用估计：**pi = τ(simi, stagei) × η(ωi)**，其中 τ 为历史迁移率，η 为基于饱和度的证据置信度。
  - 分层聚合：**Pstep = 1 − exp(−Σpi)**，用饱和形式反映冗余技能的边际效用递减。
  - 自适应门控：冷启动时用允许性门（探索优先），置信度累积后切换为保守 LCB 门。
  - 四轴复合评分：嵌入相似度、证据强度、阶段匹配度和基准分。
  - 组合级校正因子 CF = E[δactual/δpredicted]——系统的"自我认知"。
  - 三个自进化轴：个体级校准（迁移函数 τ 从先验收敛到经验均值）、组合级强化（频率-质量阈值促进模式为策展策略）、内容级进化（未消费修订建议超过阈值触发更新）。

- **图维护（自动图卫生）**：PCR 去重（P/C/R 节点语义等价时合并，整合证据）、矛盾消解（相同 P、C 但相反 R 时保留强证据变体，或将全局矛盾转为语境约束判断）、证据触发内容更新（负反馈积累后自动内容补丁，保持图反映当前运行现实）。

### 2.3 Layer 3：评估驱动的多智能体优化（Evaluation-Driven Multi-Agent Optimization）

- **优化目标拓宽**：将智能体工作流建模为有向图 A = (N, E)，节点包含三种异构类型——确定性代码节点、带提示词和采样参数的 LLM 调用节点、执行多轮推理并调用工具的智能体节点。现有提示词优化器只优化 π 分量；Layer 3 联合优化提示词、工具配置、代码逻辑和编排结构全部维度。

- **Adapt 管线流程**：资产扫描 → 自适应入口（依据现状跳过已有阶段）→ 条件性研究智能体（缺评估数据/代码时并行调研）→ 逆向 PRD/数据综合（缺数据集时从 PRD 生成，含类别-难度矩阵、种子场景设计、强制人工审批门、分层训练/验证集生成）→ 共享优化循环 → 元学习智能体（提取优化轨迹和可迁移策略，注册到 Layer 2，能力缺口聚类为新的原子技能）。

- **多智能体协作架构**：超过十二个专职智能体（科学家、代码审查员、重新设计智能体等），核心原则为**集中式决策+专职执行**：中央优化智能体直接决策"问题是什么、应尝试什么、如何解释结果"，专职智能体只执行边界清晰的任务，避免深层委托链中的上下文丢失。

- **数据感知优化**：在基线评估与优化循环之间，系统将评估结构分为三类（离散检查器、基于标准的评估、连续指标），分别用类型特定方法发现评估维度；对每个维度评估密度、多样性和基线性能；**关键洞察是区分数据缺口与工作流问题**——有充足多样训练数据但性能低说明是工作流问题，数据缺失才是缺口；只在真正缺口时生成针对性的综合数据，合成比例受缺口信号本身约束。

- **Seed-Epoch 过拟合调节**：核心定义——同一 epoch 内的所有迭代在同一固定种子 ξe 采样得到的数据集 De 上评估，**∆i = Acc(De, vi) − Acc(De, vi−1)**。这消除了数据方差，使 ∆i 的主要变异来源可归因于策略变化。当连续 m 次迭代 |∆i| < ϵ 时认为饱和并推进新种子，新 epoch 用全新数据天然验证策略是否过拟合。验证采用**动量触发策略**：仅在三处执行——基线迭代、epoch 边界、动量事件（从回归中恢复或达到新最佳分）。

- **三个安全保障**：反启发式强制执行（只允许结构性变换如 JSON 解析、编码规范化、null 处理，禁止内容感知的正则匹配、特定问题类型的条件分支、输入-输出查找表）；过拟合检测（训练-验证差距超阈值时限制为纯提示词优化）；基于可修复性的目标校准（按错误可修复性分布计算现实目标上限）。

- **跨层复合循环**：每个优化周期产生**判定（Verdict）**——(∆acc, ∆lat, ∆tok) 多维判断元组——回馈 Layer 2 更新证据置信度 η(ω) 和迁移率 τ(·)。成功提升准确率但倍增延迟的策略成为**仅在某些上下文中有效**的条件智慧，MEGA 不将"好的智慧"视为绝对范畴，而是积累经上下文条件验证的智慧。

- **评估指标**：通过率、每任务令牌消耗、策展延迟、策展 ROI（通过率提升/额外消耗的兆令牌数）。
