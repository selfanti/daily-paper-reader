## 摘要
长时程智能体累积的轨迹涵盖数百个交织的推理、动作和观察步骤，其中回答查询可能依赖于深埋在历史中的证据。外部记忆将此类轨迹存储为结构化表示，但每种结构提供独特且不完整的视图。现有的多记忆系统要么对每个查询读取固定的结构集合，从而膨胀上下文并引入噪声，要么将每个查询路由到单一结构，从而阻止互补证据的组合。对AMA-Bench的受控分析表明，最优记忆配置通常既不是单一结构，也不是全部结构的并集，而是多种结构记忆的定制组合，该组合随查询和任务需求而变化。受这些发现启发，我们提出了结构级动态选择：从专门记忆结构库中选择并融合查询自适应的子集。我们提出MESA（一种用于长时程智能体的多结构证据选择框架），它为每条轨迹构建五个互补的结构视图，并从端到端的答案级反馈中学习，为冻结的答案模型选择和融合查询特定子集。为了在这种弱监督下学习，MESA采用带有先验引导搜索和UCB引导调度的优化，以平衡探索与利用。在AMA-Bench上，MESA比最强基线高出8.5%，同时比全结构备选方案少使用41%的证据标记。

## Abstract
Long-horizon agents accumulate trajectories spanning hundreds of interleaved reasoning, action, and observation steps, where answering a query may depend on evidence buried far back in the history. External memory stores such trajectories as structured representations, yet each structure provides a distinct and incomplete view. Existing multi-memory systems either read a fixed set of structures for every query, inflating context and introducing noise, or route each query to a single structure, preventing the composition of complementary evidence. A controlled analysis on AMA-Bench shows that the optimal memory configuration is typically neither a single structure nor the full union, but a tailored composition of multiple structural memories that varies with query and task demands. Motivated by these findings, we formulate structure-level dynamic selection: selecting and fusing a query-adaptive subset from a library of specialized memory structures. We propose MESA (a Multi-structure Evidence Selection framework for long-horizon Agent), which builds five complementary structure views of each trajectory and learns from end-to-end answer-level feedback to select and fuse a query-specific subset for a frozen answer model. To learn under this weak supervision, MESA employs harness optimization with prior-guided search and UCB-guided scheduling to balance exploration and exploitation. On AMA-Bench, MESA outperforms the strongest baseline by 8.5% while using 41% fewer evidence tokens than the all-structure alternative.

# 论文总结：MESA——面向长时程智能体记忆的任务自适应多结构证据选择

## 1. 核心问题与整体含义

- 长时程智能体在执行复杂任务时，会累积包含数百个推理、动作和观察步骤的轨迹，后续查询可能依赖很早之前产生的证据。
- 将完整轨迹直接喂给长上下文 LLM 既昂贵也不可靠；截断和压缩又可能丢失关键细节。因此需要外部记忆系统对历史进行结构化存储和检索。
- 现有记忆系统依赖单一结构（如摘要、时间存储、知识图谱、向量库、原始轨迹），但每种结构都只提供不完整、有偏的视图：
  - 摘要缺步骤细节；时间存储依赖显式锚点；图谱缺步骤顺序；向量库可能返回相似但错误的步骤；原始轨迹噪声大。
- 多结构混合系统存在两种极端：
  - **固定读取全部结构**：每个查询都用所有结构，导致上下文膨胀、引入无关噪声；
  - **单一路由**：每个查询只选一个结构，无法组合互补证据。
- 论文通过受控实验发现：**最优记忆配置往往既不是单一结构，也不是全部结构的并集，而是随查询和任务变化的中间子集**。
- 据此提出**结构级动态选择**问题，并设计 MESA 框架，用答案级反馈学习“选哪些结构、如何融合”的策略，以同时提升答案质量和记忆读取效率。

## 2. 方法论

### 2.1 核心思想
构建五种互补的记忆结构，针对每个查询动态选择一个非空子集，检索并融合证据后交给冻结的答案模型；学习过程只优化选择策略，其余组件固定。

### 2.2 形式化
- 记忆结构定义为“表示 + 访问接口”的综合体。
- 对历史 τᵢ，构建 K=5 个结构：`M_i^(k) = B_k(τᵢ)`，其中 B_k 是固定构建器。
- 选择向量 `z ∈ {0,1}^K`，非空约束 `‖z‖₀ ≥ 1`，动作空间共 2⁵−1=31 种组合。
- 选择器 `S_ρ(qᵢ, cᵢ) → zᵢ`，cᵢ 是查询及可观察上下文（不含答案等结果信息）。
- 证据融合：`Eᵢ(zᵢ) = Compose({Γ_k(qᵢ, Mᵢ^(k)) | zᵢ^(k)=1})`，Γ_k 是固定访问机制。
- 答案生成：`ŷᵢ = F(qᵢ, Eᵢ(zᵢ))`，F 为冻结的答案模型。
- 效用：`rᵢ = Eval(ŷᵢ, yᵢ)`。
- 优化目标：正则化验证目标 `J_val(ρ) − λ·C_val(ρ)`，其中 J 是准确率，C 是平均证据 token 数，λ 权衡精度与成本。

### 2.3 先验引导的 Harness 优化
- 传统提示或完整程序搜索空间过大，且只有稀疏的答案级反馈，难以直接优化。
- MESA 将搜索限制在**先验方向**集合 A 内，每个方向代表一种策略生成/修改机制（如需求推断、结构效用估计、子集构建、证据感知、鲁棒性成本控制）。
- 算法流程（Algorithm 1）：
  1. 用全结构策略初始化存档 P；
  2. 每次迭代用 **UCB（Upper Confidence Bound）** 选择先验方向；
  3. LLM 提议者生成三个候选：利用候选、探索候选、失败修复候选；
  4. 验证合法性 → 在训练集上拟合 → 在验证集上评估 → 加入存档；
  5. 搜索预算用尽后，返回存档中正则化验证目标最高的策略。
- UCB 公式：`UCB(a) = mean J_val(a) + β√(log(N+2)/(n_a+1))`，平衡探索与利用。

## 3. 实验设计

### 3.1 数据集
- **AMA-Bench**：大规模长时程智能体轨迹问答基准，使用其实世界子集，共 208 个 episode、每 episode 12 个专家问答、总计 2,496 问。
  - 覆盖 6 个智能体领域：Web 任务执行、开放世界工具 QA、Text-to-SQL、软件工程、游戏、具身 AI。
  - 覆盖 4 种记忆能力：回忆、因果推断、状态更新、状态抽象。
- **LoCoMo**：长期对话记忆基准，10 个多会话对话、1,986 个问答，排除 446 个对抗性问题后评估 1,540 个（841 单跳、282 多跳、321 时间、96 开放域）。

### 3.2 对比基线
- 长上下文直接输入；
- 稀疏检索 BM25、稠密检索 Qwen3-Emb-4B；
- 代表性长期记忆系统：MemGPT、HippoRAG2、Mem0、MemoRAG、A-Mem、EMem、Hindsight；
- 多结构系统：Hindsight；基准专用 SOTA：AMA-Agent。

### 3.3 指标
- AMA-Bench：LLM-as-judge 准确率；
- LoCoMo：F1 分数；
- 同一评测协议对所有方法统一使用固定 judge 提示。

### 3.4 实现细节
- AMA-Bench 按 episode 级划分训练/验证/测试，比例 2:2:6；随机划分重复 5 次取均值（减少划分敏感性）。
- LoCoMo 用对话无关的 2:2:6 划分。
- 答案模型为 Qwen3-32B 与 Gemma-4-31B，greedy decoding。
- 优化迭代 30 轮，同一 LLM 用于 meta-harness 优化。

## 6. 主要结论与发现

- **中间子集优于单结构与全结构**：消融扫描表明大多数任务类别的最佳组合是多结构但非全部。
- **无固定组合普遍最优**：最优子集随领域和记忆能力变化，因此必须查询自适应。
- **MESA 在 AMA-Bench 上大幅领先**：
  - Qwen3-32B 下达到 65.1% 总体准确率，比最强基线 AMA-Agent 高 **8.5 个百分点**，比长上下文高 12.5。
  - 在四个记忆能力中三个最优；在六个领域中四个最优（Software、Text2SQL 提升尤为显著）。
  - Gemma-4-31B 下同样高出最强基线 6.4 个百分点。
- **效率显著提升**：MESA 平均选择 2.8 个结构，每查询 11.0k 证据 token，比全结构（18.7k）少 **41.2%**，准确率却更高（65.1% vs 63.7%）。
- **可扩展性**：同一框架在 LoCoMo 上 F1 达 49.0%，比最强基线高 1.8%，证明可迁移到对话记忆任务。
- **策略可解释**：学习到的选择策略是显式、可检查的规则（如关键词映射、无关键词时按领域/能力回退）。
- **组件有效性**：去掉先验方向或 UCB 均导致准确率下降与方差增大，验证了优化的必要性。

## 7. 优点

- **问题定义精准**：首次系统研究“结构级动态选择”，弥补了固定全读与单一路由之间的空白。
- **动机有据**：先通过穷举全部 31 个子集做受控分析，再提炼问题公式，说服力强。
- **模块化设计**：只优化选择策略，记忆构建、检索、答案模型均固定，便于将新结构或新答案模型接入。
- **弱监督学习方案巧妙**：用先验方向约束搜索空间，用 UCB 平衡探索与利用，用 LLM 生成候选策略，能够在只有答案级反馈下高效学习。
- **效率与精度兼顾**：减少 41% 证据 token 的同时提升准确率，实际部署价值高。
- **实验分析细致**：包含多维度剥离（能力、领域、成本、judge 鲁棒性、划分敏感性），并展示了策略演化过程，透明可信。
- **策略可解释性强**：最终策略为可读规则，便于错误分析和人工审查。

## 8. 不足与局限

- **结构覆盖有限**：只使用五种代表性结构，未涵盖时间超图、程序化记忆、语义缓存等其他可能设计；结论能否推广到更多结构有待验证。
- **未联合优化**：构建器、检索器、组合器与答案

续接“8. 不足与局限”最后被截断处：

- **未联合优化**：构建器、检索器、组合器与答案模型均被冻结，MESA 只在结构子集层面做“开/关”，无法通过端到端梯度或交互反馈调整记忆内部表示、检索策略或融合方式。这意味着结构内部的潜在改进空间未被利用，选择策略的性能上限受限于固定的单结构质量。
- **优化目标权重 λ 的敏感性问题**：λ 先验地权衡准确率与证据成本，但论文只报告了一个固定 λ 下的结果，未系统研究 λ 对最优策略选择的影响。不同任务可能对成本敏感度不同，单点敏感性分析缺失。
- **先验方向集合依赖人工设计**：五个先验方向（需求推断、结构效用估计等）由作者手工定义，可能带有主观性。若替换为其他归纳偏置，结论是否稳健未验证。
- **LLM 作为优化器与决策器的固有局限**：候选策略由 LLM 提议，评估依赖同一个 LLM 的 judge，存在自我偏置风险。且策略搜索预算 30 轮相对较小，无法保证收敛到全局最优，可能只是局部“足够好”。
- **评估规模与领域覆盖不均衡**：AMA-Bench 虽覆盖 6 个领域，但每领域 episode 数有限；LoCoMo 仅 10 个多会话对话，难以支撑强统计结论。论文未报告置信区间或显著性检验，只有均值比较，统计功效存疑。
- **证据融合方式过于朴素**：Compose 仅将所选结构对应的检索结果拼接起来，未考虑结构间矛盾、冗余权重和顺序位置。更聪明的融合（如按证据质量加权、去重、压缩摘要）可能进一步提升上限。
- **缺少失败案例的定性分析**：论文没有分析 MESA 仍然答错的案例究竟源于结构缺失、选择错误还是生成错误，因此缺乏可操作的改进指引。

综上，MESA 提出了一个新颖且实用的结构级动态选择框架，实验设计与分析均属上乘，但尚存上述可改进之处。
