## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可复用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将所提供的指导转化为适当的行动。然而，专门用于提升这种技能利用能力的方法仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这种目标提供的监督有限，且难以捕捉策略在利用所提供技能方面的细微差异。我们提出了BCSD（双向上下文自蒸馏），一个将自蒸馏与强化学习相结合的框架，用于训练LLM智能体更有效地利用外部技能。与先前依赖单一特权上下文的自我蒸馏方法不同，BCSD从两个互补的技能上下文视角评估每条轨迹。增强视角引入更高级的元技能指导，而缩减视角则修剪通用指导以突出任务特定技能。它们互补的令牌级信号被结合以重新缩放RL优势。在ALFWorld和WebShop上的实验表明，BCSD在不同模型规模下取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强和缩减上下文视角的互补贡献。代码将发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

- **核心问题**：现有工作很少关注一个关键问题——如何在不内化技能的前提下，让策略模型更有效地使用外部上下文中的显式技能？现有基于技能的强化学习训练通常只依赖任务级稀疏奖励，这种粗粒度监督难以区分每个决策是否真正参考或遵循了所提供的技能信息，导致策略难以学习有效利用技能。作者指出已有自蒸馏方法（OPSD）使用单一特权上下文产生token级信号，但存在信息泄露、优化不稳定、"教师-学生差距"可能放大了与任务无关的文体偏移或捷径token等问题。

- **意义**：本文识别了一个此前被忽视的重要方向——训练LLM智能体更好地利用外部技能，而非简单生成更好的技能或将技能内化为参数，这一视角对技能型智能体的训练范式具有重要意义。

### 二、方法论：BCSD 框架

**（1）核心思想**

BCSD 将自蒸馏与强化学习（GRPO）结合，从两个互补的上下文视角（增强视图与精简视图）来评估同一条策略生成的轨迹，利用两个视图产生的token级 log-probability 差值来重缩放原始GRPO优势，从而在保留环境奖励方向的前提下提供更细粒度的信用分配信号。同一策略在两个不同上下文下进行自蒸馏，使信号具有可比性，同时避免了单一特权上下文带来的偏差。

**（2）基础设定**

- 采用层次化 SkillBank：基础上下文 `C0 = (Q, G, Sc)`。其中 Q 为任务查询，G 为通用技能（General Skill），Sc 为任务特定技能（Task-specific Skill）。
- 每条轨迹 τi 通过基础上下文采样，并获得结果级奖励 ri；GRPO 计算组内相对优势：

<div align="center">

A<sup>GRPO</sup><sub>i</sub> = (r<sub>i</sub> − μ<sub>r</sub>) / (σ<sub>r</sub> + ε)

</div>

**（3）Meta-Skill 提取与刷新**

- 为每个任务类型 c 维护一个与策略相关的 **Meta-Skill M<sub>c</sub>**，它是对"如何有效使用现有技能"的高层文本指导。它是训练期间教师（Teacher）独有的特权上下文，不进入学生上下文，推理时也不使用。
- 通过一个冻结的外部 LLM，对比成功/失败轨迹的证据集（成功轨迹缓冲、失败轨迹缓冲）来提取初始 Meta-Skill；并在每个验证窗口后，基于最新收集的轨迹**动态刷新**它，以跟踪策略不断演化的技能利用模式。

**（4）双向上下文构建**

- **增强视图（Augmented Context）C1**：`C1 = (Q, G, Sc, Mc)`。引入高层 Meta-Skill 指导，提供策略依赖的"技能使用方式"建议，从正向补充信息；
- **精简视图（Pruned Context）C2**：`C2 = (Q, Gp, Sc)`。外部LLM在训练前一次性将通用技能 G 中冗余的内容删除（保留必要程序性信息），得到精简后的 Gp。该视图减少了干扰信息，突出任务特定技能 Sc，提供聚焦的参照。

**（5）双向信号融合与优势重缩放**

- 对固定的响应序列，分别计算两个视图下每个token的对数概率差：

<div align="center">
Δ<sup>aug</sup><sub>i,t</sub> = log π<sub>θ</sub>(y<sub>i,t</sub>|C1, y<sub>i,&lt;t</sub>) − log π<sub>θ</sub>(y<sub>i,t</sub>|C0, y<sub>i,&lt;t</sub>)<br>
Δ<sup>pru</sup><sub>i,t</sub> = log π<sub>θ</sub>(y<sub>i,t</sub>|C2, y<sub>i,&lt;t</sub>) − log π<sub>θ</sub>(y<sub>i,t</sub>|C0, y<sub>i,&lt;t</sub>)
</div>

- 融合：Δ<sub>i,t</sub> = α·Δ<sup>aug</sup><sub>i,t</sub> + (1−α)·Δ<sup>pru</sup><sub>i,t</sub>；
- 通过权重 w<sub>i,t</sub> 对优势进行重缩放（不改变方向）：

<div align="center">
w<sub>i,t</sub> = clip(exp(sign(A<sup>GRPO</sup><sub>i</sub>)·Δ<sub>i,t</sub>), 1−c, 1+c)<br>
A<sup>BCSD</sup><sub>i,t</sub> = A<sup>GRPO</sup><sub>i</sub>·[(1−λ<sub>n</sub>) + λ<sub>n</sub>·w<sub>i,t</sub>]
</div>

- λ<sub>n</sub> 是随训练步数 n **线性衰减**的系数，从 λ0 衰减到 0：早期提供较强的上下文指导，后期逐渐回归环境奖励主导的优化。

**（6）最终目标**

采用标准 GRPO 裁剪目标，将原始优势替换为 A<sup>BCSD</sup><sub>i,t</sub>，并加入KL正则：

<div align="center">
L<sub>BCSD</sub>(θ) = −E<sub>i,t</sub>[ min(ρ<sub>i,t</sub>·A<sup>BCSD</sup><sub>i,t</sub>, clip(ρ<sub>i,t</sub>, 1−ε, 1+ε)·A<sup>BCSD</sup><sub>i,t</sub>) ] + βL<sub>KL</sub>

### 六、主要结论与发现

1. **BCSD 在跨模型规模下取得最优综合性能**：在 Qwen2.5-7B 上，ALFWorld 平均成功率最高达 83.6，WebShop 成功率达 78.1；在 Qwen2.5-3B 上提升尤其显著，比最强基线高出 5.4（ALFWorld）、9.4（WebShop成功率）个百分点；在 Qwen3-1.7B 上也获得最高或并列最高的结果。
2. **两个上下文视图互补贡献明显**：单独去除任何一个视图都会造成显著性能下降，说明增强视图和精简视图提供的是互补的token级信号；
3. **Meta-Skill 的动态更新至关重要**：固定 Meta-Skill 导致性能大幅下降（尤其在 WebShop 上），刷新机制保证其与策略演化保持一致；
4. **λ 衰减策略有效**：保持恒定重缩放强度会阻碍后期奖励驱动的优化，线性衰减策略能兼顾早期指导与后期自主优化；
5. **BCSD 增强了外部技能的实际依赖度**：移除任务特定技能后，BCSD 的成功率下降幅度大于 Skill_GRPO*（ALFWorld：−2.3 vs −0.8；WebShop：−7.8 vs −6.2），说明其更多收益来自"利用外部技能"而非"记忆任务知识"；
6. **训练早期加速明显**：BCSD 在训练的早期阶段（如 WebShop 第60步）迅速拉开与基线的差距，且后续训练过程稳定，无不理想的性能回退；
7. **两个视图的token级信号一致性仅约50%**（波动在47%~53%），证明二者提供了实质性不同的、非冗余的监督信息。

### 七、优点

1. **问题定位新颖且实际**：明确将"提升智能体利用外部技能的能力"与"生成更好的技能"和"内化技能"区分开来，填补了研究空白，在实践中有较强的应用价值（如保留技能的可编辑性）；
2. **双向上下文机制设计巧妙**：增强视图从"正向"提供高层Meta-Skill指导，精简视图从"反向"排除冗余干扰突出任务核心，与单一特权上下文的自蒸馏相比，信号更加互补和可靠，也解决了单一教师上下文可能带来的信息泄漏或分布偏移问题；
3. **保持优化方向不反转**：BCSD 只对 GRPO 优势的大小进行重缩放，不改变其符号方向，保留了环境奖励的权威性，避免自蒸馏信号与任务目标冲突；
4. **与策略演化的动态对齐**：Meta-Skill 通过定期刷新与策略当前的行为模式保持同步，这一点非常合理——策略能力在RL训练中不断改变，固定的技能使用指导会很快过期；
5. **实验验证充分、分析深入**：不仅报告了最终结果，还进行了任务技能依赖分析、token级信号一致性分析、训练动态对比，从多个角度解释了方法"为什么有效"；
6. **保留技能的显式性和可编辑性**：智能体在推理时仍然依赖显式外部技能，保证了技能对用户来说可审计、可干预、可替换，在安全性和可控性上比参数内化方法更优。
