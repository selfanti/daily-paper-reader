## 摘要
自进化方法通过从底层LLM中采样轨迹并从中学习来提升LLM智能体的能力。然而，这些方法难以超越智能体的固有能力边界进行学习，因为智能体无法在困难样本上采样出正确的轨迹以供进一步改进。在本文中，我们提出了一种零阶自进化框架，通过对LLM参数进行扰动以适应困难样本，而无需任何轨迹标注，从而使智能体能够超越其能力边界进行学习。具体而言，我们扰动LLM的LoRA参数，运行智能体，计算扰动参数和原始参数下的损失，并利用损失差来估计梯度，进而更新LoRA参数。我们使用更新后的LLM采样轨迹进行监督微调，以突破智能体的能力边界，形成一个闭环的自进化循环。我们引入了并行扰动推理机制和自适应查找机制，以降低零阶优化中的时间消耗，并使用答案困惑度损失来提供平滑且稳定的零阶损失值。在多个深度研究基准上的实验表明，我们的方法获得了显著更多的成功轨迹，并且持续优于强基线，尤其在困难样本上。代码和发布的工件可在 https://github.com/hidk1911/ZOForLLMAgents 获取。

## Abstract
Self-evolving methods improve the capabilities of LLM agents by sampling trajectories from the underlying LLMs and learning from these trajectories. However, these methods struggle to learn beyond the inherent capability boundary of the agents, since the agents cannot sample correct trajectories on difficult examples for further improvements. In this paper, we propose a zeroth-order self-evolution framework that enables agents to learn beyond their capability boundary by perturbing LLM parameters to adapt to difficult examples without any trajectory annotations. Specifically, we perturb LoRA parameters of LLMs, run the agent, compute the losses under the perturbed and original parameters, and use the loss difference to estimate gradients and further update the LoRA parameters. We sample trajectories using the updated LLMs for supervised fine-tuning to break through the capability boundary of the agents, forming a closed self-evolution loop. We introduce a parallel perturbation inference mechanism and an adaptive lookup mechanism to reduce time consumption in zeroth-order optimization, with an answer perplexity loss that provides smooth and stable zeroth-order loss values. Experiments on multiple deep research benchmarks show that our method obtains substantially more successful trajectories and consistently outperforms strong baselines, especially on difficult examples. The code and released artifacts are available at https://github.com/hidk1911/ZOForLLMAgents.

## 一、核心问题与研究动机

- **背景**：LLM 智能体在 Deep Research（深度研究）等复杂信息检索与推理任务中展现出巨大潜力。自进化方法（Self-Evolving）通过从 LLM 自身采样推理轨迹并用于 SFT 或 RL 训练来提升智能体能力。
- **核心问题**：现有自进化方法受限于智能体的**固有能力边界（Capability Boundary）**——在困难样本上，智能体无法采样到正确轨迹，导致缺乏高质量训练信号，无法实现进一步突破。
- **关键洞察**：论文通过梯度分解分析指出，传统的固定轨迹一阶更新仅计算 `g_fixed`，缺乏轨迹分布层面的优化信号；而 RL 方法在全部轨迹均失败时（奖励相同、基线抵消），策略梯度估计 `ĝ_RL = 0`，同样无法提供有效更新。
- **解决思路**：提出**零阶自进化框架（Zeroth-Order Self-Evolution）**，通过扰动 LLM 的 LoRA 参数、比较扰动前后损失差来估计梯度，使智能体无需轨迹标注即可适应困难样本，从而发现超出当前能力边界的成功轨迹。

## 二、方法论

### 1. 核心思想

针对每个困难实例 (qi, yi)，附加一个**实例专属 LoRA 模块** wi = [Ai, Bi]，仅依赖问答对（QA pairs）作为反馈，通过零阶优化（黑盒优化）更新参数。

### 2. 关键技术流程

- **参数扰动**：沿随机方向对 LoRA 参数施加高斯扰动，扰动后参数为 θp_i,k = θ + (Bi + σϵB_i,k)(Ai + σϵA_i,k)，其中 σ 为扰动尺度。
- **轨迹采样与损失计算**：扰动策略在工具环境中生成完整轨迹，计算**答案困惑度损失**（Answer Perplexity Loss）；同样对未扰动策略采样基线轨迹并计算基线损失。
- **梯度估计与参数更新**：利用扰动损失与基线损失的差值构造零阶梯度估计（类似有限差分），再用 Adam 更新 LoRA 参数。当某扰动方向降低损失时，参数朝该方向移动；反之则远离。
- **闭环自进化**：优化后的智能体采样出成功轨迹（答案正确或损失足够低），存入高质量轨迹缓冲区，用于后续 SFT，形成"零阶优化 → 轨迹发现 → SFT → 能力提升"的闭环。

### 3. 三个关键机制

| 机制 | 作用 | 技术要点 |
|------|------|----------|
| **并行扰动推理**（Parallel Perturbation Inference） | 降低零阶优化时间开销 | 不同扰动分支共享同一 backbone 前向计算结果 θx，仅并行计算轻量 LoRA 分支 (B+ϵB)(A+ϵA)x，避免逐扰动重复计算主干 |
| **自适应查找机制**（Adaptive Lookup Mechanism） | 减少重复工具调用 | 维护工具调用缓存池；搜索类采用语义相似匹配、访问类采用 URL 严格匹配，命中则直接复用结果 |
| **答案困惑度损失**（Answer Perplexity Loss） | 提供平滑稳定的零阶损失 | 将生成答案替换为正确答案，计算轨迹条件下正确答案的负对数似然：ℓans = −(1/M)Σ log πθ(yj | q, τ\ans, y<j)；相比二元奖励或 BERT 相似度损失，能对错误轨迹提供有用梯度信号（如检索到相关证据但答案错误时仍获得部分奖励） |

## 六、主要结论与发现

1. **零阶优化能突破能力边界**：通过扰动 LoRA 参数、损失差估计梯度，智能体能够在困难样本上发现原本无法采样到的成功轨迹。
2. **性能显著优于强基线**：在 GAIA 和 WebWalkerQA 上均大幅超越 ReAct 基础智能体，并优于依赖 GPT 等强模型标注轨迹的现有深度研究智能体。
3. **答案困惑度损失是关键设计**：相比 BERT 语义损失和 LLM-as-a-Judge 损失，在困难样本上收敛更稳定、效果更好。
4. **优化轨迹发现能力可泛化**：在非检索、非逐字匹配子集及新基准（BrowseComp）上均有效，说明改进不局限于直接检索复制答案。
5. **额外采样无法替代参数优化**：在相同 rollout 预算下，初始策略的 Best-of-N 采样在 Pass@8 即饱和，而本文方法仍持续增长，证明损失引导的参数更新比单纯增加采样更有效。

## 七、方法亮点与优势

- **理论视角新颖**：首次将零阶优化引入 LLM 智能体自进化场景，解决了"失败轨迹无学习信号"的根本困境。
- **无需过程标注**：仅用 QA 对即可驱动优化，大幅降低人工标注成本。
- **工程优化扎实**：并行扰动推理（共享 backbone 前向）与自适应查找机制（缓存工具结果）有效解决零阶优化在 agentic 场景下的采样开销问题。
- **损失函数设计巧妙**：答案困惑度损失为错误轨迹提供连续、可微的代理信号，增强优化稳定性。
- **闭环自进化框架完整**：实例级零阶优化发现轨迹 → 全局 SFT 吸收能力 → 迭代提升，形成可持续的自进化循环。
- **开源与负责任发布**：代码、轨迹数据与训练模型开源，并详细说明了数据过滤、隐私过滤等负责任研究措施。

## 八、不足与局限

- **模态覆盖有限**（作者自述）：仅在纯文本 LLM 智能体上验证，未扩展到多模态智能体。
- **训练数据规模较小**：仅使用 WebShaper 筛选的 304 个 QA 对，数据多样性存疑。
- **对比公平性限制**：与现有深度研究智能体的对比依赖论文报告值，各方法所用骨架模型、搜索框架和训练数据不同，难以完全对照。

- **环境依赖与稳定性**：深度研究任务对网络延迟、工具稳定性、环境变化敏感，方法的稳定性在真实部署中可能受影响。
- **超参数与初始化依赖**：实例专属 LoRA 需要为每个样本进行优化，推理/训练流程复杂，实际部署时存在额外管理成本。
