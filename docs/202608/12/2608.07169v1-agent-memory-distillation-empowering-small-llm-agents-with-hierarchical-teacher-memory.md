## 摘要
记忆系统在提升智能体性能方面已展现出潜力，但其在小语言模型上的潜力在很大程度上仍未得到探索——小模型往往难以独自生成足够数量的成功轨迹。我们提出智能体记忆蒸馏（Agent Memory Distillation, AMD），一种免训练框架，通过层级记忆将结构化知识从大型教师智能体迁移至小型学生智能体。AMD 从成功的教师轨迹中构建三种互补的记忆类型：工作流记忆编码任务级策略，子任务记忆提供中间粒度的具体行为示例，函数记忆捕获每个函数的调用约定与常见陷阱。工作流与子任务记忆在每个任务开始时主动注入，而函数记忆则在工具调用出错时被动检索。我们使用四个学生模型（4B-8B参数）在三个工具使用基准上评估AMD，以GPT-5-mini作为教师，在AppWorld、BFCL V3和ToolSandbox上分别实现了27.2个百分点、11.2个百分点和3.4个百分点的平均准确率提升，并且持续优于现有基于记忆的基线方法。进一步分析表明，子任务记忆贡献了最大增益；教师有效性既取决于教师能力也取决于学生兼容性；4B规模的学生从AMD中获益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

- 这是第一个系统性地研究"教师到学生记忆蒸馏"（teacher-to-student memory distillation）的工作，专门针对能力鸿沟问题，通过层级化记忆设计弥合这一差距，为小模型智能体的能力提升提供了免训练的新路径。

## 2. 论文提出的方法论

### 核心思想
AMD 的核心思想是：将教师智能体的成功轨迹转化为**三种不同粒度的层级化记忆**，使小模型能够在任务规划、执行策略、API调用三个层面分别获得适当的指导，从而跨越能力鸿沟。

### 三种记忆类型

| 记忆类型 | 粒度 | 内容 | 注入时机 |
|---------|------|------|---------|
| **工作流记忆（Workflow Memory, WF）** | 任务级 | 高层任务完成策略的自然语言描述，包括涉及的应用/工具、关键前置条件、决策规则、验证线索、常见失败模式；具体值替换为类型占位符（如 `<ID>`、`<EMAIL>`） | 任务开始时主动注入 |
| **子任务记忆（Subtask Memory, ST）** | 中间级 | 教师轨迹被分割为语义连贯的子任务片段（如"登录Venmo""获取待处理请求"），每段包含标签、描述和具体的可执行代码/工具调用示例 | 任务开始时主动注入（学生先将任务分解为至多6个子任务标签，每个标签检索top-1记忆） |
| **函数记忆（Function Memory, FN）** | 函数级 | 单个函数的调用约定、参数模式、具体成功调用示例，可选附加API文档；按函数名索引 | 工具调用出错时被动检索注入 |

### 关键设计细节
- **检索机制：** 所有记忆条目用 `text-embedding-3-small` 编码，通过余弦相似度检索；低于相似度阈值的候选被丢弃；默认 top-k=1。
- **去重机制：** 多个子任务标签映射到同一记忆条目时进行去重，避免重复注入。
- **免训练：** 整个框架不涉及任何模型参数更新，纯推理时提示工程方法。
- **算法流程（简化描述）：** 任务开始时，先用任务指令检索工作流记忆注入系统提示；学生分解任务为子任务标签序列，逐标签检索子任务记忆并注入；进入执行循环，当工具调用返回错误时，提取失败函数名并在函数记忆中检索示例，追加入上下文以纠正下一步动作。

## 3. 实验设计

### 基准数据集（Benchmarks）
1. **AppWorld**：多应用智能体基准，通过Python API调用与模拟真实应用（邮件、消息、支付等）交互，用数据库状态单元测试衡量成功，168个任务。
2. **BFCL V3**：函数调用基准，要求正确调用函数并传参，每轮需匹配预期API状态，200个任务（multi-turn base子集）。
3. **ToolSandbox**：有状态、对话式工具使用基准，依赖共享世界状态和LLM模拟用户，129个场景（base子集）。

### 模型配置
- **教师智能体：** GPT-5-mini（另有教师替换实验使用 GPT-5.5、DeepSeek V4 Pro、Qwen3-32B）。
- **学生智能体：** Qwen3-4B、Qwen3-8B、Gemma4-E4B、Llama3.1-8B（另有效果分析实验使用 Qwen3-1.7B 和 Qwen3-14B）。
- **编码模型：** OpenAI text-embedding-3-small。

### 对比方法
- **Zero-shot**（学生基线）。
- **ReasoningBank**：扁平、任务级记忆方法，每任务检索单个推理见解。
- **MemP**：层级化过程记忆方法，但设计初衷是同模型自我进化而非跨模型迁移。
- **SASM**：子任务级检索粒度方法，但仅单一统一记忆类型，不区分规划/执行/纠错知识。
- **Student Memory**：使用学生自生成记忆而非教师记忆的变体。
- 所有基线均从相同的教师轨迹生成记忆，按照各自协议应用于学生推理。

## 6. 论文的主要结论与发现

1. **AMD显著提升小模型性能**：在AppWorld、BFCL V3、ToolSandbox上，相较零样本分别平均提升27.2%p、11.2%p、3.4%p，且持续优于所有基于记忆的基线。
2. **现有记忆方法迁移效果不稳定**：ReasoningBank、MemP、SASM在教师-学生跨模型迁移设置下性能提升不连贯，甚至会降低性能，说明直接迁移平铺或结构不当的教师知识会引入噪声或超出小模型理解能力。
3. **学生可以达到甚至超越教师水平**：AppWorld上Gemma4-E4B（54.17%）和Qwen3-8B（51.79%）超过教师的50.00%；BFCL V3上三个学生超过教师；平均精度上Gemma4-E4B和Qwen3-8B也超过教师。
4. **子任务记忆贡献最大**：在消融中，ST记忆提供了最大的增量收益（尤其AppWorld上WF→WF+ST提升约+25%p），说明中间粒度的具体行为示例对复杂长周期任务最关键。
5. **教师有效性与教师能力+师生兼容性共同相关**：强教师（GPT-5.5）对较强者（Qwen3-8B）效果最好，但对较弱者（Qwen3-4B），中等教师（GPT-5-mini）反而优于更强者（DeepSeek V4 Pro），表明能力鸿沟仍是重要限制因素。
6. **4B规模学生获益最多**：准确率随模型规模单调递增，但增益在4B处达到峰值（+34.52%p），更大模型边际收益递减。
7. **记忆表示应随粒度适配**：高层规划知识用自然语言最佳，低层执行知识用代码格式最佳；全部换成自然语言会导致精度从49.40%跌至26.19%。
8. **k=1最优**：增加检索数量会降低性能，小模型对低排名、弱相关记忆的干扰更敏感。
9. **记忆蒸馏在评估任务与记忆构建分离时仍然有效**：两种分离协议均保持从零样本到完整配置的单调增益，说明收益来自记忆的真实泛化价值而非任务泄漏。

## 7. 优点

1. **问题选取精准**：识别出"小模型自生成记忆质量差"这一关键痛点，并针对性地提出从更强的教师迁移经验，研究方向具有明确的应用价值。
2. **方法设计有原则性**：不像简单蒸馏一锅端，而是根据知识粒度（任务级/中间级/函数级）差异化建模，并对应不同的注入时机（主动/被动词），设计逻辑清晰。
3. **免训练、低成本**：无需模型微调即可获得大幅性能提升，对算力有限的场景非常友好，也便于快速部署在任意新模型上。
4. **诊断深入**：定性案例研究（图6）清晰地展示了三种记忆如何级联地解决不同层面的失败模式（规划错误→类型不匹配→字典键错误），非常有说服力。
5. **实验严谨**：除了主实验外，覆盖了教师替换、模型规模、检索数量、记忆表示、重复运行稳健性、训练/评估分离等多维度分析，并且给出了直观的交互效率对比。
6. **发现具有启发意义**：如"4B学生获益最大""教师-学生兼容性比教师绝对能力更重要""检索 k=1 最优"等结论，对后续研究有指导价值。

## 8. 不足与局限

1. **评测范围有限**：
   - 仅覆盖文本工具使用基准（Python API调用或结构化函数调用），未涉及多模态环境、开放代码生成、网页操作等行动空间，泛化性未验证。
   - 三个基准中教师本身准确率都不高（28.68%~50.00%），对教师成功率更高或极低的场景效果未知。

2. **记忆静态性**：
   - 记忆从固定教师轨迹集离线构建，推理时冻结，无法纳入学生在测试时的新成功/失败经验，也不能适应教师演示与学生实际遇到任务之间的分布漂移。

3. **教师选择问题未解决**：
   - 论文明确发现"更强的教师不总是带来更大增益"，但自适应教师选择（如何为给定学生匹配合适教师）仍是开放问题，限制了框架落地时的实用性。

4. **特定模型的不稳定性**：
   - LLaMA3.1-8B在添加FN记忆时出现性能下降（AppWorld 30.36→27.38），说明部分弱指令跟随模型在接收纠错注入时可能偏离计划，框架对极弱模型的稳健性不足。
   - 1.7B学生的绝对性能仍非常有限，框架对过小模型的效果天花板较低。

5. **细节信息缺失**：
   - 未报告算力消耗和推理时延的具体数据。
   - 记忆生成依赖教师LLM的提示质量，但未分析教师轨迹分割、标签质量对最终性能的敏感性。
   - 主实验仅以GPT-5-mini为教师，不同教师家族（如开源模型）下记忆蒸馏效果未知。
