## 摘要
面向自进化LLM智能体的基于学习的记忆系统面临两个紧密耦合的挑战。首先，轨迹索引的效用随交互历史增长，从而将有限的反馈分散到不断扩展的状态空间中。其次，由于轨迹级奖励被共同分配给共同检索到的记忆，不相关的经验可能收到误导性的效用更新，从而进入记忆-奖励陷阱。为了解决这些挑战，我们引入了降阶记忆强化学习（RoMeRL），它使用固定维度的每任务记忆状态来表示不断增长的轨迹索引效用空间，该状态通过结果极性和记忆动态进行分解。RoMeRL通过一组固定的语义坐标来整合新经验，这些坐标的内容随时间更新或替换，从而将反馈集中在有界的效用支持上。理论上，我们证明了这种降阶参数化增加了每个效用坐标收到的平均反馈，并刻画了通用坐标转换模型下错误坐标的稳态占用。在ALFWorld和LifelongAgentBench上的实验表明，RoMeRL提升了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，并将LLM调用减少了21.1%。这些结果表明，降阶效用状态支持高效的自进化智能体记忆，同时限制了持续的奖励污染。代码可在以下网址获取：https://github.com/YOUNG-fnxm/RoMeRL

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. ## 1. 核心问题与整体含义（研究动机与背景）

论文针对**自进化 LLM 智能体**的学习型记忆系统，指出其面临两个紧密耦合的核心挑战：

- **反馈稀释问题**：轨迹级索引的效用（trajectory-indexed utilities）随交互历史不断增长，而可用反馈有限，导致有限反馈被分散到持续膨胀的状态空间中，带来严重的效用“冷启动”问题、更新集中以及低反馈密度。
- **记忆-奖励陷阱（Memory-Reward Trap, MRT）**：由于轨迹级奖励被共同分配给所有被检索到的记忆（bundle-level reward），一些与任务成功无因果贡献、甚至是弱相关、噪声、过时或失败的记忆，可能因出现在成功轨迹中被错误地赋予正向效用更新。

作者进一步发现，简单的“加强探索”（如增加 UCB 探索项）虽能缓解反馈覆盖不足，却会加剧 MRT——因为更广的检索暴露了更多弱相关记忆，使其接收到虚假的正向奖励。

核心研究问题被明确表述为：

> **如何在提升记忆反馈覆盖的同时，不扩大暴露在错误奖励传播中的效用支撑？**

论文将此困境界定为轨迹索引效用学习的内在矛盾：每增加一条新记忆就引入一个新效用变量，而更强的探索又使更多此类变量暴露于可能错误归因的奖励中。为此，作者提出 **RoMeRL（Reduced-Order Memory Reinforcement Learning，降阶记忆强化学习）**，从更根本上重构了记忆强化学习的状态表示，而非仅仅调整探索策略。

## 2. 方法论：RoMeRL

### 2.1 核心思想

用**固定维度的每任务（per-task）记忆状态**替代随历史增长的轨迹索引效用空间。该状态由两个二值维度的笛卡尔积构成：

- **结果极性（Outcome Polarity）**：正（成功，+）与负（失败，−）
- **记忆动态（Memory Dynamics）**：巩固型（Consolidated, C）与自适应型（Adaptive, A）

由此得到 \( \mathcal{I}_{fact} = \mathcal{O} \times \mathcal{D} \)，固定维度 **d = 4**，每个任务的效用状态为：

\[
Z_{g,t} = \Phi(D_{g,t}) = 
\begin{bmatrix}
z^{+,C}_{g,t} & z^{+,A}_{g,t} \\
z^{-,C}_{g,t} & z^{-,A}_{g,t}
\end{bmatrix}
\]

每个坐标内容可随新经验被更新或替换，但语义身份永久固定——任何新轨迹只能更新/替换现有坐标，而不会新增持久化的效用变量。

### 2.2 四个语义坐标的具体选择规则

| 坐标 | 含义 | 内容选取规则 |
|---|---|---|
| **PCC**（正-巩固） | 全局巩固的成功参考 | 保留所有成功轨迹中效率最高（最短步骤）的一个 |
| **PAC**（正-自适应） | 从失败走向成功的首个恢复轨迹 | 保留首次失败之后最早出现的那条成功轨迹 |
| **NCC**（负-巩固） | 积累了正向效用的失败经验 | 在效用超过负向初始化阈值 \( Q^-_{init} \) 的失败轨迹中保留效用最高者 |
| **NAC**（负-自适应） | 当前最近失败状态的跟踪 | 始终保留最近一条失败轨迹 |

### 2.3 检索与效用更新

- 检索分数由语义相似性和学习到的效用联合加权：

\[
score(m^{o,d}_{g,t}) = (1-\omega_Q)\cos(e(x_t), e(m^{o,d}_{g,t})) + \omega_Q Q^{o,d}_{g,t}
\]

- 每个非空坐标均作为候选，取 Top-\( k_{ret} \) 条记忆进入上下文。
- 效用更新沿用标准 Q 学习形式：

\[
Q^{o,d}_{g,t+1} = Q^{o,d}_{g,t} + \alpha \cdot \mathbf{1}[m^{o,d}_{g,t} \in S_t](r_t - Q^{o,d}_{g,t})
\]

- 新坐标内容继承当前坐标效用进行热启动（warm start），随后通过任务结果反馈逐步适应新代表内容。

### 2.4 理论分析

- **Theorem 1（误差-方差分解）**：\( E[(\hat{Q}_i - \theta_i)^2] = (v^0_i + a_i)^2 + \sigma^2_i / n_i \)，表明增加反馈仅降低方差项，无法消除任务级基线与归因偏差构成的信用缺口，额外反馈只会让估计更精确地逼近“原始收益”而非“边际贡献”。
- **Definition 2（MRT 形式化）**：当记忆满足 \( \theta_i \le 0 \) 且 \( \mu_i - v^0_i > 0 \) 时，虽然边际贡献非正，但观测收益高于无此记忆的基线，形成奖励陷阱。\( E[|B_t|] = N_t \rho_t \)，说明受污染支撑随记忆维度线性增长。
- **Theorem 2（反馈预算下界）**：全池估计所有记忆的原始收益需要 \( F_T = O(N_t/\epsilon^2 \log(N_t/\delta)) \) 次更新、\( T = O(N_t/(k\epsilon^2)\log(N_t/\delta)) \) 条轨迹——反馈需求随记忆池规模线性增长。
- **Theorem 3（反馈集中）**：降维后每个坐标平均接收 \( \bar{n}_{fact} = (N_t/4)\bar{n}_{full} \) 条反馈，方差由 \( O(\sigma^2 N_t/(kT)) \) 降为 \( O(4\sigma^2/(kT)) \)。
- **Proposition 1（错误坐标稳态占用）**：在一通用“清洁-错误”马尔可夫转换模型下，活动维度 d 的错误坐标期望数量（≤ \( d\gamma/(\gamma+\lambda) \)）低于全池暴露（\( N_t \rho_{full} \)），当 \( d\gamma/(\gamma+\lambda) < N_t \rho_{full} \) 时成立。

## 6. 主要结论与发现

- **结论 1**：轨迹索引记忆学习会随效用状态增长而稀释反馈，并扩大暴露于 MRT 的持久性支撑——这是该范式的结构性缺陷，而非单纯调参可解决的工程问题。
- **结论 2**：RoMeRL 的降阶效用状态在**不依赖更强探索**的前提下，实现了反馈覆盖率的显著提升（反馈密度 6.0×、Cold-Q 降低 80%），验证了“改变状态表示而非仅调整探索”的正确性。
- **结论 3**：降阶状态还带来显著效率优势——记忆占用减少 84.4%、LLM 调用减少 21.1%，说明结构化角色化的记忆空间比全量积累更经济。
- **结论 4**：MRT 压力测试证明 RoMeRL 受噪声注入影响更小（噪声终占比 0.15% vs MemRL 的 1.02%），替换机制能有效清除污染内容。
- **结论 5**：跨模型迁移实验表明，降阶记忆状态中保存的是**跨骨干可迁移的程序性知识**，可在不同 LLM 上复用于解决问题和减少步骤数。
- **结论 6**：Q 值分层分析显示 RoMeRL 学到的 Q 值并非成功/失败标签的简单代理——高 Q 区间仍保留约 19.9% 的失败衍生记忆，证明效用信号超越了二元结果重放的信息量。

- **维度有界性**：无论任务历史多长，每任务仅维护固定 4 个坐标，从根本上切断了反馈需求随记忆池线性增长的路径。
- **坐标语义可解释**：四个坐标各自有明确语义（最高效成功、失败恢复、高效用失败、最近失败），为记忆内容提供了可审计、可解释的组织框架（附录 D 的案例研究展示了每种坐标的具体使用场景）。
- **实用效率显著**：同时改善任务性能、反馈利用、记忆容量和推理成本，展示了“降阶”作为通用策略的实用价值。
- **经验证据充分**：不仅关注最终性能，还深入分析了反馈密度、噪声鲁棒性、Q 值分布质量、迁移能力等多维度指标。

## 8. 不足与局限

- **因果归因未完全解决**：RoMeRL 仍依赖结果级奖励，只压缩了 MRT 的暴露面，并未从根本上消除信用分配偏差；其“巩固失败经验”的 NCC 坐标在理论上仍可能保留虚假正向效用。
- **理论量难以估计**：Proposition 1 中的转换参数 γ 和 λ 需要坐标级别的因果标签（配对反事实轨迹），在真实环境中获取此类标签的成本极高，限制了理论结果的直接验证。
- **基准覆盖有限**：实验仅在 ALFWorld 和 LifelongAgentBench（OS/DB）三类任务域上进行，均为较短的终端交互/家庭规划任务，缺乏对开放世界、长时程、多智能体协作等更复杂场景的验证。
- **基线覆盖不全**：未与近年其他学习型记忆方法（Memory-R1、Agentic Memory、Fine-Mem、AtomMem 等）进行正面比较，削弱了结论的横向说服力。
- **骨干模型受限**：实验仅限于 API 访问的闭源模型（DS-V4-flash、GPT-5.4-mini），未测试开源可本地部署模型，也未验证对不同能力水平模型（如小型本地模型）的适用性。
- **跨模型迁移测试范围狭窄**：仅在两个模型间迁移，且未对比 MemRL 等基线在相同迁移设置下的表现，难以判断该优势是否 RoMeRL 独有。
- **算力信息披露不足**：未报告 GPU 资源、训练时长等关键算力指标，影响了实验可复现性和成本评估的完整性。
- **主观成分**：轨迹的“最高效”选择、Q 初始化阈值等涉及若干超参数（α、ω_Q、δ 等），虽然有附录给出取值，但对不同任务的自适应调整策略阐述有限。
