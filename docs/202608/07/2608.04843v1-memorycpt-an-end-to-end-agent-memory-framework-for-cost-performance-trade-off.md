## 摘要
长时程LLM智能体需要记忆系统从大规模交互历史中恢复有用的证据，而无需向下游模型传递过多上下文。现有的记忆流水线通常依赖手工设计的启发式规则和重复的LLM调用，这可能会引入冗余上下文和高推断成本。我们提出MemoryCPT，一种端到端可训练的记忆流水线，涵盖离线记忆构建和在线查询条件上下文生成。MemoryCPT包含两个阶段：查询无关蒸馏（QAD），利用显式推理轨迹将模块化记忆构建流水线蒸馏为紧凑模型；以及查询感知检索与摘要（QAR），结合倒数排名融合（RRF）与基于LoRA的摘要器，该摘要器通过群组相对策略优化（GRPO）在成本感知奖励下训练。我们进一步引入单位成本质量（QPC）来量化单位推断成本下的答案质量。在LoCoMo和LongMemEval上的实验表明，MemoryCPT相对于评估的基线改进了成本-性能权衡，同时消融和敏感性分析表征了其各组件的贡献及关键设计选择的效果。

## Abstract
Long-horizon LLM agents require memory systems that recover useful evidence from large interaction histories without passing excessive context to downstream models. Existing memory pipelines often rely on hand-crafted heuristics and repeated LLM calls, which can introduce redundant context and high inference cost. We propose MemoryCPT, an end-to-end trainable agent memory pipeline that spans offline memory construction and online query-conditioned context generation. MemoryCPT consists of two stages: Query-agnostic Distillation (QAD), which distills a modular memory-construction pipeline into a compact model using explicit reasoning traces; and Query-aware Retrieval and Summarization (QAR), which combines reciprocal rank fusion (RRF) with a LoRA-based summarizer trained via Group Relative Policy Optimization (GRPO) under a cost-aware reward. We further introduce Quality per Cost (QPC) to quantify answer quality per unit inference cost. Experiments on LoCoMo and LongMemEval show that MemoryCPT improves the cost-performance trade-off over the evaluated baselines, while ablation and sensitivity analyses characterize the contributions of its components and the effects of key design choices.

## 2. 论文提出的方法论

### 核心思想
MemoryCPT 将记忆过程分解为两个可训练阶段：
- **离线阶段（Query-agnostic Distillation, QAD）**：将教师模型的多模块记忆构建流程蒸馏成紧凑学生模型，构建可复用的情景记忆（episodic）与语义记忆（semantic）。
- **在线阶段（Query-aware Retrieval and Summarization, QAR）**：根据用户查询检索相关记忆，并用一个通过 GRPO 训练的 LoRA 摘要器生成查询条件的紧凑上下文。

### 关键技术细节

#### QAD：查询无关蒸馏
- 教师将记忆构建分解为四个角色：`BatchSegmenter`、`EpisodeGenerator`、`EpisodeMerger`、`SemanticExtractor`。
- 每个角色产生 **推理轨迹（reasoning trace）** 和 **结构化 JSON 输出**，学生模型（Qwen2.5-7B-Instruct 或 Llama-3.2-3B）通过 LoRA（LoRA-A）进行 SFT 蒸馏。
- 训练目标使用标准因果语言建模：
  \[
  L_{QAD} = -\mathbb{E}_{(x,r,y)\sim D_{QAD}}\sum_{t=1}^{|z|}\log p_\theta(z_t | z_{<t}, x),\quad z = r \oplus y
  \]
- 训练完成后 LoRA-A 合并进基座模型得到 `base_A`，用于离线构建记忆库 \( M = M_{ep} \cup M_{sem} \)。

#### QAR：查询感知检索与摘要
- 使用 **RRF（Reciprocal Rank Fusion）** 融合稠密检索（embedding）与稀疏检索（BM25）的排名：
  \[
  s_{RRF}(m;q) = \sum_{r\in\{dense,sparse\}} \frac{1}{k_{rrf} + \text{rank}_r(m|q)}
  \]
- 将 QAR 建模为**上下文赌博机（contextual bandit）**：状态 \( s_q = (q, M^{RRF}_q) \)，动作是摘要序列 \( m_q \sim \pi_\phi(\cdot|s_q) \)。
- 通过 **GRPO** 优化 LoRA-B：
  \[
  \max_\phi \mathbb{E}_q \mathbb{E}_{m_q \sim \pi_\phi(\cdot|s_q)}[R(q,m_q)] - \beta D_{KL}(\pi_\phi \| \pi_{ref})
  \]
- 奖励函数结合 F1 质量与成本节省：
  \[
  R(q,m_q) = \alpha \cdot F1(\hat{y}, y^*) + (1-\alpha)\cdot(1-\tilde{C}(q,m_q))
  \]
  其中 \(\tilde{C}\) 是归一化的变量在线成本（基于 token 价格）。

### 完整流程
- 训练阶段：先训练 LoRA-A（QAD），合并得到 `base_A`；再在 `base_A` 上初始化 LoRA-B，通过 GRPO 训练 QAR。
- 推理阶段：RRF 检索 → LoRA-B 生成查询感知摘要 → 冻结的 QA 模型（Qwen3-14B）输出答案。

## 6. 论文的主要结论与发现

- **MemoryCPT 在成本-性能权衡上显著优于基线**：以 Qwen2.5-7B 基座为例，在 LoCoMo 上 F1 从 BudgetMem 的 0.373 提升到 0.479，成本从 24.11 降到 4.31（×10⁻⁴ USD/query），QPC 提升超过 9 倍。
- **QAD 是质量放大器**：去掉 QAD 后成本略降但 F1、Judge 明显下降，QPC 下降。
- **QAR（尤其 Fine Summary）是成本控制的关键**：去掉 QAR 后成本上升到 11.10，QPC 从 0.138 降到 0.038；去掉 FS 后成本仍明显偏高。
- **\(\alpha=0.8\) 是最佳权衡点**：过重质量（α→1）会导致摘要过长、成本上升；过重成本（α小）会过度压缩、丢失关键证据。
- **检索深度 20/50 最优**：在该深度下质量达到峰值，继续增大反而引入噪声。
- 该优势在 Llama-3.2-3B 基座上同样成立，说明方法具有模型泛化性。

## 7. 优点

- **端到端可训练**：将传统多阶段手工记忆管线转化为可学习参数，避免重复 LLM 调用和冗余上下文。
- **离线/在线分离**：离线构建成本可被后续多查询摊销，在线只有轻量检索与摘要，成本低。
- **推理轨迹蒸馏**：不只是蒸馏最终摘要，而是让模型学习中间决策（分段、生成、合并、提取），更可解释、更易学习。
- **成本感知强化学习**：通过 GRPO 与融合 F1 和成本的奖励，直接优化 cost-performance trade-off，而非单一质量。
- **评估指标 QPC 更务实**：有力推动记忆系统按“单位成本的智能收益”来评价。
- **实验分析充分**：包含消融、敏感性分析、成本摊销、细粒度类别结果，可信度较高。

## 8. 不足与局限

- **依赖教师模型**：QAD 依赖 deepseek-v3 生成的推理轨迹，可能存在教师偏差和蒸馏质量上限。
- **应用范围有限**：只在对话记忆（LoCoMo/LongMemEval）上验证，未覆盖更广泛的长程智能体记忆场景（如工具调用日志、多模态交互等）。
- **LongMemEval 无官方 split**：论文自行划分 train/val/test，可能与现有评测惯例不一致，影响结果可比性。
- **基座模型规模有限**：记忆端只使用了 7B/3B 模型，未验证在更大规模 LLM 上的表现；QA 模型固定为 14B，对更强 QA 模型的泛化未知。
- **成本模型依赖特定 API 定价**：不同部署环境的 token 价格可能不同，成本计算结果不能直接外推。
- **质量代理指标局限**：训练时使用 token-level F1 作为质量代理，虽然局部可微、连续，但可能无法完全捕捉语义正确性，LLM Judge 仅用于评估未用于训练。
- **摘要极短的风险**：QAR 生成的摘要平均不到 9 个 token，虽然大幅降本，但在复杂推理或多跳问题上可能丢失关键细节，实验中 Multi-Hop F1 相对较低也印证了这一点。
- **实验公平性的潜在质疑**：部分基线在统一评估协议下可能未发挥最佳性能（如 MemoryOS 成本极高），而 MemoryCPT 因为训练目标与 QPC 指标天然匹配，可能存在“用指标导方法”的过度适配。
