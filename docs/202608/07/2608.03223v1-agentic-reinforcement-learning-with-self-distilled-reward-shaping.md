## 摘要
智能体强化学习使大语言模型智能体能够通过交互进行学习，但稀疏的轨迹级奖励仅表明成功与否，而无法识别哪些中间步骤值得获得信用。训练专用的特权技能可以通过允许同一冻结策略快照在条件于任务匹配的程序性技能的情况下，对来自无技能轨迹的固定令牌重新评分，从而提供更密集的监督。然而，现有方法并未在交互步骤间联合校准教师分数，未将教师置信度与实际回报相关联，也未将所得信号整合到原生奖励到优势构造中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），这是一个为多轮语言智能体构建与回报关联的令牌级信用的框架。ADRS在每一步内对特权令牌分数进行中心化和归一化，通过基于组内置信度-回报关联的回报关联教师价值优势（TVA）门控对其进行调制，并将门控令牌信号纳入原生强化学习信用构造中。这些组件共同决定了教师偏好什么、该偏好何时与回报相关，以及它如何进入原生强化学习信用路径，同时保持轨迹生成和推理无技能。最后，在三个交互基准上的实验表明，ADRS在长视野任务上持续提升性能，且收益在多种强化学习骨干、减少数据设置、未见任务和延长训练中均能保持。为便于匿名评审，我们的代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. ## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：智能体强化学习（Agentic RL）使大语言模型（LLM）智能体能够通过与环境交互进行学习，应用于证据搜索、具身导航、网页交互等任务。然而，这类学习通常只依赖**稀疏的终局奖励**（terminal outcome rewards），仅告知轨迹是否成功，却无法指明哪些中间查询或动作值得获得信用，导致 token 级时序信用分配（temporal credit assignment）困难，即使对 GRPO、GiGPO 等免评论家（critic-free）的组相对方法也是如此。
- **已有思路的不足**：自然语言技能（skills）可以提供更密集的指导（描述子目标、动作规则、常见失败模式等）。已有方法（如 OPSD、Skill-SD、RLSD、SDAR）在"训练专用特权技能"方向上做了探索，但均未**联合解决三个核心问题**：
  1. **分数校准（Score Calibration）**：原始教师 log-probability 在不同交互步骤间存在偏移和尺度差异，不可直接比较；
  2. **可靠性估计（Reliability Estimation）**：高置信度的教师不一定是有用的教师（高 token 似然可能反映语言熟悉度而非与更高回报相关的决策）；
  3. **信用整合（Credit Integration）**：将蒸馏目标作为独立辅助目标，绕过了主干网络的奖励→优势（reward-to-advantage）路径，可能造成 token 级更新与 GRPO/GiGPO 组相对优势失配。
- **核心问题**：如何将训练时特权教师提供的 token 级置信度与真实回报关联起来，并通过单一的原生 奖励→优势→策略（reward-to-advantage-to-policy）路径转化为时序信用？

## 2. 方法论

论文提出 **ADRS（Agentic Reinforcement Learning with Self-Distilled Reward Shaping）** 框架，核心思想是：将任务匹配的程序性技能（privileged procedural skills）转化为 token 级训练奖励，同时保证智能体的 rollout 与推理阶段**不依赖任何技能**。整个流程在轨迹收集与 actor 优化之间作为一个"信用构建层"。

### 2.1 三个核心模块

- **模块 1：步骤内相对特权打分（Within-Step Relative Privileged Scoring，分数校准）**
  - 使用同一冻结策略快照 $\pi_{\theta_b}$，在无技能上下文与特权技能上下文下分别对已采样 token 重打分：
    - $\ell^b_{s,j} = \text{sg}[\log \pi_{\theta_b}(y_{s,j} \mid h_s, y_{s,<j})]$
    - $\ell^T_{s,j} = \text{sg}[\log \pi_{\theta_b}(y_{s,j} \mid \rho(x) \oplus h_s, y_{s,<j})]$
  - 对每个交互步骤内的 token 做中心化和尺度归一化：
    - $b_s$ 为步骤内均值，$q_{s,j} = \ell^T_{s,j} - b_s$，$\hat{q}_{s,j} = q_{s,j} / (\sigma_q + \epsilon)$
    - 归一化后满足步骤内零和性质：$\sum_{j \in \mathcal{V}_s} \hat{q}_{s,j} = 0$
  - 正负 $\hat{q}$ 分别表示该 token 在特权条件下的支持度高于/低于步骤平均水平。

- **模块 2：回报关联的教师价值优势门控（Return-Associated TVA Reliability Gate，可靠性估计）**
  - 在选定的比较组内，用原始特权分数与观测回报衡量教师置信度与回报的一致性，输出标量门控：
    - 单元置信度 $\bar{\ell}^T_u$，软高置信度权重 $\alpha_u = \sigma((\bar{\ell}^T_u - \bar{\ell}^T_{\text{batch}})/T)$
    - 高/低置信侧回报对比：$\mu^+_g = \frac{\sum \alpha_u R_u}{\sum \alpha_u + \epsilon}$，$\mu^-_g = \frac{\sum (1-\alpha_u)R_u}{\sum (1-\alpha_u) + \epsilon}$，$d_g = \mu^+_g - \mu^-_g$
    - 门控 $m_u = \text{sg}[\sigma(\tau \tilde{d}_g)]$，广播到该单元所有 token；正回报关联使门控大于 0.5，负关联降低，组过小时取 0.5，关闭 TVA 时取 1。
  - **Proposition 1**：$d_g = \frac{\text{Cov}_g(\alpha, R)}{\bar{\alpha}_g(1-\bar{\alpha}_g)}$，即 TVA 的符号与组内教师置信度和回报的经验协方差一致，赋予门控统计含义。
  - 支持两种粒度：**L2（完成级 TVA）**，与 GRPO 的按 prompt 分组匹配；**L3（步骤级 TVA）**，与 GiGPO 的重复锚定状态步骤匹配；另有一个不含回报的 L1 回退（非 TVA 估计器）。

- **模块 3：教师引导的逐 token 优势调制（Teacher-Guided Per-Token Advantage Modulation，信用整合）**
  - 教师奖励 $r^T_{s,j} = \eta m_{s,j} \hat{q}_{s,j}$，塑形后奖励 $\tilde{r}_{s,j} = r^{\text{base}}_{s,j} + r^T_{s,j}$
  - 采用**双路径**信用构建：
    - **轨迹路径**：将 $\tilde{r}$ 送入骨干（GRPO/GiGPO）原生优势计算得到 $A^{\text{traj}}$（因教师奖励步骤内零和，轨迹得分保持环境排序不变）；
    - **token 路径**：将保存的 $r^T$ 在 prompt 组内做白化得到 $Z^T_t$；
    - 最终优势 $A^{\text{ADRS}}_{i,k,t} = A^{\text{traj}}_{i,k} + \eta Z^T_{i,k,t}$，即"轨迹路径定方向，token 路径调强度"，且 $\eta=0$ 时恢复原生算法。
  - **Proposition 2**：在步骤共享门控条件下，教师奖励满足步骤内零和，并具有采样链表示 $r^T_{s,j_r} = \Phi_{s,r+1} - \Phi_{s,r}$（两端为零）——这是代数恒等式而非策略不变性保证。
  - **Proposition 3**：在行为策略点、裁剪不激活时，ADRS 的梯度等价于带 token 辅助系数 $\Delta A_t = \eta Z^T_t$ 的采样 token 辅助更新；该等价是局部的，离行为策略点后两者不再相同。
  - Actor 使用标准裁剪目标：$\mathcal{L}_{\text{actor}}(\theta) = -\frac{1}{|\mathcal{V}|} \sum_t \min[\omega_t(\theta) A^{\text{ADRS}}_t, \bar{\omega}_t(\theta) A^{\text{ADRS}}_t]$，特权信息通过分离的优势系数影响学习。

- **超参数与配置敏感性可控**：教师尺度 $\eta$ 存在甜点区间（约 0.05–0.1），过小则信用调制不足，过大会干扰环境奖励排序；全局归一化优于逐序列归一化；GateNorm 开关对稳定性有正向贡献。整体上，ADRS 对主要超参数并不特别脆弱，但 $\eta$ 仍是最需要调校的旋钮。

## 7. 局限性与开放问题

- **范围与来源局限**：所有实验均在 Qwen 系列（2.5-3B/7B、3-1.7B）上进行，未覆盖 Llama、Mistral、Gemma 等其他模型族；且完全沿用 SDAR 基准与评测协议，虽击败了 SDAR 本身，但仍属于同一评测框架内的比较，尚需第三方独立复现与扩展。
- **计算开销未透明**：论文未报告具体 GPU 卡时、吞吐量或 wall-clock 时间。考虑到 TVA 门控、置信度对比等模块需在 batch 内做统计计算，以及同一轨迹要由同一冻结策略在“有/无技能”两种上下文下各打分一次，其训练开销可能高于普通 GRPO；但论文未量化，难以判断 deploy 成本。
- **TVA 的统计性质仍有边界**：Proposition 1 将门控与协方差挂钩，但该协方差是在有限 batch 内估计的，当组大小很小或回报方差很大时，$d_g$ 可能噪声较大；虽有过小保护（回退 0.5），但极端情况下的鲁棒性未深入测试。
- **Search 任务提升有限**：在 Search 基准上 ADRS 仅比最强基线高 0.4 个宏平均点，虽然其他两个基准提升显著，但这也提示方法在工具使用类、长链推理类任务上的增益可能不及具身/网页交互任务。
- **特权技能的来源**：框架假设训练时存在“任务匹配的程序性技能”，但论文未讨论这些技能是如何生成或筛选的（是否人工编写、是否从任务说明自动提取、如何保证质量）。这在实际落地时是一个隐式前提。
- **与人类信用分配的关系**：虽然 ADRS 将教师置信度转化为 token 级奖励，但“置信度”本身不直接等价于“真实价值”，TVA 门控只能从回报相关性上间接校准，若教师系统性偏差（如对某个错误习惯信心很高且回报恰好正相关）则可能被保留。

## 8. 个人评价与总结

**优点**：本文动机清晰，精准指出了结果驱动 RL 在 token 级信用分配上的痛点；方法设计紧凑，三个模块分别对应“校准—门控—整合”，并以两个命题提供数学解释，规避了通常自蒸馏方法“高似然即高价值”的隐患；实验设计覆盖面广，从模型族、骨干算法、数据规模到训练预算均有系统消融；在 ALFWorld 与 WebShop 上的提升幅度显著，且长期训练稳定性分析让人信服。

**不足**：计算成本不透明，Search 上提升有限，特权技能来源未交代，模型覆盖较窄，且所有优势等价性证明均为局部或统计层面的而非全局收敛保证，理论上仍需更深入的收敛性分析。

**总体定位**：这是一篇将“可解释的中间反馈（技能）”与“结果驱动 RL”结合得相当自然的工作，ADRS 的“双路径优势”设计兼具原理简洁与实现可行性。若后续能开放代码、报告成本并在更多模型与任务上验证，很可能成为智能体 RL 中 token 级信用分配的重要参考方案。
