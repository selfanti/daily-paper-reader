## 摘要
递归自我改进要求智能体将累积的经验转化为更好的未来行为。个人AI智能体为研究这一能力提供了一个具体场景，因为它们可以在会话间保留偏好、任务历史、工具例程和习得技能。然而，保留的经验是否真正随时间改进了它们，尚未得到系统性测试。我们引入了PAST-Bench，一个专门用于隔离这一问题的基准。每个智能体在匹配的条件下（即保留经验开启和关闭）运行有序序列的新会话任务。它涵盖26个场景和204个片段，涉及记忆、程序复用、信息收集和更新。我们报告了后续任务的增益，以及这些增益是否遵循预期的保存、检索和更新路径。在七个基础模型和四个智能体框架中，改进是真实的，但在能力上并不均衡。具有相同总体增益的智能体在增益是否得到预期路径证据的支持方面可能差异显著。在这些发现的指导下，我们开发了Hermes+，它通过针对智能体循环各阶段的五项干预措施扩展了Hermes。Hermes+提高了保留经验的平均增益，并提供了更清晰的路径证据，其对需要替换过时状态的任务改进最为显著，但效果仍然依赖于能力和模型。总之，PAST-Bench和Hermes+为研究持久智能体如何从保留经验进展到系统性地改进提供了一个评估和诊断基础。代码：https://github.com/Gen-Verse/PAST-Bench

## Abstract
Recursive self-improvement requires agents to turn accumulated experience into better future behavior. Personal AI agents offer a concrete setting for studying this capability because they retain preferences, task histories, tool routines, and learned skills across sessions. Yet whether retained experience actually improves them over time has not been systematically tested. We introduce PAST-Bench, a benchmark designed to isolate this question. Each agent runs through ordered sequences of fresh-session tasks under matched conditions that turn retained experience on and off. It spans 26 scenarios and 204 episodes across memory, procedural reuse, information gathering, and update. We report both later-task gains and whether those gains follow the intended save, retrieve, and update pathway. Across seven base models and four agent frameworks, improvement is real but uneven across capabilities. Agents with the same headline gain can differ markedly in whether that gain is supported by evidence of the intended pathway. Guided by these findings, we develop Hermes+, which extends Hermes with five targeted interventions across stages of the agent loop. Hermes+ raises the average gain from retained experience and provides clearer pathway evidence, with its strongest improvement on tasks requiring outdated state to be replaced, although the effect remains capability- and model-dependent. Together, PAST-Bench and Hermes+ provide an evaluation and diagnostic foundation for studying how persistent agents can progress from retaining experience to systematically improving through it. ## 1. 核心问题与整体含义

- **研究动机**：递归自我改进（Recursive Self-Improvement, RSI）要求智能体将自身运行中积累的经验转化为更好的未来行为。个人 AI 智能体（如 Hermes、OpenClaw 等）天然具备跨会话保留偏好、任务历史、工具例程和习得技能的能力，因此成为研究这一能力的理想载体。
- **核心问题**：保留经验是否真的让智能体随时间变得更好？这一基本问题此前未被系统性测试过。
- **关键挑战**：评估自我进化本质上是一个"性能归因"问题——后序会话性能的提升可能来自保留经验，也可能来自基础模型能力、运行时设计、提示词、检索捷径、任务难度或评分噪声。现有基准无法区分这些来源。
- **论文定位**：提出 PAST-Bench，一个专门用于隔离"保留经验是否带来改进"这一问题的性能归因基准，并基于诊断结果提出 Hermes+ 框架，为持久智能体从"保留经验"走向"系统性地通过经验改进"提供评估与诊断基础。

## 2. 方法论

### 2.1 PAST-Bench 基准设计

- **评估单元**：任务族（task family），即一系列有序的新会话情节目。早期情节为智能体提供保存可复用经验的机会，后期情节测试其是否复用了这些经验。
- **严格上下文清除协议**：每个情节从全新会话开始，易失性上下文被完全清空；任何跨情节的改进必须通过持久化基质（记忆存储、技能文件、会话历史等）流动，而非残留的提示词重叠。
- **四维能力覆盖**：
  - **记忆（Memory）**：5 个场景 / 41 个情节，测试陈述性事实（偏好、约束、策略）的查找与应用；
  - **程序复用（Procedural Reuse）**：8 个场景 / 64 个情节，测试多步骤技术工作流的有序执行与工具组合；
  - **信息收集（Information Gathering）**：6 个场景 / 48 个情节，测试在噪声上下文中是否在正确时机主动检索预置证据；
  - **更新（Update）**：7 个场景 / 51 个情节，测试第二次写入能否覆盖第一次且不泄漏旧状态。
- **情节角色**：冷启动（cold）、学习（learn）、评估（evaluation）和控制（control）四类；控制情节包括无保留控制、干扰物控制、过期状态控制、错误机制控制。
- **匹配消融**：同一情节在"保留开启（w/ evolve）"与"保留关闭（w/o evolve）"两种条件下运行，共享相同提示词、评分器、工具栈和种子，使任何分数差距最可能归因于持久化层。

### 2.2 核心指标

- **任务分数**：$s_e = \sigma_e \times (0.80 \times c_e + 0.20 \times r_e)$，其中 $c_e$ 为完成度、$r_e$ 为工具调用错误恢复率（鲁棒性）、$\sigma_e$ 为安全门（违规直接归零）。
- **自我进化差距**：$\Delta_f = S^{w/}_f - S^{w/o}_f$，能力级 $\Delta$ 为对任务族的宏平均；$\Delta$ 需超过控制情节设定的上限才被接受为自我进化的证据。
- **机制证据分数（Mech）**：$\text{Mech}_f = \frac{1}{5}(wp + ra + uc + rh + (1 - pr))$，由写入精度（write precision）、召回准确率（recall accuracy）、更新正确性（update correctness）、保留视野（retention horizon）和污染率（pollution rate）五部分构成，用于检验改进是否走了预期的持久化路径（写入→检索→正确应用）。

### 2.3 Hermes+ 框架

基于 Hermes 的失败轨迹诊断，在智能体循环的五阶段各插入一项独立干预：

- **E1（Plan）计划期咨询检查**：起草风险或依赖记忆的行动前，必须先查询已保存的持久状态；
- **E2（Render）类型化记忆绑定**：记忆以类型、范围、实体、当前值、被取代值、过期时间写入，渲染时只呈现范围内有效的当前绑定，抑制过期条目；
- **E3（Route）技能生命周期管理**：将解决过的工作流保存为带适用条件和有序步骤的可排名、可修补技能；
- **E4（Gate）行动前检索门控**：当任务依赖先前状态且尚未发生持久化读取时，阻止草稿答案并要求先检索；
- **E5（Close）情节关闭与同步刷新**：在情节结束时提取最终绑定键/更新规则，覆盖旧值并同步刷新到持久存储，确保下一个新会话只检索到修正后的值。

## 6. 主要结论与发现

- **自我进化是真实但能力不均的**：所有 7 个基础模型都从持久化中获益（总体 Δ 从 +0.13 到 +0.24），但增益集中在不同能力上——GPT-5.4 均衡分布在记忆（38%）和更新（35%），GLM-5.1 近半增益在更新（46%），Kimi K2.6 近半在记忆（49%）；模型原本擅长的能力也是保留经验帮助最大的能力。
- **相同的 Δ 可以隐藏不同的持久化路径**：Hermes 和 nanobot 同为 Δ=+0.13，但机制证据分数差异显著（0.64 vs 0.57）——nanobot 的增益集中在单一能力且缺乏一致的写入-读取轨迹。仅凭一次性任务分数无法发现这一差异。
- **不同框架的能力画像差异明显**：ZeroClaw 擅长记忆（52% 增益份额）但程序复用为负；nanobot 60% 增益在更新但记忆几乎无提升；Agent-Zero 在四能力中三项退化（总体 Δ=-0.08）；Hermes 是唯一所有能力均正向的基线框架。
- **Hermes+ 的效果**：在 MiniMax-M2.7 下，总体 Δ 从 +0.13 提升至 +0.15，Mech 从 0.64 提升至 0.73；在更新能力上呈超加性组合（Δ=+0.24，高于任何单一机制：E5 单独 +0.16，E4 单独 +0.06），但程序复用出现小幅退步（-0.02）；跨模型迁移在 5 个模型中的 3 个上匹配或改善基线（MiniMax-M2.7、Claude Sonnet 4.6、GPT-5.4），在 DeepSeek-V4-Pro 和 Claude Opus 4.6 上略有退化。
- **总体差异需谨慎解读**：+0.02 的总体 Δ 提升小于运行间波动，论文明确不作稳定总体增益的解读；更新能力上的均值位移（+0.12→+0.24）更清晰，但其方差也增大了（σΔ 从 0.01 增至 0.09）。

- **双重指标体系**：同时报告行为分数（Δ）与机制证据（Mech），区分

- **双重指标体系**：同时报告行为分数（Δ）与机制证据（Mech），区分“表现好坏”与“路径对错”——即使总体 Δ 相同，机制分数也能暴露持久化路径是否真正生效，避免了仅凭任务分数得出的误导性结论。

- **成本与可复现性透明**：报告了每配置的 token 消耗、时耗与跨运行标准差，并给出评分器人机一致性验证与 Mech 权重敏感性分析，增强了结果的可信度与可复现性。

## 8. 不足与局限性

- **统计效力有限**：每配置仅 3 次运行，部分结论的均值差小于运行间波动（如 Hermes+ 总体 Δ 的 +0.02 提升 vs 0.13±0.04 的基线方差），难以对“总体稳定增益”做出强统计断言；更新能力上看似清晰的提升伴随方差从 0.01 增至 0.09，稳健性存疑。
- **消融实验覆盖不足**：单机制消融与全减一交互诊断仅在部分模型/框架组合上完成（主要集中在程序复用能力），跨模型的机制普适性证据不足。
- **框架间公平性天然受限**：Agent-Zero 采用多智能体架构，被给予了 4 倍放宽的时间预算，框架比较中的等时公平性存在固有张力。
- **合成数据为主**：全部任务为合成场景，不涉及真实用户数据，任务的复杂度、噪声模式与真实个人智能体使用场景仍有差距。
- **评分器一致性一般**：LLM 评分器与人类评分者精确匹配率仅 68.8%（0.5 以内为 91.7%），略低于人类间一致率（83.3%），说明自动评分在部分情节上仍存在偏差风险。
- **API 依赖与模型漂移**：所有实验通过 API 调用完成，模型版本更新、服务端解码变化等因素可能影响跨时间复现的稳定性。
- **时间跨度不足**：任务族的情节数有限（最长为 51 个情节），只能覆盖短期改进，无法回答“长期积累是否会收敛、遗忘或产生副作用”的问题。

## 9. 对领域的主要启示

- **自我改进可以且应该被“归因式”地度量**：PAST-Bench 表明，仅比较智能体前后性能不足以证明其“学会学习”；必须同时控制持久化开关、设置对照组、并在行为分数之外验证机制路径，才能把改进归因于保留经验本身。这一方法论可推广到其他记忆/技能/持续学习基准的设计中。
- **个人智能体是 RSI 研究的天然实验场**：跨会话持久化层恰好构成了 RSI 的最小闭环——新会话能否复用过去会话的产物。论文用实证表明，现有多数框架在这一闭环上存在系统性的写入、检索与应用缺陷，而这正是未来个人智能体能力的增长点。
- **“能改”不等于“会改”**：7 个模型全部从保留经验中获益，但能力分布差异极大；框架的记忆画像也各不相同。对持久智能体而言，工程上的“保留什么、何时写入、何时检索、如何更新”比单纯扩大存储容量更重要。
- **超加性意味着机制需要组合设计**：Hermes+ 的更新能力表现出 E5+E4 的超加性组合效应，说明自我改进机制之间存在非线性协同，孤立地优化单一机制未必能获得系统级收益。

## 10. 未来研究方向

- **扩大统计基础**：增加运行次数（如 10 次以上），对关键结论建立置信区间与显著性检验，区分真实均值位移与采样噪声。
- **覆盖更长的时间跨度**：设计几十甚至上百个情节的任务族，研究经验积累的长期曲线、遗忘曲线、过时信息的自清理机制及经验数量的边际收益。
- **更广泛的模型与框架矩阵**：在更大的模型集与更多主流智能体框架上进行系统比较，检验 Hermes+ 干预机制在异构架构上的可迁移性。
- **从合成走向真实**：引入真实的用户配置文件、工具 API 文档与真实任务日志，构建更接近现实部署的评估场景。
- **机制层面的细粒度诊断**：对写入精度、检索延迟、更新覆盖、污染率等机制指标做在线轨迹分析，探索运行时自适应调整机制参数的可能性。
- **安全性与风险控制**：研究自我改进过程中的灾难性遗忘、错误经验固化、安全约束被覆盖或被旁路等风险，为 RSI 设定安全阈值。

## 11. 总结

PAST-Bench 是首个专门针对“跨会话保留经验是否带来真实性能改进”这一 RSI 核心问题设计的性能归因基准。它通过严格上下文清除协议、匹配的保留开/关对照、四维能力场景与机制证据分数，将自我进化与基础模型能力、提示词捷径、任务噪声等混淆因素分离开来。基于基准诊断提出的 Hermes+ 框架，通过五阶段独立干预（计划期咨询、类型化记忆绑定、技能生命周期管理、行动前检索门控、情节关闭同步刷新），在 MiniMax-M2.7 上提高了机制证据分数，并在更新能力上展现出超加性组合效应。

论文的最大贡献不在 +0.02 的总体性能提升，而在“教会社区如何正确地测试一个智能体是否真的会从经验中学习”。其不足在于统计效力有限、消融覆盖不全、合成数据与短期视角。后续研究若能在此基础上扩大实验规模、拉长评测周期并引入真实场景，将为个人智能体的递归自我改进奠定更坚实的实证基础。
