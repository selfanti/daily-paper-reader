## 摘要
大型语言模型可以通过强化学习来改进搜索智能体，然而现有的自我对弈智能体会重复生成任务，同时丢弃在成功搜索过程中获得的知识。我们提出了CoEvoKG，一个将知识图谱转变为可验证训练任务来源和智能体进化持久证据记忆的框架。CoEvoKG联合训练任务生成器和搜索智能体：生成器从知识图谱中采样的实体链生成多跳问题，而智能体则从答案正确性的奖励和由图谱证据支持的实体路径搜索轨迹中学习。当搜索成功时，CoEvoKG会验证并去重检索到的证据，然后将其写回相应的图谱节点和边。未来的轮次会利用这个增强后的图谱进行任务生成和奖励计算，从而闭环连接模型自我进化与知识积累。在六个问答基准（NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA和Bamboogle）上的实验，使用三种骨干模型，表明CoEvoKG在Qwen2.5-3B-Instruct、Qwen2.5-7B-Instruct和Llama-3.1-8B-Instruct上分别比相应的基础模型提高了+11.2、+10.1和+11.6个宏平均准确率点。在匹配的训练预算下，CoEvoKG在三个骨干上相比竞争性的自我对弈基线和搜索智能体的RL基线进一步提高了+2.6到+3.7个宏平均点。代码可在https://github.com/lazzy1225/CoEvoKG获取。

## Abstract
Large language models can improve with reinforcement learning for search agents, yet existing self play agents repeatedly generate tasks while discarding the knowledge gained during successful searches. We introduce CoEvoKG, a framework that turns a   knowledge graph into both a source of verifiable training tasks and a persistent evidence memory for agent evolution. CoEvoKG jointly trains a task generator and a search agent: the generator creates multihop questions from entity chains sampled   from the knowledge graph, while the agent learns from rewards for answer correctness and search trajectories whose entity paths are supported by graph evidence. When a search succeeds, CoEvoKG verifies and deduplicates the retrieved evidence, then   writes it back to the corresponding graph nodes and edges. Future rounds reuse this enriched graph for task generation and reward computation, closing the loop between model self evolution and knowledge accumulation. Experiments on six QA benchmarks   (NQ, TriviaQA, PopQA, HotpotQA, 2WikiMultiHopQA, and Bamboogle) with three backbone models show that CoEvoKG improves macro average accuracy over the corresponding base models by +11.2, +10.1, and +11.6 points on Qwen2.5-3B-Instruct,   Qwen2.5-7B-Instruct, and Llama-3.1-8B-Instruct, respectively. Under matched training budgets, CoEvoKG further improves over competitive self play baselines and RL baselines for search agents by +2.6 to +3.7 macro average points across the three   backbones. Code is available at https://github.com/lazzy1225/CoEvoKG.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**核心问题**：现有基于强化学习的搜索智能体训练存在两个关键缺陷：

- **静态任务分布**：已有方法（如 Search-R1）依赖固定的人类标注 QA 池，奖励验证虽然简单，但训练分布受限，难以规模化生成高质量的多跳任务。
- **自我进化不稳定且无积累**：自我对弈方法（如 Self-Play）虽然让模型自己生成和解决问题，但生成的题目常存在太容易、太难、不可验证、答案泄露等问题；更重要的是，即使搜索成功，检索到的证据被用后即弃，没有形成任何持久化知识积累。

**整体含义**：CoEvoKG 提出了"知识图谱作为双重角色"的范式——即在训练循环中，知识图谱实体链既是**可验证多跳任务的生成来源**，又是**智能体搜索证据的持久化外部记忆**。该框架将模型自我进化与知识积累连接成一个闭环：模型通过解决任务积累证据，证据反过来丰富任务来源和奖励计算，形成一个持续进化的协同系统。

## 2. 论文提出的方法论

### 2.1 核心思想

CoEvoKG 构建了一个"提议者–求解者"自我对弈框架，围绕一个共享的、随训练动态演化的知识图谱链池（chain pool）运行：

- **提议者（Proposer）**：从图谱实体链生成多跳问题，并选择链中的一个实体作为答案。
- **求解者（Solver）**：执行多轮搜索并使用工具检索，产出最终答案。
- **图谱记忆（Graph Memory）**：成功且路径受支持的搜索轨迹经过验证和去重后，写回图谱对应节点和边，供未来轮次使用。

### 2.2 关键技术细节

**（1）基于知识图谱链的任务生成**

- 使用 KILT 的基于 Wikipedia 的知识图谱，通过离线随机游走（2–3跳）构建初始链池 G₀。
- 每个链 c = (e₁, r₁, e₂, r₂, ..., e_L) 由实体和关系标签组成，每个节点带有文章段落文本。
- 提议者生成的问题需满足：不直接命名链实体、至少两跳、答案唯一简洁。
- **质量门（Quality Gate）**：用 LLM 验证器对候选问题进行过滤（链忠实性、多跳要求、单一答案焦点、无泄露），只有通过的候选才进入求解器训练。
- **种子回退机制**：当链条无法生成通过质量门的问题时，用固定人类 QA 池中的问题填充。

**（2）路径支持与难度奖励**

- **求解者奖励**：R_s = R_ans × (1 + β·S_path)，其中 R_ans 为答案正确性（0/1），S_path 为路径支持分数（几何平均）。β=0.2。
- **路径支持验证**：从求解者轨迹中提取实体路径 ĉ_τ，对每对相邻实体计算关系一致性分数 M(u,v)（综合直接匹配、文本互提及、共现、一跳桥接），路径分数为各跳支持度的几何平均——任何一跳缺乏支持都会显著拉低分数，防止"猜对答案"或仅端点正确的情况。
- **提议者难度奖励**：R_diff = exp(−(p_s − p*(t))²/(2σ²))，鼓励问题落在求解者当前能力边缘——太容易（p_s→1）或太难（p_s→0）都受罚。目标成功率 p*(t) 从高到低退火。

**（3）验证图谱记忆（证据写回）**

- 仅当轨迹满足 R_ans=1 且 S_path ≥ τ_path 时，才将检索到的实体证据写回图谱链。
- 使用小写实体序列的哈希进行去重：新序列成为新链，已有序列仅合并新增证据段落。
- 丰富后的链池形成更密的图 G_{t+1}，供后续轮次的任务生成和验证使用。

**（4）优化算法**

- **求解器**：GRPO（组相对优势，每组 8 条轨迹）。
- **提议者**：REINFORCE++（累积折扣回报 + 全局批归一化）。
- 两者共用 PPO 风格的裁剪目标和低方差 KL 惩罚，低概率 token 的 advantage 做仿射缩放以稳定训练。

## 7. 优点

- **知识图谱的双重角色设计巧妙**：既是任务来源又是持久记忆，一石二鸟地解决了自对弈中的两个核心痛点（任务质量不可控 + 证据浪费）。
