## 摘要
在通信受限的分布式多智能体系统中，协同任务调度具有挑战性，因为每个智能体必须在部分且动态的观测下做出决策，同时满足复杂的实际约束。现有的启发式方法依赖于手工设计的投标规则和重复共识，而许多基于学习的方法假设全局观测且缺乏基于显式通信的协调。为了解决这些局限性，本文提出了一种用于分布式多机器人任务分配（MRTA）的神经调度框架，包括多解码器图注意力模型（MDGAM）策略模型和无评论家的组相对多智能体策略梯度（GRMAPG）训练算法。MDGAM使用扩展的图注意力机制来联合更新节点和边特征，并采用多个解码器生成任务选择决策和通信消息。GRMAPG从等价的任务规划实例中构建组相对优势，以替代传统MARL算法中使用的评论家网络，从而降低训练难度并提高收敛性能。在不同问题规模和通信范围下的实验表明，所提出的方法在任务完成性能上优于现有的启发式方法和基于学习的方法，同时消融、复杂性和泛化测试进一步验证了所提出的创新。

## Abstract
Cooperative task scheduling in communication-constrained distributed multi-agent systems is challenging because each agent must make decisions from partial and dynamic observations while satisfying complex practical constraints. Existing heuristics rely on handcrafted bidding rules and repeated consensus, whereas many learning-based methods assume global observations and lack explicit communication-based coordination. To address these limitations, this paper proposes a neural scheduling framework for distributed multi-robot task allocation (MRTA), consisting of a multi-decoder graph attention model (MDGAM) policy model and a critic-free group relative multi-agent policy gradient (GRMAPG) training algorithm. MDGAM uses an extended graph attention mechanism to jointly update node and edge features, and employs multiple decoders to generate task-selection decisions and communication messages. GRMAPG constructs group-relative advantages from equivalent task-planning instances to replace the critic network used in conventional MARL algorithms, thereby reducing training difficulty and improving convergence performance. Experiments under different problem scales and communication ranges show that the proposed method improves task-completion performance over existing heuristic and learning-based methods, while ablation, complexity, and generalization tests further validate the proposed innovations.

### 2.2 MDGAM 策略网络架构

- **输入**：图结构的局部观测，节点包括当前智能体、其 depot、候选任务节点、通信可达的邻居智能体；边为两两关系（实验中使用距离，接口可扩展为任意转移成本）。
- **扩展图注意力机制**（三个注意力操作）：
  1. **Node-Node Attention**：聚合节点上下文特征。
  2. **Edge-Node Attention**：用边的两端节点表示更新边表示，并通过方向感知的位置编码 PE(·,·) 区分有向边的起点和终点（起点拼接标量 -1，终点拼接标量 1）。
  3. **Node-Edge Attention**：将边信息传播回节点表示。
  - 该机制实现节点与边表示的**双向信息交换**，能处理非欧氏或不对称转移成本。
- **编码器**：类型特定的初始嵌入层映射不同类型的原始特征；堆叠 L=4 层编码器层，每层含 MHA + 残差连接 + 前馈网络 + 层归一化（公式 17–21）。嵌入维度 dm=128，8 头注意力，每头维度 16，FFN 隐藏维度 256。
- **任务解码器**：K1=1 层注意力层，以当前智能体编码为初始查询，通过单头注意力打分候选节点，对不可行节点进行掩码（-∞），输出任务选择概率分布。训练时采样，测试时贪心解码。
- **通信解码器**：K2=1 层注意力层 + 线性投影，输出 dcom=128 维连续消息向量，供通信范围内的其他智能体在后续决策中使用。

### 2.3 GRMAPG 训练算法

- **动机**：终端奖励（总完成任务数）仅在完整轨迹结束后可得，逐步骤奖励分解困难；额外评论家带来参数开销与价值估计误差。
- **核心思想**：利用**等价变换构造实例组**以提供相互监督：

  - 组内每个成员实例由共享策略独立采样生成轨迹，得到组内奖励集合。
  - 对第 k 个实例，leave-one-out 基线 bk 为组内其他 K−1 个实例奖励的平均值（公式 43），组相对优势 Âk = Rk − bk（公式 44）。

- **最终梯度估计**（公式 46）：对组内所有实例的优势 × 对数似然梯度取平均。

## 7. 优点

- **显式建模通信协调**：MDGAM 的通信解码器使智能体不仅能规划任务，还能生成对其他智能体有意义的协调消息，这是大多数现有学习方法所缺少的。
- **边感知的图表示**：节点-节点、边-节点、节点-边三种注意力联合更新，能自然地编码时间窗兼容性、非对称旅行成本等关键约束信息；方向感知位置编码轻量有效（无新增可学习参数）。
- **无评论家训练算法新颖实用**：GRMAPG 利用问题对称性构造等效实例组，以留一基线构建组相对优势，避免价值函数近似误差和逐步骤奖励设计，参数更少、收敛更快、无偏性有理论保证。
- **端到端训练且无需人工标注**：策略直接从终端奖励学习，无需监督数据。
- **实验设计较为系统**：覆盖性能、消融、复杂度、泛化四个维度；学习基线保证相近模型规模、训练算法消融控制相同推理次数，对比公平性较好。
- **实际部署友好**：单次贪心决策即完成规划，与分布式执行一致；推理时间与通信量远低于传统启发式方法，代码开源便于复现。

## 8. 不足与局限

- **问题规模多样性受限**：实验仅考虑 C=2 两种任务类型、最多 150 任务/10 智能体，现实的异构任务类型更多、规模可能更大；更大规模下的表现未验证。
- **奖励函数单一**：以完成任务数为唯一评价指标，未考虑总旅行距离、能耗、负载均衡、等待时间等实际运营指标，可能偏向以牺牲路径效率换取任务数量。

- **缺乏真实世界验证**：全部实验均为仿真，未进行真实机器人平台的验证，对实际传感器噪声、执行不确定性等因素的鲁棒性未知。
