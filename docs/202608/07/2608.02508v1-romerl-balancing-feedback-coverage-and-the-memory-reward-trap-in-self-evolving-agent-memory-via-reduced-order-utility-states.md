## 摘要
基于学习的记忆系统在自我进化的大语言模型（LLM）智能体中面临两个紧密耦合的挑战。首先，以轨迹为索引的效用随交互历史增长，从而将有限的反馈分散到不断扩展的状态空间中。其次，由于轨迹级奖励被共同分配给共检索的记忆，不相关的经验可能会接收到误导性的效用更新，进而陷入记忆-奖励陷阱。为应对这些挑战，我们引入了降阶记忆强化学习（RoMeRL），该方法通过由结果极性和记忆动态分解的固定维度每任务记忆状态来表示不断增长的轨迹索引效用空间。RoMeRL通过一组固定的语义坐标来整合新经验，这些坐标的内容随时间更新或替换，从而将反馈集中在有界的效用支持上。理论上，我们证明了这种降阶参数化增加了每个效用坐标接收的平均反馈，并在通用坐标转移模型下刻画了错误坐标的稳态占用率。在ALFWorld和LifelongAgentBench上的实验表明，RoMeRL提高了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，并将LLM调用减少了21.1%。这些结果表明，降阶效用状态支持高效的自我进化智能体记忆，同时限制了持续的奖励污染。代码可在 https://github.com/YOUNG-fnxm/RoMeRL 获取。

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. Code is available at: https://github.com/YOUNG-fnxm/RoMeRL

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 大语言模型（LLM）智能体本质上是**无状态的**，需要通过外部记忆系统来累积和复用过往经验。
- 现有基于学习的记忆系统（如 MemRL）通常为每条存储的轨迹分配一个独立的效用值（trajectory-indexed utility），并通过下游任务奖励来更新这些效用。
- 这一范式存在两个紧密耦合的挑战：
  1. **反馈稀释问题**：轨迹索引的效用空间随交互历史不断增长，有限的反馈被分散到持续扩展的状态空间中，导致大量记忆效用"冷启动"（Cold-Q），得不到充分更新。
  2. **记忆-奖励陷阱（Memory-Reward Trap, MRT）**：轨迹级奖励是共同分配给所有被检索记忆的，因此偶然与成功轨迹共检索的弱相关、过时或失败记忆可能获得正向效用更新，尽管其对成功并无因果贡献。
- 一个直觉的补救措施是加强探索（如引入 UCB），使未被充分访问的记忆获得更多反馈。但实验表明，**更强的探索虽提高了记忆覆盖率，却降低了任务性能**——因为探索同时暴露了更多弱相关记忆于错误奖励传播之中，形成"探索-污染"两难困境。

**核心洞见：** 问题根源在于轨迹索引的效用学习范式——每条新经验引入一个新的效用变量，而更广泛的探索使更多此类变量暴露于可能被错误归因的奖励之下。因此需要改变记忆强化学习所作用的状态本身，而非在持续增长的效用空间中更加激进地探索。

## 2. 论文提出的方法论

### 2.1 核心思想：降阶效用状态（Reduced-Order Utility State）

RoMeRL 的核心思想是：**用固定维度（2×2）的每任务记忆状态替代持续增长的轨迹索引效用空间**。该状态由两个二元维度分解而来：

- **结果极性（Outcome Polarity）**：O = {+, −}，区分成功与失败证据；
- **记忆动力学（Memory Dynamics）**：D = {C, A}，区分整合性（Consolidated）历史证据与适应性（Adaptive）状态迁移证据。

二者的笛卡尔积构成固定四个语义坐标：

$$I_{fact} = O \times D, \quad |I_{fact}| = 4$$

对于任务 g，可变长度的历史 D_g,t 被映射为固定维度状态：

$$Z_{g,t} = \begin{bmatrix} z_{+,C} & z_{+,A} \\ z_{-,C} & z_{-,A} \end{bmatrix}$$

坐标内容可随时间更新或替换，但其语义身份保持不变，从而保证效用空间的维度恒定（4维）。

### 2.2 四个语义坐标的具体定义

| 坐标 | 全称 | 选取规则 | 语义角色 |
|------|------|----------|----------|
| **PCC** | Positive Consolidated Coordinate | 所有成功轨迹中效率最高者（最短完成步数） | 保留全局最优的正面参考模板 |
| **PAC** | Positive Adaptive Coordinate | 首次失败之后的最早成功轨迹 | 记录"失败→成功"的恢复性迁移 |
| **NCC** | Negative Consolidated Coordinate | 效用超过负向初始化阈值 Q⁻_init 的最高效用失败轨迹 | 保留具有下游正向证据的诊断性失败经验 |
| **NAC** | Negative Adaptive Coordinate | 最近一次失败的轨迹 | 追踪当前失败状态的动态变化 |

### 2.3 检索与效用更新机制

- **检索评分**：结合语义相似度与学习到的效用值加权排序，所有非空坐标皆为候选，取 Top-k_ret 的坐标进入上下文。
- **效用更新**：沿用标准 Q-learning 风格的指数移动平均更新，对检索到的坐标基于任务级结果奖励进行更新：
  $$Q^{o,d}_{g,t+1} = Q^{o,d}_{g,t} + \alpha \cdot \mathbb{1}[m^{o,d}_{g,t} \in S_t] \left( r_t - Q^{o,d}_{g,t} \right)$$
- **暖启动**：新代表替换旧内容时继承当前效用作为初始化值，后续奖励逐步使其适配新代表。

### 2.4 理论分析（三个定理与一个命题）

1. **定理1（效用估计的偏差-方差分解）**：轨迹索引的记忆效用估计可分解为观测数学期望误差与方差项之和。关键结论：更多的反馈减少方差，但**无法消除**任务级基线 v⁰_i 与观测归因偏差 a_i 构成的信用差距。
2. **定理2（充分反馈预算）**：在 Hoeffding 不等式与联合界下，估计全部 N_t 条轨迹的原始收益需要反馈预算 F_T = O(N_t/ε² · log(N_t/δ))，即**随存储记忆数量线性增长**——解释了全池学习对反馈的饥渴性。
3. **定理3（状态降维下的反馈集中）**：在相同的交互预算 T 和每轨迹更新上限 k 下，轨迹索引学习的每个效用坐标平均获得 O(σ²N_t/(kT)) 的估计方差，而因子化学习只需 O(4σ²/(kT))——即状态降维将反馈集中于少数坐标，反馈密度提升 N_t/4 倍。
4. **命题1（错误坐标稳态占用率）**：在一阶马尔可夫转移模型下，固定维度 d 的激活状态中错误坐标的稳态占比至多为 γ/(γ+λ)（γ为洁净→错误转移概率，λ为错误→洁净转移概率），期望错误坐标数至多为 d·γ/(γ+λ)。当日志池中的暴露量低于全池的 N_t·ρ_full 时，降序状态大幅压缩记忆-奖励陷阱的持久影响面。

## 6. 论文的主要结论与发现

1. **性能提升**：RoMeRL 在 ALFWorld 和 LAB 上的整体平均成功率达到 0.862，比最强基线（MemRL，0.830）高出 3.2 个百分点。
2. **反馈利用效率显著改善**：
   - Cold-Q 比率从 MemRL 的 44.9% 降至 9.0%（降低 80.0%）；
   - 反馈密度从 4.96 提升至 29.93（约 6.0 倍）。
3. **记忆-奖励陷阱抑制**：在受控 MRT 压力测试中，RoMeRL 将噪声条目的正向效用更新次数限制在 2.4（vs MemRL 的 3.7、MemRL+UCB 的 7.2），最终噪声比例仅 0.15%（vs 1.02% 和 1.20%），同时取得最高的 82.0% 成功率。
4. **显著效率提升**：平均记忆大小从 45K 降至 7K（减少 84.4%）；LLM 调用次数从 570K 降至 450K（减少 21.1%）。
5. **跨模型可迁移性**：冻结的记忆状态可迁移至其他 LLM 骨干，在四种 模型×任务 组合中均提升性能并减少执行步骤。
6. **效用学习的表达性**：RoMeRL 的 Q 值与记忆来源的相关性更强（r=0.673 vs 0.493），在高 Q 值区间保留约 19.9% 的失败派生记忆（vs 基线的 5.3%），说明学习到的效用不是成功/失败的简单复制，而是能够捕捉可复用的失败诊断信息。
7. **坐标互补性**：NCC 提供可复用的负面证据（在 OS 和 DB 中分别占 27.14% 和 42.78% 的占用率），PAC 提供稀疏但关键的成功恢复信号（占 8.21% 和 5.05%），两者缺一不可。

## 7. 优点

1. **理论框架完整**：以严格的形式化定义（Definition 1、定理 1-3、命题 1）剖析了 MRT 的结构性根源，将"原始收益估计"与"边际信用分配"两个概念清晰解耦，为记忆强化学习提供了坚实的理论解释。
2. **问题定义精准**：MRT 的形式化定义（θ_i ≤ 0 但 μ_i − v⁰_i > 0）精确刻画了"无贡献但有正向观测信号"的记忆被错误强化的反直觉现象。
3. **方法设计优雅简约**：仅用 4 个固定语义坐标即可覆盖正/负、整合/自适应的完整状态空间，避免了复杂的架构设计和额外的可学习参数。
4. **探索与污染的正面解耦**：与"通过更强探索提升覆盖率"的思路不同，RoMeRL 通过减小状态维度从根本上限制暴露于错误奖励传播的效用支撑范围。
5. **实验严谨性**：MRT 压力测试设计了"保留标题语义但清空行动内容"的受控噪声条目，有效隔离开记忆-奖励陷阱的影响；跨模型迁移实验验证了记忆状态的泛化价值；Q 值分层分析提供了效用学习质量的可视化证据。
6. **实用性强**：在提升性能的同时大幅降低存储和推理成本（记忆减少 84.4%、LLM 调用减少 21.1%），对实际部署有直接价值。
7. **对称性理论+实验验证**：定理 3 的反馈密度提升（N_t/4 倍）与实验观测的 6.0× 提升相互印证，理论预测直接可检验。

---

## 8. 不足与局限

1. **因果分配未完全解决**：论文明确承认，RoMeRL 仍依赖结果级奖励（outcome-level rewards），并未从根本上解决因果信用分配问题——它通过减少暴露面来限制 MRT 的影响，但没有消除 MRT 本身。
2. **理论量的可估计性不足**：命题 1 中的 γ（洁净→错误转移概率）和 λ（错误→洁净转移概率）需要坐标级因果标签（来自配对反事实轨迹）才能估计，这在实践中很难获取，理论的分析意义大于实用指导意义。
3. **基准覆盖有限**：
   - 仅覆盖文本/终端交互场景（ALFWorld、LAB-OS、LAB-DB），未涉及真实世界机器人操作、视觉导航或多模态任务；
   - LAB 的 KG（知识图谱）子任务未纳入评估；
   - 未与最近的其他记忆学习方法（如 Memory-R1、Fine-Mem、AtomMem）直接对比。
4. **消融不完整**：仅消融了 NCC 和 PAC 两个坐标，未对称地消融 PCC 和 NAC；也未对结果极性维度和记忆动力学维度逐一分解。
5. **确定性收益的归因问题**：RoMeRL 同时改变了状态维度和记忆更新机制，性能提升可能部分来自更小的记忆池（减少了无关干扰）而非降序状态本身的功劳——需要一个与降序状态同级但保持全池大小的控制实验来区分。
6. **任务规模有限**：LAB 任务（500 个实例/子集）相对短期，未验证超长时域（数百个任务、数万次交互）下的状态协调退化情况；固定 4 个坐标在任务类型极其多样的开放域中可能表达力不足。
7. **超参数敏感度**：相似度阈值 δ 是自适应选取的（任务描述余弦相似度分布的 top 20% 分位数），但其对性能的影响未做敏感性分析。
8. **模型覆盖面有限**：仅测试了 2 个推理模型 + 2 个训练模型的迁移组合，未涉及更广泛的模型族，也未报告不同温度/解码策略下的鲁棒性。

---

## 总结

RoMeRL 通过将持续增长的轨迹索引效用空间压缩为固定维度的 2×2 降序语义坐标，在反馈利用、奖励污染抑制和运行效率之间取得了显著更优的平衡。其理论框架为理解自进化记忆学习中的"探索-污染"两难提供了新的分析视角，实证结果也展示了在多种任务场景中的有效性。然而，因果信用分配的深层问题仍需未来结合更细粒度的奖励信号或反事实归因来进一步解决。
