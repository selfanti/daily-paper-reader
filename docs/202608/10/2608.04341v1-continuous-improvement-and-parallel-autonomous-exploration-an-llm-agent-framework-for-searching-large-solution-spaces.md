## 摘要
我们提出了一种框架，为LLM代理提供两种自主搜索大型解空间的机制。首先，一个基于留出数据评分的排行榜作为奖励信号，驱动每个代理在反复提交中不断改进其解决方案，即使只有单个代理也能形成这种循环。其次，该框架支持完全自主地并行运行多个代理，无需人工介入：代理独立进行分析、调研方法、实现、自我评估、提交和修订，而一个协调代理仅负责后勤事务。在共享奖励下并行运行代理可扩大解空间的探索区域，而非仅仅优化单一初始范式。我们将该框架应用于产品到目录匹配（一项核心的电子商务检索任务，具有大型、按类别结构化的解空间），并将其表述为具有精确率-覆盖率操作点的选择性预测。单个代理在其初始范式内进行改进，而并行自主代理则会发现质性不同的解决方案。在此测试床上，最佳合格覆盖率（每个类别P@1>=95%）在单个代理下达到47.8-57.4%，五个代理下达到62.8-69.4%，而基线为33.3%。我们的贡献在于框架本身：一个持续改进的奖励循环和一个完全自主的并行探索基础，辅以案例研究证据。

## Abstract
We present a framework that gives LLM agents two mechanisms for searching large solution spaces autonomously. First, a leaderboard scored on held-out data acts as a reward signal that drives each agent to refine its solutions over repeated submissions, a loop that operates even with a single agent. Second, the framework enables running many agents in parallel, fully autonomously, with no human in the loop: agents independently analyze, survey methods, implement, self-evaluate, submit, and revise, while a moderator agent handles only logistics. Running agents in parallel under the shared reward broadens the explored region of the solution space rather than refining the single seeded paradigm. We instantiate the framework on product-to-catalog matching (a core e-commerce retrieval task with a large, category-structured solution space), posed as selective prediction with a precision-coverage operating point. A single agent refines within its seeded paradigm, whereas parallel autonomous agents surface qualitatively different solutions. On this testbed, best qualified coverage (>=95% P@1 per category) reaches 47.8-57.4% with a single agent and 62.8-69.4% with five, against a 33.3% baseline. Our contribution is the framework itself: a continuous-improvement reward loop and a substrate for fully autonomous parallel exploration, backed by case-study evidence.

## 方法论

### 核心思想
将“排行榜竞争”作为自主学习的奖励信号，并利用“多个独立代理并行”来克服单一代理因初始范式局限而导致的过早收敛和狭窄探索问题。作者强调，共享奖励是唯一的跨代理信号，代理之间不共享代码或实现细节，仅共享分数和高层方法描述，以此在保持探索多样性的同时保障完整性。

### 关键技术细节

- **任务定义**：
  - 用户列表 $q = (t_q, d_q, m_q, c_q)$（标题、描述、元数据、类别），需从该类别目录 $\mathcal{S}_{c_q}$（最多33K个SKU）中检索正确的目录SKU $s^*$。
  - 每个SKU具有相同字段结构。预测附带置信度分数，低于阈值的列表被排除（即“弃权”），从而以覆盖率换取精确率。
- **评估指标**：
  - **P@1**：被覆盖预测中top-1检索正确的比例。
  - **Coverage**：做出预测的列表比例。
  - 资格要求：**每个类别独立达到≥95% P@1**。
  - 排名目标：在合格提交中最大化平均覆盖率。
- **框架基础设施**：
  - **自动排行榜（LeaderboardAPI）**：代理提交必须包含三类预测及置信度阈值；API计算P@1和覆盖率、检查资格并按平均覆盖率排序、将结果追加到持久JSON账本。代理可查看全部提交的分数和高层方法描述。
  - **训练/测试分离和完整性保护**：
    - 训练数据含标签供代理自我评估；测试数据不含标签，代理必须提交给排行榜才能获得分数。
    - 测试标签存储在仅组织者可访问的位置；通过严格的ownership边界和自动化pre-run泄漏检查来执行分离。
    - 代理仅限其自己的工作目录 + 只读共享资源，结构性阻止代理复用其他代理的产物（作者观察到过此类尝试）。
  - **GPU资源管理**：早期并发使用导致GPU崩溃后，采用两级锁，30分钟CLAIM/RELEASE协议；系统级看门狗终止未授权GPU进程。
  - **自主性保障**：
    - Append-only聊天日志是唯一通信通道；无人类介入，人类仅提供一个启动命令（如“用5个代理运行5小时”）。
    - 协调者代理被限定为后勤功能（时间警告、排行榜更新、队列管理），明确禁止其提供技术指导。
    - 持续运行是强制性的：代理必须定期发送liveness心跳，提交后不停止，而是继续分析、修订和重新提交。
- **代理设置**：
  - 代理使用**Claude Sonnet 3.5**，访问Python环境，包括BGE-M3、Qwen3-Embedding嵌入模型、FAISS索引、TF-IDF库。
  - 接收任务简报，包含任务描述、数据格式、提交协议、GPU协调规则、5小时时间预算和BGE-M3基线参考。
  - 迭代研究循环：分析数据/错误 → 调研候选方法 → 提出假设 → 实现 → 在训练集上自评 → 提交测试预测 → 观察排行榜 → 修订。

## 主要结论与发现

- **关键定性发现（跨6次运行复现）**：
  - **单一代理迭代窄、过早收敛**：在三种单代理运行中，代理均停留在其种子的嵌入范式内（迭代BGE-M3变体、分数校准、阈值调优），并且**从未实例化**词法/字符串匹配方法（这是实践者通常会首先尝试的标准基线）。在一轮运行中，代理在预算剩余时过早判断最难类别为不可解并停止。
  - **并行自主代理逃脱范式**：在所有三轮五代理运行中，代理在会话内独立达到定性不同的方法：TF-IDF重新排序、基于SequenceMatcher的字符串相似度匹配、卡号重新排序 + 纯字符串匹配、字符串匹配 + 词/字符TF-IDF融合。这些非嵌入方法推动了最优结果。
- **性能数字（表2）**：
  - 基线：平均覆盖率33.3%（未合格）。
  - 单代理：最佳合格覆盖率47.8–57.4%（三轮）；所有运行均合格。
  - 五代理：最佳合格覆盖率62.8–69.4%（三轮）；所有运行均合格；最佳P@1均为95.1%。
  - **并行探索的增益集中在最难的类别（智能手机）**：单代理覆盖率0.8–1.9% vs 并行24.8–41.1%；在交易卡类别中，单代理在无GPU竞争时可与并行效果相当。
- **排行榜动态（图2）**：在一个代表性子运行中，首次合格提交出现在大量探索之后；覆盖率通过阈值调优和卡号重排达到65.6%后进入平台期；最终突破来自后期添加字符串匹配 + 词TF-IDF融合达到69.4%，说明并行探索能产生“后期关键推动力”。
- **结论**：共享排行榜奖励驱动持续改进，且并行执行能显著拓宽探索区域，突破单一种子范式的局限。

## 优点

- **框架设计有明确动机和通用性**：将“排行榜分数作为奖励”和“并行独立代理”结合起来，这种双机制设计在同类工作中较为新颖；适用于任何可以用预测-评估-反馈循环表达的任务，不仅是商品匹配。

- **提供了路线图**："是否将动力学泛化到其他有界优化任务"这一开放问题的提出为后续研究指明了方向。
