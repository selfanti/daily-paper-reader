## 摘要
多轮智能体强化学习中的信用分配在两个层面上运作：将轨迹级别的信用分配给行动，并将每个行动的信用分配到其令牌上。在本文中，我们介绍了FACTOR，它将这两个决策分离开来。FACTOR使用检查点校准的TD残差来分配每个行动的信用，这些信用可合计为轨迹优势，并使用反馈条件下的师生似然差距将每个信用分配到已实现的行动令牌上。逐行动归一化保留了行动平均系数，并防止了令牌级别的符号翻转。我们将此构造与行动均值归约相结合，消除了行动的标量代理权重对其令牌长度的隐式依赖。在行为策略下且在裁剪之前，每个行动的内部行动均值代理等于其TD信用。FACTOR在ALFWorld、WebShop和ScienceWorld上持续优于竞争基线，每一次环境-种子比较都倾向于FACTOR，并且在最长视界环境中出现了最大的增益。相同的超参数无需重新调整即可迁移到更大的主干网络和不同的模型家族。消融实验表明，TD行动信用是改进的主要驱动因素，而事后令牌分配贡献了互补的增益。

## Abstract
Credit assignment in multi-turn agent reinforcement learning operates at two levels: assigning trajectory-level credit to actions and distributing each action's credit across its tokens. In this paper, we introduce FACTOR, which separates these decisions. FACTOR uses checkpoint-calibrated TD residuals to assign per-action credits that telescope to the trajectory advantage, and feedback-conditioned teacher-student likelihood gaps to allocate each credit across the realized action tokens. Per-action normalization preserves the action-average coefficient and prevents token-level sign flips. We pair this construction with an action-mean reduction, removing the implicit dependence of an action's scalar surrogate weight on its token length. At the behavior policy and before clipping, each action's inner action-mean surrogate equals its TD credit. FACTOR consistently improves over competitive baselines across ALFWorld, WebShop, and ScienceWorld, with every environment-seed comparison favoring FACTOR and the largest gains emerging on the longest-horizon environment. The same hyperparameters transfer without retuning to a larger backbone and to a different model family. Ablations identify TD action credit as the dominant driver of the improvement, with hindsight token allocation contributing complementary gains.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **两层信用分配问题**：在多轮智能体强化学习（Multi-Turn Agent RL）中，训练信号通常是单一、稀疏的最终任务结果，而策略优化需要更新模型输出的每一个 token。由此产生一个“粒度不匹配”问题，迫使更新过程回答两个不同层面的问题：
  - **时间信用分配（Temporal Credit Assignment）**：每个已执行的行动（action）应当获得多少片段级别的信号？
  - **行动内分配（Intra-Action Allocation）**：一个行动获得的信用，应如何在其实现该行动的各个 token 之间分配？
- **现有方法的割裂**：
  - 轨迹级方法（如 GRPO）将单一轨迹优势广播到所有轮次和 token，同时回避了这两个问题；
  - 时间信用方法（如 GiGPO、HGPO、TRACE 等）只细化到“每个行动获得多少信用”就停止；
  - token 级调制方法（如 RLSD、SERL 等）只调整“信用落在哪些 token 上”，但将行动级信用视为固定值。
- **未解决的耦合问题**：没有任何一方检查自己的步骤是否保持另一方预期的尺度。具体表现为：
  - 若 teacher 的 token 乘数未在行动内归一化，会同时改变信用的“位置”和“总量”；
  - 在全局 token-mean 归约下，一个行动的总代理贡献会随其 token 数量缩放，导致两个信用相同的行动仅因回答长度不同而以不同量级进入训练。
- **论文目标**：提出 **FACTOR** 框架，将行动信用（多少，How Much）与 token 分配（何处，Where）解耦为两个独立的对象，通过显式的“守恒”接口连接，使第一阶段的信用决策不被第二阶段的分配所修改。

## 2. 论文提出的方法论

### 2.1 核心思想

- FACTOR 将 token 系数分解为 **C_t,j = A\*_t · ω_t,j**，其中：
  - **A\*_t** 是行动 t 的 TD 信用（由 TAC 确定）；
  - **ω_t,j** 是行动内均值为一的 token 分配权重（由 HTA + APM 确定）。
- 通过“先定总量、再分内部”的两阶段流水线，确保 token 分配永远不能修改行动级信用。

### 2.2 三个核心组件

**(1) TAC：TD 行动信用（Checkpoint-Calibrated TD Action Credit）**
- 使用检查点校准的轻量级价值头（value head），从稀疏的“仅推理”延续（inference-only continuations）中估计中间状态价值；
- 用一步 TD 残差将轨迹优势分解到每个行动：
  > A\*_i,t = r_i,t + V̄_φ(x_i,t+1) − V̄_φ(x_i,t)
- **关键性质——望远镜求和**：所有行动的信用之和恰好等于原始轨迹优势 A_seq：
  > Σ_t A\*_i,t = G_i − b_i = A_seq_i
- 边界约定：V(x₀) = 基线 b_i，V(x_T) = 0，保证等式恒成立。

**(2) HTA：事后 token 分配（Hindsight Token Allocation）**
- 使用冻结的 teacher 策略 π_T（在行动后附加真实环境反馈 Φ_t 重新评分）与学生策略 π_θ 的似然差距：
  > Δ_t,j = log π_T(y_t,j | x_t, Φ_t, y_t,<j) − log π_θ(y_t,j | x_t, y_t,<j)
- 通过以下公式生成与结果对齐的分数：
  > s_t,j = sgn(A\*_t) · clip(Δ_t,j, −d, d)
- 当 A\*_t > 0 时，Δ 较大的 token 获得更多正向信用；当 A\*_t < 0 时，Δ 较小的 token 承担更多负向信用。

**(3) APM：逐行动均值保持（Per-Action Mean Preservation）**
- 将 HTA 分数通过 softmax 归一化为非负、行动内均值为一的分配：
  > ρ_t,j = (1−η_k)·(1/L_t) + η_k · softmax_j(s_t,j / τ)
- 归一化权重为 **ω_t,j = L_t · ρ_t,j**，保证：
  > (1/L_t) Σ_j C_t,j = A\*_t
- 因为 ρ_t,j ≥ 0，teacher 不能翻转任何 token 相对于行动信用的符号。

### 2.3 行动均值损失与守恒

- FACTOR 使用**行动均值（action-mean）PPO 代理损失**：
  > L^act_RL = −(1/Σ_i T_i) Σ_i,t (1/L_i,t) Σ_j min(q_i,t,j·C_i,t,j, clip_ε(q_i,t,j)·C_i,t,j)
- **关键性质**：在行为策略点（q_i,t,j = 1），每个行动的内部平均代理值恰等于其 TAC 信用 A\*_i,t，与 token 数量无关。
- 非行动 token（推理、格式）使用独立的 token-mean 分支，系数为 A_seq。
- 总损失 = 行动分支 + 非行动分支 + λ_k·SERL 辅助 KL 项。

## 6. 论文的主要结论与发现

- **主结果**：FACTOR 在 ALFWorld（+2.2 pp）、WebShop（+2.4 pp）、ScienceWorld（+4.2 pp）上一致优于 SERL-Repro，且在所有 9 个种子-环境比较中占优；
- **最长视界收益最大**：ScienceWorld（最长视界环境）增益最大，ALFWorld 内的视界分层分析也显示增益随轨迹长度单调增加（从 +0.4 pp 到 +5.6 pp）；
- **跨骨干与跨模型族迁移**：7B 的超参数直接迁移到 Qwen2.5-14B（+0.8/+0.9/+2.7 pp）和 Llama-3.1-8B（+2.1/+1.9/+2.9 pp）仍有收益；
- **消融定位**：TD 行动信用（TAC）是改进的主导驱动（平均移除损失 2.5 pp）；事后 token 分配（HTA）在 WebShop 和 ScienceWorld 上贡献互补增益（1.6/2.1 pp），但在 ALFWorld 上近乎中性；
- **协议交互**：action-mean 归约使 FACTOR 的守恒性质在损失层面“载重”，在 2×2 研究中，action-mean 下 FACTOR 的优势大于 token-mean 下；
- **机制验证**：SERL 的行动平均系数有 6.7% 的中位数偏差（28% 行动超过 10%），FACTOR 全部低于 4×10⁻⁷；TAC 符号准确率达 84.2%（晚期 89.2%）；高权重 token 的扰动显著影响回报。

## 7. 优点

- **概念清晰**：将“信用总量”与“信用分布”两个决策明确解耦，并通过数学上严格的守恒接口连接，避免了此前方法的耦合漂移问题；
- **理论优雅**：TD 残差的望远镜求和恒等式 + 行动均值损失的“行为策略点恒等性”（行动内部均值代理值恰等于其 TD 信用），具有精确的可验证性质；
- **工程上轻量**：仅修改可执行行动 token 的系数，保留 SERL 的辅助蒸馏损失不变；价值头为轻量 MLP，延续采样为仅推理操作；
- **实验全面**：多环境、多种子、跨骨干、跨模型族、9 种消融、超参数扫描、机制诊断一应俱全；
- **统计可信**：层次化 bootstrap 置信区间、逐种子报告结果、无失败实验排除，提升结果可信度；
- **诚实报告**：消耗预算有详细清单，没有在测试集上选择超参数；
- **写入公平性**：提供拆分清单的 SHA-256 校验和，确保可分性。

## 8. 不足与局限

- **需要可恢复状态与环境**：FACTOR 要求能够从轨迹中途恢复环境状态并生成延续样本，这在真实物理系统或不可重置的在线环境中不可用，限制了应用范围；
- **计算成本增加**：延续采样使环境交互增至 3.5 倍，即使墙钟时间仅增加 1.25 倍，交互预算在真实环境中可能是瓶颈；
- **价值头校准依赖蒙特卡洛目标**：价值头的质量取决于延续样本的多样性和数量；ScienceWorld 上校准质量最差（sign accuracy 82.7%），说明长视界、稀疏奖励场景下仍有改进空间；
- **HTA 的收益任务相关**：在 ALFWorld 上移除 HTA 反而微增（+0.2 pp），说明 token 级分配并非在所有环境中都有效；
- **消融中部分变体间的差异较小**：Batch-global norm 与 FACTOR 的差距仅约 1 pp 左右，且 WebShop 上 Batch-global 甚至略优（+0.2 pp），说明逐行动归一化在不同环境中的有效性有所波动；
- **机制验证的因果性受限**：token 扰动实验无法完全消除语义混杂（如动词和物体名词同时具有高分配权重和高功能重要性），作者也承认证据是“一致的但非证明性”；
- **TC 信用符号噪声**：早期训练符号准确率仅 76.8%，13.2% 的行动存在符号不匹配，可能向错误方向传播梯度；
- **仅三种环境**：均为文本交互环境（家居、网购、科学实验），未覆盖多模态、具身或真实网络环境。
