## 摘要
长时程智能体在交互过程中会积累不断增长的上下文，损害其性能与稳定性。紧凑记忆通过压缩和重写模型调用之间保留的历史信息来缓解这一问题。学习保留哪些内容通常依赖于带有最终任务奖励的近端策略优化（PPO），但稀疏奖励对单个记忆更新的指导作用有限。这一局限催生了在线策略蒸馏（OPD），它在学生策略的交互轨迹上提供密集的教师监督。要使这种监督有效，教师必须在采样动作生成时的同一状态下评估每个动作。然而，记忆压缩过程中进行的上下文重写可能破坏这种对齐。当采样响应被保留并重新编码以供后续调用时，将交互扁平化为持久历史可能导致教师在学生从未在交互中访问过的状态下对动作评分。因此，该动作在来源上属于在线策略，但在状态上未必如此。为此，我们提出了记忆对齐在线策略蒸馏（MemOPD）。MemOPD 记录每次模型调用的输入与采样输出，恢复其原始标记位置及因果可见性，并打包重建的调用以实现高效的教师评分。教师在采样动作位置提供全词汇表监督，而 PPO 保留最终任务目标。实验验证了多次上下文更新中的状态对齐，并显示在匹配控制条件下，相比持久历史教师评分，其 F1 值提升了 7.0%。总体而言，MemOPD-3B 相较于 PPO 的 F1 值最高提升了 416.2%，同时打包机制在训练期间使演员计算速度提升至 1.63 倍。本工作代码公开于：https://github.com/TPssp/MemOPD。

## Abstract
Long-horizon agents accumulate growing contexts during interaction, impairing performance and stability. Compact memory mitigates this problem by compressing and rewriting the history retained between model invocations. Learning what to retain typically relies on proximal policy optimization (PPO) with final task rewards, but sparse rewards provide little guidance for individual memory updates. This limitation motivates on-policy distillation (OPD), which supplies dense teacher supervision on student rollouts. For such supervision to be valid, the teacher must evaluate each sampled action under the same state in which it was generated. However, the context rewriting performed during memory compression can break this alignment. When sampled responses are retained and re-encoded for later invocations, flattening the interaction into a persistent history may cause the teacher to score the action under a state that the student never visited during rollout. The action therefore remains on-policy by provenance, but not necessarily by state. We therefore propose Memory-Aligned On-Policy Distillation (MemOPD). MemOPD records the inputs and sampled outputs of each model invocation, restores its original token positions and causal visibility, and packs the reconstructed invocations for efficient teacher scoring. The teacher provides full-vocabulary supervision at the sampled action positions, while PPO preserves the final task objective. Experiments verify state alignment across several context updates and show that it improves F1 by 7.0% over persistent-history teacher scoring in a matched control. Overall, MemOPD-3B improves F1 over PPO by up to 416.2%, while packing yields up to a 1.63x speedup in actor computation during training. The code for this work is publicly available at: https://github.com/TPssp/MemOPD.

  - 在线策略蒸馏（OPD）可以提供密集的教师监督，但**上下文重写会破坏“状态对齐”**——当采样响应被保留并重编码为后续上下文时，将交互扁平化为持久历史会使教师在学生从未访问过的状态下评估动作，导致动作“来源上是 on-policy，但状态上不是 on-policy”。
- **整体含义**：论文指出现有紧凑记忆智能体的训练中，动作来源（provenance）与状态有效性（state validity）必须分离。要保证 OPD 在长时程智能体上真正有效，必须恢复采样动作生成时的精确调用状态。该工作为压缩记忆智能体的训练确立了“记忆状态对齐”这一必要条件。

### 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：MemOPD 通过记录每次模型调用（invocation）的精确输入和采样输出，在训练时恢复原始 token 位置、因果可见性和预测位置，将重建的调用打包后进行教师监督，确保教师在学生实际访问过的状态下评估动作。

- **关键技术步骤**：

  - **紧凑记忆交互形式化**：定义行为策略调用状态 `σt = (zt, ρt, Vt, γt)`，其中 `zt` 为精确 token 化输入，`ρt` 为 token 位置，`Vt` 为因果可见性，`γt(k)` 标识预测动作 token `a_t,k` 的位置。状态对齐要求 `σ̃t,k = σt,k`，即训练重建状态与 rollout 状态逐一相等。
  - **精确调用重建与打包**：
    - 记录采样 token ID 而非重新解码，保持动作边界；
    - 将多次调用打包为物理序列 `y = [q, x0, a0, x1, a1, …]`，共享任务前缀 `q`；
    - 恢复每个调用块独立的 token 位置和因果可见性，不同调用块之间禁止注意力；
    - 若超长导致条件 token 被截断，直接拒收该样本而不是静默改变状态。
  - **采样动作域标记**：通过 mask `m^act` 区分“采样动作出现”与“后续上下文复制”，防止将被保留的响应副本误算为策略决策。GAE 与价值学习仅在采样动作域上前进。
  - **训练目标**：
    - **PPO 分支**：在采样动作域上计算裁剪策略比率与 GAE 优势，保留最终任务目标；
    - **OPD 分支**：在教师监督 mask（默认覆盖全部采样动作 token）上计算全词表反向 KL 散度：`L_OPD = (1/Σm^T_j) Σ_j m^T_j Σ_v p_θ,j(v) log(p_θ,j(v)/p_T,j(v))`；
    - 参考策略 KL 惩罚、熵正则、值函数学习均在重建状态上执行。
  - **RCE 验证准则**（Rollout Context Equivalence）：要求打包执行与独立执行对每个采样动作 token 产生相同的全词表 logits（数值精度内），用于离线审计而非训练损失。

### 6. 主要结论与发现

- **状态对齐是 OPD 应用于紧凑记忆智能体的必要条件**：持久历史重建导致 p99 log 概率误差达 1.774，改变了 651 个采样动作位置的 top-1 预测，并使 13.29% 的动作在策略未更新的情况下被错误触发 PPO 裁剪。
- **MemOPD 在长时程任务上显著优于 PPO**：Q2 / Q8 / Q16 上 F1 分别提升 14.3% / 283.2% / 416.2%（五个种子平均）；Q16 上峰值上下文降低 33.0%，推理时间降低 14.1%。
- **在 Wiki-RAG 上具有跨任务迁移能力**：EM 与 F1 分别较 PPO 提升 6.1% 与 7.4%，同时依赖度和推理时间分别降低 31.6% 和 28.5%。
- **状态对齐本身带来可分离的增益**：匹配控制中，持久历史教师打分将 F1 提升 5.6%，而 MemOPD 的状态对齐在教师监督之上再提升 7.0%。
- **打包在保持 RCE 的前提下带来训练加速**：最高 1.63× 演员计算加速。

### 7. 优点

- **问题识别精准且具有普遍性**：首次系统性地指出紧凑记忆智能体中“上下文重写破坏 OPD 状态对齐”这一本质问题，并给出严格形式化定义。
- **方法论完整自洽**：从记录采样 token ID、重建调用状态、区分采样动作与上下文复制、到 GAE 在动作域上前进，形成了完整闭环；RCE 作为独立验证准则提升了可信度。
- **实验控制严谨**：PPO 与 MemOPD 共享初始化、数据顺序、打包表示、采样动作 mask，差异仅在于教师引导，归因清晰。
- **具有很好的泛化支持**：重建接口不依赖特定记忆拓扑，在 full response、suffix retention、summary replacement、sliding window、retrieval refresh 等 5 种上下文更新策略下均保持 RCE。
- **代码已开源**，有利于复现和后续研究。

### 8. 不足与局限

- **实验覆盖仍有局限**：

  - 仅评估了 3B 学生 + 7B 教师一种组合，未分析教师规模、学生规模、λ 系数的敏感性。
- **部分关键信息缺失**：训练时长、数据规模（轨迹数）未明确披露，算力成本报告不够完整。
- **潜在偏差风险**：
