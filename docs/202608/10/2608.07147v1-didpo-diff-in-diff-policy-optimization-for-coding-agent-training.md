## 摘要
基于可验证奖励的强化学习(RLVR)已成为训练编码智能体的有效范式，其中编译和测试的执行反馈提供了客观验证。然而，与一般智能体任务不同，编码智能体面临独特且更细粒度的信用分配挑战：在每一步中，编码操作同时将不同的更改打包到代码版本的不同区域，这使得独立更改的贡献难以区分。现有的RLVR方法大多利用结果奖励或步骤级奖励，未能深入代码差异，使得编码操作的独特属性在训练中不可见。在本文中，我们提出了差分中的差分策略优化(DiDPO)，一种无评论家的RL方法，直接从代码差异的结构中构建细粒度的信用单元。DiDPO将多轮编码交互组织为多个思考-行动步骤，并在采样轨迹中发现代码差异。然后，它通过我们的“可分组性分数”从每个完整差异中拆分出高度相似的子差异，并聚合这些子差异来选择锚点，该分数提供了在锚点的语义范围及其可能形成的组质量之间取得最佳平衡的拆分方案。最后，这些锚点形成优势组，并将差异级别的优势投影回各个响应标记。在长视野编码和推理基准上的实验表明，DiDPO显著优于强智能体RL基线。在Qwen2.5-7B-Coder上，DiDPO超过可比方法10%以上，并缩小了与更大模型的差距，为编码智能体训练中的细粒度信用分配提供了一个有原则的框架。我们还开源了verl-code，一个支持多种RL方法和编码基准的智能体RL代码库。

## Abstract
Reinforcement learning with Verifiable Reward (RLVR) has emerged as a powerful paradigm for training coding agents, where the execution feedback from compilation and tests provides objective verification. However, unlike agent tasks, coding agents face a unique and finer-grained credit assignment challenge: at each step, coding actions simultaneously pack varying changes into different regions of a code version, which makes the contribution of independent change indistinguishable. Existing RLVR methods mostly leverage the outcome reward or step-level reward, which fails to dive into a code diff and makes unique properties of coding actions invisible to training. In this paper, we propose Diff-in-Diff Policy Optimization (DiDPO), a critic-free RL method that constructs fine-grained credit units directly from the structure of code diffs. DiDPO organizes multi-turn coding interactions into multiple thought--action steps and discovers code diffs across sampled trajectories. It then selects anchors by aggregating highly similar sub-diffs split from each whole diff by our ``groupability score'', which provides the splitting schema that optimally balances the semantic scope of anchors and the group mass they may form. Finally these anchors form advantage groups and project the diff-level advantage back to individual response tokens. Experiments on long-horizon coding and reasoning benchmarks show that DiDPO significantly outperforms strong agentic RL baselines. On Qwen2.5-7B-Coder, DiDPO exceeds comparable methods by over 10\% and narrows the gap with far larger models, offering a principled framework for fine-grained credit assignment in coding agent training. We also open-source verl-code, an agentic rl codebase that supports various RL methods and coding benchmarks.

- **核心难点**：与一般智能体任务中“一个状态对应一个动作”的设定不同，编码智能体在每一步中可能同时将多个修改（diff）应用到代码版本的不同区域，这些独立修改的贡献互相纠缠，难以区分。论文将其归纳为三个结构性特征：
  - ❶ 编码动作与代码片段捆绑，且片段随任务难度扩大，更困难的任务需要更长编辑，动作在多个区域间交错；
  - ❷ 每一步的整个 diff 可能包含多个功能不同的子 diff（sub-diff），将整个 diff 视为整体会掩盖语义单元的真实贡献；
  - ❸ 代码受严格语法与执行正确性约束，任何小的错误编辑都可能影响长轨迹，需要特殊关注。
- **现有方法局限**：GRPO/GSPO/DAPO 等仅使用结果级奖励，GiGPO 虽提出状态级信用分组，但无法处理编码动作内部的子结构——功能相似但代码区域不同的编辑无法按环境状态对齐。
- **论文意义**：提出第一个直接基于代码 diff 层次结构进行细粒度信用分配的智能体强化学习算法 DiDPO，以无评论家（critic-free）方式将可验证的结果反馈转化为局部的、token 级的训练信号。

## 2. 论文提出的方法论（DiDPO）

### 2.1 总体框架
DiDPO 将多轮编码交互组织为思考-行动步骤，跨采样轨迹发现 diff 的结构相似性，将完整 diff 按“可分组性分数（Groupability Score, GS）”切分为子 diff，聚合高度相似的子 diff 为锚点，进而形成优势组，将 diff 级优势与轨迹级优势结合后投影到响应 token。全程不引入额外评论家网络、不增加环境采样。

### 2.2 关键技术细节

- **Diff 可分割性**：聚合所有轨迹、所有步骤的 diff 集合 S = {{D_{i,k}; 1≤k≤T_i}; 1≤i≤N}，每个 diff 附带元数据 (u(s), v(s), w(s), q(s))，分别表示归一化文本、响应 token 跨度、动作类型（add/del/none）、所属任务实例。
- **子 diff 锚点枚举**：对每个 diff 枚举连续子片段 I(s) = {Seg(s, [p,q))}，在不同轨迹/步骤的子 diff 之间计算相似度矩阵，仅在 w(s)=w(s′)（同类型编辑）间匹配，相似度 σ ≥ η 视为匹配候选。
- **可分组性分数（GS）**：

  GS(c) = (1 − e^(−L̄(c))) · (1 − e^(−(n(c)−1)))

  其中 L̄(c) 为锚点的平均归一化大小（语义范围），n(c) 为锚点的出现次数（组质量）。该设计保证锚点既携带足够语义功能又聚合足够样本量。
- **锚点选择（子模最大化）**：为避免重叠锚点重复占用同一子 diff，DiDPO 以基数约束的设施选址形式求解 C⋆ = argmax Σ max 1[s∈O(c)]·GS(c)，采用贪心法获得 (1−1/e) 近似保证。
- **Diff 级优势计算**：同一锚点的所有动作形成优势组，组内进行相对优势估计（减去组均值、按组作归一化），得到 AD(a_{t,m}^{(i)})。
- **最终训练目标**：将轨迹级优势 AE 与 diff 级优势 AD 按系数 λ 组合为 token 级优势 Â_{i,l} = AE(τ^(i)) + λ·AD(a_l^(i))，使用标准 clipped PPO 形式更新策略，ρ_{i,l} 为新旧策略的 token 级概率比。
- **理论保证**：两个定理给出了方法的统计依据——
  - 定理 4.1：若组内子 diff 与锚点的对应误差为 ε，则局部信用偏差有 O(Lε) 上界（L 为局部奖励的 Lipschitz 常数）；
  - 定理 4.2：若组内包含 m>1 个子 diff，则局部优势估计的 MSE ≤ O(L²ε²) + O(σ²ξ/m)，即锚点质量控制偏差，跨 rollout 聚合降低非因果轨迹噪声的方差。

- **锚点覆盖不完整**：并非所有子 diff 都能被锚点覆盖，未分组部分直接退化为轨迹级优势 AE 主导，算法有效性对锚点覆盖率存在隐式依赖，但论文未报告覆盖率的具体数值与分布。

- **评估方差缺失**：全部实验仅报告均值，未给出多次运行的方差或置信区间；考虑到 RL 训练本身的高方差特性，部分小差距结论（如 7B 上 DiDPO 与 GiGPO 的 4.2 点差异）的统计显著性存疑。
- **骨干模型范围有限**：仅验证了 7B 和 4B 两个小规模模型，未在更大模型（如 14B/32B）上验证 DiDPO 的可扩展性；小模型上 RL 增益大，大模型上是否仍有显著优势未知。
- **高难度任务地板效应**：USACO Gold/Platinum、竞赛难度极高层级上所有方法均接近 0%，导致在这些区间无法区分算法优劣，实验结论的外推范围受限。

实验维度较丰富（8 基准 × 多难度分层 × 多组消融），主结论"DiDPO 显著优于 GRPO/GiGPO"在多个基准上方向一致，可信度较高。但方差缺失、消融覆盖不全、高难度地板效应等问题削弱了结论的精确性，读者在引用具体数值时需谨慎。

### 9.4 学术价值
- **创新性**：高。首次将细粒度 diff 结构引入智能体 RL 训练，开辟了"编辑级信用分配"这一新方向；
- **可复现性**：中等偏高。算法描述清晰、超参数完整，但锚点贪心选择与相似度计算的实现细节（如 GPU/CPU 分工）论文未完全展开；
- **实用价值**：高。对编码智能体训练具有直接指导意义，且 2.3% 的额外开销使其容易嵌入现有 RLVR 流水线。

### 9.5 展望
未来工作可能沿以下方向推进：引入语义级（而非文本级）的子 diff 匹配以提升锚点质量；将 DiDPO 与过程奖励模型（PRM）结合形成多层次信用分配；在更大骨干模型和真实软件工程任务（如 SWE-bench）上验证泛化性；探索锚点组数、覆盖率与最终性能之间的定量关系以简化超参数选择。

**总体评价**：DiDPO 是一篇方法新颖、理论扎实、实验较充分的强化学习论文。它以轻量级、无评论家的方式实现了编码智能体的细粒度信用分配，在多个竞赛与函数合成基准上取得了明显优于现有智能体 RL 方法的效果，是该方向上一个有价值且具有后续启发力的工作。
