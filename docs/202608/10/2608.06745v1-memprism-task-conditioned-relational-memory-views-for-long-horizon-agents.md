## 摘要
长时程智能体依赖记忆来复用经验，然而现有的记忆系统往往假设可以通过固定表示直接消费证据。这导致了表示不匹配，即相关信息可用但未针对当前决策进行组织。为此，我们提出MemPrism，一种任务条件关系记忆框架，将持久化经验存储与决策时的工作记忆分离。MemPrism将交互记录为事件流，并根据当前任务上下文动态构建关系视图。一个轻量级视图策略选择关系结构、证据范围、结果条件和粒度，而一个确定性组合器与渲染器将历史事实转换为临时的工作记忆视图，供冻结的任务策略使用。在长时程具身和Web智能体基准上的实验表明，MemPrism一致地提升了任务性能，尤其是在轨迹变长时，同时减少了记忆令牌消耗。此外，学习到的视图策略无需额外适应即可跨不同VLM迁移，展示了任务条件关系视图作为智能体通用记忆接口的有效性。

## Abstract
Long-horizon agents rely on memory to reuse experiences, yet existing memory systems often assume that evidence can be directly consumed through a fixed representation. This leads to representation mismatch, where relevant information is available but not organized for the current decision. To this end, we propose MemPrism, a task-conditioned relational memory framework that separates persistent experience storage from decision-time working memory. MemPrism records interactions as the event stream and dynamically constructs relational views according to the current task context. A lightweight view policy selects the relation structure, evidence range, outcome condition, and granularity, while a deterministic composer and render transform historical facts into a temporary optical working-memory view for a frozen task policy. Experiments on long-horizon embodied and web-agent benchmarks show that MemPrism consistently improves the task performance, especially as trajectories become longer, while reducing memory token consumption. Furthermore, the learned view policy transfers across different VLMs without additional adaptation, demonstrating the effectiveness of task-conditioned relational views as a general memory interface for agents.

## 一、论文核心问题与整体含义（研究动机与背景）

### 1.1 核心问题：表示不匹配（Representation Mismatch）

- **背景**：随着 LLM/VLM 智能体在网页导航、软件工程、工具使用和具身交互等场景中的广泛应用，单条轨迹常涉及数十甚至上百步，智能体对交互历史的结构化利用能力成为任务成败的关键。
- **已有进展**：现有记忆系统沿三个方向推进——①结构化持久记忆（层级摘要、知识图谱、笔记存储）；②可学习的记忆控制（写入、更新、删除、检索的决策化）；③光学/视觉记忆表示（将历史渲染为图像以压缩 token）。这些方法分别改善了记忆的存储、管理和访问方式。
- **被忽视的盲点**：上述系统都隐含一个共同假设——**只要相关证据被保留并成功检索，就可以通过固定表示直接喂给策略模型**。然而，同一段历史对于不同决策往往需要不同的组织方式：回路检测需要动作-结果对齐，状态追踪需要同一实体的纵向归组，失败分析需要动作与反馈的关联，依赖分析需要跨时空事件的连接。
- **关键观察**：作者明确指出：**"获取正确证据 ≠ 该证据对当前决策有用"**。当证据虽已存储并检索到，但其组织形式不符合当前子任务所需的关系结构时，决策仍然失败——这种失败既非存储失败，也非检索失败，而是发生在检索与决策之间的"读时接口"上，被定义为 **后检索表示不匹配（post-retrieval representation mismatch）**。
- **核心主张**：持久记忆应保存稳定、可复用的交互事实，而工作记忆应为当前决策动态构建——即**不仅要学习存什么、取什么，还要学习如何呈现取出的证据**。

## 二、方法论：MemPrism 框架

### 2.1 核心思想：持久历史与临时工作视图的解耦

MemPrism 将交互历史统一记录为事件流，在每个决策步骤由轻量级视图策略选择"如何看历史"，再由确定性管道构建临时的、任务条件化的关系视图供冻结的 VLM 策略使用。该视图仅服务当前决策，用完即弃，**永不回写**持久记忆。

### 2.2 五模块架构

| 模块 | 职责 |
|------|------|
| **Recorder** | 将每次交互保存为原始事件和结构化事件：$\tilde{e}_t = (t, e^{ent}_t, e^{act}_t, e^{out}_t, \Delta s_t, \xi_t)$，其中包含主实体、规范化动作类型、结果类型（exception / state_update / no_observed_change）、稀疏状态更新及可选证据（标签、图像、框、裁剪图）。 |
| **Router** | 编码当前观测、任务目标、近期事件特征和全局历史统计，在 **144 种联合视图动作**（4 种关系类型 × 3 种时间范围 × 4 种结果过滤 × 3 种粒度）中做出选择，使用联合头部保持各因素间的依赖关系。 |
| **Composer** | 按所选视图动作从事件流中选择证据，构建四类关系结构：**TemporalTrace**（时间顺序）、**ActionEffect**（按动作-实体分组，对齐重复尝试与结果）、**EntityState**（按实体的状态键纵向归组，展示状态演化）、**DependencyChain**（以最新事件为锚点的局部依赖追踪，非因果图）。 |
| **Render** | 以固定视觉语法将关系结构渲染为光学工作记忆视图：空间邻近表示分组，行列对齐支持状态比较，箭头表示变化/依赖，高亮标记失败与任务相关证据。 |
| **Adapter** | 仅训练阶段使用，分两阶段训练 Router 的视图选择策略：①**动作条件监督初始化**（LSFT = KL 散度 + 结构成本项）；②**分组 GRPO 在线优化**（同任务轨迹共享归一化优势，仅更新 Router）。 |

### 2.3 关键设计要点

- **四因子联合视图动作空间**：$A_v = \mathcal{T} \times \mathcal{W} \times \mathcal{O} \times \mathcal{G}$，共 4×3×4×3=144 种组合，联合预测保持了因子间的依赖关系。
- **两阶段训练**：第一阶段用"视图教师"（view teacher）提供基于参考动作的软标签分布进行监督蒸馏；第二阶段用轨迹级分组 GRPO，将视图选择的收益直接归属于记忆表示接口而非任务策略。
- **训练隔离**：任务策略、事件提取器、Composer、Render 全程冻结，只有 Router 被更新，从而将性能增益直接归因于记忆视图的选择。
- **光学视图的双重功能**：既是压缩历史的媒介，更是表达关系语义的结构化接口——二维布局本身编码了时序、动作-结果、实体状态和局部依赖等关系。

## 六、主要结论与发现

### 6.1 核心结论

1. **MemPrism 一致优于现有记忆系统**：ALFWorld 上 SFT+GRPO 达 40.71% SR，超过最强基线 LangMem（38.27%）2.44 个百分点；Mind2Web 上整体动作准确率 12.87%，超 Full History 4.08 个百分点；EB-ALFRED 上平均 SR 17.7%，比 Full History（10.3%）高 7.4 个百分点。
2. **表示不匹配是真实瓶颈**：在相同证据窗口下，四种固定关系视图的 SR 从 30.00% 到 35.71% 不等——同样的历史，不同的组织方式直接导致 5.71 个百分点的差异，直接验证了"证据在但组织不当"的假设。
3. **动态组织与光学呈现产生互补增益**：动态组织独立贡献 5.00 点，光学呈现独立贡献 3.57 点，两者结合达到最佳（40.71%）。
4. **粒度是最重要的视图因子**：固定 fine 粒度导致最大降幅（-7.84 点），固定视图类型次之（-4.99），固定结果过滤器影响最小（-0.70）。
5. **轨迹越长，优势越大**：≤15 步时 MemPrism 反超 Full History，到 ≤50 步时差距扩大至 9.3 个百分点；同时 prompt token 稳定在 642-852 区间，Full History 则线性增长至 1,201。
6. **视图策略可跨 VLM 迁移**：同一 planner checkpoint 零样本应用至三种未见过的 VLM，全部获得 SR 提升（+2.26 至 +9.40 点），同时实现 30.6%-48.2% 的 token 压缩。

## 七、方法亮点

1. **问题定义新颖且尖锐**："后检索表示不匹配"这一概念精准地定位了现有记忆系统的共同盲区——检索与消费之间的接口问题，独立于存储失败与检索失败。
2. **模块化架构高度解耦**：持久事件流与临时工作视图的分离避免了固定摘要、重复压缩和既往视图造成的不可逆信息失真；临时视图用完即弃，持久记忆保持纯净。
3. **光学视图作为结构化接口而非单纯压缩手段**：二维布局显式编码关系语义（空间邻近、行列对齐、箭头、高亮），使"表示"本身成为可学习的决策对象。
4. **训练隔离设计精巧**：冻结任务策略和其余模块，仅训练 Router，配合 GRPO 将奖励归因于视图选择，使性能增益可以更直接地归于记忆接口。
5. **教师蒸馏与强化学习两阶段互补**：教师提供基于参考轨迹的上下文条件初始能力，GRPO 进一步用任务级反馈校准视图选择。
6. **跨模型泛化验证扎实**：验证了学到的视图策略作为通用记忆接口的潜力，而非针对特定 VLM 的过拟合。
7. **实验设计细致严谨**：广泛的消融、约束因子分析、频率匹配对照、分辨率敏感性测试、视图分布分析等，提供了充分的机制可解释性。

## 八、不足与局限

1. **EB-ALFRED Visual 子集的显著失败未被解释**：所有方法（包括 MemPrism）在该子集均为 0% SR，论文仅报告结果而未分析原因——这可能暗示视觉记忆在处理复杂视觉推理时的根本性不足，也可能是该子集的评价协议存在问题，论文未予澄清。
2. **跨模型迁移收益不均衡**：虽然所有 VLM 都获得了提升，但提升幅度差异大（MiniCPM-V-2.6 +9.40 vs Qwen3-VL-4B +2.26），论文未深入分析收益与模型能力/视觉 token 密度之间的关系，也未测试在更强模型（如更大的 Qwen-VL 系列）上的表现。
3. **Mind2Web 上的绝对性能偏低**：所有方法在此基准上的动作准确率仅为 7.9%-12.9%，整体有效性有限；且该基准是教师强制重放设置，不涉及真实环境反馈的积累，与"长时程"场景的适配性存疑。
4. **视角策略动作空间仍有限**：144 种联合动作虽覆盖四因子组合，但时间范围（6/10/all）、粒度（三档）等选择相对粗糙，更多细粒度或连续化的视图设计可能进一步优化性能。
5. **未充分讨论失败模式**：DependencyChain 在 ALFWorld 上最终使用频率为 0%（虽然教师分布中约 3%），论文将其归因于策略集中，但未深入探讨这是否反映该视图类型在某些场景下的无效性。
6. **AgentOCR 对比的 token 口径不严格**：论文承认 AgentOCR 报告的是"memory-context tokens"而 MemPrism 报告的是"完整平均 prompt 长度"，两者不可直接比较，弱化了"token 效率更优"这一主张的证据强度。
7. **训练成本较高**：需要 8×H200 GPU 和 24-48 小时的训练

## 九、未来研究方向（论文隐含与显式建议）

1. **扩大视图动作空间的精细度**：论文的四因子离散组合虽已有 144 种，但时间范围、粒度等因子仍偏粗。更细的时间窗口划分、层级化粒度（如实体-属性-值三级）、以及基于任务进度动态调整视图的机制，都是自然的扩展方向。
2. **突破"只读"范式**：当前工作视图用完即弃、永不回写，这是为了保持持久记忆纯净的设计选择。但未来可在视图中识别出稳定的、跨任务复用价值高的关系结构，将其提炼回持久记忆，实现"工作视图→持久记忆"的闭环。这需要解决信息失真与循环写入的稳定性问题。
3. **多智能体与协作场景扩展**：当前框架面向单智能体交互。在多智能体协作中，不同角色对同一历史的关注点差异更大（如规划者需要全局依赖、执行者需要局部动作细节），任务条件化视图的语义空间将更丰富。
4. **其他模态与关系类型的扩展**：当前四类关系视图主要覆盖时序、因果、状态与动作-效应四类关系；未来可引入空间关系、社交关系、情绪状态等更多关系类型，并支持多关系叠加的复合视图。
5. **模型的端到端联合优化探索**：论文刻意冻结任务策略以隔离 Router 的贡献，这是严谨的归因设计，但也限制了上限。未来可以探索 Router 与任务策略联合训练时的协同效应，以及在推理成本约束下的视图策略蒸馏与压缩。
6. **更严格的跨环境泛化测试**：在 ALFWorld、EB-ALFRED、Mind2Web 之外的更多真实场景（如软件工程仓库、浏览器自动操作、机器人操作）中验证视图策略的可迁移性，测试"训练于一个环境、零样本部署到另一环境"的泛化能力。

## 十、总体评价

### 10.1 学术贡献定位

MemPrism 的贡献不在于提出一个更强的新型记忆存储结构，而在于**重新定义了记忆系统的接口语义**——它将"如何向策略模型呈现已检索证据"从实现细节提升为一等公民的设计维度，并给出了一个完整可复现的解决方案：

- **概念层面**：提出"后检索表示不匹配"这一此前未被显式命名和系统研究的失败模式，填补了记忆系统分类学中的空白。
- **方法层面**：持久事件流与临时任务条件关系视图的解耦架构，为记忆系统设计提供了新的范式参照。
- **实证层面**：在三个差异显著的基准（文本具身、视觉具身、离线网页导航）和四种 VLM 上的一致增益，表明该思路不是单一环境下的偶然现象。

### 10.2 与现有工作的关系定位

| 维度 | 与现有工作的区别 |
|------|------------------|
| 对比 Mem0 / LangMem / A-Mem | 它们关注"存什么、忘什么、何时检索"，MemPrism 关注"取到之后怎么组织"——不是替代，而是补齐了链条中缺失的一环 |
| 对比 AgentOCR | AgentOCR 将历史渲染为图像以压缩 token，MemPrism 的渲染超越压缩目的，其二维布局显式编码关系语义，且视图构建本身可学习 |
| 对比 RAG | RAG 的瓶颈通常在检索召回率，MemPrism 的瓶颈在检索后呈现；两者可叠加使用 |
| 对比上下文工程（prompt engineering） | 上下文工程以启发式规则组织提示，MemPrism 用强化学习学到的策略动态决定组织方式 |

### 10.3 适用场景建议

- **最适合**：长轨迹（>20 步）、需要跨步骤回顾与比较的决策任务；视觉输入丰富的具身任务；对 token 预算敏感的部署场景。
- **较不适合**：短轨迹（<10 步）的简单任务——此时记忆表示不匹配尚未成为瓶颈，动态视图策略的开销收益比低；纯单步决策任务（如单轮问答）——无历史可组织；对可解释性要求极高的安全关键领域——当前视图策略是一个不可解释的神经网络决策。

### 10.4 一句话评价

> MemPrism 是一篇**问题定义精准、方法架构优雅、实验验证严密**的高质量工作，它揭示了一个被主流记忆系统共同忽视的接口瓶颈，并给出了一个跨环境、跨模型、可复现的解决方案。尽管存在若干未解之谜（如 Visual 子集的全面失败）和资源门槛较高的问题，但其核心洞察——"记忆的呈现方式本身是一种需要学习的决策"——将对后续记忆系统设计产生持续影响。
