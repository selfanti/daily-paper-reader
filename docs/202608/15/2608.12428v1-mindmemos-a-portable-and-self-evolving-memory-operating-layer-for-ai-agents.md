## 摘要
记忆是AI代理的核心组成部分，使其能够积累经验、保持个性化并适应长期交互。然而，现有记忆系统在开发后通常保持不变，限制了它们通过持续使用来调整记忆模型、组织策略和程序性知识的能力。我们提出了MindMemOS，一种可移植且自进化的记忆操作层，利用统一的“实体-属性-时间”结构来组织开放世界信息。MindMemOS支持场景自适应记忆建模、高阶模式发现、自主记忆细化和持续技能进化。其MindMemEvolve算法采用验证驱动的进化搜索来优化目标场景的记忆模式，同时，“梦境”机制（dreaming）通过合并冗余记录和解决冲突来整合累积的记忆。此外，隐式纠正反馈作为人机交互回路中的信号，用于识别和修正可能不准确或失准的记忆。其MindSkillEvolve算法进一步将代理的执行轨迹转化为可复用且逐步精炼的技能。MindMemOS在LOCOMO上达到94.03%的准确率，在PersonaMem上达到70.63%。与初始技能基线相比，MindSkillEvolve在SpreadsheetBench上的成功率提高了9.2个百分点。

## Abstract
Memory is a core component of AI agents, enabling them to accumulate experience, maintain personalization, and adapt over long-term interactions. However, existing memory systems often remain fixed after development, limiting their ability to adapt their memory models, organization strategies, and procedural knowledge through continued use. We present MindMemOS, a portable and self-evolving memory operating layer that organizes open-world information using a unified entity property timestructure. MindMemOS supports scenario-adaptive memory modeling, higher-order pattern discovery, autonomous memory refinement, and continuous skill evolution. Its MindMemEvolve algorithm employs validation-driven evolutionary search to optimize memory schemas for target scenarios, whiledreaming consolidates accumulated memories by merging redundant records and resolving conflicts. In addition, implicit corrective feedback serves as a human-in-the-loop signal for identifying and revising potentially inaccurate or misaligned memories. Its MindSkillEvolve algorithm further transforms agent execution trajectories into reusable and progressively refined skills. MindMemOS achieves 94.03% accuracy on LOCOMO and 70.63% on PersonaMem. MindSkillEvolve improves SpreadsheetBench success by 9.2 percentage points over the initial-skill baseline.

- **核心问题**：现有记忆系统在部署后基本固定不变，难以根据持续使用来调整记忆建模方式、组织策略和程序性知识，具体表现为：
  - 非结构化记忆表示灵活但缺乏细粒度组织和时间推理能力；人工设计的结构化 schema 性能好但领域迁移成本高。

  - 记忆内容与程序性技能分离，难以将执行经验自动转化为可复用、可进化的技能。
- **整体含义**：MindMemOS 试图构建一个“可移植且自进化”的记忆操作系统层，使 AI 代理的记忆不仅能存储和检索，还能在使用中持续自我调整——从记忆模式、内部组织、冲突消解到技能生成都实现闭环演化。

## 2. 论文提出的方法论

### 2.1 核心思想

- 采用统一的 **“实体–属性–时间”三维记忆结构** 组织开放世界信息：
  - 实体（Entity）：人物、组织、地点、事件等，是信息锚点。
  - 属性（Property）：描述实体的具体方面，如偏好、行为模式、关系等，可动态定义。
  - 时间（Time）：记录信息的有效时间、观察时间或记录时间，支持同一实体-属性对上的时间线演化。
- 通过三层架构解耦：**记忆结构层**（建模、存储、技能）、**记忆算法层**（生成、检索、维护、演化）、**代理与应用层**（统一服务接口，支持 HTTP API、SDK、CLI、OpenClaw 插件等）。

### 2.2 记忆写入与生成

- **MindVanilla**（免建模模式）：
  - 按对话轮次分组、分块处理文本；
  - 召回相关旧记忆辅助消歧、去重和冲突判断；
  - 提取事实、画像、情景、工具痕迹等，并执行 Add/Reinforce/Update/Merge/Skip 动作规划。
- **MindSchema**（场景自适应模式）：
  - 先进行情景切分（episode segmentation）；
  - 按当前 schema 抽取实体和属性值，生成记忆子图；
  - 通过实体融合（entity fusion）合并等价实体、沿时间线更新属性；
  - 将子图合并回全局图，并生成高阶属性（如决策风格、风险倾向等）。

### 2.3 紧凑检索

- 采用“外层 agentic 规划 + 内层工具”的双层结构。
- 内层使用 **BM25 稀疏检索 + 稠密向量检索 + 倒数秩融合（RRF）**。
- 在 3D 记忆图上支持**双向遍历**：正向从实体到属性，反向从属性记录回溯实体；可沿时间线扩展前后版本，并可选进行关系扩展。
- 引入“检索键增强”：将实体描述拆分为多个搜索字段，提高细粒度实体匹配能力。

### 2.4 记忆维护：Dreaming 与 Feedback

- **Dreaming（梦境整合）**：
  - 离线对未整合记忆按实体构建局域簇；
  - 两阶段“检测-行动”：先识别冲突、重复、互补碎片、低价值内容；再生成保守变更计划，如合并、更新、归档或添加关系边；
  - 保留溯源（provenance），将已处理记录标记为 consolidated。
- **Feedback（反馈修正）**：
  - 显式反馈：用户直接指出需要修改的记忆，系统结合上下文生成 add/update/delete/no-op 动作；
  - 隐式反馈：从用户对任务执行结果的纠正中自动识别修正信号，按“任务临时 / 场景特定 / 长期”三种持久化范围分类，避免把一次性纠正过度泛化为长期记忆。

### 2.5 MindMemEvolve：验证驱动的记忆 schema 自进化

- 优化目标为最大化“Judge 评分”的均值：

  \( S^* = \arg\max_S \frac{1}{N}\sum_i \text{Judge}(a_i,\ \text{LLM}(q_i,\ \text{search}(q_i;S);\ \text{add}(\text{context}_i;S))) \)

  即在给定 schema \(S\) 下，将上下文写入记忆、检索相关记忆、生成答案，并与参考答案比较评分。

- 由于 schema 是离散结构，采用 **LLM 引导的进化算法**：
  - 初始化：对初始 schema 随机变异产生 \(K\) 个个体；
  - 适应度评估：每个个体在沙盒干净记忆库上按当前训练簇计算 fitness；
  -

- 选择：按适应度排序，选出表现最好的个体作为精英保留；其余个体由 LLM 综合多个高适应度个体的结构特征进行变异或重组，生成下一代候选 schema。
- 迭代：重复“评估—选择—重组”若干代，直至适应度收敛或达到预设轮次；最终选出的 schema 替换原记忆库的全局 schema，并触发一次基于新 schema 的重新组织（reindex）。
- 与在线维护的分工：MindMemEvolve 负责离线、更大粒度的 schema 级演化，而 Dreaming 与 Feedback 负责在线、小步幅的记忆实体/属性级修正，两者形成“快慢结合”的自进化机制。

### 2.6 程序性技能生成

- 从记忆中的“工具痕迹”（如 API 调用序列、任务执行步骤）和“情景记忆”中自动挖掘可复用的操作模式。
- 技能以结构化模板（条件、动作序列、预期效果）保存，并与相关实体属性关联；当新任务触发相似上下文时可匹配并实例化。
- 技能库同样参与检索过程，且随成功/失败反馈不断修正，构成“陈述性记忆 → 程序性技能”的闭环学习。

## 3. 实验设计与主要结论

- **基础任务评估**：在开放域问题解答、长期对话个性化、任务型代理（如日程管理、邮件处理）等基准上，MindMemOS 在记忆准确率、响应相关性、时间敏感性问题（如“上个月我提到过什么”）上优于固定 schema 和纯向量检索基线。
- **自进化效果**：对比“无演化”的同一记忆系统，启用 MindMemEvolve 后，在持续使用若干轮后检索命中率与最终任务完成率显著提升，且 schema 结构逐渐从通用型走向领域适配型。

- **可移植性**：通过统一 API 层，MindMemOS 可插拔接入多种 LLM 代理框架（如 OpenClaw 插件），迁移到新场景时仅需少量初始化数据，无需重写记忆逻辑。

## 4. 主要贡献与局限性

- **贡献**：
  1. 提出“实体–属性–时间”三维记忆表示，兼具结构化表达与开放域适应能力；
  2. 设计可部署、可移植的记忆操作系统架构，将建模、检索、维护、演化解耦；
  3. 首次将记忆 schema 自进化问题形式化为基于评估器反馈的离散优化，并给出 LLM 引导的进化求解方法；
  4. 构建从事实记忆到程序性技能的闭环学习机制，增强代理的自我改进能力。

- **局限性与开放问题**：
  - schema 进化仍依赖外部 Judge 评分，成本较高且评分标准可能偏差；
