## 摘要
长期语言模型智能体在交互过程中积累记忆，但其检索器通常不积累检索经验。语义检索高效，但嵌入相似度并不总能反映记忆是否包含与当前查询相关的证据。大型语言模型（LLM）重排序器提供更强的查询条件相关性分数，然而无状态重排序会反复对大型候选池进行打分，并在每次查询后丢弃这些分数。我们引入了EARM，一种经验摊销的重排序框架，将先前获得的LLM相关性分数视为可复用的检索经验。EARM将稀疏的查询-记忆相关性分数存储在一个在线矩阵中，通过因果矩阵补全学习其共享结构，并将少量新观测分数与估计分数相结合，对剩余候选进行重排序。随着经验的积累，打分预算逐渐减少，使LLM重排序从每次查询的重复开销转变为智能体生命周期内习得的检索能力。在长期对话记忆上的实验表明，混合观测与估计的重排序相比语义检索，答案准确率提升最高达6.62%，且当仅17.5%的候选获得直接LLM相关性分数时仍保持有效，从而大幅降低了LLM重排序的推理开销。这些结果促使对智能体记忆的更广泛理解：一个长期存活的智能体不仅应记住过去的内容，还应记住这些内容在检索中如何被证明有用。

## Abstract
Long-term language-model agents accumulate memories across interactions, but their retrievers typically do not accumulate retrieval experience. Semantic retrieval is efficient, but embedding similarity does not always reflect whether a memory contains evidence relevant to the current query. Large language model (LLM) rerankers provide stronger query-conditioned relevance scores, yet stateless reranking repeatedly scores a large candidate pool and discards these scores after each query. We introduce EARM, an experience-amortized reranking framework that treats previously acquired LLM relevance scores as reusable retrieval experience. EARM stores sparse query--memory relevance scores in an online matrix, learns their shared structure through causal matrix completion, and combines a small set of newly observed scores with estimated scores to rerank the remaining candidates. The scoring budget decreases as experience accumulates, changing LLM reranking from a repeated per-query expense into a retrieval capability learned over an agent's lifetime. Experiments on long-term conversational memory show that mixed observed-and-estimated reranking improves answer accuracy over semantic retrieval by up to 6.62% and remains effective when only 17.5% of candidates receive direct LLM relevance scores, thereby substantially reducing the inference overhead of LLM reranking. These results motivate a broader view of agent memory: a long-lived agent should remember not only past content, but also how that content has proved useful for retrieval.

### 1. 核心问题与整体含义

- 长期语言模型智能体（long-term language-model agents）需要跨交互积累记忆，但当前系统中的记忆存储与检索机制存在根本性不对称：记忆库随交互不断演化，而检索器每次查询都从零开始，不积累任何检索经验。
- 语义检索（semantic retrieval）虽然高效，但嵌入相似度并不等同于查询条件下的记忆相关性。一个记忆可能主题接近却无助于回答，反之表面不相关但包含关键的时间、因果与实体关系。尤其当相关证据在时间上较远时，语义检索的局限性更为突出。
- LLM 重排序器能通过联合理解查询与记忆提供更强的相关性分数，但传统做法是无状态（stateless）的：每次查询都要对全部候选池重复打分，且用后即弃。这种成本随交互次数和候选池规模线性增长，对长期智能体尤其不可承受。
- 论文提出的核心观点是：**检索器应当记忆**。智能体不仅应记忆内容，还应记忆“内容如何被证明在检索中有用”，即将历史 LLM 相关性评分视为可复用、可学习、可摊销的检索经验，使重排序从每次查询的重复开销转变为终身学习的检索能力。

### 2. 方法论

- **核心思想**：将 LLM 对查询-记忆对给出的相关性评分视为“检索经验”，存入在线稀疏矩阵，通过因果矩阵补全学习其隐藏结构，再用少量新观测分数 + 大量估计分数完成混合重排序。重心在于利用历史查询与记忆的共享结构来估计当前查询未打分的候选记忆。
- **EARM 框架由五个组件构成**：
  - **语义候选生成**：用嵌入相似度返回 top-N 候选集（N=200），只缩窄范围，不决定最终上下文，且保留持久记忆身份（稳定行标识）。
  - **检索经验矩阵**：构建稀疏矩阵 R(t)，行为持久记忆条目，列为历史查询，已观测条目为 LLM 打分分数。未观测单元格分两类：被检索但未直接打分，或语义检索根本未召回该记忆。
  - **分阶段经验获取**：查询流按索引分块（10 个查询一组），初始阶段用高观测比率（100%）建立矩阵，后续阶段逐步递减预算到 40%→25%→20%→17.5%。锚点子集由高相似度层（exploitation，占半预算）与剩余部分（exploration，占半预算）随机采样构成，防止只观察语义检索偏好的样本。
  - **因果相关性补全**：使用带偏置的低秩模型  R̂_iτ = μ + α_i + β_τ + p_iᵀz_τ，其中 μ 为全局水平，α_i 为记忆偏置，β_τ 为查询偏置，p_i 与 z_τ 为潜在记忆与查询因子。通过最小化掩码重建误差 + L2 正则化，用交替最小二乘法（ALS）优化，并用上一轮的解做热启动。因果掩码确保仅使用历史列和当前列的观测锚点，不泄漏未来信息。
  - **混合重排与上下文构建**：对每个候选记忆，若已被直接打分则用观测分数，否则用补全分数；按分数降序选择 top-K 记忆，再恢复为时间顺序后送入答案生成器。排名域 D_t 可以扩展到语义候选集 C_t 之外的历史支持记忆（白格），实现搜索扩展。

- **对比方法（baselines）**：

  3. **Observed-only**：禁用补全，仅将直接打分的记忆放进 top-K 上下文。

- **消融逻辑**：Semantic vs. Observed-only 分离“直接打分记忆”的贡献；Observed-only vs. Mixed 分离“补全分数选中的记忆”的额外贡献；Mixed vs. Full reranking 量化在有预算约束下与完整重排的差距。

- **多跳问题收益最大**：Top-10 多跳问题提升 10.29%，单跳提升 7.25%；开放域与时间类问题提升相对较小。

- 核心论点验证成立：检索器可以也应该“记住”经验，将重排序从逐次开销变为长期能力。

### 7. 优点

- **研究视角新颖**：将 LLM 重排序的逐次分数重新定义为“可持久化的检索经验”，提出“内容记忆（content memory）”与“检索记忆（retrieval memory）”的区分，为智能体记忆研究打开了新方向。
- **方法设计精巧**：
  - 使用带偏置的低秩矩阵补全，能解释全局、记忆侧、查询侧和个人交互四层结构；
  - 因果掩码 + 热启动保证无未来信息泄漏，同时学习过程增量高效；
  - “分层采样锚点”（高相似度 exploitation + 随机 exploration）在利用语义先验的同时保证了探索覆盖；
  - 观测窗口决策均衡：保留观测分数，补全剩余候选，简单且实用。
- **同时具备方法论与实用价值**：不只是提升了准确率，还大幅降低了推理调用预算（减少 74.43% 调用量），兼顾成本与质量。
- **消融设计干净**：通过 Observed-only 与 Mixed 的对比，将“直接打分”与“补全选记忆”的收益清晰分开，实验逻辑严谨。
- **应用范围不限于候选内重排**：补全模型可以对语义检索未召回的“白格”记忆打分，把固定候选池变成软边界，有潜力直接扩展检索覆盖范围。

### 8. 不足与局限

- **单一数据集评估**：仅在 LoCoMo 上验证，未在 LongMemEval、MemBench 等其它长期记忆基准上测试，泛化性未知。
- **固定预算调度**：观测比率按查询索引的预先定义递减（100%→17.5%），不随模型不确定性、分布漂移或新记忆冷启动情况自适应调整。
- **低秩结构假设限制**：矩阵补全假设查询-记忆相关性中存在可复用的低维结构；若查询流高度异构，或者记忆内容快速演变与失效（身份不稳定），历史分数可迁移性差，方法可能失效。
- **对 LLM 评分器质量敏感**：点式相关性评分可能噪声大、校准不良且对 prompt 敏感，补全会继承并可能传播评分器的系统性误差，而非仅仅降低成本。
- **评测指标较单一**：端到端指标仅为 LLM-as-a-judge 的答案准确率，缺少对检索质量（如 MRR、Recall@K）、鲁棒性（重复实验方差）、延迟和成本的具体量化分析。
- **模型固定假设**：实验假定记忆人口在评测期间固定、按数据顺序处理查询，与实际动态增长的智能体记忆场景存在差距。
