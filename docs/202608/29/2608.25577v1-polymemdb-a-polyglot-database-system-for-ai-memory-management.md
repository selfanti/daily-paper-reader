## 摘要
随着个人智能代理的广泛采用，用户在长期交互中会产生海量、异构的数据。将这些数据用作长期记忆有助于减少令牌开销并提供个性化体验。然而，现有的记忆系统面临两个主要限制：它们依赖单一存储范式，导致多维数据碎片化；并且缺乏细粒度的数据溯源来解决长期事实冲突，从而加剧了LLM的幻觉问题。在本次演示中，我们介绍了PolyMemDB，一种专为管理代理记忆而设计的新型系统。PolyMemDB具有多语言存储架构，旨在跟踪和管理各种记忆类型，包括图、向量、概率和时空数据。为了确保事实一致性并减少幻觉，它配备了一个概率推理引擎，该引擎将时间衰减与半环聚合相结合，解决长期事实冲突，提供详细的数据溯源，并使用户能够透明地追踪推理链。

## Abstract
With the widespread adoption of personal intelligent agents, users generate massive, heterogeneous data during long-term interactions. Leveraging this data as long-term memory helps reduce token overhead and deliver personalized experiences. However, existing memory systems face two primary limitations: they rely on single-storage paradigms that fragment multi-dimensional data, and they lack fine-grained data provenance to resolve long-term factual conflicts, thereby worsening LLM hallucinations.   In this demonstration, we introduce PolyMemDB, a novel system tailored for managing agent memory. PolyMemDB has a polyglot storage architecture designed to track and manage various memory types, including graph, vector, probability and spatial-temporal data. To ensure factual consistency and reduce hallucinations, it features a probabilistic inference engine that integrates temporal decay with semiring aggregation, resolving long-term factual conflicts, providing detailed data provenance, and enabling users to trace reasoning chains transparently.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体架构

PolyMemDB 的工作流分为三个阶段：

- **记忆摄取与索引（Memory Ingestion & Indexing）**：将输入数据分解为原子事实。
- **多语言存储层（Polyglot Storage Layer）**：根据事实的多维特征，将其路由到不同的存储引擎。
- **推理与级联问答（Inference & Cascaded QA）**：通过三级检索机制生成最终回答。

### 2.2 记忆摄取与索引

### 2.4 推理与级联 QA

采用自顶向下的三级联邦检索机制，平衡推理开销与召回率：

- **Tier 1（Graph QA）**：优先进行低延迟的子图遍历，并结合概率数据库与时空索引进行规则过滤和逻辑推理。
- **Tier 2（Dense Retrieval）**：若第一级未获得答案，利用查询嵌入向量在向量数据库中进行 Top-k 语义检索。
- **Tier 3（Multi-modal Retrieval）**：若仍未获得足够证据，直接检索原始数据片段（文本、图像、音频等），生成最终回答。

### 2.5 概率记忆图维护

- **记忆图形式化**：定义为 G = (V, E, α)，其中 V 是异构实体集合，E 是有向关系边集合，α 是属性标注函数。
- **事实表示**：单个事实记为三元组 f_i = ⟨ρ_i, c_i, t_i⟩，其中 ρ_i ∈ {+, −} 表示证据情感极性，c_i ∈ [0,1] 表示 LLM 赋予的初始置信度，t_i 为观察时间戳。
- **证据链构建**：对于图中任意边 e = (u, l, v)，系统维护历史观察序列 F = (f₁, f₂, …, f_T)，按时间排序，避免简单覆盖状态，完整保留不同时间点的证据。
- **时间衰减与权重计算**：引入指数衰减因子 λ ∈ (0,1]，对于距离当前时间索引 Δᵢ = T − i 的事实，动态权重为 wᵢ = cᵢ · λ^(T−i)。
- **半环聚合（Semiring Aggregation）**：将证据分成正集 F⁺ 与负集 F⁻，利用包含-排除原理计算联合置信度：

  - P⁺ = 1 − ∏(1 − wᵢ)，其中 fᵢ ∈ F⁺
  - P⁻ = 1 − ∏(1 − wⱼ)，其中 fⱼ ∈ F⁻

- **四种认知状态**：
  - 正驱动 S_action = P⁺(1 − P⁻)
  - 负抑制 S_inaction = P⁻(1 − P⁺)
  - 证据冲突 S_conflict = P⁺P⁻
  - 证据缺失 S_ignorance = (1 − P⁺)(1 − P⁻)

- **净证据可靠性得分**：

  R = (S_action − S_inaction) · (1 − S_conflict − S_ignorance)

  其中 R ∈ [−1, 1]。第一项刻画事实方向的真实性，第二项作为动态惩罚因子，当事实争议大或证据不足时降低 R。当 R ≈ 0 时，通过 arg max 中间状态可区分低分是源于事实冲突（S_conflict）还是证据空缺（S_ignorance）。

## 7. 优点

- **多语言存储架构**：突破单一存储范式，整合图、向量、概率、时空和原始对象存储，支持复杂异构数据的统一管理与联合查询。
- **概率推理与时间衰减结合**：在底层数据库层面实现证据权重计算，而非仅依赖 LLM 提示词，增强了数学严谨性与可解释性。
- **细粒度数据溯源**：保留每个事实的历史观察序列和证据链，避免粗暴覆盖，使回答可以追溯到具体原始语料。
- **级联检索策略**：从低延迟图问答到密集检索再到多模态检索，分层回退机制兼顾效率与召回。
- **冲突 vs 证据缺失的可区分性**：通过 R 值与 4D 中间状态（S_action、S_inaction、S_conflict、S_ignorance）的联合分析，能够明确低置信度原因，帮助 LLM 生成更细致、更可靠的回答。
- **交互式可视化界面**：提供了知识面板、证据面板和时空地图，便于用户理解和验证推理过程。
