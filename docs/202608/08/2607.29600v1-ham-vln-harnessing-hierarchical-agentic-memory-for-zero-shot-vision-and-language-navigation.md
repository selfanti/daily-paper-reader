## 摘要
视觉与语言导航（VLN）使机器人能够在未见过的环境中遵循指令。最近，出现了一种免训练范式：机器人查询多模态大语言模型来理解其观测并规划下一个动作。然而，基于图像流或密集地图的长时程导航不可避免地引入了不断增长的记忆和推理瓶颈。我们提出了HAM-VLN，一种决策耦合的、智能体自生成的记忆，为机器人配备了持久的、基于深度的世界图。在用于选择下一个动作的同一模型调用中，HAM-VLN还记录语义和反思信息——包括房间类型、物体、导航进度和失败笔记。最近的路标在有限窗口内保持逐字记录，而较旧的历史仅通过与相关性、近期性和显著性相关的检索，以及一跳拓扑扩展重新进入上下文。这种设计除了每个路标的决策外，不需要额外的LLM调用。与之前的方法相比，HAM-VLN不仅改善了各种导航指标，还将上下文长度减少了超过65%。具体来说，HAM-VLN在VLN-CE R2R上实现了61.0%的成功率（SR），在VLN-CE RxR上实现了52.7%的SR，在HM3D-v2 ObjectNav上实现了79.7%的SR，无需任何训练。

## Abstract
Vision-and-language navigation (VLN) enables robots to follow instructions in previously unseen environments. Recently, a training-free paradigm has emerged: the robot queries a multimodal LLM to understand its observations and plan the next action. However, long-horizon navigation based on either image streams or dense map inevitably introduces a growing memory and reasoning bottleneck. We present HAM-VLN, a decision-coupled, agent-authored memory that equips the robot with a persistent, depth-grounded world graph. In the same model call used to select the next action, HAM-VLN also records semantic and reflective information---including room type, objects, navigation progress, and failure notes. Recent waypoints remain verbatim within a bounded window, while older history re-enters the context only through retrieval scored by relevance, recency, and salience, together with one-hop topological expansion. This design requires no additional LLM calls beyond the per-waypoint decision. Compared to previous methods, HAM-VLN not only improves various navigation metrics but also reduces the context length by more than 65%. Specifically, HAM-VLN achieves 61.0% Success Rate (SR) on VLN-CE R2R, 52.7% SR on VLN-CE RxR, and 79.7% SR on HM3D-v2 ObjectNav without any training.

# HAM-VLN：利用分层智能体记忆实现零样本视觉与语言导航

## 1. 论文的核心问题与整体含义

**研究背景与动机：**

- **视觉与语言导航（VLN）** 任务要求机器人遵循自然语言指令，在未见过的复杂环境中导航至目标位置或物体。
- **零样本/免训练范式** 的兴起使得机器人可以借助多模态大语言模型（MLLM）直接理解观测并规划动作，无需任何任务特定训练。
- **核心瓶颈在于"记忆"**：在长时程导航中，机器人需要知道"去过哪里、指令进展到哪一步、哪些分支失败过"，但现有的两种历史表征方式均有根本性缺陷：
  - **密集语义地图**：存储量随地图面积增长，语义信息与导航决策脱耦（是构建的表示，而非与决策同步产生的）。
  - **原始视觉历史**：直接将全部历史全景图拼接进模型上下文，导致上下文随轨迹无限膨胀、关键地标被无关细节淹没、且失败分支不会被标记。
- **整体含义**：HAM-VLN 将"智能体记忆"（Agentic Memory）这一概念引入机器人导航，让 MLLM 决策本身即产生持久化、结构化的记忆，从而在有限上下文预算下实现长时间高效的零样本导航。

## 2. 论文提出的方法论

### 2.1 核心思想

- **决策耦合的记忆写入**：MLLM 在每次选择动作的同一调用中，同步输出记忆写入内容（房间类型、物体、导航进度、失败原因），不额外增加 LLM 调用。
- **分层记忆管理**：近期观测保存于"工作记忆"（小窗口逐字保留），更早历史存入"世界图"结构中，按需检索进入上下文。

### 2.2 双过程架构（Dual-Process Architecture）

- **System 2（慢思考-规划层）** ：大型 MLLM（Gemini-3.1-Pro），每个路标（waypoint）调用一次，读取当前全景图 `Ot`、工作记忆 `Wt`、指令进度 `Lt` 和检索到的图子图 `R(Gt, qt)`，输出结构化 JSON 决策 `(at, wt, rt)` ——即高层的方向决策、进度/语义更新和行动理由。
- **System 1（快反应-执行层）** ：轻量级接地模型（Qwen3.6-35B），将 System 2 的高层意图（方向描述）转化为像素空间的目标框，通过深度图反投影到 3D 世界坐标，再由确定性控制器基于局部可通行图执行短时轨迹。
- **策略分解公式**：`At = πrobot(φ1(φ2(T, Ot, Mt), Dt, Pt, Kcam))`，即 System 2 负责"去哪里/为什么"，System 1 负责"如何执行"。

### 2.3 分层智能体记忆结构

- **四类功能视图**：
  - **工作记忆（Working Memory）** ：最近 K 个路标的逐字视觉帧（实验中 K=1），提供即时的感知连续性。
  - **情景记忆（Episodic Memory）** ：访问轨迹与时间戳元数据，为检索提供"近期性"信号。
  - **语义记忆（Semantic Memory）** ：地点–物体图的内容与拓扑，为检索提供"相关性"信号。
  - **反思记忆（Reflection Memory）** ：附着于特定地点的失败笔记（死胡同、错误停止等），在该地点被检索时以逐字形式重新进入上下文。
- **深度接地世界图（Depth-Grounded World Graph）** ：

  - 形式化为 `Gt = (VPt, VOt, E PPt, E POt)`：地点节点（增量单链聚类）拥有空间锚点、语义上下文、访问统计和可选失败证据；物体节点拥有深度接地的类别观测和开放词汇描述；边包括导航连通性和语义包含关系。
  - 图的大小随发现的"地点/物体"数量增长，而不是随地图面积或轨迹长度增长。

- **检索公式**：每个地点按 `st(p) = α·rel(qt, p) + β·rect(p) + γ·sal(p)` 打分（相关性、近期性、显著性），取前 3 为种子、一跳拓扑扩展、保留至多 5 个地点注入上下文。
- **失败记忆回溯**：当 System 2 决定回溯时，系统将放弃的轨迹后缀对应的地点标记失败证据（附决策理由），该证据**不会**直接改变检索分数或阻碍访问，而是在对应地点被检索时逐字返回，供 System 2 在"当前子目标"下重新解读。

## 6. 论文的主要结论与发现

- **性能显著领先**：R2R-CE 上 SR 61.0%（较最强零样本基线 +22.7 点）、RxR-CE 上 SR 52.7%（+18.9 点）、HM3D-v2 ObjectNav 上 SR 79.7%（超越最强监督方法 +2.7 点）。

## 7. 优点

- **设计巧妙**：将记忆写入与决策耦合在同一个模型调用中完成，不消耗额外 LLM 调用，这一设计在真实部署中极具成本优势。
- **理论基础扎实**：明确借鉴生成式智能体（Park et al. 2023）的相关性/近期性/重要性记忆原则，并将其适当地拓展到空间导航场景，引入深度接地世界图为记忆提供几何和拓扑锚定。
- **实验对比面广**：同时覆盖 VLN-CE（R2R/RxR）和 ObjectNav 两个任务族、监督与零样本两大类基线、以及导航性能和检索效率两个维度。
- **分析有深度**：消融实验揭示了不同记忆组件的差异化贡献（情景/语义主要影响 SR，反思主要影响 SPL），为后续研究提供了清晰的方向指引。
- **结果可复现性强**：固定了检索权重 `(α,β,γ)=(1.0,0.3,0.3)`、衰减率 `ρ=0.85`、种子/地点预算等全部超参数，三基准统一配置；提交了均值±标准差，置信度明确。

## 8. 不足与局限

- **评估规模有限**：全部结论建立在各基准 100-episode 子集之上，尽管有校准参考，但对完整验证集上的表现是间接推断；测试环境均为仿真（Habitat），未在真实物理机器人上验证。
