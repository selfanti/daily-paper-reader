## 摘要
大型语言模型（LLM）智能体必须保留并利用跨步信息，才能在长时程任务中一致行动。现有方法改善了记忆的可访问性，但行动相关信息仍可能因形成、组织、优先级排序或呈现方式不佳而无法指导当前决策。我们将这种访问后失败称为“记忆-行动鸿沟”。我们提出MemArbiter，一种功能感知的记忆仲裁框架，旨在解决该鸿沟中由记忆管理引发的问题。MemArbiter将交互历史分解为原子条目，将其组织为五个功能性记忆库，并结合库级需求、条目级相关性、焦点-环境表征以及时间呈现门控来动态控制记忆显著性。我们在ALFWorld上，在统一的逐步记忆预算下，将MemArbiter与扁平检索和扁平近因方法进行比较。在500和750词元预算下，使用开放权重行动生成模型，MemArbiter的成功率分别达到82.8%和92.5%，分别超过最强基线20.9和25.4个百分点。它还改善了失败后的恢复能力，并减少了失败动作重复和状态-动作复现。这些结果表明，功能感知的记忆仲裁能使可访问的信息更有效地指导行动。

## Abstract
Large language model (LLM) agents must retain and use cross-step information to act coherently in long-horizon tasks. Existing methods improve memory accessibility, yet action-relevant information may still fail to guide the current decision because it is poorly formed, organized, prioritized, or presented. We call this post-access failure the Memory-Action Gap. We propose MemArbiter, a function-aware memory arbitration framework that addresses the memory-management-induced component of this gap. MemArbiter decomposes interaction histories into atomic items, organizes them into five functional Memory Banks, and combines bank-level demand, item-level relevance, focal-ambient representations, and a temporal presentation gate to dynamically control memory salience. We evaluate MemArbiter on ALFWorld against Flat Retrieval and Flat Recency under unified per-step memory budgets. With an open-weight action-generation model, MemArbiter achieves success rates of 82.8% and 92.5% under 500- and 750-token budgets, outperforming the strongest baseline by 20.9 and 25.4 percentage points, respectively. It also improves post-failure recovery and reduces failed-action repetition and state-action recurrence. These results show that function-aware memory arbitration enables accessible information to guide actions more effectively.

## MemArbiter 论文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究问题**：长时程任务中的 LLM 智能体必须依赖跨步骤信息来保持行动一致性，但现有的记忆系统主要关注“可访问性”（accessibility），即能否存储、检索和保留信息，却忽略了“决策影响力”（decision influence）——即使相关信息已进入记忆管理流程，也可能因记忆的形成、组织、优先级排序和呈现方式不当，而未能有效指导当前动作选择。
- **核心概念**：论文将这种“信息可访问但未能影响决策”的现象定义为 **Memory-Action Gap（记忆-行动鸿沟）**。它不同于“遗忘”（信息未保存）或“检索失败”（信息无法被定位），而是发生在信息已被记忆管理流程处理后、即将影响行动生成之前。
- **关键洞察**：该鸿沟的一个重要来源在于，不同类型的记忆在决策中承担着**异质功能**（目标设定、状态跟踪、约束限制、经验回顾、事实参考），而现有方法往往将这些记忆作为同质化文本块处理，导致关键记忆在应有的时机未能获得足够的显著性。
- **整体含义**：记忆管理不仅是“存下来”和“找出来”的问题，更是“如何组织、如何权衡、如何呈现”的端到端仲裁问题。MemArbiter 的提出表明，通过功能感知的动态记忆仲裁，可以显著提升可访问记忆对动作选择的实际引导作用。

### 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

**核心思想**：MemArbiter 是一个**决策时（decision-time）工作记忆仲裁框架**，将记忆管理视为一个端到端仲裁问题，涵盖记忆形成、功能组织和提示呈现三个环节。

**技术细节与流程**：

- **原子记忆条目与五类功能记忆库**：将交互历史分解为原子记忆条目，按决策功能分为五类记忆库：
  - **Goal（目标）**：保持任务目标与完成标准，持久有效；
  - **Task State（任务状态）**：描述当前决策条件（位置、持有物、物体状态），频繁更新；
  - **Constraint（约束）**：限制非法行为，需满足属性、位置、数量等要求；
  - **Episodic（情景）**：记录以往动作与成败结果，持续累积；
  - **Reference（参考）**：保存探索中发现的环境事实（如物体位置），按需激活。

- **候选写入（Candidate Writes）**：在每个决策步骤，候选写入器接收完整决策上下文（目标、当前观察、前序动作及结果、累积轨迹），为各记忆库生成候选写入，经有效性检查、去重和冲突消解后按各库更新策略执行（拒绝、合并、覆盖或新增）。

- **双波段表示（Dual-Band Memory Representation）**：每个记忆条目拥有两种表示：
  - **Focal（焦点）**：保留完整内容，直接支持动作选择；
  - **Ambient（环境）**：基于确定性模板的简洁线索，保留关键实体、关系和状态信息。
  
  两种波段可动态切换，无需重新提取或分类。

- **决策相关性信号（Decision-Relevance Signals）**：
  - **库级需求（bank-level demand）**：评估当前步骤对各功能记忆角色的整体需求；
  - **条目级相关性（item-level relevance）**：评估具体条目对当前决策的贡献，用于状态转移和提示排序。

- **时间呈现门控（Temporal Presentation Gate）**：
  - 将呈现控制视为有状态分配问题，综合**前序呈现状态、库级需求、条目级相关性、相关性历史**四个输入，决定每个条目处于 **Focal、Ambient 或 Hidden** 状态；
  - 避免瞬时波动导致有价值的记忆被过早降级或频繁切换呈现波段；
  - 应用角色特定的转换规则：Goal 与 Constraint 受保护，Task State 取最新状态快照，Episodic 与 Reference 动态调整。

- **提示组装（Prompt Assembly）**：将门控输出的记忆按记忆库分组，焦点条目以完整形式优先呈现，环境条目使用简洁表示，同波段内按相关性排序，隐藏条目排除，最终生成结构化记忆提示 Pt。

整体流程可概括为：**上下文解析 → 候选生成与库更新 → 相关性估计（库级+条目级） → 时间门控状态更新 → 结构化提示组装 → 动作生成**。

### 3. 实验设计：数据集/场景、Benchmark、对比方法

- **任务场景**：ALFWorld（Shridhar et al., 2021），一个将具身家务任务映射为多步语言交互的文本基准。
- **数据规模**：使用了 eval_out_of_distribution 划分中的全部 **134 个未见任务**，涵盖六类子任务：Pick（24个）、Look（18个）、Clean（31个）、Heat（23个）、Cool（21个）、Pick Two（17个）。每轮最多50个交互步骤。
- **对比方法**：
  - **Flat Recency**：扁平存储观测与动作，在预算内保留最近的记录；
  - **Flat Retrieval**：使用 BM25 基于目标、前序动作和最近观测构造查询进行检索排序；
  - **MemArbiter 完整版**及三个消融变体。
- **统一评价条件**：所有方法在相同的**每步记忆呈现预算**（500 token 与 750 token）下进行比较，预算仅应用于插入动作提示的记忆块。
- **行动生成模型**：主实验使用 Qwen3.6-27B-FP8（开放权重模型）；交叉模型验证中替换为 GPT-5.4（仅用于动作生成）。

### 4. 资源与算力

- 论文明确提及的算力资源为：**单张 NVIDIA A100-SXM4-80GB GPU**，用于通过 vLLM 服务 Qwen3.6 模型，最大上下文长度为 4,096 tokens。
- 由于 MemArbiter 是**推理时（inference-time）记忆管理框架**，不涉及模型训练，论文中未报告训练时长或总 GPU 时数。
- 运行配置细节：temperature=0、随机种子 42，每个任务运行一次；BM25 参数 k1=1.2、b=0.75。

### 5. 实验数量与充分性

论文的主要实验包括以下几个维度：

1. **主实验**：在 500/750 两种 token 预算下，对比 MemArbiter 与两种基线在 134 个任务上的总体成功率及六类任务的分类成功率；

4. **消融实验**：分别移除功能性记忆库（w/o Functional Banks）、动态信号（w/o Dynamic Signals）、时间门控（w/o Temporal Gate），共三个消融变体；

**充分性评估**：

- 实验设计整体较为规范，采用了**统一的记忆预算**和**相同的任务集与交互上限**，保证了对比的公平性；
- 消融实验覆盖了三大核心组件，且报告了早晚期（SR@15 与 SR@50）的变化趋势，有助于理解各组件的时间效应；
- 交叉模型验证增强了结论的稳健性；
- **不足之处**：（1）仅在 ALFWorld 单一环境中评估，缺乏在网页导航、多模态或更开放式任务上的验证；（2）每个任务仅运行一次（temperature=0），未报告多次运行的方差或置信区间；（3）机制诊断属于关联性证据，作者也承认无法确定记忆呈现状态变化与后续行为之间的因果关系。

### 6. 论文的主要结论与发现

- **主结果**：在 500-token 预算下，MemArbiter 成功率达 **82.84%**，超过最强基线 Flat Retrieval（61.94%）**20.90 个百分点**；在 750-token 预算下达 **92.54%**，超基线（67.16%）**25.38 个百分点**。
- **任务类型分析**：在 500-token 预算下，MemArbiter 在六类任务中胜出五类；750-token 预算下全部六类均最优。其中 **Pick Two** 任务差异最大：两个扁平基线在该类任务上全部失败，而 MemArbiter 分别达到 58.82% 和 70.59% 的成功率。
- **效率与成功率的关系**：MemArbiter 在相同步数限制下完成更多任务，说明其更高的最终成功率并非仅仅通过多跑步骤获取，而是能有效利用更长的交互轨迹。
- **跨模型迁移**：使用 GPT-5.4 生成动作时，MemArbiter 仍超出最强基线 12.69 个百分点（83.58% vs 70.89%），表明方法优势不依赖于特定模型。
- **消融结果**：
  - 移除功能记忆库：SR@50 下降 15.68 个百分点；
  - 移除动态信号：下降 17.17 个百分点（最大降幅）；
  - 移除时间门控：下降 8.96 个百分点（但在 SR@15 上反而提升 2.98 个百分点）。说明功能组织、动态信号和时间状态维护各自贡献显著，且其价值主要体现在较长交互中。
- **失败响应与复现行为**：MemArbiter 显著提升失败后一步恢复率（500-token 下较 Flat Retrieval 高 18.2 个百分点，750-token 下高 34.8 个百分点），大幅降低失败动作重复率、相邻重复率和状态-动作复现率；失败后情景记忆在提示中的占比明显上升，而消融时间门控的变体几乎无此变化，说明时间门控与失败敏感的记忆呈现存在关联。

### 7. 优点

- **概念新颖**：提出 Memory-Action Gap，将“可访问但无影响力”这一现象从遗忘和检索失败中区分出来，为记忆管理研究提供了新的理论视角。
- **方法系统性强**：从记忆形成（原子化分解）、功能组织（五库分类）、动态权衡（双层信号）到最终呈现（时间门控+提示组装），形成了完整的端到端仲裁流程，各组件设计相互衔接、逻辑自洽。
- **实验设计规范**：统一记忆预算确保对比公平；同时报告了 SR@15 与 SR@50 等多个时间点，能区分早期与晚期效应；消融实验清晰揭示各组件贡献。
- **诊断细致**：不仅报告成功率，还深入分析了失败恢复、动作重复、状态-动作复现等机制层面的行为指标，并关联了记忆呈现状态的变化，为理解方法为何有效提供了证据。
- **跨模型验证**：采用开源和商业模型分别验证，增强了结论的普适性。

### 8. 不足与局限

- **单一环境评估**：仅在文本型 ALFWorld 上进行，无法确认方法在网页导航（如 WebArena）、多模态环境或更开放式任务中的泛化能力。
- **显式角色设计**：五个记忆库及其相关性信号为人工预定义，虽然可解释性强，但可能难以直接迁移到功能角色不同的新领域，缺乏自适应学习能力。
- **因果证据不足**：诊断分析仅显示“失败后情景记忆占比增加”与“恢复率提升/重复率下降”之间的关联，未通过受控干预证明记忆呈现状态的改变直接导致行为改善。
- **统计稳健性有限**：每任务仅运行一次，未提供多次运行的均值和方差，无法评估方法在随机性下的稳定性。
- **模型依赖问题**：候选写入和状态解析仍依赖 Qwen3.6 模型，框架自身的记忆质量可能受到底层模型能力的制约。
- **未比较更强的专门化基线**：未与 HiAgent、MemAct、AgeMem 等工作记忆管理方法进行对比，仅与扁平基线比较，结论的说服力有一定局限。
