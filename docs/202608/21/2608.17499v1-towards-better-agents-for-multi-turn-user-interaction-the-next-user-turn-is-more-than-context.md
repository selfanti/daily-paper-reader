## 摘要
面向用户的工具智能体必须在用户目标多轮展开过程中协调对话与工具使用。然而，交互式强化学习通常将每次轨迹简化为一个最终奖励，对有效的引导、错误和后续修复赋予相同的信用。下一轮用户不仅是上下文：它还提供了关于前一轮用户-用户片段的有噪声、时间上局部的证据。我们引入了反馈感知信用分配（FACA），它将每个反应与该片段对齐，推导出局部归一化的反应优势，并将其与经过验证的最终结果优势相加，而无需额外的评论器或轨迹。与仅在模拟器、可见对话、初始化、轨迹和优化上匹配的仅结果交互式GRPO对照组相比，FACA在三个独立训练运行中，将九域τ家族平均值在8B和14B规模上分别提高了5.91和10.22个百分点。增益集中在电信领域；在8B规模下，随机化反应极性消除了电信领域的增益。在Pare-Bench和Co-Gym上的零样本测试中，排序顺序相同。这些结果表明，下一轮用户反应为改进多轮用户交互智能体提供了可操作的局部信用。

## Abstract
User-facing tool agents must coordinate dialogue and tool use as user goals unfold over multiple turns. Yet interactive reinforcement learning typically reduces each rollout to a terminal reward, assigning the same credit to effective elicitation, errors, and later repair. The next user turn is more than context: it also provides noisy, temporally local evidence about the preceding user-to-user segment. We introduce \textbf{F}eedback-\textbf{A}ware \textbf{C}redit \textbf{A}ssignment (\textsc{FACA}), which aligns each reaction with that segment, derives a locally normalized reaction advantage, and adds it to verified terminal outcome advantage without an extra critic or rollout. Against an outcome-only Interactive GRPO control matched in simulator, visible dialogue, initialization, rollout, and optimization, \textsc{FACA} improves the nine-domain $τ$-family average across three independently trained runs by 5.91 and 10.22 percentage points at 8B and 14B, respectively. Gains concentrate in Telecom; at 8B, randomizing reaction polarity removes the Telecom gain. The same ordering holds zero-shot on Pare-Bench and Co-Gym. These results demonstrate that next-turn user reactions provide actionable local credit for improving multi-turn user-interacting agents.

## 论文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：面向用户的工具型语言智能体正从单轮助手走向多轮交互系统，需要协调对话、工具使用和用户决策。例如旅行智能体需要检查预订、引导用户提供偏好、比较选项、获得授权后才能修改数据库。这类任务中用户是主动参与者，目标可能一开始被省略，需要智能体主动引导。
- **核心问题**：现有的交互式强化学习（如 MUA-RL、UserRL）将每次多轮 rollout 压缩为单一终局奖励（terminal reward），导致所有交互片段——有效的引导、错误和后续修复——获得相同的信用。终局奖励能说明轨迹是否成功，却无法指出是哪个环节改变了走向。这种"时间平坦"的信用分配缺乏对交互过程本身的局部监督。
- **关键洞察**：下一轮用户反应（next user turn）不仅是指导下一步决策的上下文，**更是对前一个"用户到用户（U2U）片段"的局部证据**——用户提供请求的信息可能说明引导有效，用户的质疑或澄清则暴露了交互摩擦。这些反应是噪声的、上下文相关的，并非正确性标签，但蕴含着可用的过程级信用信息。论文将此洞察形式化为 **Faca（反馈感知信用分配）** 方法。

### 2. 论文提出的方法论

**核心思想**：将每个 U2U 片段视为局部信用分配单位，把紧随其后的用户反应视为该片段的局部证据信号，经过极性映射、局部归一化后形成过程优势（process advantage），与终局结果优势（terminal outcome advantage）相加，共同指导策略优化。

**关键技术细节与流程**：

1. **U2U 片段定义**：相邻两次用户消息之间智能体产生的所有消息、工具调用和工具结果组成一个 U2U 片段 a_{k,q}。
2. **用户反应极性映射**：模拟器每次发出一句话语和私有策略元数据 z_{k,q+1}，Faca 将策略映射为三元极性 f_{k,q} ∈ {−1, 0, +1}：
   - **+1（进展一致）**：confirm（确认）、close（完结）、reveal-piece（揭示被请求的信息）
   - **0（中性）**：be-vague（模糊）、invalid（无效）
   - **−1（摩擦一致）**：ask-clarification（澄清请求）、challenge-solution（质疑方案）、change-mind（目标变更）
3. **结果优势（outcome branch）**：沿用 GRPO 的组内归一化公式：
   
   A_o_k = (R_k − μ_R(x)) / (σ_R(x) + ε)
   
4. **过程优势（process branch）**：对同一提示词、同一 U2U 索引 q 的 rollout 集合内做局部归一化：
   
   A_p_{k,q} = (f_{k,q} − μ_f(x,q)) / (σ_f(x,q) + ε)
   
   仅使用紧随的下一反应，不向后传播后续反应；单例锚点或常数锚点归零。
   
5. **总优势**：A_{k,q} = A_o_k + λ·A_p_{k,q}，其中 λ 默认取 0.5（上限约束），确保终局结果优势在整体上保持主导。
6. **优化目标**：采用 PPO 裁剪的 GRPO 重要性比率目标，仅训练助手语言和生成的工具调用 token，用户与原始工具结果 token 被掩码。
7. **关键设计原则**：策略元数据仅在 rollout 构建后读取，从不进入智能体可见上下文；无需学习评论器、额外 rollout 或额外展开；反应分支可关闭——关闭后等式退化为纯结果版 Interactive GRPO 对照。

### 3. 实验设计：数据集、Benchmark 与对比方法

- **主数据集——τ-bench 家族九域**：
  - τ-bench：Airline（50 任务）、Retail（115 任务）
  - τ²-bench：Airline（50）、Retail（114）、Telecom（114）
  - τ³-bench：Airline（50）、Retail（114）、Telecom（114）、Bank（97）
  - 关键设计：**后续 RL 阶段仅使用 τ-bench 的 Airline 和 Retail 训练集**；Telecom 和 Bank（含非结构化策略集）仅用于评测，衡量超出 RL 训练域的迁移能力。
- **零样本迁移基准**：
  - **Pare-Bench**：143 个主动移动场景，测试从反应式客服到主动移动协助的协议迁移。
  - **Co-Gym**：312 个双向协作场景（102 Travel + 100 Related Work + 110 Tabular），测试非轮转协调结构变化。
- **对比方法**：
  - **Base**：预训练 Qwen3 模型（未训练）
  - **+SFT**：在公开 MUA-RL 数据上冷启动 SFT
  - **+Interactive GRPO**：仅终局结果优势的匹配对照（核心对照）
  - **+Faca**：结果优势 + 反应过程优势
  - 消融设置：λ 取值（−0.5/0/0.1/0.5）、移位（Shifted）反应、随机化（Randomized）反应极性
- **严格控制变量**：两个 RL 臂共享冻结的 DeepSeek-V4-Flash 模拟器、智能体可见对话、SFT 初始化、训练数据、rollout 构造、优化器和 horizon；差异仅在信用分配方式。

### 6. 论文的主要结论与发现

1. **核心结果——Faca 显著优于纯结果 GRPO**：8B 规模九域平均从 34.66 提升至 40.57（+5.91 个百分点）；14B 从 42.51 提升至 52.73（+10.22 个百分点）；按种子配对的增益在 8B 为 4.67/6.33/6.75 点，14B 为 8.62/10.14/11.91 点，**所有运行、两个规模均保持排序一致**。
2. **增益具有领域异质性**：Faca 在 8B 和 14B 各领先九域中的七个域，最大增益出现在全部四个 Telecom 规模–基准格（如 14B τ² Telecom：30.7→83.6，τ³ Telecom：50.6→82.7）；14B 上两个 Retail 域出现退步。
3. **反应语义与时间对齐缺一不可**：随机化反应极性在 8B 上消除 Telecom 增益（47.37→26.32），单 U2U 移位也抹除增益（39.37→33.92），证明仅存在 token 级变化不够，必须保留反应内容和时间关联。
4. **零样本迁移保持排序**：Pare-Bench 上 8B Pass@1 从 6.29% 升至 10.49%，14B 从 10.49% 升至 13.29%；Co-Gym 整体 13/16 个评价单元领先，但 Travel DR 有小幅下降。
5. **λ 敏感性支持辅助而非替代目标**：λ=0.1 即有增益但弱于 λ=0.5；λ=−0.5 严重破坏性能——反应信度是辅助监督信号，不可替代终局目标。
6. **反应可观测性是机制解释**：增益集中在"用户能观察到前一片段后果"的领域（Telecom 的双控结构），而非简单随对话长度增加。

### 7. 优点

1. **问题切入锐利**：将"下一轮用户不仅是上下文"这一观察升华为局部信用信号，角度新颖且具有一般性。
2. **方法简洁高效**：无需额外评论器（critic）、无需额外 rollout、无需改变模拟器或智能体可见上下文——只改信用分配，工程成本极低。
3. **控制变量极严格**：冻结模拟器、共享初始化/数据/优化器，与对照的差异仅在信用计算方式，使性能差可归因于方法本身。
4. **消融设计富有说服力**：移位和随机化两个控制直接证明"反应内容"和"时间对齐"均不可或缺，λ 扫描验证了辅助目标的定位。
5. **分析深入多维度**：包括领域异质性分析、反应可观测性解释、训练动态遥测（U2U 极性分布与优势覆盖率）、Telecom 成对审计和完整轨迹对照，贯穿"宏观增益—微观机制"链条。
6. **写作坦诚**：作者明确标注了方法的归纳偏差（如 reveal-piece 可能奖励不必要追问）、分析的描述性边界和不能据此做强因果声明，学术表达克制客观。

### 8. 不足与局限

1. **依赖私有反应元数据**：Faca 利用模拟器产出的私有策略标注（strategy metadata），该标注在真实用户部署中不存在；作者虽提出可用话语提取器替代，但未加以验证。
2. **模拟器单一性**：仅使用 DeepSeek-V4-Flash 一个模拟器家族；未验证不同类型模拟器或真实用户对方法有效性的影响。
3. **模型架构覆盖面窄**：仅 Qwen3-8B/14B 两个同族模型，两点的比较不足以支撑任何规模法则推断。
4. **单次评估的统计局限**：每个训练检查点仅评估一次，论文报告的标准差混入了评估随机性，无法完全分离两种波动来源；消融实验未重复多种子。
5. **零样本迁移的绝对水平偏低**：Pare-Bench 上最好成绩仅 13.29% Pass@1，Co-Gym Travel 出现退步，比较性结论强于绝对性能声明。
6. **时间相邻性是归纳偏差而非因果**：Faca 将反应归因于紧邻的前一 U2U 片段，但并未证明因果关联；作者明示这是"可操纵的偏差"而非事件级因果归属。
7. **Telecom 增益不均匀**：在 τ³ Service 子集上 Faca 反而落后于 Interactive GRPO（20/29 vs 24/29），说明即使增益最大的领域也存在失败片段。
8. **"反应可观测性"仍是事后解释**：论文没有设计直接操纵反应可观测性的实验来验证该机制假设，结论停留在相关性层面。
