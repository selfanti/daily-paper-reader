## 摘要
随着基于大语言模型的智能体被部署到更长期、更高风险的任务中，其记忆系统仍存在关键缺口。现有记忆基准大多聚焦于检索型任务，但我们认为，有效的记忆系统必须追踪世界状态的演化；当事实、约束和决策在长时间交互中被修订时，答案必须反映当前状态，而非已被取代的旧状态。我们将这一能力定义为状态追踪，并将其实例化为StateMemBench——一个包含234个跨会话场景、覆盖两种对话长度区间的基准。其封闭池评分用于判断答案反映的是当前状态、被取代状态，还是其他失败情形，从而在构造上区分状态追踪失败与其他错误。我们的分析表明，该任务对现有记忆系统、检索增强基线和长上下文基线均构成挑战。随后，我们提出了StateMem——一种状态优先的记忆方法，显式追踪取代关系与依赖关系，并展示其在DeepSeek-V4-Flash上比最强同骨干基线在当前状态准确率上提升1.8倍（0.205 -> 0.363），在Qwen-3.5-9B上比最强记忆系统提升1.6倍（0.149 -> 0.233），同时与长上下文基线保持竞争力。最后，我们展示了同样的状态方法可作为轻量级单次调用包装器应用于现有记忆系统，在StateMemBench上将六个记忆与检索后端的当前状态准确率提升+32至+67个百分点。一项长度和成本匹配的对照实验显示，其中+15至+32个百分点归因于状态结构本身，而非额外上下文。

## Abstract
As LLM-based agents are deployed for longer and higher-stakes tasks, their memory systems continue to have crucial gaps. While existing memory benchmarks focus largely on recall-shaped tasks, we argue an effective memory system must track the evolving state of the world; as facts, constraints, and decisions are revised over a long interaction, answers must reflect the current state and not a superseded one. We define this capability as state tracking and instantiate it in StateMemBench, a benchmark of 234 multi-session scenarios spanning two conversation-length regimes. Its closed-pool grading scores whether an answer reflects the current state, the superseded state, or fails otherwise, separating state-tracking failures from other errors by construction. Our analysis shows that this task is challenging for existing memory systems, retrieval-augmented baselines, and long-context baselines. We then present StateMem, a state-first memory method that explicitly tracks supersession and relational dependencies, and show it improves current-state accuracy over the strongest same-backbone baseline by 1.8x (0.205 -> 0.363) on DeepSeek-V4-Flash and over the strongest memory system by 1.6x (0.149 -> 0.233) on Qwen-3.5-9B, while remaining competitive with the long-context baselines. Finally, we show the same state approach can be applied as a lightweight single-call wrapper over existing memory systems, lifting current-state accuracy by +32 to +67 points on StateMemBench across six memory and retrieval backends. A length- and cost-matched control attributes +15 to +32 of those points to state structure rather than added context.

**核心概念——状态漂移（State Drift）：**
- 定义为：相关事实虽然存在于已装配的上下文中，但智能体仍基于过期或不完整的版本行动。
- 与检索失败的区分：状态漂移不是"获取不到信息"，而是"无法判断哪条信息当前有效"，**更好的检索算法无法解决这一问题**。
- 论文论证了漂移是普遍且被忽视的失败模式：在 LongMemEval oracle（保证完美检索）上，DeepSeek-V4-Flash 的失败中有 44.4% 被双重判官确认为状态漂移，是最大的确认失败类别；在 MemoryArena 购物任务中漂移占 63.5%。

**整体含义：**
- 论文首次将**状态追踪（state tracking）**作为独立于回忆、推理的能力进行系统刻划，并给出了可构造、可验证的评测方法与解决方案。该工作重新定义了智能体记忆系统应具备的核心能力维度。

## 2. 论文提出的方法论

论文包含两大核心贡献：**评测方法（StateMemBench）** 与 **解决方法（StateMem）**。

### 2.1 StateMemBench 基准的构造方法

**符号化场景生成：**
- 每个场景由**符号事件程序**（typed state operations）描述，包含规则声明、值更新、作用域例外、承诺与撤回等操作序列。
- 正确答案由**确定性求值器**重放程序计算得出，不依赖人工标注，保证黄金真相可验证。
- 同时实现一组"懒惰阅读者策略"（lazy reader policies）作为反事实启发式，用于构造陷阱场景。

**五类失败模式：**
1. **状态错误（Status errors）**：值已变更，但读者锚定在更早、更响亮的承诺上，返回被取代值。
2. **显著性错误（Salience errors）**：有效值在场，但更频繁或更显眼的竞争值胜出（并非真实取代）。
3. **序列错误（Sequence errors）**：派生值在输入变化后未重算，返回陈旧推导结果。
4. **复合错误（Compound errors）**：多种机制交互作用。
5. **反陷阱（Anti-trap）**：锚定回答才是正确的，过度激进的失效策略反而出错——防止"总是偏好最新值"的启发式获得高分。

**三个领域：** 科研（研究？research）、购物、个人金融。
- 选择理由：购物/金融捕获单用户-助理状态，科研捕获协作型项目状态；三者覆盖分类选择与约束的不同混合；可用公开数据做表层素材。

**场景规模：** 234 个多会话场景。
- **Set A（短）**：190 个场景，18 个会话，中位数 165 轮（约 3k tokens）。
- **Set B（长）**：44 个场景，三条不同模式的陷阱线索融合为约 38 个会话，中位数 599 轮（7–15k tokens），三部分探针问题。
- 共 322 个评分探针。

**封闭池评分（Closed-pool grading）：**
- 生成时为每个探针构造 3–4 个候选答案：黄金真相、目标策略的漂移答案、中立干扰项。
- 评分区分：当前状态（gold）、被取代状态（drift）、其他错误（other/off-pool）——将状态追踪失败与其他错误在构造上分离。

### 2.2 StateMem 方法

**核心思想：** 将多轮对话记忆表示为**结构化状态单元（state units）**的集合，显式记录取代关系与依赖关系，而非仅存储原始文本片段。

**三阶段流程：**
1. **摄取（Ingestion）**：TurnEncoder 对每一轮对话调用一次 LLM，解析为状态单元，每个单元为元组 *u = (id, content, priority, source, deps)*。priority 分 hard/soft，deps 包含 derived_from（值来源）与 coupled_with（有效性关联）两类依赖链接。可主动标记现有单元"面临被取代风险"并提供替代单元。
2. **更新（Update）**：应用取代标记，将目标单元标记为 superseded；**确定性重检器（Rechecker）** 在依赖图上传播失效——若单元 u*ᵢ* 依赖的单元状态变化，则将 u*ᵢ* 标记为 needs_recheck。整个过程 O(|E|)，无额外 LLM 调用。
3. **测试时（Test Time）**：从 StateStore 确定性装配有效状态块（active 单元，含 needs_recheck 标记的），渲染为结构化提示，引导模型重算当前值并回答。仅需一次 LLM 调用。

**StateMemWrapper（轻量级包装器）：**
- 将 StateMem 的状态解析原则融入**单次答案调用提示词**，无存储、无逐轮处理、无额外 LLM 调用。
- 两阶段融合：Trace（≤250 词，按时间顺序追踪被问及槽位的值链，带轮号，先承诺再作答）与 Resolve（四条优先级规则：稍后取代更早；常设规则优先于一过性实例；派生值重算而非引用；仅显式取代或过期才退休事实）。
- 匹配对照（wrapper-ctrl）：除结构外完全相同（不含值链、轮号、优先级规则），以隔离"结构"与"额外文本量"的贡献。

## 6. 论文的主要结论与发现

1. **状态追踪 ≠ 回忆**：现有基准被"检索-回忆"范式主导，但失败分布中漂移占据最大份额。在 LongMemEval oracle（保持完美检索）上，漂移占确认失败的 44.4%（16/36，Wilson 95% CI [30%, 60%]），且在多会话问题中漂移率高达 71.4%。
2. **状态漂移不是推理能力不足**：启用思维链不改善（84.0% → 76.0%，p=0.34），而显式状态维护能改善。
3. **现有系统普遍失败**：StateMemBench 上，长上下文最佳模型（GPT-5.4-Nano）仅 0.277；同骨干长上下文在 Qwen-3.5-9B/DeepSeek-V4-Flash 上仅 0.149；记忆系统普遍低迷；多种 GraphRAG 与检索增强亦远远不足。
4. **StateMem 显著有效**：
   - DeepSeek 上 0.363，为同骨干长上下文的 2.4 倍（0.149），为最强记忆系统 A-Mem（0.199）的 1.8 倍。
   - Qwen 上 0.233，超过最强记忆系统 Mem0（0.149）1.6 倍，与 GraphRAG（0.224）统计持平。
   - 外部验证：LongMemEval 上负责任的（0.580/0.656），与长上下文接近；LoCoMo 上领先所有记忆系统（0.566/0.592）且与长上下文持平——**状态追踪不损害回忆能力**。
5. **组件贡献可定位**：超取代标记是最有效的单一步骤（DeepSeek：0.174 → 0.298）；依赖传播有助于目标模式但对 Set B 反陷阱过度传播（−12.5 pp）；重算引导贡献约 6 pp。
6. **状态追踪是可分离、可移植的轴**：StateMemWrapper 在 12 个单元（6 后端 × 2 骨干）上全部显著改善（+31.7 至 +66.6 点），其中结构贡献 +15.0 至 +31.7 点；强骨干模型对状态结构的依赖更小。
7. **弱骨干是限制因素**：Qwen 上所有方法漂移率 61–66%，记忆层几乎不改变结果；强骨干 DeepSeek 上方能分离方法，StateMem 漂移率下降 15 个百分点（64.3% → 49.1%），正确数增加 42。

## 7. 优点

1. **问题定义清晰且原创**：将"状态追踪"从回忆和推理中独立出来，给出可操作的定义（状态漂移）和严格的排除性标注流程（从检索失败、理解失败、格式错误、推理失败中逐步排除才归于漂移）。
2. **构造性评测设计**：符号事件程序 + 确定性求值器使黄金答案可验证、可重放，不依赖语言学家设计的人工标注；反陷阱设计防止"总信最新"启发式刷分。
3. **封闭池评分精良**：在生成时构造漂移答案与干扰项，可区分"错误类型"（漂移 vs 其他）与"参与度"（in-pool vs off-pool），避免了低漂移率
