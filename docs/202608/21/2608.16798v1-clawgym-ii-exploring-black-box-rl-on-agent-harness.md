## 摘要
智能体装备通过协调智能体与环境的交互，显著提升了长时程任务的性能。然而，通过复杂装备进行强化学习在很大程度上仍未得到探索，因为将此类训练扩展到长时程智能体任务会带来根本性挑战。在这项工作中，我们提出了一种统一的黑盒强化学习框架，用于通过复杂装备对通用智能体进行稳定且可扩展的优化。具体而言，我们首先构建了一个基于沙箱的执行基础设施，将任务环境和装备隔离在临时沙箱中，以支持大规模并发回放。然后，我们将策略优化与不透明的装备执行解耦，并在模型边界放置一个服务代理以捕获模型调用。为了重建多轮轨迹并提高训练效率，我们将捕获的调用组织为前缀树，并进一步调整基于评论家的PPO和无评论家的GRPO，以在恢复的树结构上进行优化。同时，我们在整个优化过程中保持训练与推理的一致性。最后，我们引入了混合装备训练，允许通过异构装备联合优化单个模型。使用Qwen3-30A3B，黑盒强化学习在ClawGym-Bench上通过OpenClaw和Claude Code分别将Pass@1提升了9.98和14.81个百分点，同时在200-400个优化步骤中保持稳定。此外，该框架在更具挑战性的任务（如JobBench和OfficeQA）上也取得了持续的性能提升。总体而言，我们的框架通过黑盒装备实现了对通用智能体的有效、稳定且可扩展的优化，并支持跨异构执行系统的统一训练。

## Abstract
Agent harnesses have substantially improved performance on long-horizon tasks by coordinating agent interactions with the environment. However, reinforcement learning through complex harnesses remains largely unexplored, as scaling such training to long-horizon agent tasks introduces fundamental challenges. In this work, we present a unified black-box RL framework for stable and scalable optimization of general agents through complex harnesses. Concretely, we first build a sandbox-based execution infrastructure that isolates task environments and harnesses within temporary sandboxes for large-scale concurrent rollouts. We then decouple policy optimization from opaque harness execution and place a serving proxy at the model boundary to capture model calls. To reconstruct multi-turn trajectories and improve training efficiency, we organize the captured calls into prefix trees and further adapt both critic-based PPO and critic-free GRPO to optimize over the recovered tree structure. Meanwhile, we maintain training-inference consistency throughout the optimization process. Finally, we introduce mix-harness training, allowing a single model to be jointly optimized by heterogeneous harnesses. With Qwen3-30A3B, black-box RL improves Pass@1 on ClawGym-Bench by 9.98 and 14.81 points through OpenClaw and Claude Code, respectively, while remaining stable over 200-400 optimization steps. Moreover, the framework yields consistent gains on more challenging tasks such as JobBench and OfficeQA. Overall, our framework enables effective, stable, and scalable optimization of general agents through black-box harnesses, supporting unified training across heterogeneous execution systems.

  > **如何通过 harness 进行黑盒强化学习，以稳定地优化通用智能体？**
- **整体含义**：论文旨在建立一套统一的、可扩展的黑盒 RL 框架，使训练可以直接“穿过”复杂、不透明的生产级 harness 进行，同时兼顾稳定性、可扩展性以及跨不同 harness 的统一训练能力。

## 2. 论文提出的方法论

### 2.1 核心思想

将策略优化与不透明的 harness 执行解耦，把 harness 当作黑盒 rollout 引擎，仅在模型服务边界捕获模型调用，并据此重建可训练轨迹，再使用 PPO/GRPO 等 RL 算法进行优化。同时引入混合 harness 训练，使同一模型可联合学习多个异构 harness 的经验。

### 2.2 关键技术细节

- **沙箱化并发执行基础设施**：
  - 每个任务环境与所选 harness 封装在临时沙箱中，按需创建、完成后销毁；
  - 沙箱提供隔离的工作区和运行时依赖，支持大规模并发 rollout；
  - 通过 MCP（Model Context Protocol）服务器在沙箱内提供网络搜索和任务特定工具，无需修改 harness 原生工作流。
- **服务代理捕获模型调用**：
  - 在模型服务边界放置 serving proxy，作为 harness 的模型端点；
  - 代理调用当前 rollout 策略、以 harness 期望的协议返回响应，并记录输入 token、生成 token、rollout 对数概率以及任务元数据。
- **前缀树构建与轨迹恢复**：
  - 将每次 rollout 捕获的模型调用组织为 rollout 级别的前缀树；
  - 根据输入上下文的累积历史最长前缀匹配，将调用挂到对应节点；
  - 恢复树中节点之间的非模型内容（工具输出、环境反馈）；
  - 每条根到叶路径对应一条候选多轮轨迹。
- **轨迹过滤**：
  - 移除因重试或无效生成产生的“死叶”（dead leaves）；
  - 丢弃过度分支（叶子数超过阈值）的 rollout，避免污染梯度；
  - 排除子代理（subagent）和上下文压缩（compaction）产生的辅助轨迹，只优化主智能体轨迹，避免终端奖励分配模糊。
- **基于树结构的策略优化**：
  - **GRPO 适配**：以同一任务下的 n 个 rollout 为组，用组奖励归一化得到每条 rollout 的优势：

    \[
    \hat{A}_i = \frac{R_i - \mu_q}{\sigma_q + \varepsilon}
    \]

    rollout 共享同一终态奖励，所有保留轨迹中的可训练 token 节点参与优化，共享前缀只计一次。

  - **PPO 适配**：使用简化版本，设 γ=1、λ=1，独立处理同一 rollout 内的各条轨迹，GAE 退化为：

    \[
    \hat{A}_t = R_i - V_\phi(s_t)
    \]

    即优势只取决于最终奖励与当前状态价值估计之差，未在分支点间传播优势。
- **训练–推理一致性**：
  - 采用 black-box token-in-token-out 纪律：训练使用的 token 序列直接取自推理引擎生成的原始 token，而 harness 实际消费的文本从这些 token 解码得到，二者解耦，避免 harness 重序列化/工具归一化破坏训练序列；
  - 采用 token 级重要性采样修正，补偿推理引擎与训练引擎之间数值精度、核函数与并行化差异导致的对数概率偏差：

    \[
    w_t = \min\left(\exp(\log \pi_{\text{old}}(a_t|s_t) - \log \pi_{\text{rollout}}(a_t|s_t)), \bar{c}\right)
    \]

    以截断上限控制方差。
- **混合 harness 训练（Mix-Harness Training）**：
  - 每个任务–harness 对构成一个基本训练实例；
  - 不同 harness 的 rollout 随机混合在同一训练批次中；
  - 每个优化组按任务–harness 对独立进行优势归一化，避免不同 harness 的奖励分布差异扭曲相对优势估计。
- **工程性保障措施**：
  - 沙箱执行超时强杀、显式失败丢弃；
  - 伪流式解析：缓冲输出并持续发送 synthetic SSE 保持连接，turn 结束后用非流式解析，避免增量解析错误；
  - 轨迹完整捕获：等待记录数稳定后才进行轨迹组装，防止异步后台写入导致轨迹不完整。

## 6. 主要结论与发现

- **黑盒 RL 能带来显著且一致的性能提升**：
  - Qwen3-30A3B 经黑盒 RL 后，ClawGym-Bench 上通过 OpenClaw 提升 9.98 点，通过 Claude Code 提升 14.81 点；
  - PinchBench 上分别提升 11.71 和 17.28 点；
  - ClawII-OC-30A3B 比 ClawGym-30A3B SFT 基线高出 5.80 点。
- **框架在不同 harness 上均有效**：
  - 8B 与 30A3B 基座在 OpenClaw 和 Claude Code 下均获得提升，30A3B 模型还超过 Qwen3-235A23B（OpenClaw 下高 8.14 点，Claude Code 下高 6.28 点）。
- **训练稳定性良好**：
  - PPO 与 GRPO 在 200–400 步内训练奖励与评测分数呈稳定上升趋势；
  - PPO 熵曲线更平滑，GRPO 波动稍大。
- **混合 harness 训练可行**：
  - 混合模型在两种 harness 下的训练奖励与评测分数都能匹配甚至略优于单 harness 训练模型，未引入明显不稳定或性能退化。
- **框架可扩展到更复杂任务**：
  - JobBench-Easy 从 20.46 提升到 27.20；OfficeQA-Full 从 8.53 提升到 21.54。
- **冷启动初始化增强稳定性**：
  - 冷启动模型训练奖励起点更高、曲线更平滑、熵更稳定，下游表现更强；但直接 base 初始化也能有效训练。
- **黑盒 RL 与白盒 RL 各有优劣**：
  - 白盒 AgentLoop RL 在同分布白盒评测下表现更好（59.90 vs 51.37），且可迁移到黑盒 harness（50.33）；
  - 但白盒训练模型在 OpenClaw 黑盒 harness 下仍明显低于直接在 OpenClaw 上训练的黑盒模型（62.62），说明 harness 特有交互模式仍需黑盒训练来充分适应。

## 8. 不足与局限

- **黑盒本质上的可解释性限制**：harness 内部逻辑完全不可见，论文只能通过模型调用边界推断轨迹，无法获知 harness 内部状态、工具调用失败原因或上下文压缩细节，可能导致轨迹恢复存在系统性偏差。
- **辅助轨迹被排除**：子代理和上下文压缩轨迹被直接丢弃，未利用其中可能包含的丰富探索信息，论文也承认这是未来工作，说明当前方法可能损失一部分学习信号。
- **PPO 的简化处理**：PPO 对分叉轨迹采用独立处理且 γ=λ=1，未在图结构上做完整信用分配，可能造成优势估计方差较高；论文将其留作未来工作。
- **任务分布覆盖有限**：
  - 训练任务主要来自 ClawGym-SynData 及其合成扩展，真实世界任务多样性有限；
  - 评测基准集中在 ClawGym 与 PinchBench，未在更多独立第三方 benchmark（如 Terminal-Bench、SWE-Bench 等）上进行系统验证。
- **资源信息缺失**：未报告 GPU 型号、数量、训练时长、沙箱并发规模等关键算力信息，限制了复现和成本评估。
- **统计严谨性不足**：未报告多次运行的标准差、置信区间或显著性检验，单一结果可能受随机性影响。
- **初始化策略的混淆因素**：ClawII-OC 使用了冷启动初始化而 ClawII-CC 未使用，两者绝对性能差异不能完全归因于 harness 差异；冷启动消融只在 OpenClaw 下进行，结论的普适性受限。
- **评测协议中 rubric 依赖 LLM Judge**：使用 GPT-5.4 进行评分，虽然与代码验证混合，但 rubric 评分本身存在主观性和不稳定风险，且未报告 Judge 一致性指标。
- **白盒对比可能不公平**：白盒 AgentLoop 更简单，训练数据和任务分布可能与黑盒设置不完全一致，导致对比结果解释需谨慎。
