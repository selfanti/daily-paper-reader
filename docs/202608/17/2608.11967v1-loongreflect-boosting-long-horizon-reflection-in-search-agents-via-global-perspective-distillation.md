## 摘要
大型语言模型代理越来越依赖长时程推理来解决涉及规划、工具使用和记忆的复杂任务。在这种环境中，一项关键能力是反思：评估轨迹进展，识别缺失的证据和不可靠的中间状态，并决定是继续、修正还是放弃当前分支。然而，学习有效的反思是具有挑战性的，因为反思是在当前分支内局部执行的，而其效用只能通过其对最终轨迹结果的贡献来确定。这种局部-全局不匹配使得基于结果的强化学习只能为反思决策提供局部、稀疏和延迟的监督。为了解决这些问题，我们提出了LoongReflect，一个将反思表述为记忆控制策略的训练框架。代理通过显式的反思（reflect）和回溯（backtrack）操作在可逆的轨迹树上运行。反思将已验证的事实、缺失的证据和特定分支的风险整合到工作记忆中，而回溯则从当前上下文中移除不可靠的分支，并保留简洁的纠正经验。为了学习这一策略，LoongReflect通过一种前瞻性的、外梯度风格的协调机制结合了两种互补信号。一个快速通道从特权教师中蒸馏具有全局信息的反思行为，监督仅限于反思和回溯标记。一个慢速通道使用基于结果的GRPO优化完整轨迹，使局部控制决策与最终任务成功对齐。在多跳检索增强生成和数学推理基准上的实验表明，与仅基于结果的强化学习和自蒸馏基线相比，我们取得了持续一致的改进。

## Abstract
Large language model agents increasingly rely on long-horizon reasoning to solve complex tasks involving planning, tool use, and memory. A critical capability in such settings is reflection: assessing trajectory progress, identifying missing evidence and unreliable intermediate states, and deciding whether to continue, revise, or abandon the current branch. Learning effective reflection, however, is challenging because reflection is performed locally within the current branch, whereas its utility can only be determined by its contribution to the final trajectory outcome. This local-global mismatch makes outcome-based reinforcement learning provide only local, sparse and delayed supervision for reflective decisions. To solve these, we propose LoongReflect, a training framework that formulates reflection as a memory-control policy. The agent operates over a reversible trajectory tree using explicit reflect and backtrack actions. Reflection consolidates verified facts, missing evidence, and branch-specific risks into working memory, while backtracking removes an unreliable branch from the active context and preserves a concise corrective lesson. To learn this policy, LoongReflect combines two complementary signals through a look-ahead, extragradient-style coordination mechanism. A fast channel distills globally informed reflective behavior from a privileged teacher, with supervision restricted to reflection and backtracking tokens. A slow channel optimizes complete trajectories using outcome-based GRPO, aligning local control decisions with final task success. Experiments on multi-hop retrieval-augmented generation and mathematical reasoning benchmarks demonstrate consistent improvements over outcome-only reinforcement learning and self-distillation baselines.

## 1. 核心问题与整体含义（研究动机与背景）

**核心问题：长时程反思（Long-Horizon Reflection）学习中的"局部-全局错位"难题。**

- 大型语言模型（LLM）代理在复杂任务（规划、工具使用、记忆维护）中越来越依赖长时程推理，而"反思"（reflection）是其中关键能力：评估轨迹进展、识别缺失证据与不可靠中间状态、决定是继续、修正还是放弃当前分支。
- 反思本质上是**对轨迹本身的控制过程**，而不仅仅是附加的推理文本。
- 论文指出两大根本挑战：
  - **C1 学习信号困境（Learning-signal dilemma）**：反思决策的价值要经过许多后续动作才在最终结果中显现，基于结果的强化学习只能提供稀疏、延迟、弱归因的监督；但给反思显式中间奖励又容易引发奖励黑客（reward hacking），如鼓励过度或浅层反思而不提升任务成功率。
  - **C2 局部-全局视角鸿沟（Local–global perspective gap）**：反思在"当前分支的局部上下文"中做出，但其真正价值取决于该分支对完整轨迹的贡献，局部反思器无法直接观察到继续/修正/放弃分支的最终影响。
- 现有方法只解决部分问题：一类方法做步骤级验证或动作评估（如过程监督），另一类通过特权反馈或错误定位提供更密监督，但都未将反思真正作为"轨迹级控制"来学习。
- 该论文的意义在于：将长时程反思重新定义为**可训练的记忆控制策略**，并设计了两通道优化框架，同时解决稀疏监督与局部-全局错位问题。

## 2. 方法论

### 2.1 核心思想：反思即记忆控制（Reflection as Memory Control）

- 代理同时具备执行策略与记忆控制策略，运行在一个**可逆轨迹树**上，并配备两个显式控制动作：
  - `<reflect>`：将已验证事实、缺失证据、分支风险整合进工作记忆，并给出结构化总结 `rt = {evid_t, risk_t, ret_t, ctrl_t}`，其中 `ctrl_t ∈ {continue, backtrack}` 决定下一步是继续还是回溯，使反思成为"状态控制诊断"而非泛泛批评。
  - `<backtrack>`：当判定当前状态不可靠时，将活动轨迹回滚到可信前缀，移除被污染的后缀并归档，同时保留一条简洁的前瞻性纠正经验（如关键矛盾、被证伪的假设、下一步必须满足的约束）。
- 状态定义：`zt = {x, Tt, Pt, mt}`，其中 `Tt` 为累积轨迹树，`Pt` 为活动执行路径，`mt` 为从该路径压缩得到的工作记忆。模型上下文只序列化 `ct = Serialize(x, Pt, mt)`，不活动的分支被排除在上下文外，防止不可靠状态污染后续决策。
- 回溯转换公式：`Pt+1 = Pj ⊕ uj:t`，`Bt+1 = Bt ∪ {Pj+1:t}`（`Pj` 为恢复的可信前缀，`uj:t` 为压缩纠正更新）。

### 2.2 两通道优化框架（Two-Channel Optimization）

- **快速通道——答案掩码局部蒸馏（Fast Channel）**：
  - 特权的 EMA 教师基于全局执行记录（含活动路径与归档分支）构造结构化提示 `ht = Hφ(x, T≤t, Pt, mt)`，输出与反思总结同构（证据、风险、返回点、控制决策），但**掩码掉最终答案**，避免答案模仿。
  - 学生与教师对同一 on-policy 延续计算 log 概率，仅在 `<reflect>` 和 `<backtrack>` 标记上施加**掩码反向 KL 目标**（k3 风格的无偏估计器）：
    - `Lfast = (1/Z) Σ mref_{t,k} · min(exp(−δ_{t,k}) − 1 + δ_{t,k}, c)`，其中 `δ_{t,k}` 为学生与教师 log 概率之差，`c` 为裁剪常数。
  - 作用：提供密集的局部监督与全局信息校准，缓解 C1 和 C2。

- **慢速通道——基于结果的全局优化（Slow Channel）**：
  - 对完整轨迹使用**基于结果的 GRPO**，每组采样 G 条轨迹，计算组内相对优势 `bAi = (Ri − mean(Rg)) / std(Rg)`。
  - 损失函数为标准 GRPO + KL 正则：对最终活动执行中的策略 token 计算裁剪重要性比（clip 到 `1±ε`）。
  - 作用：从终端结果出发校准反思决策是否真正提升任务成功率，防止局部蒸馏偏离全局目标。

- **前瞻协调机制（Look-Ahead Coordination）**：
  - 先做 K 次内层快速通道更新得到临时策略 `θ̃ = U^K_fast(θ)`，估计快速方向 `gf = (θ − θ̃)/α`；
  - 在 `θ̃` 下计算慢速方向 `gs = ∇θ̃ Lslow(θ̃)`；
  - 若 `⟨gf, gs⟩ < 0`（两者冲突），则去除 `gf` 中与 `gs` 相反的分量：`gLA_f = gf − (⟨gf, gs⟩/‖gs‖²) · gs`；
  - 最终融合更新：`θ+ = θ − ηs·gs − ηf·gLA_f`。
  - 设计意图：校准而非削弱快速信号，确保局部反思更新与全局结果目标一致。

## 6. 定性案例分析

- 论文通过典型轨迹展示了 `<reflect>` 和 `<backtrack>` 的协同行为：当代理在多跳检索中收集到相互矛盾的证据时，反思解释器会输出高风险信号并触发回溯，将活动路径回滚到包含关键假设的可信前缀，同时压缩一条"纠正经验"（例如：先前假设的实体关系已被证伪，下一步需满足的约束条件）。随后代理在修正后的记忆指导下重新规划检索，最终得到正确回答。
- 另一个案例显示，当某分支虽然局部看起来合理但缺乏终局证据时，反思会倾向于 `continue` 并补充缺失证据清单，而不是盲目回溯，说明模型学会了区分"可挽救的局部错误"与"需要放弃的不可靠分支"。

## 7. 局限性与讨论

- **对特权教师的依赖**：快速通道需要本地部署的 Qwen3-32B 教师模型构造全局提示，这在资源受限环境中是额外开销；且教师能力上限可能约束学生性能。
- **反思模式的人工设计**：反思总结的四个字段（`evid, risk, ret, ctrl`）和回溯公式是手工定义的，虽然具有较强的可解释性，但可能无法覆盖所有任务类型（如开放式生成、多智能体协作）中更抽象的反思需求。
- **回溯的代价**：回溯会废弃一部分已生成的轨迹，虽然在实验中任务成功率提升了，但 token 效率或延迟方面的代价未做详细分析；过度回溯可能是某些失败案例的原因。
- **实验规模有限**：仅在 3B/7B 模型上验证，未测试 13B/70B 及以上规模；数学迁移实验只覆盖两个数据集，泛化结论需谨慎。
- **与真实世界轨迹的差异**：训练时使用受限的检索环境（统一检索器、top-k 固定），而真实场景中工具返回格式、延迟和噪声更复杂，需要进一步适配。
