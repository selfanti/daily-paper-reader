## 摘要
强化学习通过评估从当前策略中采样的轨迹来改进自动驾驶视觉-语言-动作（VLA）模型。组相对策略优化（GRPO）在每个rollout组内根据奖励差异进行学习。当所有采样轨迹都较差时，这种相对信号可以对失败进行排序，但无法识别失败区域之外的行为。我们引入了FIRE-VLA，一种失败信息自我进化框架，将此类未解决的失败转化为下一策略的特权监督。低奖励、低多样性的组会触发对同一模型冻结的轮次起始副本的自我蒸馏。教师和学生具有相同的参数规模，但只有教师能观察到隐藏的未来轨迹。监督遵循学生生成的前缀，并仅限于答案令牌，而GRPO对每个组保持激活。更新后的策略为下一轮提供教师，使得路由的失败分布随策略变化，而无需更大的外部教师。从相同的Qwen2.5-VL-3B SFT检查点出发，比较匹配了学生的rollout和策略更新次数。在来自150个保留的nuScenes场景的6,019个示例上，FIRE-VLA保持可比的单样本规划，将G=4平均L2从1.848降至1.500米，并将评估持续性失败发生率从13.03%降至11.20%。平均误差的减少主要源自罕见的严重rollout，而非普通轨迹的均匀改进。

## Abstract
Reinforcement learning improves autonomous-driving vision-language-action (VLA) models by evaluating trajectories sampled from the current policy. Group relative policy optimization (GRPO) learns from reward differences within each rollout group. When all sampled trajectories are poor, this relative signal can rank failures without identifying behavior outside the failed region. We introduce FIRE-VLA, a failure-informed self-evolution framework that converts such unresolved failures into privileged supervision for the next policy. Low-reward, low-diversity groups trigger self-distillation from a frozen round-start copy of the same model. Teacher and student have the same parameter scale, but only the teacher observes the hidden future trajectory. Supervision follows the student's generated prefix and is restricted to answer tokens, while GRPO remains active for every group. The updated policy supplies the teacher for the next round, allowing the routed failure distribution to change with the policy without requiring a larger external teacher. Starting from the same Qwen2.5-VL-3B SFT checkpoint, the comparison matches student rollout and policy-update counts. On 6,019 examples from 150 held-out nuScenes scenes, FIRE-VLA retains comparable single-sample planning, reduces G=4 mean L2 from 1.848 to 1.500 m, and lowers evaluation-persistent failure prevalence from 13.03% to 11.20%. The reduction in mean error arises mainly from rare severe rollouts rather than uniform improvement across ordinary trajectories.

### 1. 核心问题与整体含义

- **研究动机**：强化学习（RL）被广泛用于自动驾驶视觉-语言-动作（VLA）模型的后训练，其中组相对策略优化（GRPO）通过组内奖励对比来引导策略更新。但当一组 rollout 全部为低质量轨迹时，GRPO 只能对失败进行排序，无法提供“如何逃离失败区域”的矫正性信息。此类“未解决失败组”（unresolved failure groups）构成了 RL 后训练的信息瓶颈。
- **核心问题**：如何在无需引入更大规模外部教师模型的前提下，将策略自身的失败转化为有价值的监督信号，从而帮助下一代策略突破失败区域？
- **整体含义**：论文提出 FIRE-VLA，一种失败信息自我进化（failure-informed self-evolution）框架。其核心洞察是：策略在某个 rollout 组中失败这一事实本身，可以通过特权自蒸馏（privileged self-distillation）加以利用——由同规模、冻结的轮次起始策略作为教师，仅向其提供隐藏的未来轨迹信息，沿学生自身生成前缀进行 token 级别的分布监督。该框架使失败分布随策略演进而动态变化，形成“失败 → 监督 → 新策略 → 新失败”的闭环进化，在匹配 rollout 与更新次数的条件下，显著降低了随机采样的平均轨迹误差与持续性失败率。

### 2. 方法论

- **整体框架**：FIRE-VLA 以 GRPO 为基础目标（对所有组保持激活），通过四阶段流程在部分组上叠加特权自蒸馏（PSD）：
  1. **失败路由**：基于组奖励均值（r̄）、奖励标准差（σ）和合法响应占比（v）判断组是否为“未解决失败组”。路由条件为 r̄ 和 σ 分别低于当前 batch 的 30 分位数、且 v ≥ 0.5。满足条件时额外启用 PSD，否则仅用 GRPO。
  2. **双上下文构造**：教师和学生每轮从相同权重初始化。学生上下文为“多模态输入 + 学生生成前缀”；教师上下文额外包含隐藏的真实未来轨迹（privileged token），除此之外与学生共享前缀，教师冻结无梯度。
  3. **回答令牌蒸馏**：在教师 top-16 token + 残差桶的紧凑分布上计算 Jensen-Shannon 散度（JSD，β=0.5），每个 token 的散度以 0.05 为上限封顶。梯度仅流过学生。监督仅施加于回答（answer）span 内的轨迹 token，采用“按 token 数加权、组与响应不单独重加权”的聚合方式。
  4. **损失组合与轮次进化**：总损失为 L = L_GRPO + λ·L_PSD（λ=0.1），GRPO 对所有组保持激活。每轮结束后，更新后的策略成为下一轮的初始权重和新的教师，从而改变下一轮未解决失败分布。
- **轨迹建模**：每例输入为前视图像 + 历史自车描述，策略生成推理后接 6 个未来 BEV 自车坐标点（0.5 秒间隔）。奖励函数为 L2 距离的倒数有界变换：r = 1 / (1 + (1/6)Σ‖p_t − p*_t‖²)。无效响应奖励为 0。
- **关键设计差异**：与传统知识蒸馏不同，教师不来自更大模型，而是当前轮次策略自身的冻结副本，唯一优势在于能观察未来真实轨迹；监督分布在学生当前策略真实访问的前缀之上，避免了离策略偏差。

### 3. 实验设计

- **数据集**：使用 nuScenes 数据集（12），包含 6,019 个评估样本，来自 150 个与训练场景完全分离的保留场景；训练使用 1,200 个 unique RL prompts 的固定集合。
- **基准与对比**：基线方法为同一 Qwen2.5-VL-3B SFT 检查点上连续运行的 **标准 GRPO**（150 次更新）；FIRE-VLA 将 150 次更新分为两个 75 次更新的进化轮，使用不相交的 600-prompt 子集。两者匹配了初始化、提示集规模、rollout 总数（4,800）与更新次数（150）。
- **评价协议**：
  - 单样本低温度（temperature 0.2）与四随机样本（G=4，temperature 0.8）两种评估方式；全部指标按样本内平均后跨样本平均。
  - 持续性失败检测器在独立的 256 样本、37 场景 SFT 校准分割上冻结阈值（无场景/样本重叠），用于跨模型统一衡量持续性失败率。
  - 所有 GRPO-FIRE 对比均为按样本配对的场景聚类 bootstrap（10,000 次重采样）置信区间。
- **主要评估维度**：单样本各时间戳 L2、G=4 平均 L2、奖励、持续性失败率（当前与参考恢复率）、任意候选超越 10 m 的样本比例、CVaR、分位数等分布性指标。

### 4. 资源与算力

- **算力配置**：4 块 NVIDIA RTX 3090 GPU，采用全参数 BF16 FSDP 训练。
- **超参数**：学习率 5×10⁻⁷，权重衰减 10⁻²，warm-up 0.05，梯度裁剪 1.0，全局 batch size 8，响应长度上限 384 token，视觉塔可训练，未使用 LoRA 和 KL 惩罚。
- **训练轮次与耗时**：共 150 次策略更新（两轮 × 75 次）；**具体训练时长（小时数）文中未明确给出**。
- **额外开销说明**：FIRE-VLA 需要额外的冻结教师前向传播，且第二轮会重置优化器与调度器状态，因此论文明确指出该比较**不构成等计算量对比**（not equal-compute）。

### 5. 实验数量与充分性

- **总体实验规模**：核心实验包括单样本和 G=4 两组对比，辅以持续性失败率、恢复率、严重错误尾部统计（CVaR95/99、worst-of-4、intra-std）、分位数与 winsorized 分析、定性案例（4 个场景）、以及场景聚类 bootstrap 区间。
- **提供的证据强度**：论文在主结果上给出了配对置信区间，结论相对审慎——单样本规划差异不显著（CI 跨零），G=4 平均 L2 与持续性失败率差异显著。恢复率差异（GRPO 23.35% vs FIRE-VLA 25.21%）不确定，未作结论。
- **充分性评估**：
  - **优点**：评估协议设计了固定的样本清单、独立的检测器校准分割、场景聚类统计推断与防泄漏验证；分布性分析（winsorized 均值差异）清晰地揭示了收益集中在罕见重型失败上，而非普通轨迹的均匀改进。
  - **不足**：每种方法仅运行一次训练（单一随机种子），训练种子间方差未被量化；未分别隔离路由、特权蒸馏、教师轮次提升三者的独立贡献（无消融实验）；两轮使用不相交的提示子集，无法纵向追踪同一提示跨轮的演化；单次对比组合无法验证方法在更多轮次下持续收敛或单调改进；未做闭环评估。

### 6. 主要结论与发现

- **核心结果**：在 G=4 随机采样下，FIRE-VLA 将平均 L2 从 1.848 m 降至 1.500 m（降低了 0.348 m，约 18.8%，场景聚类 95% CI [−0.771, −0.032]）；持续性失败率从 13.03% 降至 11.20%（绝对差异 −1.83 pp，CI [−2.55, −1.11]）；任意候选超越 10 m 的严重错误样本比例从 1.35% 降至 0.83%。
- **单样本规划**：FIRE-VLA 数值上在所有时间戳上更低（Avg L2 0.642 → 0.602 m），但配对 CI 跨零，因此结论为“性能相当”而非统计显著的提升。
- **收益分布特征**：FIRE-VLA 的平均误差改善主要由减少罕见严重失败（tail）驱动；在普通轨迹区域（中位数、P90、P95），GRPO 反而略优。winsorized 分析表明，封顶后差异转为正值（FIRE 略差于 GRPO），证实降均值的主要来源是尾部重型失败。
- **奖励与几何的分离**：GRPO 的平均奖励（0.637）高于 FIRE-VLA（0.616），但其极端几何误差更重——由于奖励采用有界倒数变换，严重 L2 差异被压缩到奖励空间中；两种模型的 Spearman 相关均 >0.98，而 Pearson 相关仅为 0.08 左右，说明奖励饱和效应导致排序一致但尺度失真。
- **与 SFT 的关系**：两种 RL 方法相对 SFT 都引入了更高的随机采样误差；FIRE-VLA 只是一定程度上缓解了 GRPO 导致的性能退化，并未恢复 SFT 级别的随机鲁棒性。

### 7. 优点

- **问题定义清晰、动机自然**：准确识别 GRPO 在“全失败组”场景下的信息缺失，并用“未解决失败组”这一可操作的统计条件（低均值 + 低方差 + 合法响应占比）形式化该问题。
- **自我进化的设计优雅**：使用同等规模冻结教师 + 特权未来信息，避免引入更大外部模型；教师随策略逐轮提升，使监督位置随失败分布变化而动态演变，形成自然的内生课程。
- **同策略前缀监督**：教师与学生共享学生生成的 on-policy 前缀，严格沿当前策略的响应分布施加监督，有效缓解了离策略蒸馏导致的分布失配。
- **评估协议严谨**：配对场景聚类 bootstrap、冻结检测器、独立校准分割、显式检查场景/图像泄漏、winzorized 分布分析、SFT 参考集恢复率——这些设计在同类论文中少见且执行得较规范。
- **不回避负面结果**：明确报告单样本优势不显著、恢复率差异不显著、GRPO 在普通轨迹区域更优、FIRE-VLA 未恢复 SFT 级随机鲁棒性，且不宣称等计算量对比。这种诚实报告增强了可信度。

### 8. 不足与局限

- **统计与复现层面**：仅单一训练种子，所有结论依赖一次运行；两轮训练使用不相交的提示子集，无法纵向追踪同一提示跨轮表现；FIRE-VLA 第二轮重启优化器状态，且需要额外的教师前向计算，与 GRPO 不是等计算量/等开销比较。
- **方法归因层面**：端到端对比无法分离失败路由、特权蒸馏与教师轮次提升三者各自贡献；路由阈值（30 分位数）与 λ=0.1 等超参数的敏感性未被分析。
- **实验覆盖层面**：未报告不同模型规模（3B 之外）或不同基础 VLA 骨干的泛化性；未进行三轮以上的进化实验验证持续改进能力；未消融教师策略在轮内冻结 vs 在线更新的影响。
- **评估任务层面**：评估为前视摄像头 open-loop 规划，不涉及闭环安全性、交通规则遵守度、驾驶舒适性、状态偏移累积等关键自动驾驶指标；不使用多模态输入组合（如雷达/激光雷达）；真实世界部署价值未经验证。
- **收益范围有限**：改进集中在罕见的极端失败减少上，普通轨迹没有改善，因此对整体驾驶质量的提升可能有限；且 FIRE-VLA 的 G=4 随机误差仍明显高于 SFT，说明 RL 后处理的随机鲁棒性退化问题只是缓解而非解决。
