## 摘要
空间智能正成为具身智能体、机器人规划和多模态助手的基础。为了提升 VLM 智能体的空间推理能力，现有工作主要沿两条路线展开。一条路线采用后训练方法，如监督微调和强化学习。另一条路线采用智能体范式，模型调用外部空间工具（如深度估计和三维重建工具）来收集中间空间证据。我们研究了一条互补且尚未充分探索的路径：冻结的 VLM 智能体能否通过**无需参数更新的自我进化**来提升其空间推理能力，且在推理时不依赖外部专家空间工具？我们提出了**空间记忆智能体（SMA）**，一个**经验 grounded 的运行时框架**，将经过验证的空间经验转化为可复用、可迁移的教训。在可验证的空间环境中，SMA 查询冻结的 VLM，获得预测答案和奖励，并使用**验证器引导的反思**从空间经验中提炼出紧凑的可迁移教训。SMA 进一步为每条教训分配一个**迁移可靠性评分（TRS）**，该评分初始化为均匀分布，并根据后续检索结果作为未来迁移可靠性的访问证据进行校准。在**只读部署**期间，SMA 通过语义过滤和相似度-TRS 组合排序检索教训，使检索到的记忆能够指导冻结模型的推理。在五个代表性空间基准和四个基础 VLM 上，SMA 在每个基础模型区块中取得了最高的宏平均性能，并在 20 项评估中的大多数中取得了所评估方法中的最佳准确率，为跨所评估的冻结模型规模和环境的空间自我进化建立了一条实用的无需参数更新的路径。

## Abstract
Spatial intelligence is becoming a foundation for embodied agents, robotic planning, and multimodal assistants. To improve the spatial reasoning ability of VLM agents, existing work has mainly followed two lines. One line uses post-training methods, such as supervised fine-tuning and reinforcement learning. Another line adopts an agentic paradigm in which the model calls external spatial tools, such as depth estimation and 3D reconstruction tools, to gather intermediate spatial evidence. We study a complementary and underexplored route: Can a frozen VLM agent improve its spatial reasoning through \textbf{parameter-update-free self-evolution}, without depending on external expert spatial tools at inference time? We present \textbf{Spatial Memory Agent (SMA)}, an \textbf{experience-grounded runtime framework} that converts verified spatial experience into reusable transferable lessons. In a verifiable spatial environment, SMA queries the frozen VLM, obtains a predicted answer and reward, and uses \textbf{verifier-guided reflection} to distill compact transferable lessons from spatial experience. SMA further assigns each lesson a \textbf{Transfer Reliability Score (TRS)}, which is initialized uniformly and calibrated from later retrieval outcomes as visit evidence of future transfer reliability. During \textbf{read-only deployment}, SMA retrieves lessons by semantic filter and similarity-TRS combined ranking, allowing the retrieved memory to guide frozen model inference. Across five representative spatial benchmarks and four base VLMs, SMA achieves the highest macro average in every base-model block and the best accuracy among the evaluated methods in most of the 20 evaluations, establishing a practical parameter-update-free path for spatial self-evolution across the evaluated frozen model scales and environments.

## 二、论文提出的方法论

### 核心思想

- 提出**空间记忆智能体（Spatial Memory Agent, SMA）**，一个**经验 grounded 的运行时框架**（experience-grounded runtime framework），核心思想是：把在可验证环境中获得的**经过验证的空间经验**，转化为**可复用、可迁移的教训和记忆**，再在后续推理中检索这些记忆来指导冻结模型的决策，从而实现无需任何参数更新的自我进化。

### 关键技术细节

1. **可验证环境中的经验收集**：
   - SMA 在可验证的空间环境中查询冻结的 VLM，获得预测答案与对应的奖励/反馈信号。
   - 依赖环境验证器提供客观反馈，而非模型自评。

2. **验证器引导的反思（Verifier-Guided Reflection）**：
   - 利用验证器提供的反馈，将空间经验蒸馏为**紧凑、可迁移的教训**，去除冗余的上下文细节，保留可复用的知识。

3. **转移可靠性评分（Transfer Reliability Score, TRS）**：
   - 为每条教训分配一个 TRS，初始化为**均匀分布**。
   - 随着后续检索和使用的反馈，TRS 根据**访问证据**被动态校准，反映该教训在未来场景中迁移的可靠性。
   - TRS 使框架具备**元认知能力**：不仅知道“学了什么”，还知道“学到的知识有多可靠、何时该用”。

4. **只读部署阶段的记忆检索**：
   - 在部署阶段，模型权重保持**只读**，不进行任何参数更新。
   - 检索过程分为两步：
     - **语义过滤**：先通过语义相似度过滤出候选记忆；
     - **相似度-TRS 组合排序**：将语义相似度与 TRS 结合进行排序，选出最相关的记忆。
   - 检索到的记忆以提示（prompt）的形式注入，指导冻结模型的推理过程。

### 算法流程概述

```
1. 在可验证空间环境中查询冻结 VLM → 获得预测答案与奖励
2. 若答案错误或次优 → 验证器引导的反思 → 提炼出可迁移教训
3. 为新教训分配初始 TRS（均匀分布）
4. 在后续检索中，根据记忆的复用效果校准对应教训的 TRS
5. 部署时：语义过滤 → 相似度-TRS 组合排序 → 检索记忆 → 指导推理
```

- 还包含**消融实验**和**记忆分析实验**（如 TRS 校准效果、记忆迁移效果可视化等），对框架的各个组件进行了深入验证。

### 充分性与客观性

- **优点**：
  - 多基准、多模型的实验设计增强了结论的普适性；
  - 消融实验验证了各组件（验证器引导反思、TRS 校准、检索机制）的独立贡献；
  - 与多种类型的方法（后训练、工具调用、基线）对比，对照全面。
- **可提升空间**：
  - 论文未详细说明对比方法是否使用了相同的基础模型、是否控制了变量（如推理采样次数、提示格式等），因此公平性需进一步确认；
  - 是否在更多真实世界、非合成空间任务上验证缺少细节；
  - 未见统计分析或多次运行方差报告，鲁棒性信息不足。

## 六、论文的主要结论与发现

1. **SMA 在每个基础模型区块中均取得了最高的宏平均性能**——即对 4 个不同的冻结 VLM，SMA 都带来了稳定的性能提升。
2. 在 **20 项评估中的大多数**，SMA 在同类已评估方法中取得了**最佳准确率**。
3. **免参数更新的自我进化确实可行**：冻结 VLM 可以通过经验积累与记忆检索，在空间推理任务上实现持续提升，无需修改权重或调用外部工具。
4. TRS 校准机制能够有效区分**可靠迁移与不可靠迁移**的经验，提升了记忆检索的精准度。
5. 验证器引导的反思能够从失败和成功经验中提炼出**跨场景可复用的知识**，而非仅过拟合当前任务。

## 七、优点

### 方法层面的亮点

- **创新性强**：首次系统性探索了冻结 VLM 在空间智能上的**参数更新自由的自我进化路径**，填补了研究空白。
- **轻量高效**：不需要反向传播、不需要更新模型权重，避免了后训练的高昂成本与灾难性遗忘风险。
- **无需外部工具**：推理时不依赖深度估计、3D重建等外部专家工具，部署简单，适用范围广。
- **记忆的可信度建模**：TRS 设计精巧，使记忆系统拥有自我反思能力，提升了经验的长期价值。
- **框架通用**：不限定特定 VLM 或特定空间任务，具备良好的迁移性和扩展性。

### 实验设计的亮点

- 覆盖 4 种基础模型 × 5 个基准的交叉实验，验证框架在不同模型规模和任务类型上的稳定性；
- 包含对记忆质量、TRS 校准效果的单独分析，实验维度较为丰富。

## 八、不足与局限

### 实验覆盖方面的局限

- **算力与效率未量化**：论文未报告运行时间、内存开销或计算成本的具体数据，无法与其他方法进行效率对比。
- **基准代表性有限**：5 个基准虽覆盖不同空间能力，但可能仍受限于合成场景或仿真环境，缺乏真实世界机器人任务、复杂 3D 场景的验证。
- **缺少统计显著性检验**：未报告多次运行的均值和方差，难以判断性能提升是否具有统计显著性。

### 偏差风险

- **反思质量依赖验证器**：如果验证器本身有偏或奖励信号噪声较大，提炼出的教训可能带有系统性偏差；
- **记忆积累曲线未深入分析**：框架需要多少经验才能达到饱和？在经验不足时的表现如何？这些问题未充分讨论；
- **TRS 初始化的敏感性**：均匀分布的初始 TRS 是否适用于所有场景？在不同环境中是否需要不同的初始化策略？未做敏感性分析。

### 应用限制

- **需要可验证环境**：SMA 依赖环境验证器提供反馈，在缺乏可验证奖励的开放域任务中难以直接应用；
- **上下文窗口限制**：检索到的记忆以提示形式注入，当记忆数量增多时可能受到上下文窗口长度限制；
- **“只读部署”期间的推理开销**：由于需要检索和注入记忆，实际推理延迟可能高于原生推理，论文未对此进行量化分析。
