## 摘要
LLM智能体在单个任务中会执行异质的模型调用序列：有些调用需要仔细推理，而另一些则是结构化步骤，如格式化或工具参数构建。先前的路由方法利用这种不对称性，将简单调用分配给更便宜的小模型，将困难调用分配给大模型。这类策略降低了推理成本，但并未改变小模型的能力，因此可实现的节省仍受限于学生模型已能解决的工作量。MERA则不同，它直接改进小模型自身，以单次模型调用作为适配单元。在每个循环中，MERA重放失败的学生调用以获得经执行验证的教师演示，将反复出现的流程提炼到迭代更新的SkillBook中，并通过监督学习和可选的GRPO微调学生LoRA适配器。路由作为部署的辅助机制：改进后的学生模型被置于成本校准的路由器之后，并带有验证器支持的回退；仅当联合重放保持任务质量时，候选的SkillBook、适配器或路由器才被采纳。实验上，四轮适配将Qwen2.5-Coder-1.5B在保留的HumanEval+MBPP上的通过率从28.7%提升至49.7%。在验证器支持的回退下，部署策略以始终使用Luna成本的60.8%保持了88.3%的通过率。在TAU-2上，微调后的Qwen3.5-2B从14/35提升至18/35，并匹配未适配的4B模型。这些结果表明，验证器支持的多轮适配可以提升小模型能力，而不仅仅是绕开固定的学生模型进行路由。

## Abstract
LLM agents execute heterogeneous sequences of model calls within a single task: some invocations require careful reasoning, while others are structured steps such as formatting or tool-argument construction. Prior routing methods exploit this asymmetry by assigning easy invocations to a cheaper small model and difficult ones to a large model. Such policies reduce inference cost, but they leave the small model's capability unchanged, so attainable savings remain bounded by the work the student can already solve. MERA instead improves the small model itself, using a single model invocation as the unit of adaptation. In each cycle, MERA replays failed student invocations to obtain execution-verified teacher demonstrations, distills recurring procedures into an iteratively updated SkillBook, and fine-tunes a student LoRA adapter via supervised learning and optional GRPO. Routing serves as supporting machinery for deployment: the improved student is served behind a cost-calibrated router with verifier-backed fallback, and a candidate SkillBook, adapter, or router is admitted only when joint replay preserves task quality. Empirically, four-cycle adaptation raises Qwen2.5-Coder-1.5B from 28.7% to 49.7% pass on held-out HumanEval+MBPP. Under verifier-backed fallback, the deployed policy retains 88.3% pass at 60.8% of always-Luna cost. On TAU-2, a fine-tuned Qwen3.5-2B improves from 14/35 to 18/35 and matches an unadapted 4B model. These results indicate that verifier-backed multi-cycle adaptation can increase small-model capability, rather than only routing around a fixed student.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想：**
- **以单次模型调用为适配单元**：MERA不优化整个用户任务，而是优化任务内部的每次模型调用。
- **在线轨迹驱动离线更新**：运行时产生的大量执行痕迹（traces）被收集并重放（replay），作为更新三个核心组件——SkillBook、LLM适配器（LoRA）、路由器——的共同监督信号。
- **保守的联合准入机制（Joint Admission）**：任何组件更新必须通过联合重放评估，验证在新的组合状态下，端到端任务质量不下降，才被批准进入部署。

**关键技术细节与流程（文字说明）：**

1. **运行时服务路径（Runtime Loop）**：
   - 路由器（Router）仅基于**序列化的当前调用提示（prompt）**，从强模型、便宜模型或专用学生模型中做出选择。这是一个“仅输入”的路由器，不依赖隐藏智能体状态。
   - 技能选择器（Skill Selector）可调度稳定的模板（Skills），用于处理重复出现的局部结构（如格式化、提取）。
   - 模型执行后，**验证器（Verifier）** 检查输出的模式合法性、工具调用合法性、可执行测试或下游成功性。若验证失败，则自动回退（Fallback）到更强模型。

2. **轨迹产品（Trace Products）与三种证据流（Evidence Streams）**：
   - 将轨迹规范化（Canonicalize）为“步骤切片（Step Slices）”？包含提示、上下文、工具模式、输出、验证结果、重试次数和回退元数据。
   - **SkillBook**：记录重复提示签名的成功/失败统计数据，用于提取稳定的流程模板（外部程序性提示记忆，而非响应缓存）。
   - **路由器训练**：基于提示文本和小模型可执行结果派生的便宜/昂贵标签（若小模型通过验证器，则为便宜标签），使用冻结的嵌入特征（如Qwen3-Embedding-0.6B）加上逻辑回归头。
   - **LLM适配器训练**：选择“困难样本”（便宜模型失败或路由器/SkillBook分歧处）进行监督微调（SFT）和可选的GRPO强化学习。

3. **依赖尊重式更新顺序（Skill → LLM → Router）**：
   - 在一个周期内，**先更新SkillBook**，因为LLM适配器训练时需要将SkillBook程序预置（prepend）到提示中。
   - **其次更新LLM适配器**（LoRA），基于当前技能状态训练。
   - **最后更新路由器**，使其标签能反映当前周期的学生模型表现和技能状态。

4. **算法流程概览（Algorithm 1）**：
   - 运行时代码循环：对每次调用，选择模型（和可选技能），执行，验证失败则回退，记录日志。
   - 更新循环：规范化轨迹为步骤切片，按Skill→LLM→Router顺序更新三个组件，执行联合重放，仅在质量保持时许可（Admit）新状态进入下一轮。

### 6. 论文的主要结论与发现

- **多周期适配显著提升小模型独立能力**：四周期适配（SFT+GRPO）将Qwen2.5-Coder-1.5B在留出HumanEval+MBPP上的直接通过率从28.7%提升至**49.7%**（SFT-only提升至44.2%）。GRPO相比SFT有5.5-6.7个百分点的显著增益。
- **验证器回退实现成本-质量双优的部署点**：在验证器支持的部署下，MERA策略**以60.8%的“始终用Luna”成本保持了88.3%的通过率**，质量接近始终用大模型（86.9%）。
- **路由器的贡献有限，验证器回退是主要安全保障**：在重建的研究中，**学习型预路由器的能力较弱**，大部分质量保障来自“执行验证+失败回退”，而非准确的前置路由。
- **适配器提升可迁移到多轮工具使用场景**：在TAU-2上，训练后的Qwen3.5-2B从14/35提升至18/35，“匹配”未适配的4B端点（17/35），但统计功效不足。
- **核心主张**：验证器支持的多周期适配能**真正提升小模型能力**，而不是仅仅绕开固定学生模型，这是可实现低成本部署的新路径。

### 7. 优点：方法或实验设计上的亮点

- **以单次调用为适配单元的视角**：超越了传统的任务级路由和整体模型微调，更细粒度地匹配了智能体工作负载的异构性。
- **保守的进化协议**：通过“重放-验证-准入”机制，将更新流程与部署流程解耦，确保任何变更都必须证明不会降低端到端质量，符合生产级部署的谨慎性要求。
- **依赖顺序合理的多组件更新**：Skill→LLM→Router的调度尊重了数据依赖（适配器需要当前技能提示；路由器需要当前周期的学生表现），这是方法论上的细致考量。
- **证据流的共享与特化**：同一轨迹切片可同时服务于技能统计数据、路由标签和LLM训练样本，但各组件消费的监督格式互不相同，实现了高效且不互相干扰的证据利用。
- **清晰的实验归因**：将“直接SLM能力提升”与“部署后的级联表现”分开展示，防止混淆“级联通过率高”与“学生模型本身强”或“路由准确”等不同含义。
- **严谨的消融对比**：TAU-2实验严格控制了解析器、用户模拟器、Token限制等变量，隔离了适配器的效果，并诚实地报告了统计功效不足。
- **诚实的局限披露**：明确承认预路由器较弱、验证器覆盖是关键瓶颈、实验是重放而非在线等，增强了论文的可信度。

### 8. 不足与局限

- **验证器覆盖瓶颈**：所有标签质量和准入决策都依赖验证器。若验证器无法捕捉重要的语义失败模式，重放会高估便宜路径的安全性，可能导致“廉价但隐蔽”的失败进入生产。
- **统计功效不足的TAU-2证据**：7胜3负25平，p=0.17，无法在统计上确立工具使用场景的增益，跨领域泛化性存疑。
- **在线行为不确定性**：重放无法完美模拟运行时策略变更带来的分布偏移（改变路由会影响后续调用的流量分布和上下文）。
- **技能表示的适用性有限**：假设智能体行为中存在可识别的重复局部子图，但对于高度异质或非平稳的任务，技能模板可能收益甚微。
- **路由器能力弱**：MERA的部署优势主要来自验证和回退，而非准确的pre-routing，这意味着在验证成本较高或无法立即验证的场景中，其成本节省能力有限。
- **算力投入不透明**：未披露训练所需的GPU资源、时长，难以评估“多周期适配”本身的效率。
- **评估场景有限**：仅覆盖代码生成和受限工具使用，缺乏对长时程规划、随机性高、或策略敏感决策等更难场景的验证。
- **域分布的稳定性要求**：若工作负载高度非平稳，或可复用的步骤类型极少，则专业化带来的增益会迅速衰减，限制了其长期适用性。
