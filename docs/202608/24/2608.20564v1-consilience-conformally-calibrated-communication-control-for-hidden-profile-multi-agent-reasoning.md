## 摘要
多智能体LLM系统可以通过汇集不同视角来提高推理能力，但其有效性取决于通信的协调，特别是在隐藏信息（hidden-profile）场景中，每个智能体只持有正确决策所需的部分证据。现有的协议，包括固定调度、循环交换和非结构化辩论，无法保证对话动作的适当性。我们提出了Consilience，一个推理时编排框架，在分布式私有信息下既引导又认证多智能体通信。在每一轮，Consilience使用一个紧凑的状态总结讨论，该状态捕获不确定性、分歧、证据增益、冗余和过早共识，然后选择通信干预（挑战、澄清、寻求证据或路由）以及合适的说话者。其核心贡献是逐轮保形校准程序，提供无分布、有限样本的保证：在每一讨论轮，以到达该轮为条件，控制器提议动作的一步遗憾以边际概率至少1-alpha被校准阈值所界定；一个接受机制通过替换不可接受的提议，对执行的动作强制执行相同的保证。在HiddenBench风格的隐藏信息任务上，跨越12个开放和封闭权重语言模型，Consilience在决策准确性和通信效率上优于固定和非结构化讨论协议，有时甚至超过每个智能体观察所有证据的全信息基线。这些结果表明，认证的自适应通信控制可能比增加信息可用性更有价值，为可靠的多智能体LLM协调提供了实用机制。

## Abstract
Multi-agent LLM systems can improve reasoning by pooling diverse perspectives, but their effectiveness depends on coordinating communication, particularly in hidden-profile settings where each agent holds only part of the evidence required for a correct decision. Existing protocols, including fixed schedules, round-robin exchange, and unstructured debate, provide no guarantee that a conversational action is appropriate. We propose Consilience, an inference-time orchestration framework that both steers and certifies multi-agent communication under distributed private information. At each turn, Consilience summarizes the discussion using a compact state capturing uncertainty, disagreement, evidence gain, redundancy, and premature consensus, then selects both a communication intervention (challenge, clarify, seek evidence, or route) and an appropriate speaker. Its central contribution is a round-wise conformal calibration procedure that provides a distribution-free, finite-sample guarantee: at each discussion round, conditional on reaching that round, the one-step regret of a controller's proposed action is bounded by a calibrated threshold with marginal probability at least 1 - alpha; an acceptance mechanism enforces the same guarantee for the executed action by replacing inadmissible proposals. On HiddenBench-style hidden-profile tasks spanning 12 open and closed weight language models, Consilience improves decision accuracy and communication efficiency over fixed and unstructured discussion protocols, sometimes surpassing a full-information baseline where every agent observes all evidence. These results demonstrate that certified adaptive communication control can be more valuable than increasing information availability, providing a practical mechanism for reliable multi-agent LLM coordination.

## 论文详细总结

### 1. 核心问题与整体含义（研究动机与背景）

- **隐藏档案（Hidden-Profile）问题**：在医学诊断、情报分析、组织决策等场景中，任务所需信息分散在多个智能体手中，没有任何单个智能体掌握完整证据。信息共享支持一个看似合理但次优的选项，而各智能体的独有信息汇总后才能揭示正确答案。
- **现有方法的核心缺陷**：固定调度、轮询（round-robin）交换和非结构化辩论等现有多智能体通信协议，无法根据讨论动态自适应地调整通信行为，对"当前对话动作是否适当"没有任何统计保证。
- **人类群体中的共同信息偏差**：行为研究反复表明，群体讨论倾向于重复和强化共享信息，而忽略仅有单一个体掌握的独特信息，导致讨论强化而非纠正初始偏好。多智能体LLM系统同样复现了这类集体推理失败（HiddenBench研究证实）。
- **关键洞察**：隐藏档案任务的核心瓶颈并非LLM能否从已观察证据中推理，而在于群体能否控制其通信过程——在共识形成之前，将正确的证据引出、路由并整合进来。**通信控制应被视作序列决策问题，而非固定的提示协议。**

### 2. 方法论（Consilience框架）

#### 2.1 核心思想

Consilience将隐藏档案推理建模为**闭环通信控制问题**：控制器根据不断演化的讨论状态，选择通信干预类型（挑战、澄清、寻求证据或路由）及合适的说话者，并通过**逐轮保形校准**为每个提议动作提供分布无关、有限样本的统计保证。

#### 2.2 五阶段流程

- **阶段1 — 信念elicitation与状态构建**：每轮讨论后，各智能体报告其在公共转录条件下的信念分布向量 \(p_i^{(t)}\)，Consilience聚合为集体信念并构建六维状态向量 \(s_t = [H_t, D_t, R_t, G_t, C_t, P_t]\)：
  - \(H_t\)（群体不确定性）：集体信念的归一化熵
  - \(D_t\)（智能体间分歧）：各智能体信念与集体信念的Jensen–Shannon散度均值
  - \(R_t\)（消息冗余）与 \(G_t\)（证据增益）：通过固定估计器评估消息的重复程度与新决策相关信息的贡献
  - \(C_t\)（通信成本）：归一化转录长度
  - \(P_t\)（过早共识）：高置信度但近期证据薄弱的组合信号
  - 以上变量构成代理讨论损失 \(J(s_t)\)，数值越低越好。

- **阶段2 — 通信动作提议**：定义四种通信干预（Challenge、Clarify、SeekEvidence、Route），可选的第五种为自适应终止的Vote。控制器可以是：
  - **规则基控制器**：对状态变量施加固定阈值
  - **学习控制器（MLP）**：基于反事实动作回报训练的多层感知机，输入六维状态，输出四/五维动作价值
  - **LLM控制器**：由LLM直接根据任务、转录、状态、信念和说话者计数选择动作

- **阶段3 — 反事实评估与保形接受**：对当前状态下所有可行动作执行反事实分支评估，计算每个动作的**一步遗憾（one-step regret）**：
  \[
  \Lambda_t(s_t, a) = J(s_{t+1}^a) - \min_{a' \in \mathcal{A}_m(s_t)} J(s_{t+1}^{a'})
  \]
  离线校准阶段收集控制器提议动作的遗憾作为非一致性分数，确定逐轮阈值 \(\epsilon_m^t\)；在线阶段，若控制器提议的遗憾超过阈值，则从保形集合中选择最低遗憾动作替代执行。

- **阶段4 — 动作条件路由与转录更新**：根据动作类型选择说话者——分歧相关动作选择与集体分歧最大的智能体，证据获取动作选择发言次数最少的智能体；选定的智能体生成动作条件的消息并追加到公共转录。

- **阶段5 — 终止与集体预测**：达到Vote动作、提前停止条件或最大轮数后，各智能体独立投票，采用置信度加权的多数投票产生最终答案。

#### 2.3 理论保证（Proposition 1）

**逐轮边际遗憾覆盖保证**：固定控制器和方法，对于第 \(t\) 轮，在测试轨迹到达该轮且校准队列规模为 \(n_t\) 的条件下，控制器提议动作的遗憾以边际概率至少 \(1-\alpha\) 被校准阈值 \(\epsilon_m^t\) 界定；即提议动作以至少 \(1-\alpha\) 的概率属于保形动作集。当校准与测试分数几乎必然不同时，覆盖概率等于 \(\frac{k_t}{n_t+1}\)，位于 \([1-\alpha, 1-\alpha + \frac{1}{n_t+1})\) 区间。

### 6. 主要结论与发现

- **RQ1（自适应通信是否有效）**：Consilience一致性地显著优于无控制协议。最强控制器平均任务准确率为0.83，对比固定轮询的0.26，绝对提升0.57。增益来源于结合群体状态的适应性干预选择，而非单纯允许智能体通信。
- **RQ2（通信能否补偿信息分布）**：最强Consilience策略在12个模型中的11个上达到或超过全信息基线，平均高出0.13。分阶段证据共享和明确分歧消解能比单次呈现全部事实更有效地促进证据整合。
- **RQ3（控制器设计影响）**：规则基控制器平均表现最强（0.83），随后是LLM（0.80）、LLM+Vote（0.80）和MLP（0.77）。自适应投票对小模型有利（避免重复/误导讨论导致上下文漂移），大模型则从更长讨论中受益。
- **RQ4（泛化）**：仅在5个任务上训练的MLP在60个未见任务上达到0.73平均准确率（全任务训练为0.77），表明紧凑状态捕获了可复用的协调条件而非任务特定内容。
- **消融发现**：路由和新证据寻求是最关键的动作；动作条件路由优于通用路由策略；保形集合包含多个有效动作；信息相关状态特征对动作选择最关键；完整状态表示在任务成功和讨论质量间取得最佳平衡。
- 异构智能体群体在包含足够强大且互补的模型时依然有效，但性能对组成和分配敏感。

### 7. 方法/实验设计的亮点

- **闭环通信控制的首次系统性提出**：将隐藏档案推理重新定义为序列通信控制问题而非固定提示协议，实现真正意义上的讨论自适应协调。
- **保形校准的逐轮统计保证**：将保形预测理论适配到多轮序列决策中，提供分布无关、有限样本的遗憾界——这是现有辩论/编排方法所缺乏的关键可靠性保障。
- **反事实评估设计**：所有候选动作从同一冻结的预动作状态并发评估，只有最终接受的分支提交到公共转录，严格隔离真实分支与反事实分支。
- **确定性动作保证与概率性提议保证的区分**：执行动作的遗憾 ≤ 阈值是算法性的（确定性）；控制器提议落入保形集的覆盖是概率性的——这一区分严谨且清晰。
- **控制器比较的公平性**：所有控制器共享相同的动作定义、路由规则、智能体和提示，仅动作选择不同，隔离了控制策略的影响。
- **消融的独立性**：每个消融仅改变一个组件，其余固定，结果干净可解释。
- **诚实评估局限**：作者明确区分了"达到/超越全信息"与"超越理论上限"的含义，指出全信息只是一个经验基线。

### 8. 不足与局限

- **理论保证的局限**：Proposition 1提供的是逐轮边际覆盖而非轨迹级联合保证；覆盖是条件于到达该轮和校准队列规模的边际概率，并非条件于实际校准样本；后续轮次的交换性需要额外假设，不自动成立。
- **计算开销未报告**：保形校准需要对每个状态穷举评估所有可行动作的完整反事实分支，这在大型模型上的推理成本显著；论文未提供计算成本分析或资源需求报告。
- **生成基准的可比性问题**：GroupTravelBench风格基准是自行生成的（原数据不可用），其结果不能与原benchmark直接比较，降低了该部分实验的外部有效性。
- **MLP训练依赖反事实rollouts**：学习控制器需要训练期穷举动作的回报信号，这在真实部署中可能不可得；全任务MLP被作者定位为"预言模仿诊断"而非严格泛化测试。
- **LLM控制器等效性**：LLM控制器与智能体使用同一模型，可能低估了更强/更弱控制器的影响；控制器能力对异构群体结果有显著影响但分析有限。
- **现实应用差距**：评估完全基于LLM代理模拟的隐藏档案问题，未涉及真实人类-代理混合场景；状态估计（如证据增益）依赖LLM评估，其可靠性本身可能随模型变化。
- **未报告不确定性**：缺乏跨种子的方差、置信区间或显著性检验报告，偶发的小差异（如某些模型上留出MLP优于全任务MLP）被归因于随机波动但未加以验证。
