## 摘要
搜索智能体在强化学习（RL）微调期间面临严重的可靠性危机。启发式Top-K检索常导致关键证据丢失或噪声混入，而渐进式RL引发的过度自信则导致幻觉答案和冗余搜索。为构建高度可靠的智能体，我们引入保形预测（CP）并提出保形化智能体搜索（CAS）。该框架在检索侧和训练侧均建立了可靠性保证：在检索侧，自适应预测集（APS）作为CP的一种特定实现，将统计覆盖率转化为动态文档截断，以构建大小自适应的预测集；在训练侧，自适应保形推断（ACI）作为一种动态CP算法，动态构建具有可控覆盖率的预测集以量化答案置信度，随后用于在组相对策略优化（GRPO）目标中对低置信度轨迹进行惩罚，确保模型仅从可靠轨迹中学习。跨单跳和多跳QA数据集的实验表明，我们的框架显著提高了推理准确性，同时大幅减少了冗余工具调用，建立了一种高度可靠且高效的智能体范式。我们的代码可在https://github.com/S1llyBird/CAS获取。

## Abstract
Search Agents face a severe reliability crisis during reinforcement learning (RL) fine-tuning. Heuristic Top-K retrieval often causes critical evidence loss or noise inclusion, while over-confidence induced by progressive RL leads to hallucinated answers and redundant searches.   To build highly reliable agents, we introduce Conformal Prediction (CP) and propose Conformalized Agentic Search (CAS). This framework establishes reliability guarantees on both the retrieval and training sides: on the retrieval side, an Adaptive Prediction Set (APS), a specific CP realization, translates statistical coverage into dynamic document truncation to construct prediction sets that are adaptive in size; on the training side, Adaptive Conformal Inference (ACI), a dynamic CP algorithm, dynamically constructs prediction sets with controllable coverage to quantify answer confidence, which is then used to penalize low-confidence trajectories within the Group Relative Policy Optimization (GRPO) objective, ensuring the model learns only from reliable ones.   Experiments across single-hop and multi-hop QA datasets demonstrate that our framework significantly improves reasoning accuracy while drastically reducing redundant tool invocations, establishing a highly reliable and efficient agent paradigm. Our code is available at https://github.com/S1llyBird/CAS.

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 总体设计思想
CAS 框架在检索与训练两侧分别引入 CP 的两个具体实现：
- **检索侧**：使用 **Adaptive Prediction Set（APS）** 实现动态文档截断，构建大小自适应的可靠检索子集。
- **训练侧**：使用 **Adaptive Conformal Inference（ACI）** 动态量化答案置信度，并据此在 GRPO 目标中惩罚低置信度轨迹。

### 2.2 检索侧：APS 动态检索截断
- 传统固定 Top-K 换成 APS 动态截断机制。
- 搜索返回候选集 D = {d₁,...,dₙ} 后，对检索分数做 softmax 归一化得到相关概率 p(dᵢ|q)。
- 按照 APS 推理流程，累加概率直到首次超过校准阈值 q̂_APS，得到截断索引 k，构成自适应子集 D_APS = {d₁,...,dₖ}。
- **关键优势**：简单查询得到小集合（减少噪声），复杂查询得到大集合（保证证据充分），同时维持 1−α_APS 的边缘覆盖率统计保证。

### 2.3 训练侧：ACI 引导的 GRPO 加权
- **非一致性分数定义**：对轨迹 yᵢ，其分数定义为 `<answer>...</answer>` 标签内生成 token 的负对数似然（NLL）均值：
  ```
  s(x_t, y_i) = Σ_{j∈Mᵢ}(−log π_θ(y_j|y_{<j}, x_t)) / |Mᵢ|
  ```
- **ACI 动态误差率更新**：采用指数加权移动平均的平滑更新规则：
  ```
  α_{t+1} = α_t + γ(ρ − Σ_{s=1}^{t} v_s · err_s)
  ```
  其中 ρ 为目标误差率，v_s 为时间权重（平滑因子 0.95）。
- **量化阈值**：在滚动校准窗口（最近 2000 个分数）上计算经验分位数 q̂_t = Q̂_t(1−α_t)，用于划分低置信度轨迹。
- **置信度权重**：
  ```
  ω_i = 1（若 s(x_t, y_i) ≤ q̂_t）
  ω_i = η（否则，η = 0.5）
  ```
- **ACI 引导的 GRPO 损失**：
  ```
  L_GRPO(θ) = E[(1/G)Σᵢ ωᵢ·L_clipᵢ(θ) − β·D_KL(π_θ||π_ref)]
  ```
- **双重约束机制**：对"低置信度但恰好猜对"（s > q̂_t 且 Aᵢ > 0）的轨迹折扣正向强化，防止模型学会猜测；对"高置信度但回答错误"（s ≤ q̂_t 且 Aᵢ < 0）的轨迹施加全额惩罚。

### 2.4 Agentic Search 概览
- 模型用严格生成语法，在 `<think>...</think>` 内推理，知识边界处发出 `<search>query</search>` 调用搜索引擎，检索结果经 APS 截断后包在 `<information>...</information>` 中追加到上下文，循环直至输出 `<answer>...</answer>`。
- 奖励设计为 r = r_acc + r_fmt，其中 r_fmt 为兼顾结构完整性与防奖励黑客的格式奖励。

- **两个模块互补**：APS 提供单步自适应无噪上下文；ACI 抑制不必要的探索性搜索，二者协同才能达到最佳效果。

1. **理论保证扎实**：首次将 CP 引入搜索智能体的 RL 微调，检索侧提供有限样本边缘覆盖率保证，训练侧 ACI 提供分布无关的长期误覆盖率收敛保证（附录 B 含完整形式化证明）。

## 8. 不足与局限

1. **实验场景局限**：仅在通用开放域 QA 任务上验证，未覆盖专业领域（如法律、医疗、金融）的高专业性检索任务，其适用性未知。
