## 摘要
大语言模型（LLM）智能体已展现出解决需要规划、工具使用和外部信息访问的多步骤任务的能力，但不断增长的执行历史增加了推理成本，并使推理暴露于过时、无关或误导性信息中，可能降低推理质量。现有的记忆方法会组织或压缩执行历史，但在决定哪些记忆保持活跃方面提供的机制有限。我们引入了一种分层记忆系统，将执行组织为任务、子任务和动作，同时为每个记忆分配动态保留分数。基于事件的更新和基于选择的衰减会修正这些分数，使加权记忆树（WMT）能够保留有用信息、折叠已完成的轨迹、抑制低效用内容，并保留对折叠上下文的访问。我们使用Qwen3-8B、Gemma 4 E4B和Llama-3.1-8B在GAIA-Text上评估了WMT，并进行了消融实验和记忆中毒实验。相对于线性记忆，WMT平均提高了9.97个百分点的准确率，同时将提示令牌使用量减少了32.8%。记忆中毒实验表明，WMT限制了不可靠信息的持续存在和传播。我们的结果表明，有效的长时程智能体记忆与其说依赖于存储更多信息，不如说依赖于决定哪些信息应保持活跃。

## Abstract
Large language model (LLM) agents have demonstrated the ability to solve multi-step tasks requiring planning, tool use, and external information access, yet growing execution histories increase inference cost and expose reasoning to outdated, irrelevant, or misleading information, potentially degrading reasoning quality. Existing memory approaches organize or compress execution histories but provide limited mechanisms for deciding which memories remain active. We introduce the, a hierarchical memory system that organizes execution into tasks, subtasks, and actions while assigning each memory a dynamic retention score. Event-based updates and selection-based decay revise these scores, allowing WMT to preserve useful information, fold completed trajectories, suppress low-utility content, and retain access to folded context. We evaluate WMT on GAIA-Text using Qwen3-8B, Gemma 4 E4B, and Llama-3.1-8B, with ablations and memory-poisoning experiments. Relative to linear memory, WMT improves accuracy by an average of 9.97 percentage points while reducing prompt-token usage by 32.8%. Memory-poisoning experiments show that WMT limits the persistence and propagation of unreliable information. Our results suggest that effective long-horizon agent memory depends less on storing more information than on deciding which information should remain active.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：大语言模型（LLM）智能体在执行长时程任务（如开放域研究）时，需要不断与外部环境交互，积累大量执行历史（推理步骤、工具调用、观察结果等）。但历史不断增长会带来两个核心挑战：
  - **效率问题**：完整保留交互历史会使 prompt 长度持续膨胀，大幅增加推理成本；
  - **质量问题**：过时的观察、失败尝试、无关细节与有用信息混杂，相关证据需要同陈旧/误导性内容竞争注意力。已有的长上下文研究表明，即使上下文窗口足够大，模型也未必能有效利用其中的关键信息，性能常低于名义窗口上限。
- **现有方法不足**：已有记忆方法（如 Task Memory Engine、Context-Folding）通过层级组织或压缩历史来缓解问题，但**均缺少对每条记忆"当前效用"的动态估计机制**，导致低价值或已被后续证据推翻的记忆可能长期保持活跃。
- **研究问题**：能否通过显式估计记忆效用来控制进入工作上下文的内容，从而提升长时程推理质量？
- **整体含义**：有效的长时程智能体记忆，关键不在于存储多少信息，而在于**持续决定哪些信息应保持活跃**。WMT 以"动态遗忘/保留"为核心，为这一观点提供了系统性的方法验证和实证支持。

### 2. 方法论：核心思想、关键技术细节、公式与算法流程

#### 2.1 核心思想

- 将智能体执行历史组织为**层次化记忆树**（任务 → 子任务 → 动作）；
- 为每条记忆维护一个**动态保留分数**（retention score），用两个信号驱动更新：
  - **事件信号**：动作的成功/失败等执行结果；
  - **选择信号**：记忆在候选池中是否被实际选入工作上下文；
- 记忆控制器根据分数执行生命周期操作（折叠、抑制、重开），Prompt 合成器基于分数和语义相关性构造精简上下文，实现"有用信息保留、低效用内容抑制"。

#### 2.2 关键公式与算法流程（文字说明）

- **事件更新**：动作记忆根据执行结果 `ωi ∈ {success, failure}` 设置中间分数：成功为 `usuccess`（设为 0.75），失败为 `ufailure`（设为 0.30）。失败动作不被自动删除，可保留作为警示。
- **选择衰减**：一个非全局记忆如果连续 m 次进入候选池但未被选中，则分数乘以 `ρ^min{m,M}`；全局记忆使用独立的衰减率 `ρG`；被选中的记忆将未选中计数重置为 0。
- **分支优先级**：对每个任务分支，优先级由其下所有记忆分数中的最大值和均值综合计算，并扣除失败比例与过时比例两部分惩罚。
- **抑制决策**：当分支优先级低于阈值 τ_obs 时，该分支根节点被标记为 OBSOLETE（抑制但不删除）。分支完成后被折叠为摘要，重新回到已折叠任务时则恢复为 ACTIVE。
- **Prompt 合成**：候选池包含当前活动路径、全局记忆、任务/动作记忆、折叠摘要、失败警告；OBSOLETE 分支被排除。采用 LLM 语义选择器，综合相关性、保留分数和分支优先级进行选取。

### 3. 实验设计：数据集、Benchmark 与对比方法

#### 3.1 数据集与 Benchmark

- **GAIA 验证集**：共 165 道验证问题，分三个难度等级，需要多步推理、信息检索与工具使用；
- **GAIA-Text**：其中 127 道无附加文件的问题，排除文档/图像等模态差异，聚焦文本推理；
- 使用官方参考答案与归一化规则评判。

#### 3.2 模型与配置

- 三种冻结基座模型：**Qwen3-8B**、**Gemma 4 E4B**、**Llama-3.1-8B**；
- 使用同一 OpenTools-based agent 脚手架，工具、任务指令和交互预算完全一致，仅记忆系统不同。

#### 3.3 对比方法

- **No Memory**：不保留历史（下界参照）；
- **Linear History**：线性追加完整交互历史；
- **Unweighted Tree（A1）**：仅用层级结构，无保留评分；
- **Full WMT**：完整框架；
- 组件消融：Tree + Selection、Tree + Summary、Tree + Selection + Summary，用于分离语义检索和分支折叠的独立贡献。

#### 3.4 记忆中毒实验

- 构造 100 个长时程场景、297 个子任务、1118 条记忆（709 良性、409 条故意注入的"中毒"记忆）；
- 对比 Linear Memory、三个消融（A1/A2/A3）和 Full WMT；
- 评估指标：攻击成功率（ASR）、中毒检索率（PRR）、感染持续率（IP）、爆炸半径（BR）、放大因子（AF）、上下文压缩比（CCR）、任务成功率（TSR）、prompt token 数和延迟。

### 6. 主要结论与发现

- **准确率提升显著**：在 GAIA-Text 上相对 Linear History，Qwen3-8B 提升 13.39 个百分点、Gemma 4 E4B 提升 8.66、Llama-3.1-8B 提升 7.87，**平均提升 9.97 个百分点**；GAIA 上平均提升 10.10 个百分点；
- **Prompt token 大幅下降**：GAIA-Text 上平均减少 **32.8%**，GAIA 上平均减少 32.2%；
- **层级结构本身不够**：Unweighted Tree 不稳定，部分模型/基准上甚至低于线性记忆；动态保留评分、生命周期管理和语义检索的组合才是关键；
- **鲁棒性提升**：在记忆中毒实验中，Full WMT 取得最优的攻击成功率（0.419）、最低的检索率（0.097）、最小爆炸半径（0.315）、最低放大因子（0.965），并达成最高任务成功率（0.575）；
- **核心洞见**：长时程记忆的瓶颈不是存储容量，而是**对什么信息应保持活跃的持续决策**。

### 7. 优点

- **问题选择精准**：直击长时程 LLM 智能体的关键痛点——线性历史的上下文膨胀与信息干扰；
- **方法论完整**：将层级组织、动态评分、生命周期控制与语义检索统一在一个框架中，形成了完整的记忆管理闭环；
- **公式设计清晰**：事件更新（结果信号）与选择衰减（使用信号）双通道驱动评分，逻辑简单有效，参数固定且无需训练；
- **实验设计较公正**：所有配置共享相同的 agent 脚手架、工具、任务指令和交互预算；token 统计包含语义选择和摘要生成的额外模型调用，避免"省 token 靠隐藏开销"；
- **考虑安全维度**：引入记忆中毒实验，覆盖攻击成功率、传播、爆炸半径等多维度指标，前瞻性地考察了记忆管理的安全性；
- **消融设计系统化**：逐步分离层级、选择、摘要、评分、控制器、语义检索的贡献，结论具有很好的可解释性。

### 8. 不足与局限

- **基准覆盖有限**：只在 GAIA 家族上验证，缺少交互式网络环境、软件工程智能体、具身任务或长时间多轮对话等场景；
- **全局记忆模式未评估**：跨对话全局记忆（global memory）虽有设计，但评测中每个问题都新建树，该模式未经过实证检验；
- **模型规模范围窄**：仅使用 8B 左右的小型开放权重模型，未验证更大模型（可能更能忽略无关上下文）下的收益变化；
- **大量手工参数**：初始分数、事件分数、衰减率、分支优先级系数、过时阈值均为固定手工设定，对不同任务分布/智能体架构可能不是最优；
- **分数不衡量真实性**：保留分数反映的是操作效用而非事实正确性；看起来成功的操作若携带错误信息，仍可能获得高分数；
- **额外推理开销**：LLM 语义选择器和摘要生成器需要额外的模型调用，对短任务或简单场景可能得不偿失；
- **效率优势的边界不清晰**：WMT 的 token 优势在长历史任务中较明显，但对简短任务的相对收益可能显著缩小。
