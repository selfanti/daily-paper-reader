## 摘要
开放网络未来事件预测要求智能体从嘈杂、冗余且不完整的证据中提炼出可靠信号。现有的检索/记忆机制直接将检索到的信息馈送给智能体，或依赖简单的记忆功能（例如存储和复用先前的信息进行预测），这使得它们不足以应对开放网络预测。我们提出在预测之前将原始网络证据转化为结构化记忆，从而使智能体能够基于提炼后的、针对问题的证据进行推理，而非基于嘈杂的检索结果。本文提出了ForeDreamer，一种用于管理开放网络证据记忆的自演化双智能体框架。ForeDreamer将事实性记忆（当前预测的针对问题的证据状态）与经验性记忆（跨预测场景累积的持久智能体经验）分离。它使用一个主智能体进行搜索和预测，以及一个记忆处理子智能体，通过专用工具将搜索结果转化为事实性记忆。ForeDreamer进一步通过两条轨迹演化经验性记忆，同时改进预测决策和事实性记忆构建。在Prophet Arena和FutureX上的实验证明了ForeDreamer的有效性。项目页面：https://zhongzero.github.io/ForeDreamer

## Abstract
Open-web future event prediction requires agents to distill reliable signals from noisy, redundant, and incomplete evidence. Existing retrieval/memory mechanisms directly feed retrieved information to agents or rely on simple memory functions such as storing and reusing prior information for prediction, leaving them insufficient for open-web forecasting. We propose to transform raw web evidence into structured memory before prediction, enabling agents to reason over distilled, question-specific evidence rather than noisy retrieval results. This paper presents ForeDreamer, a self-evolving dual-agent framework for managing memory over open-web evidence. ForeDreamer separates factual memory, a question-specific evidence state for the current forecast, from experiential memory, persistent agent experience accumulated across forecasting episodes. It uses a main agent for search and prediction, and a memory-processing subagent to convert search results into factual memory with dedicated tools. ForeDreamer further evolves experiential memory through two tracks, improving both forecasting decisions and factual-memory construction. Experiments on Prophet Arena and FutureX demonstrate the effectiveness of ForeDreamer. Project page: https://zhongzero.github.io/ForeDreamer

  - RQ1：智能体如何从嘈杂的开放网络证据中做出可靠的未来事件预测？

### 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

- **核心架构：ForeDreamer 双智能体框架**
  - **两个核心概念**：
    - **事实记忆（Factual Memory）**：针对当前预测问题的、经加工提炼的证据状态，是原始检索结果与最终预测之间的可审计接口。
    - **经验记忆（Experiential Memory）**：跨预测场景累积的持久智能体经验，用于指导未来的搜索规划、证据整合与预测校准。
  - **双智能体分工**：
    - **主智能体（Main Agent）**：负责多轮搜索规划、整合加工后的事实记忆，并给出最终预测。
    - **记忆处理子智能体（Memory-Processing Subagent）**：接收搜索结果，依据 MemGuide（证据处理工作流说明）并使用 MemTools（可执行的证据操作工具）将原始搜索制品转化为结构化事实记忆。
- **推理流程**：
  1. 给定预测问题 `q` 和时间截止 `τq`，主智能体在经验库 `B` 的指导下进行多轮搜索。
  2. 每轮搜索通过 `Search(st, E≤τq)` 获取截止时间有效的数据。
  3. 子智能体按 `Pg,Tg(rt,k, q)` 对每个检索结果进行处理，形成事实记忆 `mt,k`。
  4. 主智能体在最后一轮不调用搜索工具，综合全部事实记忆给出预测 `ŷ` 和推理依据 `ρ`。
- **双轨自演化机制（Dual-Track Self-Evolution）**：
  - **文本性预测经验演化（Textual Forecasting Experience Evolution）**：对经验库 `B` 进行 ADD / MODIFY / REMOVE 操作，候选版本只有在验证集上表现更优时才会被接受（`B(v+1) = B̃` 当且仅当 `B̃ ≻ B(v)`）。
  - **程序性证据加工经验演化（Procedural Evidence-Processing Evolution）**：以 MemGuide 树的形式维护工作流版本，通过"父节点选择 → 采样演化样本 → 批评者生成设计需求 → 生成候选 MemGuide/MemTools → 验证门控 → 入树"的循环演化。
- **两项关键优化**：
  - **组合式工具复用（Compositional Tool Reuse）**：在设计新流程时，先总结并复用现有工具，仅生成缺失的新 MemTool，减少近重复工具生成。实验显示 vanilla 演化生成的 201 个 MemTools 在 token-Jaccard 阈值为 0.5 时可聚类为 98 个簇（簇率 48.8%），确认了大量冗余。
  - **多样性引导探索（Diversity-Guided Exploration）**：为避免演化集中在单一工作流原型上（10 个 vanilla MemGuide 全部落入同一工具编排原型），引入演化调度器，在不进行新 rollout 的情况下，基于现有 MemGuide 类别摘要和代表性指南生成类别多样化的候选。
- **约束与控制**：主智能体只能访问公开的 search-and-process 接口；子智能体只能调用当前 MemGuide 指定的 MemTools（allowlist），工具执行在沙箱中完成，隔离外部网络和无关本地状态。

- **计算成本未说明**：论文未披露演化所需的实际算力开销、时间成本以及 API 调用量，影响对实用性的全面判断。
