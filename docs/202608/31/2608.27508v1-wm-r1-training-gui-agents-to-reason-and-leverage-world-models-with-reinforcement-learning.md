## 摘要
使用强化学习（RL）训练的GUI代理在移动平台上展现了强大的环境学习能力。然而，RL通常需要大量的真实环境交互，导致高资源成本和不稳定性，尤其是在GUI场景中。为了解决这些问题，我们提出了WM-R1，这是第一个使用世界模型而非真实环境来训练移动GUI代理的强化学习框架。具体而言，世界模型在所有推出过程中作为状态转移的来源，取代了训练循环中的真实Android环境。WM-R1还将世界模型直接嵌入到思考过程中，使代理能够在决定最终行动之前推理候选行动的后果。关键的是，WM-R1消除了对真实环境交互的需求，支持基于世界模型的大规模并行化和步骤级别的粒度化轨迹生成，并引入了多维基于规则的奖励，共同优化任务成功率、轨迹效率和世界模型利用率。为了高效训练，我们策划了一个包含2000个具有挑战性任务的高质量数据集。在Android移动基准上的实验表明，经过WM-R1训练的代理显著优于仅使用GRPO的基线和推理时间模拟方法。代码可在 https://github.com/genalyu/WM-R1 获取。

## Abstract
GUI agents trained with reinforcement learning (RL) have showcased strong environment learning capabilities on mobile platforms. However, RL typically demands extensive real-environment interactions, leading to high resource costs and instability, especially in GUI scenarios. To address these, we propose WM-R1, the first reinforcement learning framework that trains mobile GUI agents with world models instead of real environments. Specifically, world models serve as the source of state transitions during all rollouts, replacing the real Android environment within the training loop. WM-R1 also embeds world models directly into the thinking process, enabling agents to reason about the consequences of candidate actions before committing to the final action. Crucially, WM-R1 eliminates the need for real-environment interaction, supports massively parallelized and step-level granularized trajectory generation grounded in world models, and introduces a multi-dimensional rule-based reward that jointly optimizes task success, trajectory efficiency, and world model utilization. For efficient training, we curate a high-quality dataset of 2000 challenging tasks. Experiments on Android mobile benchmarks demonstrate that WM-R1-trained agents significantly outperform GRPO-only baselines and inference-time simulation methods. Code is available at https://github.com/genalyu/WM-R1 .

### 1. 论文的核心问题与整体含义

**研究动机与背景**
- 移动端 GUI 智能体（如 UI-R1、ARPO 等）通过强化学习（RL）训练已展现出强大的环境交互与任务执行能力，其核心算法通常采用 GRPO（Group Relative Policy Optimization）。
- 然而，现有 RL 方法几乎全部依赖 **真实环境交互**（如 Android 模拟器），带来三大瓶颈：
  1. **计算成本高**：环境交互速度远慢于模型推理，训练 wall-clock 时间被环境延迟拖累；
  2. **不可逆性**：长程任务中单个错误动作即导致整条轨迹失轨，容错率低；
  3. **环境噪声**：真实环境非确定性状态转移会污染奖励信号，影响训练稳定性。
- 虽然已有工作（如 Code2World、ViMo、MobileDreamer）将世界模型用于 GUI 任务，但它们**仅将世界模型作为推理期的辅助模拟器**，未改变 RL 训练循环本身。

**WM-R1 的核心意义**
- 论文提出 **首个将世界模型作为训练环境本身的 RL 框架**：训练过程中所有 rollouts 的状态转移完全由世界模型模拟生成，彻底消除对真实环境的依赖。
- 该范式不仅降低成本，还将世界模型嵌入智能体的推理流，实现"先模拟、后行动"的决策模式，为高效、稳定、可扩展的 GUI 智能体训练提供了新路径。

### 2. 方法论

**2.1 整体框架**
- 采用 GRPO 作为策略优化算法，但将真实 Android 环境替换为世界模型 \( W \)（具体为 Code2World-8B，冻结参数）。
- 世界模型负责在 rollouts 中根据当前截图 \(\hat{\phi}_t\) 与动作 \( a_t \) 生成下一步模拟截图：\(\hat{\phi}_{t+1} \sim W(\cdot | \hat{\phi}_t, a_t)\)。
- 训练循环中，策略模型与世界模型迭代交互生成完整轨迹 \(\tau_{i,j} = (\hat{\phi}_0, a_0, \hat{\phi}_1, a_1, \ldots, \hat{\phi}_T, a_T)\)，随后由规则奖励模型计算得分，完成 GRPO 优势估计与策略更新。

**2.2 世界模型嵌入推理（Reasoning with the World Model）**
- 通过 `<call_wm>` 机制将世界模型调用嵌入思考流内部，而非作为单独的对话轮次。
- 智能体在思考过程中可以随时调用 `<call_wm>` 模拟候选动作的后果，模拟截图作为 System (WM) 观察反馈回来，智能体在**同一个 thinking block 内**基于模拟结果继续推理、修正动作，直至做出最终决策。
- 该机制支持多轮"推理—模拟—修正"循环，使智能体学会在行动前利用模拟器进行自我校验。

**2.3 轨迹生成流程**
- 每一步迭代：
  1. **Observe**：接收当前模拟截图与完整交互历史；
  2. **Think**：策略模型生成推理块，其中可含 `<call_wm>` 调用；
  3. **Simulate & Continue**：若含 `<call_wm>` 则世界模型生成下一步截图并反馈，推理继续；若无则输出最终动作；
  4. **Repeat**：直至产生终止动作或达到最大轨迹长度 \(T_{\max}\)（实验中为 15）。

**2.4 多维度规则奖励**
复合奖励形式为：\( R = \alpha \cdot R_{\text{success}} + \beta \cdot R_L + \gamma \cdot R_{WM} \)，默认权重 \(\alpha=1.0, \beta=0.5, \gamma=0.1\)。

- **成功奖励 \( R_{\text{success}} \)**：二值奖励（成功=1/失败=0），由 LLM-as-judge（GPT-4o）判断最终轨迹是否与参考解语义等价。
- **长度奖励 \( R_L \)**：基于 DAST 方案，定义长度预算 \( L_{\text{budget}} = p \cdot \bar{L}_r + (1-p) \cdot L_{\max} \)，\( p = c/N \)（已完成子任务比例）；通过归一化偏差 \(\lambda = (L_i - L_{\text{budget}})/L_{\text{budget}}\) 计算：任务成功时 \(\max(-0.5\lambda + 0.5, 0.1)\)，失败时 \(\min(0.9\lambda - 0.1, -0.1)\)。
- **世界模型调用奖励 \( R_{WM} \)**：以组平均调用数 \(\bar{N}_{WM}\) 为基准，定义归一化偏差 \(\mu = (N^{(i)}_{WM} - \bar{N}_{WM})/\bar{N}_{WM}\)，成功时 \(\max(-0.5\mu + 0.5, 0.1)\)，失败时 \(\min(0.9\mu - 0.1, -0.1)\)。目的是引导智能体选择性、策略性地使用世界模型，而非过度或不足使用。

**2.5 GRPO 更新**
- 组内优势：\( A_i = (r_i - \mu_r)/\sigma_r \)；
- 策略更新：\( J(\theta) = E\left[\frac{1}{G}\sum_{i=1}^{G} \min(\rho_i A_i, \text{clip}(\rho_i, 1-\epsilon, 1+\epsilon)A_i)\right] - \beta \cdot \text{KL}(\pi_\theta \| \pi_{\text{ref}}) \)，其中 \(\rho_i\) 为重要性采样比。

### 3. 实验设计

**3.1 训练数据与筛选**
- 整合三个公开 Android GUI 数据集：**AndroidCode**、**GUI-Odyssey**、**GUI-R1**。
- 按任务难度过滤：剔除零样本成功率 >80%（过易）和 <5%（过难）的任务，最终随机采样 **2000 个中等复杂度的任务**，使世界模型反馈最具信息量。

**3.2 评测基准**
- **长程任务**：
  - **AndroidWorld**：多步移动设备控制，最大执行长度 15；
  - **GUI-Odyssey**：Android 跨应用导航；
  - 两者均定义 **Hard 子集**（需 ≥5 步真实轨迹完成任务）。
- **动作预测与 UI 接地**：

**3.3 对比方法**
- 3B 规模：Qwen2.5-VL-3B ZS、+ Code2World（推理时增强）、GUI-R1-3B、UI-TARS-3B、UI-R1-3B；

### 7. 方法优势与潜在问题

**优势**：
1. **训练与推理统一使用世界模型**，彻底摆脱真实环境依赖，训练成本仅为在线 RL 的约 1/3（7B：11.2h vs 36.5h），且无限并行、无环境噪声；
2. **推理时“先模拟后行动”**：通过 `<call_wm>` 机制使模型在决策前可试错，显著提升长程任务的成功率，同时保持较低模拟开销；
3. **奖励塑形细致**：长度奖励 + WM 调用奖励有效控制了轨迹效率与模拟频率，避免模型滥用世界模型或产生冗余动作；
4. **对基座模型通用**：在 Qwen2.5-VL 与 Qwen3-VL 多种尺寸上均有效，表明方法与基座适配性良好。

**潜在问题**：
1. **世界模型泛化边界**：Code2World-8B 仍可能对未见过的 UI 布局、系统弹窗或动态内容产生失真模拟，导致策略学到“幻觉环境”上的行为；
2. **奖励冲突**：当任务本身需要多步模拟才能成功时，$R_{WM}$ 的惩罚可能抑制必要的探索，需更精细的奖励设计；
3. **判官依赖**：LLM-as-judge 的误判（尤其在复杂语义等价性判断上）可能给 GRPO 提供噪声优势信号；
4. **现实迁移差距**：世界模型与真实 Android 环境间的 domain gap 未定量分析，策略在真实设备上的表现存疑。

### 8. 总体结论

WM-R1 是首个将冻结的世界模型直接作为强化学习训练环境的移动端 GUI 智能体方法。它用低成本、低噪声、可并行的模拟交互替代昂贵且不可逆的真实环境交互，并通过将世界模型嵌入推理流，使智能体具备“行动前模拟、模拟后修正”的推理能力。大量实验证明其在长程任务、动作预测与 UI 接地方面均达到 SOTA，且训练效率显著优于在线 RL。尽管模型在真实环境泛化与超长任务上仍有待验证，但其“世界模型即环境”的范式为轻量级 GUI 智能体训练提供了非常可行的新方向。
