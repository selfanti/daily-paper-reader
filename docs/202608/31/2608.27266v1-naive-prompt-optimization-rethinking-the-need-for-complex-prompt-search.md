## 摘要
高效地改进跨多种任务的自主代理，对于加速代理式AI中的递归自我改进（RSI）至关重要，其中提示优化已成为一种有前景的方法，能够提供与微调模型权重相当的性能提升，同时降低优化和服务中的计算成本。然而，近期的发展越来越倾向于不必要的复杂提示优化器。我们引入了朴素提示优化（NPO），一种轻量级的单线方法，利用教师模型和回滚反馈迭代修改提示。NPO以更少的回滚次数实现了与GEPA相当或更好的性能，并且其优势随着教师模型能力的增强而增加，这表明更强的教师推理能力可以部分替代优化器端的搜索复杂性。在交互式游戏中，NPO与GEPA大致保持竞争力，而GRPO在部分不太适合提示优化的任务上表现更好。我们还表明，将NPO优化的提示逐字应用于其他学生模型时，也能带来类似的性能提升，尤其是同一系列内的模型。总体而言，我们的初步结果表明，简单、线性的提示优化可以与更复杂精密的搜索过程相媲美。

## Abstract
Efficiently improving autonomous agents across diverse tasks is central to accelerating recursive self-improvement (RSI) in agentic AI, with prompt optimization emerging as a promising approach capable of delivering performance gains comparable to those achieved by fine-tuning model weights, while reducing computational costs in both optimization and serving. However, recent developments increasingly favor unnecessarily complex prompt optimizers. We introduce Naive Prompt Optimization (NPO), a lightweight single-lineage method that iteratively revises prompts using a teacher model with rollout feedback. NPO achieves comparable or better performance than GEPA with fewer rollouts, and its advantage increases with stronger teacher models, suggesting that stronger teacher reasoning can partially substitute for optimizer-side search complexity. In interactive games, NPO remains broadly competitive with GEPA, while GRPO performs better on some tasks less amenable to prompt optimization. We also show that NPO-optimized prompts elicit similar performance improvements when applied verbatim to other student models, especially across models within the same family. Overall, our preliminary results show that simple, linear prompt optimization can rival substantially more sophisticated and complex search procedures.

- **背景**：提升大型语言模型（LLM）性能主要有两条互补路径——强化学习（PPO、RLHF、GRPO 等权重更新方法）和自动提示优化（保持模型权重不变，仅改进指令）。

- **问题提出**：现有提示优化方法（OPRO、ProTeGi、MIPRO、GEPA 等）日益依赖复杂搜索策略（如束搜索、贝叶斯优化、多候选池 Pareto 选择）。本文核心研究问题为：**这种优化器端的搜索复杂性是否真正必要？**
- **核心主张**：更强的教师模型推理能力加上丰富的轨迹反馈，可以部分替代复杂的搜索机制，简单的线性迭代提示优化即可达到与复杂方法相当甚至更好的性能。

## 2. 方法论

### 2.1 NPO 核心思想

- **朴素提示优化（Naive Prompt Optimization, NPO）**：一种轻量级单线（single-lineage）方法，不维护多个候选提示池，也不使用显式搜索算法。
- **迭代流程**（对应 Algorithm 1）：
  1. 使用当前提示 P(i) 在学生模型上对一个小批量任务运行，收集完整的 rollout 轨迹与奖励 R(i)；
  2. 构造长度为 W 的滑动窗口反馈，包含最近 W 个版本的提示、对应 rollout 轨迹与奖励；
  3. 将上述丰富上下文交给教师模型（reviser/reflection model），由其生成下一版提示 P(i+1)；
  4. 重复迭代，最终返回提示序列与最优候选。
- **与 OPRO 的关键区别**：OPRO 仅基于先前提示和标量分数进行优化；NPO 则提供**完整的 rollout 轨迹与逐 rollout 奖励**，使教师能进行更深入的反省。
- **与 GEPA 的对比**：GEPA 维护候选池，通过反思、接受/拒绝机制和 Pareto 选择扩展候选（图 2 的谱系树）；NPO 则是线性演化，仅靠一条提示血统迭代。

### 2.2 对比方法

- **GEPA（GEneric-PAreto）**：多候选、基于 Pareto 选择的提示进化方法，作为复杂搜索的代表基线。
- **GRPO（Group Relative Policy Optimization）**：权重微调基线，固定基础模型与默认提示，仅训练任务特定的 LoRA 适配器；在二人游戏中目标策略对抗固定的未修改基础模型对手，并在每个 rollout 组内平衡先手/后手顺序。

### 2.3 低方差实验设计技术

- **共享伪随机性**：对各优化方法使用相同的随机种子序列生成匹配的环境实例（配对评估），降低实例难度差异带来的噪声。
- **约束解码**：强制模型输出 `<think>...</think> [action]` 结构；预填充 `<think>` 标记；用环境提供的合法动作集构建 token 级前缀字典树，在合法动作上重新归一化概率。推理预算耗尽时自动插入闭合标记并从保留的 action 预算中强制选择动作，避免将格式失败与决策质量混淆。这保证了比较的是决策能力而非格式遵循能力。

## 6. 主要结论与发现

1. **NPO 的 rollout 效率**：在 IFBench 与 HotpotQA 上，NPO 以略低于 GEPA 的 rollout 预算达到相当或更高的峰值性能；**教师越强，NPO 相对 GEPA 的优势越大**。GPT-5.5 作为教师时 NPO 收敛最快、验证性能最高，而 GEPA 从强教师中的获益较小。
2. **强教师可替代复杂搜索**：更强的教师推理 + 丰富的轨迹反馈，能降低复杂搜索机制的边际收益，支持"简单线性搜索足够"的核心论点。
3. **提示可迁移性**：NPO 优化出的提示可直接逐字应用于其他学生模型，**同族模型（如 Qwen 系）内迁移效果最强**，跨族迁移（如到 Llama）也有增益但更不稳定；几乎所有组合均呈正增益，仅少数例外。
4. **与 GRPO 对比**：22 个 TextArena 游戏中**无普遍最优方法**；NPO 与 GEPA 总体相当，GRPO 在部分提示优化效果不佳的任务上提供互补增益；与早期报告不同，GEPA 并未在所有任务上一致优于 GRPO。
5. **无评估集泄漏**：NPO 与 GEPA 优化出的提示与训练集答案的重合自然增长，但与验证集答案的重合可忽略不计；少量交叠源于不同问题共享同一答案，而非验证集直接暴露。

## 7. 优点

- **方法极简而有效**：NPO 仅一个提示谱系 + 教师反思 + 滑动窗口反馈，却能与高度复杂的 GEPA 搜索程序抗衡，揭示了一个重要的"奥卡姆剃刀"式结论。
- **丰富的反馈信号**：利用完整 rollout 轨迹而非仅标量分数，使教师能定位具体失败原因（如示例中提示被误导于 `summary_1`），这是相对 OPRO 的关键进步。
- **实验控制严谨**：共享伪随机性配对评估、约束解码分离格式与决策、预算对齐，体现了较高的方法论严谨性。
- **完整的泄漏检测**：系统追踪提示与训练/验证集答案的重合度，增强了结果可信度。
- **实用导向**：跨学生、跨家族的提示迁移实验直接回应了提示优化相对权重微调的核心实用优势（可移植性），同时开源了优化后提示示例。

## 8. 不足与局限

- **任务覆盖有限**：仅 2 个检索/指令遵循任务 + 22 个短期交互游戏，未覆盖复杂长时程（long-horizon）智能体环境，结论外推需谨慎。
- **学生模型规模受限**：未评估 GPT-5.5 等前沿闭源模型作为学生，原因是 API 不支持 token 级 logits 与细粒度解码控制，且存在时变性能不一致问题。
- **RL 稳定性问题**：GRPO 在某些任务上训练不稳定，不同任务可能偏好不同 RL 算法或奖励设计，提示优化与 RL 在长时程场景下的相对优劣尚未确定。
- **可迁移性波动**：跨族迁移的增益不稳定，已有少数负增益案例，提示迁移并非普遍可靠。
- **算力信息不透明**：教师模型 API 调用成本、NPO/GEPA 的总计算开销未量化，GRPO 的算力信息也仅提及两张 H100。
- **潜在风险与责任**：强教师 + 少样本高效率可能被滥用为恶意任务快速优化小模型；教师模型需保持安全护栏并避免生成帮助有害任务的优化提示；闭源教师托管时共享学生 rollout 轨迹存在数据隐私风险，需掩码与脱敏。
- **未来方向未验证**：多任务提示整合与"eigen-tasks"基础提示蒸馏仅作为设想提出，尚无实验支撑。
