## 摘要
大语言模型智能体通常通过具有稀疏轨迹级奖励的强化学习进行训练，这种奖励对单个词元应如何更新提供的指导有限。同策略自蒸馏（OPSD）通过在特权回放视图下对生成的词元重新评分来获得密集的词元级监督，从而解决了这一问题。然而，我们识别出一个混杂问题：由此产生的支持分数可能同时反映回放视图中包含的特权信息以及回放脚手架引起的分数偏移，使得难以将支持分数专门归因于该信息。当未来的环境观测作为特权信息时，这个问题尤为突出，因为回放这些观测需要重构一个扩展的脚手架，而该脚手架本身会扰动词元分数。为解决这一混杂问题，我们提出了观测校准自蒸馏（OCSD），它对比两个结构匹配的回放视图——完整视图和观测消融视图——两者仅在是否存在实际未来观测上有所不同，从而推导出观测残差，以折扣回放脚手架共享的分数变化。OCSD随后在高度不确定的步骤中应用该残差来调节词元级GRPO更新，同时保留轨迹级更新方向。在ALFWorld、WebShop和Search-QA上跨三个Qwen3模型规模的实验表明，OCSD始终优于强基线。诊断分析进一步确认，校准残差与局部环境反馈的一致性更好。我们的代码公开于https://github.com/yiy1x/OCSD。

## Abstract
Large language model agents are commonly trained through reinforcement learning with sparse trajectory-level rewards, which offer limited guidance on how strongly individual tokens should be updated. On-Policy Self-Distillation (OPSD) addresses this by re-scoring generated tokens under a privileged replay view to obtain dense, token-level supervision. However, we identify a confounding issue: the resulting support may reflect both the privileged information contained in the replay view and score shifts induced by the replay scaffold, making it difficult to attribute the support specifically to that information. This issue is especially pronounced when future environment observations serve as privileged information, since replaying them requires reconstructing an extended scaffold that itself perturbs token scores. To resolve this confounding, we propose Observation-Calibrated Self-Distillation (OCSD), which contrasts two structurally matched replay views, Full and Observation-Ablated, differing only in whether the actual future observation is present, to derive an observation residual that discounts score changes shared by the replay scaffold. OCSD then applies this residual to modulate token-level GRPO updates at high-uncertainty steps, while preserving the trajectory-level update direction. Experiments on ALFWorld, WebShop, and Search-QA across three Qwen3 model scales show that OCSD consistently outperforms strong baselines. Diagnostic analyses further confirm that the calibrated residual aligns better with local environment feedback. Our code is publicly available at https://github.com/yiy1x/OCSD.

## 1. 核心问题与整体含义

- **研究背景**：大语言模型（LLM）智能体在长周期交互任务（网页导航、具身控制、信息检索等）中通常通过强化学习（RL）训练，常见方法如 GRPO。但 GRPO 将稀疏的轨迹级奖励统一赋给同一轨迹中的全部 token，无法区分各 token 对最终奖励的贡献，导致 token 级更新缺乏细粒度指导。
- **已有方案的不足**：同策略自蒸馏（OPSD）通过在特权回放视图下对已生成 token 重新评分，提供稠密 token 级监督。然而论文发现其中存在**归因混杂（confounding）**问题：Full 视图产生的支持分数既包含了未来观测等特权信息带来的变化，也包含了回放脚手架（replay scaffold，如额外格式、未来动作 schema 等）本身引起的分数偏移，因此难以将支持分数准确归因于目标特权信息。
- **核心问题**：当未来环境观测作为特权信息时，重构回放上下文会引入与观测无关的分数扰动，导致现有自蒸馏信号不纯净，可能误导 token 级策略更新。
- **论文意义**：提出一种去混杂的观测校准机制，将未来环境反馈转化为更可靠、与局部反馈更一致的 token 级监督信号，从而提升智能体 RL 的训练效率与最终性能。

## 2. 方法论

### 2.1 核心思想
OCSD 构建两个**结构匹配**的回放视图：
- **Full 视图**：包含实际未来观测 + 自然化的未来动作 schema；
- **Observation-Ablated 视图**：仅将未来观测内容替换为固定短语 “Observation: not provided”，其余字段、格式和未来动作脚手架保持不变。

两者仅在“是否包含实际未来观测”这一点上不同，因此二者的分数差可以抵消回放脚手架带来的共同偏移，得到更纯净的**观测残差（observation residual）**。

### 2.2 关键技术细节

- **Token 级支持分数**：
  \[
  \delta_{i,k,t}(E) = \log \pi_T(y_{i,k,t}|h_{i,k,t}, E) - \log \pi_S(y_{i,k,t}|h_{i,k,t})
  \]
  即教师视图（回放条件）与学生视图（原始上下文）的 log 概率差。

- **观测残差**：
  \[
  e_{i,k,t} = \delta^F_{i,k,t} - \delta^A_{i,k,t}
  = \log \pi_F(y|h, E^F) - \log \pi_A(y|h, E^A)
  \]
  学生项相互抵消，残差直接反映 Full 与 Ablated 两个教师视图对同一 token 的分歧。

- **有界校准信号**：
  \[
  q_{i,k,t} = \tanh(e_{i,k,t}/2), \quad q \in [-1,1]
  \]
  符号表示哪个视图支持度更高，幅度表示两视图分歧程度。

- **NLL 引导的步骤选择**：
  - 计算每个交互步骤的平均 token NLL 作为不确定性分数 \(u_{i,k}\)；
  - 在每个轨迹内按 NLL 降序选择前 \(\rho\) 比例的步骤（默认 \(\rho=0.2\)），仅对这些高不确定步骤进行双视图评分。

- **与 GRPO 的符号保持整合**：
  \[
  \hat{A}^{\text{OCSD}}_{i,k,t} =
  \begin{cases}
  \hat{A}_i [1 + \beta \operatorname{sgn}(\hat{A}_i) q_{i,k,t}], & k \in S_i \\
  \hat{A}_i, & k \notin S_i
  \end{cases}
  \]
  由于 \(q \in [-1,1]\)，增益因子始终非负，因此**保留轨迹级优势的更新方向**，仅调整 token 级更新强度。

- **最终目标函数**：将标准 GRPO 代理目标中的轨迹级优势替换为校准后的 token 级优势，并保留重要性比裁剪和 KL 正则项：
  \[
  J_{\text{OCSD}}(\theta) = \mathbb{E}\left[\min(r(\theta)\hat{A}^{\text{OCSD}}, \operatorname{clip}(r,1-\epsilon,1+\epsilon)\hat{A}^{\text{OCSD}}) - \beta_{\text{KL}} D_{\text{KL}}(\pi_\theta\|\pi_{\text{ref}})\right]
  \]

- **训练流程**（Algorithm 1）：on-policy 采样 → 计算轨迹优势 → NLL 高不确定性步骤选择 → 构造双视图回放证据 → 双视图重评分 → 计算残差与校准信号 → 构造校准优势 → 更新策略。

## 6. 主要结论与发现

- **发现 1**：Full 回放支持中存在大量与真实未来观测无关的分数变化，即回放脚手架本身会引入混杂信号；Full 与 Observation-Ablated 支持分数高度重叠，而观测残差突出的是另一组更贴近环境反馈的词。
- **发现 2**：观测残差与局部环境反馈的一致性显著优于 Full 支持（AUROC：0.707 vs. 0.654），且该优势在标准化、分层匹配和不同训练阶段下保持稳定。
- **发现 3**：OCSD 在全部三个基准和三个模型规模上均取得最佳或接近最佳的总体性能；例如 ALFWorld 总体成功率相比 GRPO 提升 8.9–14.0 个百分点，SearchQA 的 OOD EM 稳定领先。
- **发现 4**：直接使用 Full 支持（如 OPSD 或 GRPO+OPSD）无法保证稳定增益，说明去混杂是必要的。
- **发现 5**：观测残差的判别能力依赖于“当前动作-未来观测”的正确对应关系；替换为不匹配的观测后 AUROC 显著下降，接近随机水平。

## 7. 优点

- **问题识别清晰有价值**：首次系统指出特权回放评分中“回放脚手架效应”与“未来观测信息”的混杂问题，并给出针对性解决方案。
- **方法简洁高效**：通过两个结构匹配的视图相减即可获得去混杂残差，无需额外训练目标或复杂模块。
- **设计严谨**：保留了轨迹级优势的符号方向，只调节幅度，避免 RL 更新方向被噪声破坏；NLL 步骤选择聚焦高不确定性步骤，进一步降低噪声。
- **诊断极为充分**：词级、功能类别、AUROC、观测交换、训练动态等多角度验证，提供了很强的可解释性证据。
- **泛化性好**：在三个异构基准（具身、Web、检索问答）和三种模型规模上均表现稳定，OOD 性能尤其突出。
- **计算开销可忽略**：额外训练开销仅约 1.40%，工程上容易落地。

## 8. 不足与局限

- **环境类型受限**：实验仅覆盖模拟/文本交互环境（ALFWorld、WebShop、Search-QA），未在真实 Web 或物理机器人环境验证；
- **模型规模有限**：最大仅 Qwen3-8B，尚未验证更大规模（如 30B+）上的有效性；
- **训练步数较短**：所有方法仅训练 150 步，长期训练下的表现未知；
- **步骤选择依据单一**：高 NLL 步骤不一定是最值得校准的步骤，可能忽略某些低 NLL 但关键的动作 token；
- **消融规模不足**：核心消融只在 Qwen3-4B 上完成，缺少跨模型规模的一致性验证；
- **超参敏感**：ρ=0.2、β=0.5 为全局默认值，未对每个任务单独调节，且从敏感性分析看性能对超参有一定依赖；
- **诊断标注有误差**：valid/invalid 标签由确定性规则自动生成，复杂环境下可能误分类；
- **依赖未来观测可得性**：该方法要求任务过程中能够获得未来的环境反馈，不适用于完全离线或观测不可得场景；
- **缺乏理论分析**：论文主要依靠经验验证，未给出残差去混杂的理论保证或收敛性分析。
