## 摘要
大语言模型（LLM）智能体在长时程交互中必须保留可复用信息、控制有界的活动上下文，并恢复早期证据。现有方法通常分别优化长期记忆（LTM）和短期记忆（STM），而统一策略往往主要使用轨迹级反馈进行训练，这为单个记忆决策提供了较弱的信用分配。我们提出了可验证记忆（VerMem）框架，该框架将长期记忆、活动上下文和情节历史表示为不同状态，并通过一个记忆操作策略控制它们。七个原子操作使策略能够添加、修订或软删除LTM条目；将LTM检索到活动上下文；过滤或总结活动上下文；以及恢复所选的情节片段。VerMem通过监督微调初始化，并使用三阶段强化学习课程进行训练。局部验证器对可执行的记忆转换进行评分，全局验证器在任务完成后评估证据连贯性和最终记忆一致性。这些分数通过分层信用分配与程序化计算的任务、证据召回、效率和约束信号相结合。这些验证器仅在训练期间使用。在五个基准和两个LLM骨干网络上，VerMem在绝大多数报告指标上取得了最佳结果，并持续优于强记忆基线。在三个交互基准的受控在线令牌预算下，它还在比较方法中实现了最强的效率-性能前沿。代码可在 https://github.com/Sun-SYSU-24/VerMem 获取。

## Abstract
Large language model (LLM) agents must retain reusable information, control a bounded active context, and recover earlier evidence during long-horizon interaction. Existing methods commonly optimize long-term memory (LTM) and short-term memory (STM) separately, while unified policies are often trained primarily with trajectory-level feedback, which provides weak credit for individual memory decisions. We present Verifiable Memory (VerMem), a framework that represents LTM, active context, and episodic history as distinct states and controls them with one memory operation policy. Seven atomic operations let the policy add, revise, or soft-delete LTM entries; retrieve LTM into the active context; filter or summarize the active context; and restore selected episodic fragments. VerMem is initialized by supervised fine-tuning and trained with a three-stage reinforcement-learning curriculum. The local verifier scores executable memory transitions, and a global verifier assesses evidence coherence and terminal-memory consistency after task completion. These scores are combined with programmatically computed task, evidence-recall, efficiency, and constraint signals through hierarchical credit assignment. The verifiers are used only during training. Across five benchmarks and two LLM backbones, VerMem achieves the best result on the vast majority of reported metrics and consistently outperforms strong memory baselines. Under controlled online-token budgets on three interactive benchmarks, it also achieves the strongest efficiency--performance frontier among the compared methods. Code is available at https://github.com/Sun-SYSU-24/VerMem.

- **背景与动机**：大语言模型（LLM）智能体在长时程交互中需要同时完成三类任务：保留可复用的长期信息（LTM）、控制有界的活动上下文（STM）、在任务阶段变化后恢复早期证据。现有方法往往**分别优化** LTM 与 STM，而统一策略又主要依赖**轨迹级反馈**进行训练，无法为单个记忆操作提供细粒度的信用分配，导致“写得好不好”“检索是否及时”等局部决策缺乏有效监督。
- **核心问题**：(A) 异构记忆协调困难（LTM 与 STM 状态、时间尺度不同）；(B) 历史上下文恢复困难（早期证据可能已离开活动上下文）；(C) 多粒度信用分配困难（记忆操作的效用具有延迟性，依赖后续操作）。
- **整体含义**：作者提出 **VerMem（Verifiable Memory）** 框架，将 LTM、活动上下文、情节历史建模为独立状态，用一个统一的记忆操作策略协调七种原子操作；通过局部验证器（操作级）与全局验证器（轨迹级）结合的分层信用分配，实现对记忆决策的细粒度训练。验证器仅训练时使用，推理零开销。

## 2. 论文提出的方法论

### 核心思想
- **状态分离**：定义记忆决策状态 \(s_t = (q, M_t, C_t, H_t)\)：
  - \(q\)：固定任务说明；
  - \(M_t\)：长期记忆，持久化存储；
  - \(C_t\)：活动上下文，任务求解器可见的有界视图；
  - \(H_t\)：同任务情节历史，记录完整事件顺序。
- **统一策略**：策略 \(\pi_\theta\) 在每一步输出完整的记忆命令 \(u_t=(v_t, \xi_t)\)，其中 \(v_t \in V \cup \{\emptyset\}\)，\(V\) 包含七种原子操作：
  - LTM 工具：`Add`（添加）、`Update`（修订）、`Delete`（软删除）；
  - STM 工具：`Retrieve`（从 LTM 检索到上下文）、`Filter`（过滤上下文）、`SelectEpisode`（从情节历史恢复片段）、`Summarize`（总结上下文）；
  - 另有空操作 \(\emptyset\)（无变更，但计入决策轨迹）。

### 关键技术细节
- **训练流程**：SFT 热身后接三阶段强化学习课程：
  1. **Phase A**：仅训练 LTM 操作（`Add/Update/Delete/∅`）；
  2. **Phase B**：仅训练 STM 操作（`Retrieve/Filter/SelectEpisode/Summarize/∅`），引入干扰项；
  3. **Phase C**：所有操作联合训练，在完整任务中协调 LTM/STM。
- **局部验证器**：针对每个可执行的记忆转换，评估任务相关性、证据基础、局部进展、信息保真度，输出 0–4 分，分数归一化为 \(A^{\text{local}}_{t,k}\)，按操作类型进行归一化。
- **全局验证器**：在轨迹完成后评估证据连贯性与终端记忆一致性；全局分支还结合程序化计算的任务正确率、支持事实召回率和效率指标，合成 \(A^{\text{global}}_k\)。
- **分层信用分配**：每个记忆决策的最终优势为：
  \[
  A^{\text{hier}}_{t,k} = \lambda_{\text{local}} A^{\text{local}}_{t,k} + \lambda_{\text{global}} A^{\text{global}}_k - \lambda_{\text{constraint}} c_{t,k}
  \]
  其中 \(c_{t,k}\) 为硬约束违规成本。局部与全局优势分别归一化，约束成本单独计入；被拒绝的命令局部优势为 0，仅保留全局信号和约束惩罚。
- **目标函数**：使用 GRPO 风格的 token 级 clip 目标与 KL 正则：
  \[
  \ell_{t,k,j}(\theta) = \min\left(\rho_{t,k,j}(\theta) A^{\text{hier}}_{t,k}, \text{clip}(\rho_{t,k,j}(\theta), 1-\epsilon_{\text{clip}}, 1+\epsilon_{\text{clip}}) A^{\text{hier}}_{t,k}\right) - \beta_{\text{KL}} d_{\text{KL}}
  \]
  损失仅作用在记忆命令 token 上，不作用于任务求解器输出或环境观测。
- **奖励设计**：三个独立通道——局部操作奖励、复合全局轨迹奖励（含任务分数、证据召回、证据连贯性、终端一致性、效率）和硬约束惩罚。效率项带门控（仅当 \(r_{\text{task}} \ge \delta\) 时生效），防止低成本失败获得效率奖励。

## 6. 论文的主要结论与发现

- **性能提升**：在 Qwen2.5-7B-Instruct 下，VerMem 平均分 48.01，相比 Base 提升 19.96 分（相对提升 71.16%），比最强外部基线 AgeMem 高 6.05 分；在 Qwen3-4B-Instruct 下平均 59.85，比 AgeMem 高 5.54 分。
- **任务差异**：最大提升出现在 HotpotQA 与 SciWorld（多跳证据聚合与长状态跟踪需求高），PDDL 提升最小但依然优于最强外部规划基线。
- **跨任务迁移**：仅用 HotpotQA 训练却能提升 ALFWorld、SciWorld、PDDL、BabyAI，说明学到了可迁移的记忆管理行为，而非任务特定模式。
- **效率前沿**：受控 token 预算下，VerMem 达到目标成功率 \(S^*=40.0\) 所需插值 token 数（\(TN@S^*\)）为 2,080，比 AgeMem 降低 20%；在 \(B^*=2500\) 预算下宏平均成功率 44.30，高于 AgeMem 5.30 点。
- **消融结论**：LTM 操作提供最大初始增益；完整 LTM/STM 空间进一步改进；局部与全局信用分支互补，组合最佳；全奖励（All-Returns）比仅任务奖励更早稳定、波动更小，同时提高记忆质量与任务分数、降低 token 数（结合工具调用数增加，说明并非单纯抑制调用换取低 token）。

## 7. 优点

- **统一记忆管理**：将 LTM、活动上下文、情节历史分离但放在同一策略框架下，支持历史片段恢复（`SelectEpisode`），相较只做检索/过滤/总结的 STM 方法更完整。
- **细粒度信用分配**：局部验证器（操作级语义打分）与全局验证器（轨迹级连贯性与终端状态）结合，通过分层优势解决了“成功轨迹中的坏操作、失败轨迹中的好操作”这一长程信用分配难题。
- **验证器仅训练使用**：推理时零额外调用，不增加延迟与成本，工程部署友好。
- **三阶段课程**：先 LTM、后 STM、再联合，降低联合学习的探索难度，并保证了状态隔离与可复现性。
- **实验严谨**：多基准、多骨干、三种子、固定验证器独立评估、损失掩码明确、约束与语义通道分离，细节完备（附录 29 页）。
- **效率-性能双重验证**：不仅看任务成功率，还在受控 token 预算下验证帕累托前沿，更贴近实际成本约束。

## 8. 不足与局限

- **单一训练域**：仅在 HotpotQA 上构造训练数据，虽然展示了迁移性，但跨领域记忆行为（如对话、工具调用、多用户个性化）未被直接验证。
- **骨干覆盖有限**：仅使用 Qwen2.5-7B-Instruct 与 Qwen3-4B-Instruct，未在更大模型、其他模型家族（如 Llama、DeepSeek 本身）上验证；结论可能受模型族偏置影响。
- **单会话评估**：所有记忆状态每集重置，只测“会话内”持久化与跨基准迁移，未测跨会话/跨用户长期记忆保留。
- **评估器依赖**：HotpotQA 的 \(J_{\text{judge}}\) 与 MEM 质量（MQ）依赖固定 Qwen-Max 快照，虽公开快照与提示但并非完全独立可复现；局部/全局验证器使用冻结 DeepSeek-V3.2，可能继承教师模型的判断偏差。
- **未量化训练成本**：未报告 GPU 型号、数量、训练墙钟时间，以及教师/验证器离线开销，难以直接评估工程可承受性。
- **安全与对抗鲁棒性缺失**：未测试冲突记忆、隐私敏感信息、对抗性提示或错误记忆传播等场景，实际部署中可能存在记忆污染风险。
- **PDDL 特例**：在 Qwen2.5 下 VerMem 比 VerMem-noVerify 略低 0.35 分，说明验证器反馈在结构化规划任务上未带来一致增益，论文未深入分析原因。
