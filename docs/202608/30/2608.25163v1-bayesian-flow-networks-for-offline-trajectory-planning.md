## 摘要
离线强化学习利用静态数据集学习决策策略，无需实时环境交互。尽管最近的序列建模方法依赖于连续扩散模型进行轨迹合成，但将这些方法应用于离散规划任务需要分类公式而非标准高斯构造。我们提出了BFN-RL，一个基于贝叶斯流网络（BFNs）的离线强化学习统一生成建模框架。通过迭代演化分布参数而非噪声数据实例，BFN-RL在单一概率公式中原生地建模离散和连续轨迹空间。分类规划器生成未来状态序列，学习到的逆动力学模型将连续生成的状态转换为动作。在离散规划和连续控制中的评估表明，BFN-RL能够在分类和连续状态空间中生成有效轨迹。我们的结果确立了BFNs作为跨数据模态离线轨迹规划的多功能生成基础。

## Abstract
Offline reinforcement learning (RL) leverages static datasets to learn decision policies without real-time environment interaction. While recent sequence-modeling approaches rely on continuous diffusion models for trajectory synthesis, applying these methods to discrete planning tasks requires a categorical formulation rather than the standard Gaussian construction. We present BFN-RL, a unified generative modeling framework for offline RL based on Bayesian Flow Networks (BFNs). By iteratively evolving distribution parameters rather than noisy data instances, BFN-RL natively models both discrete and continuous trajectory spaces within a single probabilistic formulation. The categorical planner generates future state sequences, and a learned inverse-dynamics model converts consecutive generated states into actions. Evaluations in discrete planning and continuous control show that BFN-RL can generate effective trajectories across both categorical and continuous state spaces. Our results establish BFNs as a versatile generative foundation for offline trajectory planning across data modalities.

## 2. 论文提出的方法论

**核心思想：**

- 与传统扩散模型（对噪声数据实例进行迭代去噪）不同，BFN-RL 通过**贝叶斯推断驱动的连续时间参数流**来迭代更新输入分布的参数。
- 生成过程从先验分布开始，逐步更新分布参数，使其逐渐集中于某个数据点，最终采样得到近似真实数据分布的结果。
- BFN-RL 仅建模**状态序列**，并通过一个**逆动力学模型**将连续状态对转换为动作，从而分离状态生成与动作推断。

**关键技术细节：**

1. **状态序列生成（Categorical BFN planner）：**
   - 对于离散数据，每个状态变量由因子化分类分布参数化，初始为均匀分布。
   - 每个 BFN 步中，从输出分布中采样类别，按精度调度添加噪声得到发送者分布（Sender Distribution），接收者分布（Receiver Distribution）为输出分布与噪声的卷积。
   - 损失函数为发送者分布到接收者分布的 KL 散度，使用连续时间损失函数并附加干净数据交叉熵项（权重 0.5）。

2. **条件化返回（Return Conditioning）：**
   - 采用 **classifier-free guidance** 方式，直接在训练时将返回（return）作为条件输入网络，无需训练额外的返回分类器。
   - 测试时，通过指定期望返回值，引导生成过程偏向高回报轨迹。

3. **当前状态固定（Inpainting）：**
   - 借鉴扩散模型的 inpainting 技术：在采样过程中，将已知状态（当前状态）的分布参数替换为对应于该 BFN 步的正确值。
   - 离散数据的 inpainting 算法见 Algorithm 2（用条件值构造消息并替代采样消息），连续数据见 Algorithm 3。

4. **逆动力学模型：**
   - 一个简单的两层 MLP（256 单元），以相邻状态为输入，预测将环境从状态 \(s_t\) 带到 \(s_{t+1}\) 的动作。

**算法流程（文字描述）：**

- 训练阶段：给定一个数据点 \(x\)，从先验参数 \(\theta_0\) 出发，按精度调度进行多次贝叶斯更新得到 \(\theta_i\)；将 \(\theta_i\) 输入神经网络得到输出分布 \(p_O\)；将噪声与 \(p_O\) 卷积得到接收分布 \(p_R\)，同时将噪声加到数据得到发送分布 \(p_S\)；最小化 \(p_S\) 到 \(p_R\) 的 KL 散度。
- 生成阶段：从先验分布出发，利用神经网络输出分布，采样后执行贝叶斯更新，重复迭代；每一步中，已观测状态通过 inpainting 被固定，未观测状态正常采样；最终从输出分布采样得到完整状态序列，再由逆动力学模型转换得到动作序列。

## 3. 实验设计

**离散实验：**

- **环境：**
  - MiniGrid 系列：Empty-Random-6×6、DoorKey-8×8、BlockedUnlockPickup
  - FrozenLake-8×8（滑溜版）
  - Sokoban-7×7（两箱）
- **数据集：** MiniGrid 使用 2,000 / 5,000 / 3,000 条成功轨迹训练（DoorKey 和 BlockedUnlockPickup 包含随机扰动和专家恢复数据），FrozenLake 使用 30,000 条，Sokoban 使用 10,000 条。
- **对比方法：** 与**匹配的分类扩散基线**（uniform categorical corruption + cosine schedule）进行公平对比，两者在训练数据、网络架构、状态表示、条件信号、inpainting 方式、逆动力学模型、规划视界、动作执行协议和评估种子等均保持一致，以单独隔离生成模型的影响。
- **评估指标：** 成功率（Success Rate）、平均回报（Mean Return）。

**连续控制实验：**

- **环境与数据集：** D4RL MuJoCo 基准（HalfCheetah、Hopper、Walker2d）的 Medium-Expert、Medium、Medium-Replay 数据集。
- **对比方法：** BC、CQL、IQL、DT、TT、MOReL、Diffuser、Decision Diffuser（DD）以及 BFN-RL。
- **评估指标：** 归一化平均回报（normalized score），报告 3 个随机种子的均值和标准误。

## 6. 论文的主要结论与发现

1. **BFN-RL 在离散规划任务中表现良好：** 在 Empty-Random 中成功率 99.7%，DoorKey 中成功率 100%（平均回报 0.934，优于分类扩散的 0.916），FrozenLake 中成功率与分类扩散相当；在 Sokoban 中 BFN-RL 在全部三个训练种子上均优于分类扩散，平均成功率提升 9.7 个百分点（68.7% vs 59.0%）。
2. **BFN-RL 在连续控制任务中具有竞争力：** 在 D4RL MuJoCo 上平均归一化得分 77.0，高于 Decision Transformer（74.7）和 Diffuser（75.3），总体与 CQL（77.6）、IQL（77.0）相当。
3. **BFNs 可作为统一的规划生成基础：** 同一套规划公式在分类和连续状态空间均有效，支持向联合连续-分类环境的自然扩展。
4. 综合而言，**BFN-RL 确立了贝叶斯流网络作为离线轨迹规划跨模态通用生成框架的潜力**，尽管其在离散任务中并未一致地优于分类扩散。

## 8. 不足与局限

1. **实验规模与多样性有限：** 离散实验仅覆盖 5 个网格类环境（MiniGrid、FrozenLake、Sokoban），均为小规模、符号化的规划场景；连续实验仅覆盖 MuJoCo 三类机器人环境，缺少更多样化的连续控制基准（如 Ant、Kitchen、Adroit、物体操作等）以及混合离散-连续空间任务。
