## 摘要
长期语言模型智能体会在多次交互中积累记忆，但其检索器通常不会积累检索经验。语义检索效率高，但嵌入相似度并不总能反映某段记忆是否包含与当前查询相关的证据。大语言模型（LLM）重排序器能提供更强的查询条件相关分数，但无状态重排序会对大型候选池反复打分，并在每次查询后丢弃这些分数。我们提出EARM，一种经验摊销重排序框架，将先前获得的LLM相关分数视为可复用的检索经验。EARM将稀疏的查询-记忆相关分数存储于在线矩阵中，通过因果矩阵补全学习其共享结构，并将少量新观测分数与估计分数结合，对剩余候选进行重排序。随着经验积累，打分预算逐渐减少，使LLM重排序从每次查询的重复开销转变为在智能体生命周期内习得的检索能力。长期对话记忆实验表明，混合观测与估计的重排序相比语义检索，答案准确率最高提升6.62%，且在仅17.5%的候选获得直接LLM相关分数时依然有效，从而大幅降低LLM重排序的推理开销。这些结果启发对智能体记忆的更广阔视角：长期存活的智能体不仅应记住过往内容，还应记住该内容在检索中被证明有用的方式。

## Abstract
Long-term language-model agents accumulate memories across interactions, but their retrievers typically do not accumulate retrieval experience. Semantic retrieval is efficient, but embedding similarity does not always reflect whether a memory contains evidence relevant to the current query. Large language model (LLM) rerankers provide stronger query-conditioned relevance scores, yet stateless reranking repeatedly scores a large candidate pool and discards these scores after each query. We introduce EARM, an experience-amortized reranking framework that treats previously acquired LLM relevance scores as reusable retrieval experience. EARM stores sparse query--memory relevance scores in an online matrix, learns their shared structure through causal matrix completion, and combines a small set of newly observed scores with estimated scores to rerank the remaining candidates. The scoring budget decreases as experience accumulates, changing LLM reranking from a repeated per-query expense into a retrieval capability learned over an agent's lifetime. Experiments on long-term conversational memory show that mixed observed-and-estimated reranking improves answer accuracy over semantic retrieval by up to 6.62% and remains effective when only 17.5% of candidates receive direct LLM relevance scores, thereby substantially reducing the inference overhead of LLM reranking. These results motivate a broader view of agent memory: a long-lived agent should remember not only past content, but also how that content has proved useful for retrieval.

## 1. 论文的核心问题与整体含义

长期语言模型智能体在多次交互中会持续积累记忆内容，但其检索器在每次查询时都从同一初始状态开始，**不积累检索经验**。这构成了一个不对称现象：记忆存储随交互演化，而检索流程却始终“遗忘”自己执行过的每次检索。

- **语义检索的问题**：基于嵌入相似度的检索高效，但“表征相似”不等于“查询条件下的记忆相关性”。一个记忆可能在词面或主题上接近查询，却不包含回答所需的关键证据；反之，一个看似遥远的记忆可能提供缺失的时间、因果或实体关系。
- **LLM重排序的问题**：LLM重排序器能提供更强的查询条件相关分数，但传统的无状态重排序对每个查询都要对大型候选池重复打分（T个查询、N个候选，需 T×N 次LLM打分），产生巨大且重复的推理开销。
- **核心洞察**：每次LLM打分实际上都揭示了关于该记忆可访问性的信息，但无状态重排序器没有保留这些证据。论文主张将这些分数重构为**“检索经验”**——长期智能体不仅应记住“经历了什么”，还应记住“如何访问这些经验”。

## 2. 方法论

### 2.1 核心思想

论文提出 **EARM（Experience-Amortized Reranking for Memory）** 框架，将先前获得的LLM相关分数视为可复用的检索经验，存储在持久化的查询-记忆相关矩阵中，通过**因果矩阵补全**学习潜在的“记忆可访问性地图”：

- 新查询只需少量LLM打分的锚点来确定自己在经验地图中的位置；
- 其余候选的相关性可通过累积经验估计，而非逐条LLM打分；
- 打分预算随经验积累逐步减少，将重排序从“每次查询的重复开销”转变为“智能体生命周期内习得的检索能力”。

### 2.2 技术细节

EARM由五个组件构成：

1. **语义候选生成**：嵌入检索返回 top-N（实验中N=200）候选集，刻意保持高召回、不决定最终上下文。
2. **检索经验矩阵**：构造稀疏矩阵 R(t) ∈ R^{|I_t|×t}，行是稳定记忆条目，列是查询；已观测格点记录LLM打分，未观测格点包括“未直接打分”和“未被语义检索召回”两种情况。矩阵是**因果**的——只允许使用历史和当前观测，不能使用未来查询分数。
3. **分阶段经验采集**：将查询流划分为阶段，观测比例递减（100% → 40% → 25% → 20% → 17.5%）。每个查询的预算一半用于从高相似度层随机采样（利用），一半从其余候选随机采样（探索），防止补全模型只看到语义检索器的偏好样本。
4. **因果相关性补全**：使用带偏置的低秩模型估计缺失分数：
   
   bR_iτ = μ + α_i + β_τ + p_i^T z_τ
   
   其中 μ 为全局相关水平，α_i 为记忆偏差，β_τ 为查询偏差，p_i 和 z_τ 为潜在记忆/查询因子。通过带L2正则的交替最小二乘法（ALS）优化，热启动（warm start）复用前一次解。历史列学习共享记忆参数，当前查询的锚点约束新列参数，从而将新查询定位到历史相关结构中。
5. **混合重排序与上下文构建**：观测到的锚点使用真实LLM分数，未观测的使用补全分数，取 top-K 后**按时间顺序还原**以保持对话时间连贯性。补全域还可扩展至当前语义候选集之外的历史支持记忆（白色格点），实现超出余弦检索边界的搜索扩展。

## 3. 实验设计

### 3.1 数据集与场景

- **数据集**：LoCoMo（Long Conversation Memory），包含长对话及测试长期会话记忆的问题，覆盖多跳、开放域、单跳和时间四类问题。
- **记忆管道**：采用 Mem0 的记忆提取与存储流程，仅修改检索与重排序阶段。每段对话先构建完整记忆库，再按数据集顺序依次处理问题（每对话约500个问题，共400+问题参与实验）。
- **模型**：Qwen3.5-4B-Q80 作为LLM相关性打分器；GPT-4o-mini 生成答案、同时作为LLM评估器（LLM-as-a-judge）。

### 3.2 对比方法与指标

| 方法 | 说明 |
|---|---|
| Semantic | 直接使用第一阶段语义排序，无LLM打分 |

| Mixed（EARM） | 混合观测分数与补全分数进行重排序 |

主要指标为 LLM 评估的答案准确率（overall + 按问题类型），以及LLM重排序调用次数。

1. **整体效果**：Top-10、秩r=8时，EARM将答案准确率从语义检索的82.21%提升至88.83%（**+6.62%**），与完整LLM重排序的差距缩小至2.79%；Top-20下最佳提升2.99%，差距2.34%。

3. **低观测比例下依然有效**：在仅17.5%候选获得直接LLM分数时（B5+阶段），EARM仍比语义检索高5.53%（Top-10, r=8），说明累积检索经验在直接分数稀疏时仍具价值。
4. **补全贡献分离**：直接打分的记忆贡献约1.36–3.83%准确率提升，补全分数选取的记忆额外贡献0.78–2.79%，证明补全本身改进上下文选择，而非仅依靠少量真实LLM分数。
5. **成本收益**：EARM以完整重排序约四分之一的LLM调用量（减少74.43%），恢复了完整重排序相比语义检索增益的约56–70%。

## 7. 优点

- **问题定义新颖且有洞察力**：将“检索器遗忘”这一被忽视的不对称性显式提出，视角独特，具有广泛启示意义。
- **“检索经验”概念重构**：将LLM相关分数从一次性的推理痕迹转化为持久的状态，概念上有力地重新定义了检索与记忆的关系。
- **因果矩阵补全设计严谨**：因果掩码正确排除了未来数据泄露；偏置+低秩分解有效分离了通用记忆偏差、查询偏差与配对特定结构；热启动累进更新符合在线学习场景。
- **分层采样策略合理**：利用-探索平衡，既保持高相似度区域的锚点质量，又防止补全模型只见过语义检索器的偏好样本。
- **消融实验设计干净**：上下文预算固定时比较Semantic/Mixed，直接打分固定时比较Observed-only/Mixed，能准确归属各部分贡献。
- **超越候选池的扩展视角**：通过补全白色格点（语义检索未召回的持久记忆），将语义检索从不可逆的边界变为软边界，为未来工作提供了有趣方向。

## 8. 不足与局限

- **预算调度僵化**：论文自身的局限声明指出，观测预算按查询索引预定义，不响应模型不确定性、分布偏移或冷启动记忆；无自适应调度策略。
- **低秩假设局限**：矩阵补全假设查询-记忆相关性具有可复用的低维结构，高度异质的查询流可能违反此假设，导致补全质量下降。
- **分数噪声传播**：逐点LLM相关分数可能包含噪声、校准偏差、提示敏感性，补全过程可能传播而非仅降低成本。
- **实验覆盖不足**：单一数据集（LoCoMo）+ 单一打分器 + 单一QA链，缺乏跨域/跨模型泛化验证；未报告统计显著性或置信区间。
- **评估指标单一**：仅用LLM评估器判断答案准确率，缺乏人工评估或多指标交叉验证；“准确率”本身对某些问题类型可能过于粗粒度。
- **固定记忆库设定**：实验中的记忆库在评估前构建完毕并固定，未评估记忆库增长、记忆更新/冲突消解等真实长期场景中的表现。
- **未见消融**：对采样策略（随机 vs. 其他）、锚点数量、潜在秩、正则系数的敏感性分析不足；r ∈ {2, 8} 仅两个取值。

总体而言，EARM在此前被忽视的“检索经验积累”方向上迈出了扎实的第一步，框架设计有理论支撑，实验虽受限于规模但消融逻辑清晰、结论一致。该工作为长期智能体记忆系统提供了新的设计维度——**检索器应当记忆自己学到的检索方式**。
