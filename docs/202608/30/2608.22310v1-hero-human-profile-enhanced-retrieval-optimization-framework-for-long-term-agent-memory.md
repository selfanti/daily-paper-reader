## 摘要
长期记忆对于个性化响应和长时间跨度的智能体交互至关重要。现有方法通常依赖大语言模型压缩或重写对话历史，并将转换后的记忆用作检索证据。尽管在组织碎片化上下文方面取得了进展，但仍存在两个主要缺陷：（1）压缩导致的信息丢失，会丢弃细粒度但后续有用的细节；（2）重写导致的语义漂移，会侵蚀原始语气和情境上下文。在本工作中，我们提出了一种新颖的人类画像增强检索优化框架，用于长期智能体记忆（HERO）。具体而言，HERO将对话历史转换为可追踪的异质记忆图，保留原始对话文本作为推理证据，从而减轻信息丢失。在检索方面，HERO从当前查询中提取初始锚点，并通过迭代图遍历融入人类画像；这些锚点和画像提供引导信号，自适应地激活图中信息量最大的区域。在两个基准数据集上的实验表明，HERO在事实性推理和个性化推理方面均优于强基线，同时对原始对话证据的访问更加忠实。

## Abstract
Long-term memory is crucial for personalized responses and long-horizon agent interactions. Existing methods often rely on LLMs to compress or rewrite dialogue histories and use the transformed memories as retrieval evidence. Despite the progress in organizing fragmented contexts, two major drawbacks persist: (1) information loss from compression, which discards fine-grained but later useful details, and (2) semantic drift from rewriting, which erodes the original tone and situated context. In this work, we propose a novel Human-profile Enhanced Retrieval Optimization framework for long-term agent memory (HERO). Specifically, HERO converts the dialogue history into a traceable heterogeneous memory graph that preserves raw dialogue text as evidence for reasoning, thereby mitigating information loss. For retrieval, HERO extracts initial anchors from the current query and incorporates human profiles via an iterative graph traversal; these anchors and profiles provide guidance signals that adaptively activate the most informative regions of the graph. Experiments on two benchmark datasets show that HERO outperforms strong baselines on both factual and personalized reasoning, while providing more faithful access to raw dialogue evidence.

  1. **信息丢失**：压缩过程会丢弃写时看似不重要、但后续查询时可能关键的细节（如时间引用、因果条件、数值事实、细微偏好变化）。
  2. **语义漂移**：将对话重写为摘要、画像或标准化记忆单元时，即使核心事实被保留，用户的原始措辞、情感色彩、说话人归属和情境上下文也会被削弱。
- 此外，基于图的方法在关系抽取和分层聚类中容易引入噪声与歧义，错误会从底层表示传播到高层抽象，造成幻觉累积。
- 论文的核心主张：长期智能体记忆应该**保留原始对话作为证据**，而更高层的画像信息只用于**引导记忆激活**，而非替代记忆本身——这一设计灵感来自人类认知科学中的情景记忆（Episodic Memory）机制。

## 2. 论文提出的方法论

### 核心思想
- 提出 **HERO**（Human-profile Enhanced Retrieval Optimization）框架，遵循"以情景为中心"的设计原则：
  - **原始对话痕迹**作为情景证据保留；
  - **人类画像（Profile）** 只作为导航桥梁，不作为替代记忆。
- 将记忆组织为**异构记忆图**，支持细粒度文本证据的遍历、跨会话关联和时间链式访问。

### 记忆构建（Memory Construction）
- 图结构 G = (V, E) 包含两层：
  - **情景层（Episodic Layer）**：忠实记录原始对话，包含三类节点：
    - **Episodic Traces（Vt）**：按语义连贯的会话或时间窗口划分，保存完整原文、时间戳和顺序索引；
    - **Episodic Units（Vu）**：原子级句子单元，是证据的基本载体；
    - **Episodic Cues（Vc_epi）**：从单元中提取的实体和关键词，作为联想桥梁；跨单元的实体归一化后合并为全局共享的 cue 节点。
  - **画像层（Profile Layer）**：对用户进行高层语义抽象，包含两类节点：
    - **Profile Insights（Vp）**：为每个情景轨迹抽取用户中心的 Facts、Insights、Traits；
    - **Profile Cues（Vc_pro）**：从画像节点中进一步提取细粒度实体，链接回全局语义空间。
- 边类型有三种：
  - **结构包含边**：单元/画像节点 → 源情景轨迹；
  - **语义索引边**：cue 节点 ↔ 轨迹/画像节点（带权重，基于共现频率）；
  - **时间链接边**：相邻情景轨迹之间的时序连接。
- 图支持**增量更新**：新对话只创建局部节点和边，无需全图重建。

### 记忆检索（Memory Retrieval）
- 目标函数：检索最优记忆子集 M∗ 以最大化生成概率 P(r | q, M, P; Φ_LLM)。
- 检索分为三个阶段：
  1. **初始锚点识别**：从查询 q 中抽取实体集 Eq，通过与 cue 节点集合的嵌入余弦相似度匹配，生成初始激活集 S0。
  2. **迭代上下文扩展**（模拟人类"顺藤摸瓜"的回忆过程，共 K 轮）：
     - 别名扩展：对当前 cue 集做近义词扩展（阈值 τ_alias 约束语义漂移）；
     - 收集上下文节点 Nk（与 cue 相邻的 Episodic Units 和 Profile Insights）；
     - 按与查询的相关性过滤（阈值 τ_iter）；
     - 激活新的 cue 节点 Sk，并沿"先前 cue → 中间上下文 → 新 cue"传递激活权重。
  3. **全局相关性传播与证据排序**：
     - 计算情景轨迹的激活强度 = 密集检索相关度 + cue 匹配奖励（含频率与层级深度加权）；
     - 用**个性化 PageRank（PPR）** 在图上传播能量，但将 Profile Insights 节点**遮蔽**，确保传播只流经证据承载节点；
     - 按 PPR 分数对 Episodic Traces 排序，经重排序后返回 top-k 作为 LLM 的推理证据。
- 这种设计使 HERO 能同时处理两类查询：
  - **事实型问题**：激活查询相关 cue，直接定位完整原始证据；
  - **个性化推理问题**：激活画像相关 cue，通过画像桥接抽象偏好与多个原始片段。

## 6. 论文的主要结论与发现

- HERO 在 **LoCoMo** 上达到 87.99% 准确率、56.06% F1、48.38% BLEU-1，**全面超越所有基线**；在 **PERSONAMEM** 上达到 70.63% 总体准确率，同样最优。

- **画像引导有效**：画像层在个性化偏好类任务（如偏好推荐 80.00%、偏好更新原因回顾 87.88%、完整偏好演化追踪 72.66%）上有明显增益；消融显示移除画像层使准确率下降约 2 个百分点。
- **效率与效果兼得**：HERO 以最低的每查询 token 开销和低于 1 秒的延迟取得最高 F1，因为重活（语义建链、画像维护）在构建阶段离线完成。
- **稳定性好**：超参数在合理范围内变化时，准确率波动不超过约 3 个百分点；在不同骨干 LLM 下表现稳定，不依赖于单一生成模型。

## 7. 优点

- **忠实于原始证据**：以原始对话文本作为最终生成依据，避免缩写/重写导致的信息损失与语义漂移，显著提升开放域问答的措辞保真度。
- **异构双层图设计巧妙**：情景层与画像层分离，画像只做导航不参与证据生成，从架构上缓解了对 LLM 抽象能力的过度依赖。
- **迭代 cue 激活机制具有认知启发性**：通过"cue → 上下文 → 新 cue"的传播方式模拟人类联想回忆过程，兼顾显式事实检索和隐式跨片段依赖。
- **PPR 传播时遮蔽画像节点**：确保能量只流经证据承载节点，防止抽象噪声污染检索结果，这一细节体现了设计上的严谨性。
- **增量更新与低检索开销**：内存构建可局部更新，检索阶段只需轻量 cue 提取和图上遍历，每查询仅需 248 tokens、延迟亚秒级。
- **实验体系完整**：在效果之外还涵盖了效率、鲁棒性、可解释性案例和构建成本分析，验证充分。

## 9. 总体评价与展望

### 总体评价
HERO 为长期记忆研究提供了一条**颇具说服力的技术路线**：与其让 LLM 在记忆写入阶段进行有损压缩，不如在检索阶段用轻量画像做导航、以原始文本做证据，让 LLM 在生成时自行完成抽象与推理。这一设计在 LoCoMo 与 PERSONAMEM 两项基准上的全面领先，验证了“证据保留 + 引导检索”范式在大规模长期对话记忆中的有效性。

从研究贡献角度看，HERO 的价值体现在三个层面：
- **方法论层面**：明确提出“画像只用于引导、不替代记忆”的设计原则，并给出了一套可落地的双层异构记忆图实现；
- **技术层面**：迭代 cue 扩展与 PPR 传播相结合，解决了跨会话联想回忆和证据排序问题，检索开销被控制在亚秒级；
- **评测层面**：同时报告了生成质量、检索质量和效率指标，并辅以案例分析和消融验证，为后续工作提供了完整参照。

### 与同类工作的定位区分
HERO 与 Mem0、MemoryOS 等“摘要式记忆”方法的根本区别在于**记忆粒度与存储对象**：前者保存原始对话作为第一性证据，后者保存 LLM 重写的结构化记忆。与 HippoRAG 等“图式记忆”方法相比，HERO 的主要差异在于**双图层级**和**画像的导航性角色**——图被明确分为情景与画像两层，抽象知识不参与证据传播，从而减少了图噪声对检索结果的干扰。

### 未来发展方向
基于论文的局限，可预见以下拓展空间：
1. **记忆生命周期管理**：引入时间衰减、重要性权重和用户反馈驱动的记忆淘汰机制，使图谱在长期运行中保持精炼；
2. **画像自校正机制**：让画像节点在检索效果反馈下自动调整权重或淘汰不准确洞察，减少错误引导；
3. **多模态记忆扩展**：将视觉、语音等模态的痕迹纳入情景层，构建统一的多模态记忆索引；
4. **隐私与合规设计**：开发细粒度的记忆删除、脱敏和审计机制，满足真实产品部署的要求；
5. **更大规模与更广泛任务的验证**：在更长的对话历史（10万+ tokens）、更多用户和更多任务类型上检验 HERO 的可扩展性与稳定性。

### 结语
HERO 的核心启示在于：**在 LLM 能力快速增强的背景下，记忆系统的设计重点应从“让机器替用户总结”转向“让机器帮用户找到原始证据”。** 这一思路不仅适用于智能体记忆，也值得推荐系统、知识管理等领域借鉴。尽管当前在实验规模、生命周期管理和多模态支持上仍有不足，但 HERO 无疑为长期记忆研究确立了一个高水准的新基准。
