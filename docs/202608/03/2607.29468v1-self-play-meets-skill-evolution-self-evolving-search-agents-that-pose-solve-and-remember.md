## 摘要
自我对弈智能体可以在没有目标基准问题的情况下生成训练问题，但其课程缺乏持久状态：失败会影响梯度，却不会明确塑造未来的练习。外部技能记忆保留了程序性经验，但通常是从固定任务分布中学习的。我们提出了\textbf{SESA}（自我进化的技能增强智能体），它将程序性记忆变为工具增强搜索自我对弈的进化状态。挑战者提出问题，而单独参数化的求解器仅检索技能。信息性失败被提炼为可复用的技能并写回记忆。更新后的记忆改变求解器行为和成功率，进而改变挑战者的奖励和未来问题的分布；由此产生的前沿产生新的失败，这些失败又改写记忆。这种双向循环使任务生成和技能记忆共同进化。由于检索到的技能塑造了策略内训练轨迹，它们的好处既可以进入模型参数，也可以保留在外部库中，从而实现无需记忆的部署和可选的推理时检索。在七个开放域和多跳问答基准上，SESA在多种骨干网络上将平均准确率比SSP提高了1.2至3.2个百分点，并在统一评估协议下比技能增强的SkillRL基线高出0.9个百分点。在Qwen3模型上，SESA-Off相对于SSP保持了1.8至2.2个百分点的改进，而最终技能库又额外增加了0.5至1.0个百分点。这些结果表明，进化技能记忆不仅仅是一个推理时的插件：它改变了策略学习和未来的训练分布，同时作为可选外部记忆保留了价值。我们的代码可在https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents获得。

## Abstract
Self-play agents can generate training problems without questions from target benchmarks, but their curricula lack persistent state: failures affect gradients yet do not explicitly shape future practice. External skill memories preserve procedural experience but are typically learned from fixed task distributions. We introduce \textbf{SESA} (Self-Evolving Skill-Augmented Agent), which makes procedural memory an evolving state of tool-augmented search self-play. A challenger poses problems, while a separately parameterized solver alone retrieves skills. Informative failures are distilled into reusable skills and written back to memory. The updated memory changes solver behavior and success, which changes the challenger's reward and the distribution of future problems; the resulting frontier produces new failures that rewrite memory. This bidirectional loop makes task generation and skill memory co-evolve. Because retrieved skills shape on-policy training trajectories, their benefits can enter the model parameters as well as remain in the external bank, enabling memory-free deployment and optional inference-time retrieval. Across seven open-domain and multi-hop question-answering benchmarks, SESA improves average accuracy over SSP by 1.2--3.2 points across multiple backbones and surpasses the skill-augmented SkillRL baseline by 0.9 points under a unified evaluation protocol. On Qwen3 models, SESA-Off retains 1.8--2.2 points of improvement over SSP, while the final skill bank adds a further 0.5--1.0 points. These results show that evolving skill memory is not merely an inference-time plug-in: it changes policy learning and the future training distribution while retaining value as optional external memory. Our code is available at https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：大语言模型（LLM）智能体越来越倾向于从自身经验中训练，而非依赖固定的人工演示语料。两条主流路线各有缺陷：
  - **自我对弈（Self-Play）**：如 Search Self-Play (SSP) 等，智能体自行生成问题并求解，无需外部问题集，训练分布可以随能力提升自适应调整。但经验通常是**瞬时**的——一条轨迹只贡献一次策略梯度，失败并未留下可复用的显式策略记录，即“课程缺乏持久状态”。
  - **技能增强强化学习（Skill-Augmented RL）**：如 SkillRL 等，将经验蒸馏为可检索的策略或结构化笔记，保存在模型权重之外。这类方法能保留程序性知识，但技能通常从**固定数据集或手工设计的课程**中学习，即“记住了并非自己选择的任务”。
- **核心空白**：缺少一个既能“自主选择练习内容”又能“记住失败教训”的智能体——自我对弈决定练什么但会遗忘，技能增强 RL 记住经验但无法自主选择任务。
- **本文方案**：提出 **SESA（Self-Evolving Skill-Augmented Agent，自我进化技能增强智能体）**，将在线技能演化嵌入工具增强的搜索自我对弈中，实现任务生成与技能记忆的**双向耦合共演化**。

## 2. 方法论

### 2.1 核心思想

SESA 构建了一个“失败→技能→求解器→更难问题→新失败”的闭环飞轮：
- **挑战者（Proposer）** 生成问题；
- **求解器（Solver）** 单独检索技能并尝试求解；
- 信息性失败被蒸馏为可复用技能，写回记忆库；
- 更新后的记忆改变求解器行为，进而改变挑战者奖励与未来问题分布，推动前沿不断前进。

### 2.2 关键技术细节

**（1）技能记忆表示**

每个技能存储为结构化卡片：
`s = (u, c, a, z, m)`
- `u`：技能描述
- `c`：触发条件
- `a`：避免提示（反模式/常见混淆）
- `z`：可复用查询模板
- `m`：检索次数、有帮助/有害计数（用于维护）

**（2）四个算法阶段**

1. **记忆初始化（Memory Priming）**：用 15 条手写技能 + 142 条自对弈引导挖掘技能初始化记忆库，提供初始检索基座，锚定后续蒸馏粒度。
2. **非对称自我对弈（Asymmetric Self-Play）**：挑战者与求解器**分别参数化**；技能检索**仅对求解器开放**，防止技能直接泄漏给挑战者，保持问题生成与求解之间的信息不对称。
3. **前沿塑造（Frontier Shaping）**：用钟形奖励函数引导挑战者生成求解器当前能力边界附近的问题：
   - 成功率为 0 或 1 时给予端点惩罚；
   - 中间成功率奖励最高，避免“太简单无信号”和“太难是噪声”两个极端。
4. **失败蒸馏（Failure Distillation）**：三步生命周期——检索（top-k 技能）、失败收集（仅保留前沿信息性失败，300 条队列）、整合（用大模型抽象为技能，经余弦相似度 ≤0.93 去重后写入）。

**（3）优化目标**

- 求解器使用 GRPO 分组奖励归一化更新；检索到的技能进入 on-policy 轨迹，使技能收益内化到模型参数中。
- 挑战者根据求解器群体的经验成功率获得难度塑形奖励，同样用无评论家的策略梯度后端更新。
- 记忆库维护：非种子技能若被检索至少 3 次且“帮助数−有害数”为负则淘汰；超过 800 条时移除最低分项。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **训练数据**：零数据设置，使用 SSP 发布的 50,000 个目标答案及 1/2/3 跳需求种子（16,547/16,729/16,724），不消费任何评测基准的问题。
- **评估数据**：7 个基准的 3,125 个留出问题——
  - 开放域事实检索：NQ、TriviaQA、PopQA；
  - 多跳组合推理：HotpotQA、2WikiMultiHopQA、MuSiQue；
  - 挑战性小型集：Bamboogle（125 题，需显式分解）。前六个数据集各取 500 题。

### 3.2 对比方法

- **骨干网络**：Qwen3-4B、Qwen3-4B-Instruct、Qwen3-8B、Qwen2.5-7B-Base、Qwen2.5-7B-Instruct、LLaMA-3.1-8B、Search-R1-7B。
- **基线**：Base（预训练原始模型）、SSP（无技能库的自对弈）、SkillRL-Search-7B（技能增强 RL 基线）。
- **三个受控模式**：
  - **SESA-Off**：训练后禁用技能库进行推理（测参数内化能力）；
  - **SESA-On**：训练后启用最终技能库（测推理时检索增益）。

## 6. 主要结论与发现

1. **持续技能演化确实增强自对弈**：SESA 在不同骨干上相对 SSP 平均提升 1.2–3.2 点，相对 Base 提升 3.6–28.5 点（跨模型规模、家族和搜索特化初始化均成立）。
2. **能力主要内化在策略参数中**：SESA-Off（禁用记忆）相对 SSP 仍保持 1.8–2.2 点提升，证明技能增强的自对弈是训练机制而非推理技巧。
3. **最终记忆库提供额外可选增益**：启用记忆库（SESA-On）相对 SESA-Off 再增加 0.5–1.0 点；但数据集层面效果混合——相关技能有帮助，不相关上下文也可能干扰。
4. **组件贡献排序**：失败蒸馏最重要（去除后下降 2.7 点），前沿塑造次之（2.2 点），记忆初始化再次（1.5 点）。
5. **记忆库自我精炼**：活跃技能数量先增后减，表明去重和负效用淘汰机制在起作用，而非无界增长。
6. **相对 SkillRL 的优势**：在同一评估协议下，SESA（51.0）超过 SkillRL（50.1）0.9 点，说明与内生任务前沿耦合的技能演化比固定数据集的技能学习更有价值。

## 7. 优点与亮点

- **概念创新**：将“选择练什么”与“记住学到什么”统一到一个闭环中，直接回应了两条研究路线互为镜像的局限。
- **非对称设计精巧**：技能仅对求解器可见，防止解决方案策略泄漏到问题生成中，保持了博弈的对抗性和训练信号的有效性。
- **双路径评估方法论**：SESA-Off / SESA-On 的受控对比为“技能增益驻留在哪里”提供了清晰可量化的回答，这一设计可推广到其他记忆增强智能体研究。
- **技能可读性与可维护性**：技能以人类可读的结构化卡片存储，附带触发条件和反模式，兼具可解释性与自动维护机制（去重、淘汰、效用追踪）。
- **实践灵活性**：支持免记忆部署（适合推理资源受限场景）和记忆增强部署（适合追求极致性能场景）。

## 8. 不足与局限

- **实验覆盖有限**：消融仅在单一骨干（Qwen3-4B）上执行；训练动态仅展示 150 步；未报告更长时间训练的趋势或收敛性。
- **结果非单调**：部分数据集上 SESA 反而低于 SSP（如 2Wiki、Bamboogle），说明技能检索在个别场景下可能引入干扰而非帮助，方法稳定性有待提升。
- **分布外泛化未充分验证**：技能在训练中不断“遗忘”（淘汰机制），未测试这种淘汰是否会丢失长期有用的稀有技能。
- **训练细节披露不足**：未提供训练总时长、GPU 小时数、技能蒸馏的 API 调用成本；也未进行多次不同随机种子实验以报告方差。
- **评估场景单一**：仅覆盖问答/搜索引擎场景，未验证该方法在工具调用、多轮交互、代码生成等更广泛智能体任务中的适用性。
- **与 SkillRL 的对比范围有限**：仅使用了官方发布的 SkillRL-Search-7B 检查点，而非在同一骨干和训练配置下复现，可能存在初始化差异的混淆因素。
- **信息不对称的代价未量化**：挑战者无法看到技能记忆，可能重复生成已经被技能解决过的问题类型，造成训练样本利用率的潜在浪费——论文未讨论这一权衡。
