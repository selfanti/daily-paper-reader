## 摘要
智能体的自我进化主要集中于学习如何行动，却忽视了同等重要的能力：学习发现智能体自身未知的领域。现有方法通常假设失败发现是已知的，侧重于在识别出失败后如何修复。我们质疑盲点诊断本身是否可以被学习。因此，我们将诊断视为一种独立于执行能力的智能体能力，并排除了两种替代进展来源：执行器适应和人工监督。在这些限制下，性能无法通过执行器更新或标注示例来提升，迫使所有改进都源于习得的诊断能力。我们提出了SkillMentor，它通过强化学习训练一个导师（Mentor）策略，以生成诊断任务、识别反复出现的失败模式，并将其整理成可复用的纠正技能。在AppWorld和BFCLv3上，SkillMentor使执行器性能平均提升了44.2%。这些结果表明，盲点诊断是一种可学习的能力，使智能体无需更新执行器权重或依赖人工策划的数据即可实现自我进化。

## Abstract
Agent self-evolution has primarily focused on learning how to act, while overlooking an equally important capability: learning to discover what an agent does not know. Existing approaches typically assume that failure discovery is given, focusing on how to repair failures once they are identified. We ask whether blind-spot diagnosis itself can be learned. We thus study diagnosis as an agent capability separate from execution, and exclude two alternative sources of progress: executor adaptation and human supervision. Under these constraints, performance cannot improve through executor updates or annotated examples, forcing all improvements to originate from the learned diagnostic capability. We propose SkillMentor, which trains a Mentor policy via reinforcement learning to generate diagnostic tasks, identify recurrent failure modes, and curate them into reusable corrective skills. Across AppWorld and BFCLv3, SkillMentor improves executor performance by an average of 44.2%. These results suggest that blind-spot diagnosis is a learnable capability, enabling self-evolution without updating executor weights or relying on human-curated data.

## 2. 论文提出的方法论

**核心思想**：训练一个Mentor策略πθ，通过强化学习（GRPO）联合优化两个耦合的奖励：发现奖励（衡量生成的诊断任务的信息量）和整理奖励（衡量生成的纠正技能的有效性），从而在"冻结执行器 + 零人工标注数据"的约束下完成智能体的自我进化。

**关键设计——三个阶段闭环**：
1. **盲点发现（Blind-Spot Discovery）**：Mentor作为探索者与环境交互，从探索轨迹中合成G个候选诊断任务。为了防止行为崩塌，维护了一个diversity buffer，对探索状态覆盖率高的行为施加惩罚。
2. **差距评估（Gap Evaluation）**：每个候选任务由强参考模型M和执行器πE分别完成。通过两者得分之差定义诊断差距 δi = max(0, sM_i − sE_i)。δ最大的任务进入技能整理环节；只有当δ超过一个线性衰减的阈值（0.5→0.2，每秒步-0.002）才进行整理，以追踪随技能积累而收缩的差距分布。
3. **技能整理（Skill Curation）**：Mentor基于失败轨迹和检索的相关技能，通过ADD、UPDATE、MERGE三种操作生成G个候选技能。每个候选需通过：①语法有效性检查；②执行器落地效用验证（执行器带技能重做任务，要求Δ = sc − sE_max > 0.5）。整理奖励为 rcurate = 0.3f(c) + 0.7Δ。同时设有DELETE机制：检索后成功率低于0.05的技能被从库中驱逐。

**训练目标**：GRPO联合优化 JGRPO = Jdisc + Jcurate − βD_KL(πθ‖πref)，G=8，裁剪范围ε=0.2。两个奖励通过不断演化的技能库耦合。

**关键创新点**：这种联合优化使发现与整理形成正反馈回路——更好的发现产生更好的技能，更好的技能迁移执行器能力边界、暴露新的盲点，形成持续进化的循环。推理阶段，执行器按任务描述从库中检索相关技能并注入提示词。

## 6. 主要结论与发现

- **诊断是可学习的能力**：RL训练的Mentor在全部三个执行器上超过所有提示型Mentor和对齐的固定提示基线，证明学习可以显著改善诊断质量。
- **学习胜过规模**：RL训练的4B Mentor稳定超过DeepSeek-V4-Flash（远大规模提示模型），表明诊断效果并非简单依赖模型规模。
- **弱执行器受益更大**：相对No Skill基线，DeepSeek-R1-Distill-Qwen-7B提升最大（+46.6%），Qwen3.5-9B最小（+36.7%），符合"盲点即程序性缺陷"的定位。
- **联合优化是必要的**：去掉发现奖励或整理奖励均使性能大幅衰减；共享参数的联合Mentor优于分离参数的变体，验证了发现-整理的正反馈回路。
- **技能具有迁移性且方向不对称**：弱执行器训练出的技能库迁移到强执行器很有效（接近甚至偶尔超过强执行器自训练结果），但强到弱的迁移效果有限。所有迁移仓库都超过No Skill基线。
- **盲点是动态的**：随着技能积累，平均诊断差距从0.48降至0.17并趋于稳定；线性衰减的阈值调度优于静态和上升调度；整理行为从早期的ADD主导逐渐转向UPDATE和MERGE，体现从获取新知识到巩固精炼的转变。
