## 摘要
记忆对于长时程LLM智能体至关重要，但现有的记忆系统主要保留交互内容，而非建模哪些智能体可以被信任以及在何种条件下被信任。这一局限性在多智能体系统中尤为重要，因为中心模型可能无法直接验证看似合理或彼此相关的同伴响应。我们引入了$Σ$-Mem，一种在线可靠性记忆，它记录个体同伴的历史能力证据以及跨同伴集合的同伴关系证据。两种形式的证据均以实对称状态维护，并根据决策后的正确性反馈进行更新。通过Weyl不等式，每次事件级更新引起的光谱变化是有界的，从而无需重新训练底层模型即可实现稳定的在线适应。$Σ$-Mem提供了通用的写入-读取接口：同一记忆可用于中心模型的残差引导、无响应同伴路由或可靠性加权投票。在五个Qwen系列模型上，$Σ$-Mem能够适应反事实可靠性转移，并泛化到未见过的同伴和任务领域。在完整OOD评估集上，直接记忆读取也优于多数投票和最佳固定同伴。此外，随着更多正确性反馈的可用，性能持续提升，表明$Σ$-Mem逐步积累可操作的可靠性信息。这些结果确立了可靠性记忆作为基于LLM的多智能体系统中自适应协调的可复用基础。

## Abstract
Memory is central to long-horizon LLM agents, yet existing memory systems primarily preserve interaction content rather than modeling which agents can be trusted and under what conditions. This limitation is particularly important in multi-agent systems, where a central model may be unable to directly verify plausible or correlated peer responses. We introduce $Σ$-Mem, an online reliability memory that records historical competence evidence for individual peers and peer relationship evidence across the peer set. Both forms of evidence are maintained as real symmetric states and updated from post-decision correctness feedback. By Weyl's inequality, the spectral change caused by each event-level update is bounded, enabling stable online adaptation without retraining the underlying models. $Σ$-Mem provides a general write-and-read interface: the same memory can be used for residual steering of a central model, response-free peer routing, or reliability-weighted voting. Across five Qwen-family models, $Σ$-Mem adapts to counterfactual reliability shifts and generalizes to unseen peers and task domains. Direct memory readouts also outperform majority voting and the best fixed peer over the full OOD evaluation set. Moreover, performance improves consistently as more correctness feedback becomes available, indicating that $Σ$-Mem progressively accumulates actionable reliability information. These results establish reliability memory as a reusable foundation for adaptive coordination in LLM-based multi-agent systems.

### 1. 核心问题与整体含义（研究动机和背景）

- **现状与不足**：当前为 LLM 智能体设计的记忆系统主要保存交互内容（“说了什么、做了什么”），解决单智能体长程任务中信息遗忘问题；但在**多智能体系统（MAS）**中，中心模型不仅要判断“内容”，更要判断“哪个同伴可信、何时可信”。
- **核心痛点**：中心模型常常无法直接验证同伴输出（例如支持上下文缺失，或评判难度不亚于生成答案），而多个同伴给出相同或相近答案时，可能反映的是**共享偏差或相关错误**，而非独立佐证。这类“信任决策”失败是 MAS 的主要失效点之一。
- **本文含义**：提出一种**可靠性记忆**（reliability memory），旨在回答“谁可以被信任、以及在什么条件下被信任”，将可信度证据作为与内容记忆互补的一等公民，为多智能体长期自适应协调提供可复用基础。

### 2. 方法论：核心思想、关键技术细节

- **整体思想**：$Σ$-Mem 不记录交互文本，而是仅记录两类“事后正确性”证据：
  1. **个体历史能力证据**：每个 peer $p$ 维护一个实对称矩阵 $M_p \in \mathbb{R}^{r \times r}$；
  2. **同伴关系证据**：跨 peer 的实对称矩阵 $G \in \mathbb{R}^{P \times P}$，反映 peer 之间正确/错误模式的协同或对抗关系。
- **状态更新（写接口）**：基于外部正确性反馈在线更新。
  - 个体记忆：$M_p^{(t+1)} = \gamma M_p^{(t)} + \eta\, c_{p,t}\, \phi(x_t)\phi(x_t)^\top$，其中 $\phi(x_t)$ 为任务能力方向（单位向量），$c_{p,t} \in \{+1,-1\}$ 为正确性标签，$\gamma,\eta$ 为衰减/更新因子。
  - 关系矩阵：$G^{(t+1)} = \gamma_G G^{(t)} + \eta_G q_t q_t^\top$，$q_t$ 为 peer 间去中心化后的正确性向量（$q_{p,t}=c_{p,t}-\frac{1}{P}\sum_j c_{j,t}$），对角设为 1。
- **稳定性设计（数学基础）**：两个状态均为实对称阵，单次更新是秩一对称扰动，因此由 **Weyl 不等式**保证每个特征值扰动不超过谱范数 $\|E\|_2$，不会因单个事件导致记忆状态突变；衰减因子使孤立噪声渐渐消失，而持续一致证据沿稳定谱方向累积。
  - 论文还给出 **Theorem 1**：当 peer 沿某方向有持续能力 $\mu_p$ 时，最大特征值的信号项 $\to \eta\mu_p/(1-\gamma)$，噪声项以概率至少 $1-\delta$ 被 $\eta\sqrt{8\log(2/\delta)/(1-\gamma^2)}$ 界定，与 $T$ 无关，从而证明“持久证据在谱中占优”。
- **读接口（多种下游决策）**：
  1. **残差引导（steered peer selection）**：记忆读出 $r_{p,t}=M_p\phi(x_t)$，经投影和可学习标度 $g$ 得到引导向量 $\delta_{p,t}$，注入中心模型上半层 decoder block 的残差流；中心模型对每个 peer 回答计算“Yes/No”对数似然差得到效用分数，再结合 $G$ 构造后验 $P(y|x,M,G)$，选后验期望最大的 peer。
  2. **无响应路由（M-route）**：直接用 $s_{p,t}=\phi(x_t)^\top M_p\phi(x_t)$ 作为可靠性分数，选择最大的 peer，不读取任何回答内容。
  3. **可靠性加权投票（M-vote）**：将 $s_{p,t}$ 作为回答的投票权重，对相同标准答案累加，取最高者。
- **学习与更新的分离**：选择过程只使用当前判断和记忆；记忆更新仅依赖外部反馈，保证“选择不污染写入”。

### 6. 主要结论与发现

1. **反事实适应能力强**：在强反事实攻击下（CF@90），Qwen3-0.6B 从 Base 的 46.22% 提升到 71.10%（Σ w/G），5 个模型在 CF@0、CF@70、CF@90 大多稳定提升。
2. **同伴关系证据（G）有补充价值**：Σ w/G 通常优于 Σ w/o G，说明跨 peer 的“同对同错”模式能帮助中心模型甄别相关错误。
3. **可泛化到未见 peer 与未知领域**：训练只有 3 个 peer、3 个领域；测试扩展到 5 个 peer、6 个 OOD 基准时，大多数设置仍优于 Base（OOD 上 27/30 提升，BBH 提升尤为显著）。
4. **记忆是通用的重启资产**：同一个冻结记忆状态既可驱动残差引导，也可直接用于路由和投票；在完整 OOD 集上，直接读出的 M-route 和 M-vote **优于多数投票和最佳固定 peer**，甚至超过一些中心模型引导下的选择。
5. **反馈越多，记忆越好**：反馈可用率从 5% 增加到 100% 时，OOD 准确率单调上升，证明记忆确实从反馈中累积了可操作信息。
6. **能力互补关系**：中心模型弱时，直接记忆读取（M-vote 等）更有效；中心模型强时，残差引导能借力内容判断进一步超越纯记忆路由。

### 7. 优点

- **问题新颖且切中要害**：将“内容记忆”和“可靠性记忆”分离，直接针对多智能体系统中“相关错误/看似一致但不可信”这一关键风险。
- **理论支撑扎实**：用 Weyl 不等式和定理 1 从数学上证明了更新稳定性和信号-噪声分离，不是纯粹的启发式。
- **记忆状态设计优雅**：实对称矩阵 + 秩一对称更新，使记忆可读方向性信息（任务条件化），又天然支持谱分析。
- **接口通用**：同一份记忆可适配路由、投票、残差引导等多种聚合方式，且不需要重新训练中心模型，易于集成到现有 MAS/Pipeline。
- **实验维度丰富**：反事实、扩展 peer 池、OOD 泛化、机制对比、反馈率消融都覆盖，且观察到“弱模型适合纯记忆读取、强模型适合结合引导”的规律，洞察有价值。

### 8. 不足与局限

- **CF@50（历史证据矛盾）下的退化**：当一半历史支持原偏好、一半支持反事实转移时，Σ-Mem 忠实累积相反信号，导致选择反倒变差；论文将其解释为“记忆的忠实性”，但实际应用场景并不乏这种信号混杂情况，需要更自适应地调节历史与当前证据的权重。
- **中心模型与 peer 的多样性有限**：中心模型只用 Qwen 系列；peer 模型也仅 3–5 个，且训练时只有 3 个固定 peer，未见跨更大 peer 池的充分验证。
- **训练数据规模较小**：仅 2,963 条事件，且基于离线固定数据集和固定外部正确性标签；真实长时程 MAS 中延后、噪声或不完整反馈的影响未充分建模。
- **后验枚举计算成本**：在选择阶段对 $\{-1,+1\}^P$ 做精确枚举，当 peer 数 $P$ 增长时计算量指数增长，论文未讨论大规模 peer 集的可扩展方案。
- **缺少算力/效率报告**：未提及训练时间、GPU 数量和推理开销；作为“online”方法，在线更新的实际吞吐成本也未量化。
- **记忆读出的投影参数需要预训练**：虽然不用重训中心模型，但 $P$ 和 $g$ 的存在意味着仍需要一个训练阶段，对“零训练即用”的目标构成一定折扣。
