## 摘要
近期推理时扩展的进展显著释放了大语言模型（LLMs）的复杂推理能力。然而，对于智能体而言，这些方法存在一个关键的效率缺陷：它们以无状态方式运行，并参与冗余的搜索过程。现有的记忆机制主要依赖LLMs的推理能力，导致高昂的计算成本。在本文中，我们提出了一种新颖的框架——GAMER（基于图的动作中心记忆与情景推理），以弥合推理扩展与情景记忆之间的差距。我们的方法将历史推理建模为动态的“动作中心图”。通过将记忆机制与LLMs解耦，我们的方法能够提供比记忆机制基线更少的记忆上下文，从而节省令牌/金钱消耗。为了有效提取图中的知识，我们利用双流时序差分学习机制，基于过去的成败来估计动作节点的正（建议）与负（规避）价值。在推理阶段，学习到的价值函数双向优化决策，使得正价值提供动作建议，负价值指示高风险动作。通过在图上进行高效搜索，我们的方法显著提升了推理扩展的效率。在多个基准上的实验表明，与朴素基线相比，GAMER在成功率/进度率上分别实现了20.81%/6.17%的优越性能。

## Abstract
Recent advancements in inference-time scaling have significantly unlocked the complex reasoning capabilities of Large Language Models~(LLMs). However, for agents, these approaches suffer from a critical inefficiency, operating in a stateless manner and engaging in redundant search processes. Existing memory mechanisms largely rely on the reasoning capabilities of LLMs, leading to prohibitive computational costs. In this paper, we propose a novel framework, \textit{GAMER}~(Graph-based Action-centric Memory with Episodic Reasoning), that bridges the gap between inference scaling and episodic memory. Our approach models historical reasoning as a dynamic \textit{Action-Centric Graph}. By decoupling the memory mechanism from LLMs, our method can save token/money usage by providing less memory context than memory mechanism baselines. To extract knowledge from the graph effectively, we use a dual-stream Temporal Difference learning mechanism to estimate the positive~(suggestion) and negative~(avoidance) value of action nodes based on past successes and failures. During the inference phase, this learned value function optimizes decision-making bi-directionally, so that positive values provide action suggestions, while negative values indicate high-risk actions. By performing efficient searches on the graph, our method significantly improves the efficiency of inference scaling. Experiments on multiple benchmarks demonstrate that \textit{GAMER} achieves superior performance by \textbf{20.81\%/6.17\%} for success/progress rate compared to vanilla baselines.

### 1. 核心问题与研究动机

- **背景**：LLM智能体在复杂多步任务中需要推理与执行能力。推理时扩展（Inference-time Scaling）方法（如 CoT、ToT、SFS 等）通过增加测试时计算来提升推理性能，已成为提升智能体能力的重要手段。

  1. 高度依赖 LLM 的推理能力，需要大量令牌进行记忆总结与检索；
  2. 将记忆仅视为“上下文增强”工具（检索事实、注入 prompt），而非真正的计算优化模块，无法剪枝搜索空间或引导决策过程。
- **本文意图**：弥合“推理时扩展”与“情景记忆”之间的鸿沟，让记忆从被动的存储变为主动的决策指导，实现高效、可复用的推理扩展。

### 2. 方法论

#### 2.1 核心思想
提出 **GAMER**（Graph-based Action-centric Memory with Episodic Reasoning）框架，将历史推理轨迹建模为**动作中心图（Action-Centric Graph）**，并通过双流时序差分（TD）学习估计各动作节点的价值，从而在推理时提供“建议动作”与“规避动作”的双向引导。关键创新在于**将记忆机制与 LLM 推理能力解耦**，克服了传统记忆方法依赖 LLM 总结、消耗大额令牌的局限。

#### 2.2 技术细节

**（1）图构建（Graph Construction）**
- 给定历史轨迹集合 D = {τ₁, τ₂, ..., τₙ}，每个轨迹 τᵢ = (o₀, a₀, r₀, ..., a_T, r_T)，构建有向图 G = (V, E)。
- 节点 V：每个唯一的动作 a 对应一个节点；
- 边 E：当动作 aⱼ 在轨迹中紧跟在 aᵢ 之后执行时，建立有向边 eᵢⱼ，编码时序依赖关系。
- 图的合并使得多条线性轨迹被压缩为一张全局推理空间地图；分支点代表历史上不同策略的决策点，环路代表递归推理循环。

**（2）双流 TD 价值估计（Dual-Stream TD Learning）**
- 采用 TD 学习解决长轨迹下奖励稀疏、更新方差大的问题。标准 TD 误差为：
  - δₜ = rₜ + γ·E[Q(vₜ₊₁)] − Q(vₜ)，并以 Q(vₜ) ← Q(vₜ) + αδₜ 更新。
- 为克服单值函数导致的风险信号被中和（如高收益但高风险动作期望值为零）的问题，引入**双流价值函数**：
  - **正价值 Q⁺(v)**：追踪动作导致成功结果的期望成功率，用标准环境奖励 rₜ 更新；
  - **负价值 Q⁻(v)**：追踪动作导致失败的风险，用阈值化奖励重新定义：
    - r₋ₜ = −1 如果 rₜ < εᵣ，否则 0。
- 两个价值函数独立更新，目标分别为：Q⁺ 使用 max 继承者价值、Q⁻ 使用 min 继承者价值。

**（3）记忆引导的推理（Graph-Memory Guided Inference Scaling）**
- 两层引导机制：
  - **全局参考轨迹**：从池中检索历史上最优轨迹 τ* 作为 few-shot 示例；
  - **局部双流动作注入**：在当前节点 vₜ 查询图的后继节点，生成：
    - 建议动作列表 A_suggest = TopK_{a∈Succ(vₜ)} Q⁺(a)；
    - 规避动作列表 A_avoid = TopK_{a∈Succ(vₜ)} |Q⁻(a)|。
- 通过 prompt 模板将上述信号注入 LLM 上下文，形成自然语言指令，引导概率分布偏向高价值区域、抑制高风险区域。prompt 模板包括历史最优轨迹、高价值动作建议和警告规避动作三部分。

**（4）理论保障**
- 论文给出定理：记忆引导策略 π_mem 的奖励分布对基础策略 π_base 满足一阶随机占优（FSD），因此期望最大奖励 J_mem(N) ≥ J_base(N)；达到目标奖励 x* 所需的采样数 N_mem ≤ N_base。

### 7. 方法亮点

- **记忆与推理解耦**：避免用 LLM 做记忆总结/检索，降低计算成本，令牌消耗可预测、稳定。
- **动作级细粒度记忆**：比检索整条轨迹或高级摘要更精确，能提供决策级的建议与规避信息。
- **双流价值设计**：解决单值函数中“高风险高回报”与“平庸动作”价值混淆的问题，保留风险信号。
- **图结构建模**：将离散轨迹压缩为全局图，支持分支、环路等复杂结构，富含时序依赖信息。
- **理论保证**：给出 FSD 性质的证明，从理论上支撑记忆引导加速推理扩展的有效性。
- **与 ICL 结合自然**：通过 prompt 注入而非修改解码过程，不需要额外训练或改变模型架构，简洁易用。
