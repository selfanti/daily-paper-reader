## 摘要
组相对强化学习等待同一提示的兄弟rollout，这对于长且多变的工具使用轨迹来说代价高昂。单流策略优化（SPO）通过持久的提示级价值估计消除了这种依赖性，但其方法在优化token均值actor损失之前，对每条轨迹的一个优势进行白化。我们表明，轨迹中心化通常不会使actor消耗的token加权量居中，并通过在动作token度量下标准化终端结果优势来修复这种不匹配。我们还根据生成提示证据的策略事件而非学习者接收顺序来组织提示证据。在ALFWorld上两个模型规模以及Math-TIR上的匹配运行中，SPO++相比SPO提高了在线学习效率。配对消融实验表明，动作token度量标准化是测试中最强的组件。

## Abstract
Group-relative reinforcement learning waits for sibling rollouts of the same prompt, which is costly for long and variable tool-use trajectories. Single-stream Policy Optimization (SPO) removes this dependency with a persistent prompt-level value estimate, but its recipe whitens one advantage per trajectory before optimizing a token-mean actor loss. We show that trajectory centering generally does not center the token-weighted quantity consumed by the actor, and fix the mismatch by standardizing terminal-outcome advantages under the action-token measure. We additionally organize prompt evidence by the policy event that generated it rather than learner receipt order. Across matched runs on ALFWorld at two model scales and on Math-TIR, SPO++ improves online learning efficiency over SPO. A paired ablation identifies action-token-measure normalization as the strongest tested component.

# SPO++：异步智能体强化学习的流对齐策略优化——详细总结

## 1. 核心问题与整体含义

- **研究背景**：在大语言模型（LLM）的推理与工具使用训练中，基于可验证结果的强化学习（RL）被广泛采用。以 GRPO 为代表的“组相对”方法通过对同一提示（prompt）的多个输出计算相对优势，从而无需学习价值函数。然而，在**异步智能体（agentic）场景**中，环境交互、工具调用和失败轨迹导致轨迹完成时间差异巨大，组相对方法必须等待同一个提示最慢的“兄弟”轨迹完成才能更新，代价高昂。
- **已有方案 SPO**：单流策略优化（Single-stream Policy Optimization）通过一个**持久的提示级价值估计**替代组内基线，使得每个提示可以进行在线单次 rollout，打破了组等待。但该方案存在两个一致性问题：
  1. **度量不匹配**：SPO 在优化一个“token 均值” actor 损失之前，对每条轨迹的单个优势做等权白化（trajectory whitening）。由于不同轨迹的 token 数不同，轨迹级白化通常不能使 actor 实际消耗的 token 加权优势居中。
  2. **时间坐标系混乱**：SPO 的顺序追踪器以“学习者接收顺序”记录证据，而非产生该结果的**策略事件（policy event）**，导致基线估计受系统时序影响。
- **SPO++ 的整体含义**：通过**动作 token 度量下的优势标准化**和**按策略事件时间组织的提示记忆**，使单流 RL 的持久统计量与策略时钟和 actor 损失度量对齐，从而提升异步智能体 RL 的在线学习效率。

## 2. 方法论

### 核心思想
保留 SPO 的单 rollout 依赖图和终端轨迹结果，但修改两个边界：
- **事件时间记忆**：决定哪些历史证据构成基线；
- **度量对齐**：决定已完成批次在优化前如何标准化。

### 关键技术细节

#### (1) 单流提示值（保留自 SPO）
- 对可重复任务 x 维护成功/失败证据 \((\alpha_x, \beta_x)\)，更新前的提示价值为：

\[
b\hat{v}_x = \frac{\alpha_x}{\alpha_x + \beta_x}, \quad A_i = R_i - b\hat{v}_x
\]

- 每次消费后按依赖策略漂移的保留因子 \(\rho_i\) 更新证据。

#### (2) 事件时间提示记忆（Event-time Prompt Memory）
- 引入**策略事件坐标** \(z\)：每个生成策略快照对应一个坐标，按配置的衰减间隔递增。
- 在请求派发（dispatch）时**冻结**基线；返回结果时将其挂到生成该结果的策略事件坐标上。
- 未来派发 q 的基线为：

\[
\alpha_q = e^{-(z_q-z_0)}\alpha_0 + \sum_{i \in H_q(x)} e^{-(z_q-z_i)} R_i
\]

\[
\beta_q = e^{-(z_q-z_0)}\beta_0 + \sum_{i \in H_q(x)} e^{-(z_q-z_i)}(1-R_i)
\]

\[
b\hat{v}_q = \frac{\alpha_q}{\alpha_q + \beta_q}
\]

- 该形式对**固定可见历史**下的接收顺序排列不变（仅有限和排列），称为“接收顺序不变性”。
- 实验中保留因子固定为 \(\rho=0.875\)，即每个策略事件衰减 \(-\log\rho\)。

#### (3) 动作 token 度量标准化（Action-token-measure Normalization）
- 轨迹级白化：先对每条轨迹优势等权求均值和方差，再标准化。这会导致 token 均值损失所见的加权平均优势不为零：

\[
\frac{\sum_i L_i \tilde{A}_i^{\text{traj}}}{\sum_i L_i} = \frac{\text{Cov}_n(L, \tilde{A}^{\text{traj}})}{\bar{L}}
\]

其中 \(L_i\) 是轨迹 i 的有效动作 token 数，通常不为零。

- SPO++ 改为**在动作 token 度量下**计算均值和方差：

\[
\mu_{\text{tok}} = \frac{\sum_i L_i A_i}{\sum_i L_i}, \quad
\sigma^2_{\text{tok}} = \frac{\sum_i L_i (A_i - \mu_{\text{tok}})^2}{\sum_i L_i - 1}
\]

\[
\tilde{A}_i^{\text{tok}} = \frac{A_i - \mu_{\text{tok}}}{\sigma_{\text{tok}} + 10^{-8}}
\]

- 这样逐轨迹的标量优势被广播到该轨迹的所有有效行动 token 上，但**中心化和缩放**是在 token 加权意义下完成的，与 token 均值 actor 损失严格一致。

#### (4) 优化与异步执行
- 不确定性采样：提示权重为 \(p b\hat{v}_x(1-b\hat{v}_x) + 0.05\)。
- 每个策略版本内收集最先完成的请求；旧策略工作在新参数发布时丢弃。
- 重要性比率上限截断为 2；负优势时使用 Dual-Clip，SPO 用 \(c=10\)，SPO++ 用 \(c=2\)；均关闭辅助奖励、KL 正则和移动参考更新。

## 3. 实验设计

### 数据集与场景
- **ALFWorld**：文本化交互式具身环境，128 个规范任务。使用 Qwen3.5-0.8B 和 Qwen3.5-2B 两个规模的智能体模型。
- **Math-TIR**：带原生 Python 工具使用的数学工具推理，使用 DAPO-Math-17K 训练集中的 1,500 个提示子样本。模型为 Qwen3.5-0.8B，使用共享的 SFT 冷启动检查点。

### 对比方法
- **SPO**：原版单流策略优化（轨迹级白化、按接收顺序更新证据、策略漂移相关保留、Dual-Clip c=10）。
- **SPO++**：事件时间提示记忆 + 动作 token 度量标准化（固定保留 ρ=0.875、Dual-Clip c=2）。
- **消融实验**：在 ALFWorld 0.8B 上隔离“标准化度量”，其他条件完全相同（轨迹级 vs 动作 token 级标准化），比较 10 步学习复合指标 C10。

### 评估指标
- **主指标**：归一化奖励曲线面积（ALFWorld 用梯形 AUC，Math-TIR 用步均值矩形面积），以及最后 5 步平均奖励。配对差异表示为 SPO++ 减去 SPO，平均 ± 样本标准差。
- **辅助指标**：优化诊断（PPO KL、梯度范数、裁剪率）在单次匹配运行的完整日志中对比。

### 训练统计
- ALFWorld：每步平均 128 条轨迹，共 50 步，每方法在线轨迹 6,400 条。
- Math-TIR：每步平均两个 128 轨迹更新，共 100 步，每方法在线轨迹 25,600 条。

- **问题识别准确**：明确指出轨迹级白化与 token 均值 actor 损失之间的度量错配，并给出形式化说明（公式 5）。

- **实验规范**：匹配独立运行、配对统计、多种子多任务，且消融隔离了最关键的组件。

## 8. 不足与局限

- **实验规模有限**：只用了 Qwen3.5-0.8B 和 2B 小模型，且训练预算较短，尚不清楚对更大模型、更长推理链或 OOD 任务的推广效果。
- **端到端比较混杂多个组件**：SPO 与 SPO++ 同时改变了事件时间跟踪、保留因子和 Dual-Clip 参数，无法单独归因于某一修改。
- **消融分解不足**：动作 token 标准化同时改变了中心化和 batchwise 缩放，没有分别验证两者各自的贡献。
