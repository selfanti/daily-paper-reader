## 摘要
智能体技能是从交互轨迹中提炼出的结构化产物，可从技能库中动态复用，已成为使基于大语言模型（LLM）的自进化智能体能够从过往经验中学习的核心机制。然而，现有工作主要关注技能的操作层面，如获取、演化和检索，而一个更基本的可靠性问题仍未解决：智能体技能库中积累的技能是否真正产生了正的机制性贡献？我们通过跨不同技能库组成和部署领域的系统性技能库审计来研究这一问题，并测量由此导致的智能体行为变化。这些审计揭示了两种反复出现的可靠性失效：联盟污染，即库级收益掩盖了联盟级技能的负面贡献；以及跨域效用反转，即源域有益的技能在迁移后效果发生反转。这些发现催生了两种可靠性干预措施：技能积累期间的联盟感知技能选择，以及迁移后的无标签技能掩蔽。联盟感知技能选择（CASS）利用采样的沙普利边际值为当前技能库选择更可靠的候选技能。无监督技能掩蔽联盟优化器（u-SMCO）掩蔽那些在未标记目标域数据上排除后能提高检索质量的迁移技能。在LoCoMo、LongMemEval、HotpotQA和ALFWorld上的智能体实验表明，CASS和u-SMCO在任务性能和跨域泛化能力上持续优于基于技能的强自进化智能体基线。除了准确性之外，联盟条件下的可靠性建模降低了对强化学习期间嘈杂的结果-奖励波动的敏感性，并揭示了基于隔离的技能评估的局限性。

## Abstract
Agent skills, structured artifacts distilled from interaction trajectories and dynamically reused from skill banks, have become a central mechanism for enabling large language model (LLM)-based self-evolving agents to learn from past experience. Yet existing work has largely focused on the operational aspects of skills, such as acquisition, evolution, and retrieval, while leaving a more fundamental reliability question unresolved: Do accumulated skills in an agent's skill bank actually make positive mechanistic contributions? We investigate this question through systematic skill-bank audits across alternative bank compositions and deployment domains, measuring the resulting changes in agent behavior. These audits reveal two recurring reliability failures: coalition pollution, where bank-level gains conceal negative coalition-level skill contributions, and cross-domain utility reversal, where source-beneficial skills reverse their effects after transfer. These findings motivate two reliability interventions: coalition-aware skill selection during skill accumulation and label-free skill masking after transfer. Coalition-Aware Skill Selection (CASS) selects more reliable candidate skills for the current bank using sampled Shapley marginals. Unsupervised Skill-Masked Coalition Optimizer (u-SMCO) masks transferred skills whose exclusion improves retrieval quality on unlabeled target-domain data. Agentic experiments on LoCoMo, LongMemEval, HotpotQA, and ALFWorld show that CASS and u-SMCO consistently improve task performance and cross-domain generalization over strong skill-based self-evolving agent baselines. Beyond accuracy, coalition-conditioned reliability modeling reduces sensitivity to noisy outcome-reward fluctuations during reinforcement learning and exposes the limits of isolation-based skill evaluation.

### 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：基于大语言模型（LLM）的自进化智能体已成为人工智能领域的重要研究方向。这类智能体通过从过去成功或失败交互中提取经验，以"技能"（Skill）的形式沉淀到技能库中。技能是从交互轨迹中提炼出的高层级、可复用的结构化产物，在推理阶段无需更新模型参数即可被检索与调用。现有研究多聚焦于技能生命周期中的操作层面，包括获取（acquisition）、演化（evolution）和检索（retrieval），但一个更根本的问题被忽视了：**技能库中积累的技能，在被实际调用时，是否真的产生了正向的机制性贡献？**
- **核心问题**：论文指出，技能库中并非所有技能都有益。技能的实际贡献受其所在"联盟"（即技能库中与之共存的其他技能）和部署领域（domain）的共同影响，而**不是技能本身的内在固有属性**。作者称之为"技能的可靠性是联合属性"（joint property of skill, bank, and deployment domain）。
- **研究意义**：本文通过系统性审计揭示了现有技能库机制中的两类隐蔽且关键的可靠性失效模式：**联盟污染**（coalition pollution）和**跨域效用反转**（cross-domain utility reversal），并据此提出两种可靠性干预手段。这项工作将技能研究的关注点从"如何操作技能"推向"技能是否真正可靠"，为自进化智能体的技能库机制设计提供了新的理论视角和实践准则。

### 二、方法论：核心思想、关键技术细节

#### 1. 基础框架与问题形式化

- 论文基于技能型自进化智能体框架（以 MemSkill 为基线）。在演化阶段 e，设当前技能库为 Bᵉ = {s₁, ..., sₙ}，技能演化策略提取出候选技能 s_new，构成候选库 eB⁺¹ = Bᵉ ∪ {s_new}。
- 传统"结果唯一门控"（outcome-only gate）通过库级增益 Gᵉ = r_out(eB⁺¹) − r_out(Bᵉ) 决定技能去留：若 Gᵉ > 0 则接受，否则拒绝。该门控只观察库级端点收益，无法获知是谁贡献了收益、技能之间如何交互。

#### 2. 技能机制性可靠性审计（SMRA）

- 论文引入 **Skill Mechanistic Reliability Audit（SMRA）**，采用夏普利值边际贡献视角。对每个技能 s，在全库上进行"敲除干预"（knockout）：
  - ∆_s^D(B) = V^D(B) − V^D(B \ {s})
- 夏普利值进一步在所有子集上取加权平均，以刻画技能在替代联盟组成下的预期边际贡献：
  - ϕ_s^D(B) = Σ_{C⊆B\{s}} [|C|!(|B|−|C|−1)! / |B|!] · [V^D(C∪{s}) − V^D(C)]
- 通过跨演化阶段和跨部署域的审计对比，SMRA 揭示了两类失效模式。

#### 3. 理论分析：定理 1（结果唯一不可辨识性）

- **定理 1（Outcome-only non-identifiability）**：对于只观察端点 V(Bᵉ) 和 V(eB⁺¹) 的门控，正增益 V(eB⁺¹) − V(Bᵉ) > 0 **无法判定** eB⁺¹ 中是否含有负贡献技能。
- 该定理表明门控失效是结构性的而非统计性的：无论采样多少结果数据，都无法区分"库确实变好了"和"只是看起来变好了"两种情况。

#### 4. 方法一：CASS（Coalition-Aware Skill Selection，联盟感知技能选择）

- **目标**：解决技能演化阶段的联盟污染问题。
- **核心思想**：将联盟审计嵌入技能演化过程本身，用采样联盟的敲除边际替代仅靠聚合收益做决策。
- **技术细节**：
  - 对给定技能库 B 和联盟 S ⊆ B，先通过蒙特卡洛采样抽取 N 个不同联盟（每个联盟大小 |S| 在 {1,...,k} 上均匀采样，再从该大小的所有子集中均匀选取）。
  - 计算每个采样联盟的敲除边际：∆_S(B) = [V(B) − V(B \ S)] / |S|，将联合移除损失均摊给各成员。
  - 将 N 个边际平均得 b̄∆_N(B)，与在线结果奖励 r_out(B) 结合为门控排序标量：σ(B) = b̄∆_N(B) + λ·r_out(B)，其中 λ = 0.2。
  - 保留评分超过历史最佳评分（best-so-far gate）的候选库。

#### 5. 方法二：u-SMCO（Unsupervised Skill-Masked Coalition Optimizer，无监督技能掩码联盟优化器）

- **目标**：解决跨域迁移后的跨域效用反转问题。
- **核心思想**：在部署阶段，仅利用无标签目标域数据，通过检索质量贡献信号对技能进行贪心掩码。
- **技术细节**：
  - 对技能集 A ⊆ B，定义检索质量分数 RQ(A) = (1/|Q_tgt|) Σ_{q∈Q_tgt} mean_{m∈Top(q)} cos(e_q, e_m)，即在目标域未标注查询上，检索到的最近邻记忆与查询之间的平均余弦相似度。
  - 技能掩码分数 ψ(s) = RQ(B) − RQ(B \ {s})，即目标域检索质量视角下的敲除比较。
  - 贪心流程（Algorithm 1）：反复计算当前保留集中每个技能的 ψ(s)，掩码分数最低的技能，直到最低分数不低于阈值 τ 为止。
  - 与基于熵的测试时适应（TTA）信号对比：论文发现智能体自身的选择策略熵信号存在偏差（因为策略在结果门控下训练并继承了其偏差），而检索质量信号与训练奖励通道解耦，与基于标签的排序相关性达到 ρ = +0.76。

### 六、主要结论与发现

1. **技能可靠性不是内在属性**：一个技能的贡献取决于它所在的技能库联盟和部署领域，不能孤立评估。
2. **联盟污染是真实存在的失效模式**：结果唯一门控接受的技能可能贡献约等于零（如 capture_activity_preferences，∆ = −0.005），而真正承载库价值的是其他技能；门控的接受/拒绝边距（0.006–0.02）低于单技能审计分辨率（±0.04），且定理 1 证明其结构性不可辨识。
3. **跨域效用反转同样真实**：source 域正向贡献的技能（如 insert，LoCoMo 上 ∆ = +0.084）在目标域（HotpotQA-50）上点估计反转为负（∆ = −0.035），说明源域效用不能作为跨域不变特征。
4. **CASS 有效提升技能库可靠性**：通过联盟感知门控，CASS 将接受率从 6/12 降至 1/12，拒绝的技能在 K 受控消融中被证明是集体净负面的（−1.38 pp 平均），四个基准上均优于 MemSkill。
5. **u-SMCO 能在无标签条件下识别并掩码有害技能**：掩码后所有技能库均有提升；MemSkill 库提升幅度（7.17 pp）是 CASS 库（3.59 pp）的两倍——说明 CASS 在门控阶段排除的污染正是 u-SMCO 在部署阶段需要清理的问题。
6. **联盟条件可靠性建模降低对噪声奖励的敏感性**：CASS 在强化学习训练中增强了鲁棒性，揭示了孤立式技能评估的局限性。

### 七、优点

- **问题视角新颖**：首次将"技能是否真正具有正向机制性贡献"作为核心研究问题，将可靠性定义为技能、技能库、领域三者的联合属性，突破了将技能视为孤立实体的传统假设。
- **系统性审计方法（SMRA）**：基于夏普利值边际贡献的敲除审计框架科学严谨，可重复、可扩展；"审计—发现问题—设计干预"的研究范式值得借鉴。
- **理论分析扎实**：定理 1 从理论上证明了结果唯一门控的结构性缺陷，超越了一般的经验观察层面。
- **方法设计轻量实用**：CASS 仅增加约 5% 训练开销；u-SMCO 完全无监督（仅需目标域未标注查询），且在部署前一次性执行、不增加推理成本；二者可直接附加到现有框架上。
- **实验设计严谨**：协议匹配严格（CASS 与基线仅门控不同）、多基准多指标覆盖、3 种子报告、成对评估控制方差，结论可信度高。
- **信号选择论证完整**：通过对比熵信号与检索质量信号的相关性（ρ = −0.18 vs +0.76），论证了为何目标域自身信号优于智能体偏好信号。

### 八、不足与局限

- **单基线依赖**：方法主要建立在 MemSkill 框架之上，虽然对比了多种记忆/技能基线，但 CASS 与 u-SMCO 本身未在其他独立框架（如 ADaPT、Voyager 等）上验证可移植性。
- **统计显著性仍有提升空间**：论文承认在目标域（HP-50）上 insert 的负效应为"方向性反转"，95% 置信区间包含零，意味着跨域效用反转在统计上并非全部显著。
- **目标域覆盖面有限**：跨域实验更多依赖 HotpotQA 作为目标域，未在更多目标领域（如具身任务间的迁移）上验证跨域反转现象的普遍程度。
- **技能类型单一**：所有实验围绕文本型记忆技能展开，未探讨代码技能、工具使用技能等非文本技能中的联盟效应是否同构。
- **超参数设定较经验化**：如 λ = 0.2、联盟大小上限 k、采样数 N 等超参数的敏感性分析不够详尽，缺少系统性扫描。
- **u-SMCO 的贪心策略可能陷入次优**：贪心逐次掩码不能保证全局最优掩码组合，论文未与穷举或束搜索等其他掩码策略比较。
- **资源信息披露有限**：未提供端到端训练的总时长、完整计算成本对比（与其他基线方法相比的算力开销差异），使得可复现性打折扣。
