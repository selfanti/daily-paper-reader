## 摘要
记忆增强的智能体在长对话中维护紧凑的用户画像，从而无需处理整个对话历史即可实现个性化且一致的响应。这些用户画像的质量依赖于底层的记忆管理策略：每一步智能体都必须决定保留、压缩或丢弃什么。然而，现有方法通常采用训练前设定的静态、一刀切策略。实际上，最优记忆决策本质上是用户特定的，并随策略优化而动态演化。为解决此问题，我们提出\textbf{HiPS}（\textbf{Hi}erarchical \textbf{P}ersonalized \textbf{S}trategy，层级个性化策略），该框架将记忆管理解耦为全局共享基础层和用户特定自适应层。具体而言，HiPS采用\textbf{Universal Strategy}（通用策略）从跨人设轨迹中提取共享原则，并利用\textbf{Persona Delta Distillation}（人设差异蒸馏）为行为偏离一般模式的用户生成定制规则。\textbf{Cross-Level Rule Flow}（跨层规则流）通过提升广泛验证的个人规则并降级被矛盾全局规则，动态校准其边界。该架构建立了一个协同进化循环，其中的机制确保所有策略改进都锚定于任务结果。大量实验表明，相对于记忆增强基线方法，该方法取得了一致的改进。

## Abstract
Memory-augmented agents maintain compact user profiles throughout extended conversations, enabling personalized and consistent responses without the need to process the entire dialogue history. The quality of these user profiles relies on the underlying memory management strategy: at each step, the agent must determine what to retain, compress, or discard. However, existing methods typically employ a static, one-size-fits-all strategy established before training. In practice, the optimal memory decision is inherently user-specific and dynamically evolves alongside policy optimization. To address this, we propose \textbf{HiPS} (\textbf{Hi}erarchical \textbf{P}ersonalized \textbf{S}trategy), a framework that decouples memory management into a globally shared foundation and a user-specific adaptive tier. Specifically, HiPS employs \textbf{Universal Strategy} to extract shared principles from cross-persona trajectories, alongside \textbf{Persona Delta Distillation} to generate tailored rules for users whose behaviors diverge from general patterns. \textbf{Cross-Level Rule Flow} dynamically calibrates their boundary by promoting broadly validated personal rules and demoting contradicted global ones. The architecture establishes a co-evolution loop where a mechanism guarantees that all strategy refinements are anchored to task outcomes. Extensive experiments demonstrate consistent improvements over memory-augmented baselines.

## 二、方法论（HiPS 框架）

### 2.1 核心思想

将记忆管理策略分解为两层，并在训练过程中与策略（policy）协同演化：

\[
S_p = S_u \cup \Delta_p
\]

- **$S_u$（Universal Strategy）**：跨用户共享的通用规则；
- **$\Delta_p$（Personal Delta）**：仅针对行为偏离总体规律的用户定制的个性化规则。

三层机制形成"发现-验证-迁移"的完整闭环：

| 机制 | 功能 | 更新频率 |
|------|------|----------|
| **USD（Universal Strategy Distillation）** | 从跨人设轨迹中提炼共享规则 | 每 K₁=20 步 |
| **PDD（Persona Delta Distillation）** | 为高发散用户生成个性化规则 | 每 K₂=10 步 |
| **Cross-Level Rule Flow** | 跨层规则迁移，动态校准共享/个性化边界 | 随 USD/PDD 周期触发 |

### 2.2 关键技术细节

**① USD：通用策略蒸馏**

- 取轨迹缓冲区中 top-k 与 bottom-k 轨迹（按 $R_{ans}$ 排序），由 LLM 元优化器对比分析；
- 输出**结构化差异（structured diff）**：`{validate: [...], hypothesize: [...], revise: [...]}`，而非自由文本；
- 规则格式统一为"`[Label]: When [condition], [action]`"；
- 每条规则维护**证据等级**（tentative → supported → established），通过验证/修正操作或预测增益自动升降级，过滤噪声假设。

**② PDD：人设差异蒸馏**

- 先计算规则 $r$ 的**预测增益（Predictive Gain）**：
  \[
  PG(r) = P(Y=1|r^+) - P(Y=1|r^-)
  \]
- 再计算用户 $p$ 的**发散度（Divergence）**：
  \[
  D_p = \sum_{r \in S_u} |PG(r|p) - PG(r)|
  \]
- 只有 $D_p \geq \theta_{div}$（θ=0.3）的用户才触发个性化规则生成，冷启动用户默认使用通用规则；
- 生成规则约束为"行为条件化"（behavior-conditioned）：描述管理动作而非内容偏好，保证对未见用户的泛化。

**③ Cross-Level Rule Flow：跨层规则流**

- **泛化（$\Delta_p \to S_u$）**：个性化规则若在 ≥θ_flow（0.6）比例的个性用户中得到"supported"以上验证，则提升为通用规则；
- **特化（$S_u \to \Delta_p$）**：通用规则被修订/降级时，曾受益于该规则的用户的替代方案以个性化形式保留在 $\Delta_p$ 中。

**④ 策略注入与反循环设计**

- **子模选择**：在 token 预算 B=200 内，按 $PG(r) \cdot (1 - \max\sigma(r,s))$ 贪心选择最有代表性且冗余最小的规则子集注入 prompt；
- **分离式奖励**：
  - $R_{ans}$（任务正确率）→ 仅用于轨迹排名和策略更新（蒸馏缓冲）；
  - $R_{follow}$（规则遵从度，按 PG 加权）→ 仅用于 GRPO 优势计算；
  - 两者分离防止"规则自我验证"的确认偏误，形成良性协同演化循环。

### 2.3 算法流程

```
每个训练步骤：
  1. 子模优化选择 Sp = Su ∪ Δp → 注入 prompt
  2. 策略 rollouts 收集轨迹；计算 Rans 和 Rfollow
  3. 仅用 Rans 更新蒸馏缓冲区；用 Rans + λ·Rfollow 做 GRPO 更新
  4. 每 K2 步：PDD 更新 Δp（对发散度≥θdiv 的用户）
  5. 每 K1 步：USD 更新 Su + 跨层规则流迁移
```

## 三、实验设计

### 3.1 数据集 / Benchmark（4 个基准，共 12 个评测设置）

| 基准 | 特点 | 评测设置 |
|------|------|----------|
| **PersonaMem** | 20 个模拟人设、7 类个性化查询、15 个任务领域 | 32K / 128K 上下文（in-domain） |
| **PrefEval** | 显式/隐式偏好，50 个干扰轮 | Explicit / Implicit |
| **PersonaBench** | 合成私人数据上的个性化检索与 QA | 4 种噪声水平（0/0.3/0.5/0.7） |
| **PERMA** | 事件驱动、10 国 10 用户画像、20 个领域 | 干净/噪声 × 单域/多域（C-S/C-M/N-S/N-M） |

### 3.2 对比方法（10 个基线）

- **原始上下文**：LongContext（直接输入全部历史）
- **检索方法**：RAG（向量检索）
- **记忆库方法**：Mem0、A-Mem、LightMem
- **RL 记忆智能体**：MemAgent、MEM-α、MemSkill

### 3.3 训练数据

- 423 条训练实例（采样自 PersonaMem 32K 子集的 70%）；
- 训练用检索后的对话作为上下文，推理用完整历史（4K-token 分块处理）。

### 3.4 主要结果

- **12 个设置全部取得最优**：PersonaMem 32K/128K 达 73.49 / 62.01（MemSkill 为 64.45 / 55.37）；
- **跨域泛化稳定**：PrefEval 显式 89.20、隐式 69.40，全面领先。

### 3.5 消融实验

在 PersonaMem 和 PERMA 上对 5 个组件（Flow / Gate / USD / PG / PDD）分别消融，共 10 组：

- **域内（PersonaMem）**：去除 USD 或 PG 降幅最大（128K 降至 53.70 / 52.22）→ 通用规则质量域内关键；
- **域外（PERMA）**：去除 Flow 致 C-S 从 66.95 降至 45.39（均值降 19.4 点），去除 Gate 均值降 11.9 点 → 跨层迁移和发散门控在域外至关重要；
- 发现**"域内/域外重要性翻转"**现象。

## 六、主要结论与发现

1. **层级协同演化有效**：将记忆策略分解为共享层 + 个性化层，并在训练中动态演化，显著优于静态统一策略（12 个评测设置全部最优）。

2. **共享/个性化边界必须动态校准**：跨层规则流机制对域外泛化至关重要（消融降幅最大），说明先验划分无法适应策略演化。

3. **组件重要性随场景翻转**：域内任务中通用策略质量（USD/PG）起决定作用；域外泛化中个性化机制（Flow/Gate）主导，揭示了记忆策略设计的"场景依赖"特性。

4. **策略可迁移**：蒸馏出的策略跨 backbone 有效（GPT-5 上达 71.48），说明学到的是模型无关的记忆管理原则。

5. **记忆可控增长**：上下文从 4K 扩展到 128K 时，记忆库大小从 ~1000 增至 ~1900 tokens 后趋于平缓，压缩与筛选有效。

6. **个性化收益不均**：Δp 对多数用户显著提升（最高 +18.6%），但少数用户反而受损（-3.3%），验证了发散门控的必要性。

## 七、优点与亮点

1. **问题定义新颖且实际**：首次系统化地定义了"记忆策略的共享-个性化边界必须经验发现"这一问题，直击现有方法"静态一刀切"的短板。

2. **方法论设计精巧**：
   - 结构化 diff 替代自由文本反馈，保证规则粒度与可追踪性；
   - 证据等级生命周期（tentative/supported/established）配合预测增益双通道验证，有效滤除噪声假设；
   - **反循环设计**（任务奖励用于蒸馏、遵从奖励仅用于策略优化）在方法论上严格切断了规则自我验证的路径，是协同进化框架可信度的关键保障；
   - 发散门控（divergence gating）巧妙地用 $PG$ 的相对排序特性避免对绝对质量的依赖，兼具理论合理性与计算效率。

3. **诊断发现具有启发性**：域内/域外组件重要性翻转是一个有价值的经验发现，为后续记忆系统设计的场景适配提供了方向。

4. **实验覆盖面广**：4 个基准 × 12 设置 + 跨模型迁移 + 参数敏感性 + 定性分析，验证链完整。

5. **策略可解释、可迁移**：自然语言规则可检查、可编辑，跨 backbone 可用，实用价值高。
