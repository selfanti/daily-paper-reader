## 摘要
智能体检索增强生成（RAG）要求语言模型决定何时继续搜索、何时作答。现有的基于强化学习的方法依赖外部监督，并忽略了智能体关于当前证据是否充分的内部信念。为解决这一问题，我们将搜索决策质量重新表述为信念-行动对齐，并提出MetaRAG，一种面向智能体RAG的信念-行动对齐策略优化框架。MetaRAG使用先验证后行动生成（Verify-first Action Generation）在每个实际行动之前引出显式验证过程，并使用内部信念探测（Internal Belief Probing）从相同的问题-历史上下文中估计策略模型自身的可回答性信念。基于这些，MetaRAG推导出一致性奖励，并进一步以答案正确性为门控，避免强化内部一致但错误的轨迹。信念探测仅在训练期间使用，不引入推理时开销。在七个公开QA基准上的实验表明，MetaRAG相比强基于RL的智能体RAG基线，持续改善了准确性与效率的权衡，且其增益可迁移至深度研究场景、不同优化器及多种模型骨干。

## Abstract
Agentic retrieval-augmented generation (RAG) requires language models to decide when to continue searching and when to answer. Existing RL-based methods rely on external supervision and overlook the agent's internal belief about whether the current evidence is sufficient. To address this problem, we reformulate the search decision quality as belief-action alignment and propose MetaRAG, a belief-action aligned policy optimization framework for agentic RAG. MetaRAG uses Verify-first Action Generation to elicit an explicit verification process before each actual action, and Internal Belief Probing to estimate the policy model's own answerability belief from the same question-history context. Based on these, MetaRAG derives a consistency reward that is further gated by answer correctness, avoiding reinforcement of internally consistent but incorrect trajectories. The belief probe is used only during training and introduces no inference-time overhead. Experiments on seven public QA benchmarks show that MetaRAG consistently improves the accuracy-efficiency trade-off over strong RL-based agentic RAG baselines, with gains that transfer to deep research settings, different optimizers, and multiple model backbones.

## 1. 核心问题与研究动机

- **研究背景**：检索增强生成（RAG）将外部证据引入语言模型输出，已成为知识密集型问答的标准范式。智能体 RAG（Agentic RAG）进一步要求模型在多轮交互中自主决定"何时检索、检索什么、何时作答"。每步决策都涉及证据充分性与检索成本之间的权衡，因此 **SEARCH / ANSWER 的决策边界**成为智能体 RAG 的核心问题。
- **核心痛点**：
  - **边界校准不良（boundary miscalibration）**：过度检索（over-search）导致不必要成本并引入干扰证据；过早作答（under-search）则产生不可靠输出。
  - **现有 RL 方法的缺陷**：① 通用步级信用分配（如 GiGPO）虽能抑制冗余检索，但未显式针对过早作答；② 外部评判过程监督（如 HiPRAG）诊断更直接，但依赖昂贵的 LLM 评判或因果干预。
  - **根本问题**：无论哪种方法，SEARCH/ANSWER 决策都只从外部监督，而智能体内部关于"证据是否充分"的信念（本应驱动该决策的信号）被弃置不用，导致行动与自身信念发生偏移（belief-action mismatch）。
- **核心主张**：将搜索决策质量重新定义为**信念-行动对齐（belief-action alignment）**——代理在每一步应选择与其自身可回答性信念一致的行动（相信充分则 ANSWER，相信不足则 SEARCH）。过度检索与过早应答被视为同一种信念-行动失配的两种方向。

## 2. 方法论：MetaRAG

### 核心思想
MetaRAG 通过耦合两个互补信号来校准 SEARCH/ANSWER 边界：
- **先验证后行动生成（Verify-first Action Generation）**：生成实际行动前，先引出显式验证推理；
- **内部信念探测（Internal Belief Probing）**：在相同上下文上以独立前向传播估计模型自身的可回答性信念。
二者失配即诊断为"信念-行动间隙"，并转化为一致性奖励用于策略优化。

### 关键技术细节

| 模块 | 技术要点 |
|---|---|
| **Verify-first Action Generation** | 先提出候选动作类型（SEARCH 或 ANSWER），再要求模型执行"验证前置推理"（Verify-before-Action Reasoning）后承诺实际动作。候选动作是决策假设而非强制标签，模型可接受或拒绝；训练与推理时均采用此策略。 |
| **Internal Belief Probing** | 对相同上下文额外运行一次前向传播，提示模型仅输出 "Yes"/"No"，取下一 token 的 logits：公式 (1) `P(Yes), P(No) = softmax(ℓ_Yes, ℓ_No)`；公式 (2) 信念分数 `b_t = P(Yes) − P(No) ∈ [−1, 1]`。分数越大表示模型认为当前上下文越可回答。探测仅在训练时用于奖励计算，推理零开销。 |
| **Belief-Action Gap Diagnosis** | 令 m ∈ [0,1) 为边界；`b_t > m` 表示自信可回答，`b_t < −m` 表示自信不足，`|b_t| ≤ m` 为 Margin Zone（信号不可判）。公式 (3)：`o_t = 1` 当且仅当 `(b_t > m 且 α_t = ANSWER)` 或 `(b_t < −m 且 α_t = SEARCH)`；`b_t > m 但 SEARCH` 诊断为 OVER-SEARCH；`b_t < −m 但 ANSWER` 诊断为 UNDER-SEARCH；`o_t = 1` 为 OPTIMAL。 |
| **Consistency Reward Calculation** | 公式 (4)：`R_consist(τ) = (1/T_τ) Σ o_t`；配合结果奖励 `R_outcome = I[EM(ŷ, y*)]`；公式 (5)：**`R_total = R_outcome · (1 + λ·R_consist)`** —— 乘法门控保证错误轨迹即使内部一致也得到零奖励，防止"自信早停/回避检索"等奖励黑客行为。λ 控制对齐强度（默认 0.1）。 |

### 算法流程（Algorithm 1）
1. 用 Verify-first Action Generation 推出轨迹 τ；
2. 提取最终答案和每步动作类型；
3. 对每步运行 Internal Belief Probing，计算信念分数 b_t；
4. 按阈值比较 b_t 与动作类型，给出步级诊断 o_t（OPTIMAL / OVER-SEARCH / UNDER-SEARCH / Margin Zone）；
5. 聚合 R_consist、计算 R_outcome、得到 R_total 供 RL 优化。

## 6. 主要结论与发现

1. **准确率-效率权衡全面改善**：Qwen2.5-3B 上平均准确率 41.7%（超 GiGPO 1.9 点），7B 上 45.4%（超 1.5 点）；多跳基准上全胜。
2. **收益来源是信念-行为对齐而非单纯改变检索频率**：相比 HiPRAG 用更少搜索获得更高准确率；相比 GiGPO 多搜索但准确率更优。
3. **训练动态揭示机制**：MetaRAG 初期因未做 SFT 预热而落后于 GiGPO，中后期反超；一致性奖励稳定上升，under-search 率在约 100 步后持续低于 GiGPO（外部 LLM 法官验证同样趋势）。
4. **消融证伪替代解释**：去掉一致性奖励导致检索数从 1.60 涨到 2.14；去掉验证前置导致准确率降至 40.4%；仅靠推理期 prompt 改变对 GiGPO 无益。
5. **知识边界感知增强**：标准 agentic RAG 训练（Search-R1/HiPRAG/GiGPO）会削弱模型区分可回答/不可回答查询的能力，MetaRAG 反而提升（AUROC 59.5→60.2，PRR 20.5→21.8）。
6. **跨设置鲁棒**：DAPO 下仍增益 0.9 点；Llama3.2-3B 与 Qwen3-14B 上均超 GiGPO；零样本迁移 BrowseComp-Plus 时准确率和证据召回率均最佳。
7. **框架兼容性强**：MetaRAG (GiGPO) 组合在 3B/7B 上进一步提升至 43.1%/47.0%。

## 7. 优点与亮点

- **问题表述新颖**：将过检索与检索不足统一为"信念-行动边界失配"，概念上具有理论简洁性。
- **轻量监督范式**：诊断信号来自策略模型自身，无需外部 LLM 评判或反事实轨迹，训练成本显著低于 HiPRAG（281s vs 525s/步）。
- **正确性门控防奖励黑客**：`R_total = R_outcome · (1 + λR_consist)` 的乘法结构是防止"自信但不正确"轨迹被强化的关键设计。
- **推理零开销**：信念探针仅在训练时使用，推理无需额外前向传播。
- **验证前置推理的可迁移性**：verify-first 推理提供了更好的决策接口，训练后即使推理时禁用仍有增益（41.5% vs 41.7%）。
- **实验严谨性**：覆盖面广（7 基准 + 深度研究 + 3 优化器 + 4 骨干 + 8 消融 + 超参网格），对内部信念诊断的循环性担忧做了外部法官验证，附有正反案例（图 6-7、11-12）。

## 8. 不足与局限

- **训练开销**：信念探测增加一次额外前向传播，verify-first 推理增加生成长度；训练比 GiGPO 慢约 13%（249s→281s），推理延迟也略增。
- **实验范围受限**：仅覆盖 QA 型 Search/Answer 决策场景；不直接监督搜索查询的词汇质量、生成的 rationale 忠实度，以及更复杂的工具调用（多工具、开放浏览、长程规划）。
- **信念信号可靠性问题**：margin 超参存在"覆盖-可靠性"权衡（m=0 最佳但更大 margin 时非单调），说明信念信号的边界行为尚未完全理解；附录也表明更强探针（Internal Confidence）反而增加检索数，提示探针选择会影响权衡。
- **基线复现局限**：部分基线结果直接引用 Xia et al. (2026)，其训练设置可能与 MetaRAG 存在细微差异（作者尽力统一检索设置并标注 ‡）。
- **外部验证的有限性**：外部 LLM 法官的 under-search 率标准更严格（35.6%→30.1%），绝对数值与内部诊断不一致，说明两类标准存在偏差。
- **潜在技术深度限制**：真实世界"可回答性"依赖多跳推理后的综合判断，简单的 yes/no logit 差可能难以捕捉复杂不确定性（作者以替代探针部分缓解，但仍是近似）。论文还自述存在误用风险（大规模信息收集、监控、虚假信息生成），需在部署时加以防护。
