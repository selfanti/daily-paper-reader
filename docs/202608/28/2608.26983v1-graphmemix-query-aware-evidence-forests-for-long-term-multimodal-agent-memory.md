## 摘要
组织多模态智能体的长期记忆仍具挑战性，因为现有方法要么依赖昂贵的与查询无关的离线摘要，要么采用朴素的嵌入相似度匹配，从而引入不完整和冗余的上下文。为解决这些问题，我们提出了GraphMemix，一种组合优化图记忆框架，将记忆组织建模为查询感知的证据森林构建。具体而言，我们的方法包含三个关键组件：（1）候选图构建，通过模式与语义关系扩展多视图种子记忆，以获取查询感知的原始上下文；（2）证据效用与激活成本，将直接记忆支持与锚定条件的关系验证解耦，以抑制冗余或冲突信息；（3）森林优化，在最大证据预算及其可靠关系结构下，联合选择森林格式的记忆上下文。通过将记忆组织为查询相关的子图，该方法避免了高昂的生命周期成本，并恢复了低相似度的补充证据。在四个长期多模态记忆基准上的实验结果表明，该方法在不同基础模型下均取得了显著改进，并在准确性与生命周期成本之间建立了新的帕累托前沿。

## Abstract
Organizing long-term memory for multimodal agents remains challenging because existing methods either suffer from expensive question-agnostic offline summaries or naive embedding similarity matching that introduces incomplete and redundant context. To address these issues, we propose GraphMemix, a combinatorial-optimization graph memory framework that models memory organization as query-aware evidence-forest construction. Specifically, our method consists of three key components:(1) candidate graph construction, which expands multi-view seed memories through schema and semantic relations to acquire query-aware original context; (2) evidence utility and activation costs, which decouples direct memory support from anchor-conditioned relation verification to suppress redundant or conflicting information; and (3) forest optimization, which jointly selects a forest-format memory context under a maximum evidence budget and its reliable relational structure. By organizing memory into a query-relevant subgraph, the method avoids substantial lifecycle cost and recovers low-similarity complementary evidence. Experimental results across four long-term multimodal memory benchmarks demonstrate significant improvements with different foundation models and establish a new Pareto frontier between accuracy and lifecycle cost.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：多模态智能体（LVLM agent）需要长期记忆来维持跨会话、多模态交互的一致性，但现有记忆组织方法存在两类根本缺陷：
  - **问题无关的离线摘要**（如 MIRIX、SGM、A-MEM、AUGUSTUS、M²A）：在查询到来前对全部历史做通用压缩，冷启动和持续更新成本极高，且可能丢失后来起决定作用的视觉属性、状态转换或局部上下文。
  - **朴素的嵌入相似度匹配**（如 MuRAG、Pensieve、MemGuide、UniversalRAG）：只按查询-记忆相似度排序，容易过度选择近重复内容、遗漏低相似度但有互补价值的记录，忽略证据之间的联合效用。
- **整体含义**：作者提出 **GraphMemix**，将长期多模态记忆组织建模为**查询感知的证据森林构建**（query-aware evidence-forest construction）问题，把记忆选择看作组合优化：节点表示单条记忆的直接效用，边表示锚定条件下的增量价值，目标是在有限证据预算下联合选择节点和可靠关系，从而在不做全量离线预处理的前提下，恢复低相似度但必要的互补证据。

## 2. 方法论：核心思想、关键技术细节与算法流程

GraphMemix 包含三个关键阶段：

1. **候选图构建（Candidate Graph Construction）**
   - **多视图检索**：每条记忆有多个检索视图（原始图像、标题、OCR、视频帧等），初始分数取所有视图与查询嵌入相似度的最大值：
     \( s_i(q) = \max_{u \in U_i} \text{sim}(h(q), h(u)) \)。
   - **查询相关子图发现**：利用两类关系构建发现图 \( G_{disc} \)：
     - **模式关系**（Schema edges）：如同会话、同位置、事件桥接、邮件与媒体对应等显式结构；
     - **语义关系**（Semantic edges）：互 KNN 近邻。
   - 从 Top-L 种子记忆出发，做 H-hop 扩展并保留 Top-M 候选，形成有界的候选图 \( C_q \)，保证后续语义推理规模可控。

2. **证据效用与激活成本（Evidence Utility and Activation Costs）**
   - **直接节点效用**：融合检索分数与一个 listwise 节点验证器（Node Verifier）的输出：
     \( p_i(q) = \sigma(\tau[\alpha s_i(q) + (1-\alpha)\tilde{v}_i(q) - \delta]) \)，
     其中 \( \tilde{v}_i \) 是归一化验证器分数，\( \alpha \) 平衡检索先验与条件判断。
   - **锚定条件关系验证（ECV）**：从高置信锚点 \( A_q \) 出发，仅检查锚点与候选之间的模式边；ECV（Evidence-Chain Verifier）为每个候选选择一个最佳锚点，预测增量支持分数 \( s^{inc}_{ai}(q) \)，并分配六种角色：`new_fact`、`clarification`、`corroboration`、`redundant`、`conflict`、`irrelevant`。仅保留正分且角色为前三种的边，形成可信边集 \( E^{trust}_q \)。
   - **边成本与独立链成本**：边不确定性成本 \( c_{ai}(q) = -\log w_{ai}(q) \)；独立证据链成本 \( C_{open}(S,F) = \kappa \, m(S,F) \)，其中 \( m(S,F) \) 是森林连通分量数。

3. **森林优化（Forest Optimization）**
   - 总目标：
     \[
     \max_{S,F} \sum_{i \in S} p_i(q) - \lambda \sum_{e \in F} c_e(q) - \kappa m(S,F)
     \]
     约束 \( |S| \le K, F \subseteq E^{trust}_q[S] \)。
   - 由于边成本非负，最优 \( F \) 必为森林，故 \( m(S,F)=|S|-|F| \)，可改写为等价的节点项 \( p_i - \kappa \) 与结构增益 \( B_e = \kappa - \lambda c_e \) 之和。这实现了自适应基数：孤立记忆必须证明自己值得开辟一条新证据链；加入已有组件则共享链成本。
   - **两阶段求解**：
     1. **固定基数提议**：从 Top-K 节点效用出发，用 1-swap 局部搜索 + Kruskal 算法对每个候选节点集计算精确最大权重森林，得到 K 节点提议 \( \bar{S}_q \)；
     2. **精确可变基数精修**：在冻结的提议内，枚举所有非空子集并用 Kruskal 精确求解最优森林，得到最终证据集与森林结构。

整个流程无需训练，只调用冻结的 LVLM 验证器和阅读器，并通过并行化降低额外耗时。

## 6. 主要结论与发现

- **显著性能提升**：在 Qwen3-VL 下，GraphMemix 四个数据集宏平均 Judge Accuracy 从最强基线 UniversalRAG 的 49.80% 提升到 61.55%（+11.75 个百分点）；在 Gemma 4 下提升到 67.42%（+12.33 个百分点），且在每个基准上都超过了所有公开基线。
- **同时提高原生指标**：ATM EM 53.83、Mem-Gallery EM 36.76、MemEye MCQ EM 54.25、H2HMem Recall 54.70，表明在严格短答案、开放式回答、多选题和覆盖率任务上都有效。
- **较低生命周期成本**：在保持最高准确率的同时，GraphMemix 的完整生命周期时间比 A-MEM 快约 1.78×，比 VimRAG 快约 4.27×，比 LightMem 快约 4.74×，在四个数据集上均处于准确率-时间帕累托前沿。
- **确实能恢复低排序互补证据**：四个数据集都有相当比例的金标证据不在源 Top-10 中，但可通过关系扩展进入有界候选图；GraphMemix 在 40.08%–68.48% 的合格问题上至少恢复一条此类金标证据。
- **联合森林优化优于点式关系加分**：增量消融中，仅将 ECV 关系作为点式奖励只提升 0.90 点；而联合节点-边优化进一步将宏平均从 59.70% 提升到 61.55%，证明“结构化集选择”是增益的关键。
- **ECV 能够抑制冗余**：相比固定边，ECV 边将每问题选定边数从约 6–7 降到 0.25–1.47，同时提升 Hit@10，说明角色门控有效过滤了无价值的传播。
- **两个验证器职责分离更优**：分离直接支持判断与条件增量判断在宏平均 Accuracy 和 Recall@10 上分别提升 2.00 和 3.00 点。

- **LLM-as-judge 的主指标风险**：虽然做了抽样一致性审计，但 GPT-5-mini 对长答案、弱差异答案的系统性偏好（如对冗长或格式相近答案的倾斜）并未完全消除；原生指标与 Judge Accuracy 之间的相关性未被量化。
- **参数敏感性分析不足**：关键超参数（Top-L、H、Top-M、α、λ、κ、δ）在所有试验中固定，论文未提供网格扫描或敏感性曲线，读者难以判断这些参数在未知数据集上的鲁棒性。
- **基线范围偏窄**：对比方法集中在记忆系统，未与通用的长上下文 LVLM（直接把全部记忆塞入上下文）或迭代式多轮检索+RAG 管线对比，难以界定 GraphMemix 相对“更强上下文模型”的增益来源。
- **内存与索引细节缺失**：多视图嵌入的存储开销、每查询子图扩展的时延统计、以及 6,592 个问题的审计实验具体耗时均未披露，工程复现需要自行测试。

## 9. 综合评价与适用场景建议

- **总体评分**：方法创新性 9/10，实验严谨性 8/10，工程实用性 8/10，可复现性 7/10，写作清晰度 9/10。综合约 8.2/10（Strong Accept 级别）。
- **适用场景**：
  - 个人多媒体记忆助手（照片、邮件、视频的跨模态问答）；
  - 多轮/多方对话中需组合多条历史证据的决策问答；
  - 对延迟不敏感但对准确性要求高的离线批处理记忆服务。
- **不适用场景**：
  - 实时交互中需要毫秒级响应的记忆查询（多步验证器的开销难以满足）；
  - 历史记录完全无元数据的纯视觉库（关系扩展收益受限）；
  - 无法负担多次 LVLM 推理调用的小规模部署。

## 10. 一句话总结

GraphMemix 通过“查询感知的证据森林构建”，将一个看似检索的问题重新定义为可精确求解的联合节点-边组合优化，在不训练、不预处理的状态下显著提升了长期多模态记忆问答的准确率与效率，为记忆增强智能体提供了新的范式，但其验证成本与参数敏感性仍需在更广泛的实际场景中进一步检验。
