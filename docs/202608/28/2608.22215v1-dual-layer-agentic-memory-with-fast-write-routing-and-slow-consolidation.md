## 摘要
大型语言模型（LLM）智能体在动态环境中运行，其中知识不断演化。现有的记忆系统通常将外部记忆视为单调增长的存储库，这不可避免地导致检索性能下降以及计算成本随时间增加。我们认为，核心挑战不仅仅是检索，而是管理知识生命周期：决定哪些知识需要外部化、更新或最终内化。受神经科学中互补学习系统（CLS）理论的启发，我们提出了双层智能体记忆（Dual-Layer Agentic Memory），该框架通过成本感知的认知路由和周期性参数整合，将记忆管理转移到写入阶段。传入信息被分类为不写入、写入新内容或写入更新，并通过从小到大（small-to-large）的模型级联进行路由，该级联在过滤冗余记忆的同时最小化路由开销。随后的写回阶段通过监督微调选择性地将高价值的外部记忆整合到模型参数中。实验证明了我们方法的双重效率：一个1.7B/8B级联可剪除高达68%的冗余外部记忆，同时仅升级不到50%的输入，却保留了穷尽保留基线所实现的下游问答精确匹配（EM）的98%以上。我们进一步表明，周期性整合成功地将外部知识内化，使得路由器能够随着模型认知边界的发展自适应地抑制冗余写入。总体而言，我们的框架为智能体记忆提供了一种统一范式：先选择性外部化，再选择性内化。代码和数据集将在论文被接收后发布。

## Abstract
Large language model (LLM) agents operate in dynamic environments where knowledge continuously evolves. Existing memory systems typically treat external memory as a monotonically growing repository, inevitably leading to retrieval degradation and increasing computational costs over time. We argue that the core challenge is not retrieval alone, but managing the knowledge lifecycle: deciding what to externalize, update, or ultimately internalize. Inspired by Complementary Learning Systems (CLS) theory in neuroscience, we propose Dual-Layer Agentic Memory, a framework that shifts memory management to the write phase through cost-aware epistemic routing and periodic parametric consolidation. Incoming information is categorized as non-write, write-new, or write-update, and routed through a small-to-large model cascade that minimizes routing overhead while filtering redundant memories. A subsequent write-back phase selectively consolidates high-value external memories into model parameters via supervised fine-tuning. Experiments demonstrate the dual efficiency of our approach: a 1.7B/8B cascade prunes up to 68% of redundant external memory while escalating fewer than 50% of inputs, yet retains over 98% of the downstream QA Exact Match (EM) achieved by an exhaustive retention baseline. We further show that periodic consolidation successfully internalizes external knowledge, allowing the router to adaptively suppress redundant writes as the model's epistemic boundaries evolve. Overall, our framework presents a unified paradigm for agent memory: selective externalization followed by selective internalization. Code and dataset will be released upon acceptance.

- **神经科学启发**：受互补学习系统（CLS）理论启发，生物记忆由快速学习的海马体（可编辑的暂时缓冲）和慢速学习的新皮层（稳定的长期表征）构成，通过离线回放（如睡眠）进行整合。作者将这一机制类比到智能体记忆：外部记忆 = 海马体快速缓冲，参数记忆 = 新皮层稳定存储，写回 = 睡眠整合。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 整体架构

- **双层载体层**：参数记忆 Θ（稳定、压缩、低成本访问）与外部记忆 E（显式、可编辑、适合动态或冲突知识）。
- **双层决策层**：快速写入路由（Fast Write Routing）与慢速写回整合（Slow Consolidation / Write-back）。

### 2.2 操作性知识分类（Operational Taxonomy）

基于模型在零样本 vs 记忆支持下的行为表现，对每个知识条目分类：
- **non-write（不写）**：零样本即可正确回答 → 参数已包含该知识，无需外部化
- **write-new（写新）**：零样本拒绝回答，提供记忆后回答正确 → 参数缺失该知识
- **write-update（写更新）**：零样本给出非拒绝但错误的回答，提供记忆后回答正确 → 参数知识过时或冲突

### 2.3 快速写入路由（Fast Write Routing）

- **核心设计**：将写入决策转化为**二值准入决策**（写入 vs 丢弃），而非显式三分类。写入收益定义为：
  \[
  r(W) = \text{EM}(W) - \text{EM}(D) - \lambda_s, \quad r(D) = 0
  \]
  其中 EM(W)/EM(D) 为写入/丢弃时的下游 QA Exact Match，λs 为存储惩罚。
- **小到大（small-to-large）级联路由**：
  - 小路由（1.7B backbone + MLP 决策头）先对所有输入做低成本筛选
  - 门控模块估计升级收益 \( g^* = V_{\text{large}} - V_{\text{small}} \)，仅当预计收益为正时才升级到 8B 大路由
  - 升级惩罚 λe 控制升级比例
- **特征构造**：
  - 语义特征：对 LLM 末层隐藏状态做均值池化 \( e = \frac{1}{L}\sum h_t \)
  - 不确定性特征：token 级负对数似然均值 \(\bar{\ell}\)、序列长度、重采样的 NLL 曲线（Interp64）三者拼接
  - 门控输入包括小路由预测、两者预测差异等
- **训练**：MLP 决策头以 MSE 回归奖励目标，LLM backbone 冻结；门控以小/大路由贪心动作构造监督信号训练。
- **收益**：约 40–49% 的输入升级到 8B，相比全部使用 8B 节省 30–39% 推理成本。

### 2.4 慢速写回整合（Write-back as Slow Consolidation）

- 将保留的外部记忆中 **write-new 和 write-update** 事实转换为监督信号：
  - 问答级样本：\( (q_{ij}, a_{ij}) \)
  - 句子级目标：\( (f_i, f_i) \)
- 用标准因果语言建模 SFT 损失优化参数 Θ → Θ′。
- **条件性移除**：仅当更新后的模型对相关探针无检索也能正确回答（EM ≥ τ_flush）时，才将事实从外部记忆移除；否则保留。
- 这形成完整生命周期：外部化 → 内部化 → 淘汰。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **在线流式评测环境**：新构建，300 个 episodes（测试集），每 episode 500 轮对话，100 个候选事实注入，共 150,000 个查询。关键性质：
  - (P1) 覆盖性：每个事实注入一次且至少被探测一次
  - (P2) 因果性：查询不会先于其支持事实出现
  - (P3) 活性：turn 0 至少有一个知识注入

## 6. 主要结论与发现

1. **选择性外部化的双重效率**：1.7B/8B 级联路由仅升级 40–49% 输入至 8B，剪除高达 **68% 的冗余外部记忆**，却保留约 **98.3% 的 Full Store 上线 EM**。在基座模型设置下，Write Router（λs=0.08, λe=0.005）达到 86.35% EM、77.00% 存储率，同时优于全 8B 监督策略（Logistic Regression 83.84%、MLP 83.18%）且计算成本更低。
2. **知识内化与认知边界迁移**：SFT 写回后，存储率从 64.81% 骤降至 **32.08%**（λs=0.2），零样本 QA EM 从 38.02% 提升到 69.16%（No Store），路由器自适应识别已内化知识并抑制冗余写入，Store Precision 达到 97.85%。
3. **标签迁移分析揭示三种现象**（30,203 个事实）：
   - **参数内化**：10,683 个检索依赖事实（5,785 write-new + 4,898 write-update）转变为 non-write
   - **部分吸收**：7,939 个 write-new 转为 write-update（模型获得部分语义熟悉性但尚未精确掌握）
   - **参数干扰**：1,752 个原本稳定的 non-write 事实退化为 write-update——**灾难性遗忘的直接证据**，这为双层架构提供了经验动机：外部记忆作为动态纠正参数回退的缓冲层。

## 7. 优点与亮点

- **理论驱动的架构设计**：将神经科学 CLS 理论落地为工程可操作的记忆架构，对外部化与内化给出统一范式。
- **视角创新**：将记忆管理的重心从"读阶段检索"前置到"写阶段准入"，提出操作性行为标签（基于模型行为而非抽象语义判断），可自动标注、可扩展。
- **成本感知的级联路由**：不仅优化记忆存储，还优化路由本身的计算开销，小到大模型级联在过滤不确定性的同时控制推理成本，形成了 EM–存储–计算三维的 Pareto 前沿优化。
- **在线流式 Benchmark**：严格解耦写入与读取，通过结构化调度（Algorithm 1）保证覆盖性、因果性、活性、干扰暴露四性质，且 O(T log T) 高效、可精确复现。
- **写回验证机制**：仅在整合成功后（EM ≥ 阈值）才从外部记忆移除事实，避免盲目内化失败知识。
- **自适应认知边界追踪**：路由器基于模型内部状态（隐藏状态 + 不确定性）做出决策，能感知参数记忆的变化，自动调整写入策略，形成知识生命周期的闭环。

## 8. 不足与局限

- **计算成本**：离线 SFT 写回带来内化延迟和较高计算开销；作者建议未来探索在线参数高效适配（如在线 LoRA）以缩短循环周期。
- **冲突更新处理缺失**：整合时将外部缓冲视为同一数据集，缺乏机制解决整合间隔期间积累的时间冲突更新（同一主题的互相矛盾事实）。
- **灾难性遗忘未主动缓解**：虽然外部层能缓冲参数干扰，但写回阶段本身不包含主动的防遗忘机制（如情节回放、权重正则化），这是终身学习的关键挑战。
- **实验覆盖有限**：仅在 ZsRE 数据集、qwen3 系列模型上验证；未在更大规模模型或多数据集上测试泛化性。路由器依赖的语义/不确定性特征可能在不同领域（如多模态、代码）或非英语语料上表现不同。
- **统计合理性存疑**：未报告误差棒或显著性检验，对随机性来源的讨论不足；类别不平衡、单一数据集可能影响结论的可外推性。
- **外部记忆的更新语义不足**：write-update 只标记"需要更新"，未解决如何确定新知识是否真的比旧参数知识更可信（来源可靠性、时间戳优先级等）。
- **路由特征局限**：基于序列平均隐藏状态和 NLL 曲线可能忽略长文档中关键位置信息；LLM backbone 冻结意味着无法随模型整合而更新特征提取器，可能导致路由与整合之间的表征漂移。
