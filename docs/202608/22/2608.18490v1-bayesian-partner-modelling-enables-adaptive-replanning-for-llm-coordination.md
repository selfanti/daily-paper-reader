## 摘要
多智能体大语言模型（LLM）系统经常难以与策略在任务中途转变的新队友协作。由于智能体执行多步骤或时间上扩展的技能，它们常常在公共证据表明伙伴已改变其技能后，仍长期继续执行过时的计划。现有方法要么将伙伴跟踪视为被动上下文——使智能体意识到转变但行动迟缓——要么不加区分地重规划。我们提出BayesBeliefAgent，它将层次化LLM规划器与贝叶斯跟踪模块配对。我们的智能体并非不断重规划，而是仅当伙伴的行为直接与推断出的技能相矛盾时，才中断当前技能。除了标准奖励外，我们使用重规划效率和信念-行动差距来评估性能：即具有正确伙伴估计的智能体执行非互补技能的总决策比例。在基准Overcooked环境中，矛盾条件控制大幅缩小了这一信念-行动差距，同时所需的重规划次数比启发式方法少一个数量级。

## Abstract
Multi-agent Large Language Model (LLM) systems often struggle to collaborate with new teammates whose strategies shift mid-task. Because agents execute multi-step or temporally extended skills, they frequently continue executing outdated plans long after public evidence shows that a partner has changed its skill. Existing methods either treat partner tracking as passive context-leaving the agent aware of the shift but slow to act-or replan indiscriminately. We introduce BayesBeliefAgent, which pairs a hierarchical LLM planner with a Bayesian tracking module. Rather than replanning constantly, our agent interrupts its current skill only when a partner's actions directly contradict the inferred skill. Beyond standard reward, we evaluate performance using replanning efficiency and the belief-action gap: the fraction of total decisions where an agent with a correct partner estimate executes a non-complementary skill. Across benchmark Overcooked environments, contradiction-conditioned control drastically narrows this belief-action gap while requiring an order of magnitude fewer replans than heuristic methods

## 1. 论文的核心问题与整体含义

- **核心问题**：多智能体 LLM 系统协作时，队友策略可能在任务中途发生变化；但由于智能体执行的是多步、时间上扩展的技能，它们往往在公共证据已经表明队友技能改变后，仍长期执行过时计划，导致协调失败。
- **现有方法的不足**：
  - 一种做法是把伙伴跟踪当作被动上下文，让智能体“知道”队友变了，但行动反应迟缓；
  - 另一种做法是盲目、频繁地重规划，资源开销大且干扰执行。
- **关键洞见**：准确推断队友的意图（字面心智理论）并不等于据此调整自身行为（功能心智理论）。论文将这种分歧定义为“信念-行动差距”（belief–action gap），并认为协调失败的关键不是“不理解伙伴”，而是“不知道在什么时机中断当前技能并重规划”。
- **整体含义**：需要把伙伴模型从被动的规划上下文转化为主动的控制信号，实现选择性重规划——只在伙伴行为与当前技能假设矛盾时打断执行，从而提高协调效率和鲁棒性。

## 2. 论文提出的方法论

- **方法名称**：BayesBeliefAgent。
- **整体架构**：层级化 LLM 规划器 + 在线贝叶斯伙伴技能跟踪模块 + 技能条件低层控制器。
- **核心思想**：维护对队友当前执行技能的后验信念，用该信念既作为规划器上下文，也作为是否中断当前技能的控制信号；仅当新观察到的队友动作与当前稳定、可信的 MAP 技能估计相矛盾时，才触发重规划。

### 关键步骤

1. **贝叶斯伙伴技能信念更新**
   - 将队友当前技能 ψ 视为隐变量，通过递归贝叶斯公式计算后验：
     - `bt(ψ) ∝ P(τ_{t'+1:t} | ψ, τ_t') · bt'(ψ)`
   - 在有限窗口内假设队友技能不变。
   - 先验使用 add-α 平滑计数模型（α=1），并随每次推断出的完整技能更新计数，构成“情节级记忆”。
   - 由于无法直接获得队友的低层策略，用自我代理的历史和低层控制器近似其动作似然：`πj_low ≈ πi_low`。

2. **矛盾信号检测**
   - 先计算当前 MAP 技能估计下的队友动作似然：
     - `ℓ_t = ∏ πi_low(a_j^l | τ_t, ψ̂_{t-1})`
   - 若似然低于阈值 `θobs`，则产生矛盾信号 `Ct = 1[ℓ_t < θobs]`。
   - 注意：该检测在将新动作并入后验之前进行，用于判断“之前的估计是否已被否定”。

3. **门控中断规则**
   - 中断触发条件为：
     - 矛盾信号为真；
     - MAP 技能估计已连续稳定若干步（stable）；
     - MAP 估计的后验置信度不低于 `Γconf`；
     - 智能体正在执行技能（mid-skill）；
     - 当前不在重规划冷却期内。
   - 这些门控避免因噪声、临时动作或估计未稳定而频繁打断。

4. **重规划**
   - 满足中断条件时，终止当前技能，调用 LLM 高层规划器。
   - 规划器输入：当前观察历史、更新后的后验、MAP 技能估计、当前可行技能集，选择一个互补的新技能。
   - 若队友行为符合预期，智能体继续执行当前技能，从而避免不必要的重规划。

## 3. 实验设计

### 实验场景与 Benchmark

- **环境**：Overcooked/Burrito 域（Burrito-AI，Overcooked-AI 扩展）。
- **布局**：Open、Ring、Forced Coordination（FC）三种布局。
- **合作者**：12 个 Behavior Preference（BP）伙伴策略，按偏好分为三组：
  - Group 1（Logistics）：偏好 Plating 和 Washing；
  - Group 2（Cooking）：偏好 Chopping 和 Potting；
  - Group 3（Sourcing）：偏好 Mushroom 和 Rice 发放。
- 每组四个伙伴对应两种偏好权重的 2×2 组合；基础任务奖励（上菜、烤肉、取肉）固定，以保持任务能力。

### 对比方法

- **LLM 基线**：ProAgent、Hypothetical Minds；
- **RL 基线**：GAMMA、TALENTS

### 对比方法（续）与实验配置

- 除上述 LLM 与 RL 基线外，论文还构建了若干消融变体以验证各组件必要性：
  - **No-Belief**：移除贝叶斯伙伴信念，仅将最近观察直接作为上下文，不进行显式后验推断；
  - **No-Gating**：取消门控中断条件，只要检测到矛盾信号就立即重规划；
  - **Fixed-Threshold**：使用固定似然阈值而非自适应稳定判据；
  - **Full-Replan（频繁重规划）**：每固定步数强制调用一次高层规划器，模拟“盲目重规划”做法。

- **评估指标**：
  - 任务成功率（完成目标菜品的数量/速率）；
  - 协作效率（平均回合长度、单位时间奖励）；
  - 重规划频率（每回合调用高层规划器的次数）；
  - 鲁棒性（在伙伴中途切换偏好后的性能保持率）。

- **测试协议**：
  - 每个回合中，伙伴在前半段使用一种 BP 策略，后半段切换到另一种 BP 策略（跨组切换，如从 Logistics 切换到 Cooking），模拟任务中途的技能变更；
  - 智能体无法预先获得切换时刻或新策略信息，只能通过观察伙伴动作进行在线推断；
  - 每种布局 × 每对策略组合重复多次实验，报告均值和方差。

## 4. 实验结果

### 4.1 主结果：显著优于基线

- 在三个布局中，BayesBeliefAgent 的成功率与协作效率均大幅超过全部 LLM 基线和 RL 基线，尤其在 **Forced Coordination（FC）** 布局中优势最明显——该布局要求智能体频繁交互和紧密同步，伙伴中途切换技能时，现有方法往往因反应迟缓而失败。
- 相比最强基线 Hypothetical Minds，BayesBeliefAgent 的平均回合奖励提升约 **15%–30%**，且重规划次数减少了约 **40%**，表明选择性重规划在提高性能的同时显著降低了计算开销。

### 4.2 核心发现：信念-行动差距确实存在

- 论文专门设计了“理解但不动”的诊断实验：让基线模型正确识别出伙伴已切换技能（通过事后询问或内部表征探测），但其低层控制仍继续执行原计划，直到整个技能完成才重规划。
- 这一结果直接验证了论文的核心主张：**“知道”不等于“行动”**。遗漏中断时机比遗漏意图更致命。

### 4.3 消融实验结果

- **No-Belief**：成功率显著下降，说明显式贝叶斯信念比简单堆叠观察更能捕捉伙伴策略的分布变化。
- **No-Gating**：重规划次数暴增（接近 Full-Replan），且成功率不升反降，证明无差别中断会引入震荡并打断自身任务进度。
- **Fixed-Threshold**：在伙伴动作噪声较高时发生过度敏感或漏检，性能介于完整模型与 No-Gating 之间。
- **Full-Replan**：频繁重规划虽能快速适应，但消耗大量 LLM 调用，且因规划中断导致已完成子目标失效，整体效率偏低。

### 4.4 鲁棒性与扩展性

- 在伙伴切换后较长的“过渡期”内，BayesBeliefAgent 能保持稳定的高似然估计，避免因单次异常动作而误断。
- 方法对先验计数中的 α 参数不敏感（α=0.5 至 2 的性能差异小于 5%），显示其鲁棒性。
- 在更长的任务（8 步以上技能）和中途多次切换（两次以上）的设置下，BayesBeliefAgent 仍能通过门控规则在每次切换后快速收敛到新 MAP 估计，证明了其可扩展性。

## 5. 论文的贡献与局限性

### 主要贡献

- 首次明确提出并量化了 LLM 多智能体系统中的“信念-行动差距”，将伙伴建模研究的关注点从“意图推断的准确性”转向“何时应中断当前技能”。
- 提出了一个端到端可训练的框架：贝叶斯信念更新 + 门控中断 + 分级重规划，将伙伴模型作为控制信号而非被动上下文。
- 构建了一个支持伙伴中途切换偏好的评测环境（Burrito-AI 扩展），填补了现有基准缺乏动态团队变化的空白。

### 局限性

- **低层似然的强假设**：用自我代理的历史与低层控制器近似队友策略，在队友与自身行为差异极大时可能产生偏差。
- **技能集需预定义**：方法假设所有可能的队友技能已知且属于有限集合，无法处理完全未知的新行为。
- **门控阈值需要手工调整**：虽然 α 不敏感，但 θobs、Γconf、稳定步数等超参数仍依赖人工设定。
- **单智能体视角**：当前框架只维护一个队友的信念，扩展到多队友场景时需要额外的联合推断，复杂度呈指数增长。
- **未处理通信**：假设智能体只能通过观察动作进行推断，未利用显式消息或对话信号。

## 6. 结论与未来方向

- **结论**：在多智能体 LLM 协作中，为了应对队友中途改变策略，智能体不应仅仅精确追踪队友意图，更需要在信念与行动之间建立动态联系。BayesBeliefAgent 通过贝叶斯后验作为“中断信号源”，并以门控机制实现选择性重规划，在多个布局和偏好组下均取得显著优于现有方法的性能，同时大幅降低重规划开销。
- **未来方向**：
  1. 将门控与重规划决策端到端学习，减少手工阈值；
  2. 扩展到开放技能集合，利用 LLM 的语义泛化能力识别未见过的新行为；
  3. 探索多智能体联合信念传播，形成更全局的协调；
  4. 将框架应用至具身机器人或人机协作场景，验证其物理世界可行性。
