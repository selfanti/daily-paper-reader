## 摘要
连续环境中的视觉与语言导航（VLN-CE）要求智能体在保持长期视觉历史以实现轨迹一致性的同时，以低延迟执行动作。现有的基于视频的VLN方法通常难以同时满足这两个需求。为了应对这些挑战，我们提出了MemVLN，一种新颖的VLN框架，以实时推理效率（14 FPS）实现了最先进的性能。MemVLN利用视觉编码器处理连续观测，并利用大型语言模型（LLM）解释指令和生成动作。我们方法的核心是应用金字塔分辨率的情景记忆管理。该机制将计算集中在即时感知上，同时保留压缩的长期历史。作为该设计的补充，我们引入了程序记忆，通过紧凑的原子中层动作词汇表实现快速动作，以绕过自回归解码延迟。在VLN-CE上的实验表明，MemVLN-4B在R2R中比基线Qwen3-VL-4B架构高5.8%的SR，在RxR中高9.7%的SR，同时实现7倍的推理延迟加速。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to maintain long-horizon visual history for trajectory consistency while executing actions with low latency. Existing video-based VLN approaches typically struggle to satisfy both demands simultaneously. To address these challenges, we propose MemVLN, a novel VLN framework that achieves state-of-the-art performance with real-time inference efficiency (14 FPS). MemVLN utilizes a visual encoder to process continuous observations and a Large Language Model (LLM) to interpret instructions and generate actions. Central to our approach is an Episodic Memory management that applies pyramidal resolutions. This mechanism concentrates computation on immediate percepts while retaining compressed long-term history. Complementing to this design, we introduce Procedural Memory for fast action with a compact vocabulary of atomic mid-level actions to bypass auto-regressive decoding latency. Experiments on VLN-CE show that MemVLN-4B surpasses the baseline Qwen3-VL-4B architecture by 5.8\% SR in R2R and 9.7\% SR in RxR, while achieving a 7$\times$ speedup in inference latency.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题定义**：连续环境中的视觉与语言导航（VLN-CE）要求智能体在未预知地图的三维空间中，根据自然语言指令从起点导航至目标位置。该任务对智能体提出了两个看似矛盾的需求：
  - **轨迹一致性**：必须长期保留视觉观测历史，以防止路径漂移；
  - **实时响应**：必须在极低延迟内生成连续控制动作。
- **现有方法的不足**：
  - 基于视频的VLN方法（如固定均匀采样8帧）虽然关注长时视觉上下文，但实际牺牲了采样的时间密度，导致指令跟随中的细节丢失；
  - 一些尝试通过Token合并（Token Merging）压缩视觉序列的方法（如Uni-Navid、StreamVLN）会破坏均匀的2D空间网格，与现代视觉语言模型中的位置编码（如M-RoPE）和序列结构（如DeepStack）产生冲突。
- **本研究的含义**：智能体亟需一种能够同时兼顾长时历史精细管理、空间拓扑完整性以及低延迟动作输出的端到端导航框架。

## 2. 提出的方法论（核心思想与关键技术）

**核心思想**：受认知科学中人类“情景记忆”和“程序记忆”的启发，MemVLN通过分层分辨率管理视觉输入，并重构成原子动作词表来绕过自回归解码的延迟瓶颈。

- **总体架构**：视觉编码器处理单目RGB观测流；Qwen3-VL作为大型语言模型（LLM）骨干，负责指令理解、跨模态对齐与动作决策；最终输出一个原子动作Token。
- **技术细节 1：情景记忆（Episodic Memory）——金字塔分辨率（Pyramidal Resolution）**
  - **动机**：通过注意力分析发现，最近4帧占累计视觉注意力的50%以上，旧帧几乎被忽略。但模型仍不能丢弃旧帧，因为它需要保留全局路径的稀疏地标。
  - **实现**：将历史帧分为三个时间层级——即时（Immediate）、短期（Short-term）、长期（Long-term），以两个时间边界 \(B_{short}\) 和 \(B_{long}\) 分隔；对应分辨率按 \(r_{imm} > r_{short} > r_{long}\) 递减（实际设置为512²、256²、128²）。
  - **设计核心**：分辨率设计确保长期和短期所有帧的Token总数不超过一帧即时帧的Token数量，从而在固定上下文窗口内大幅扩展“回看”范围。
  - **兼容性**：该方法在原始像素域下采样而非潜空间Token融合，保持了严格的网格拓扑结构，完整支持M-RoPE和DeepStack。
- **技术细节 2：程序记忆（Procedural Memory）——快速动作（Fast Action）**
  - **动机**：VLN模型推理延迟的瓶颈来自LLM的自回归解码（预填充+逐Token生成），而非首Token效率或VLM骨干本身。
  - **实现**：将导航输出空间扩展为增广动作词表 \(A_{aug}\)。词表包含10种原子中层动作（如前进25cm/50cm/75cm、左转15°/30°/45°、右转15°/30°/45°、停止），每个动作通过复用LLM原始词汇表中的一个Token来表示，使得决策在单次前向传播中即可完成，完全绕开自回归循环。
- **训练目标与数据**：使用标准交叉熵损失进行监督微调，目标为单Token的动作预测（公式 \(L = -\frac{1}{T}\sum_{t=1}^{T} \log P(a_t^* | F_t, I; \theta)\)）。训练数据融合了R2R、RxR及其EnvDrop增强，外加ScaleVLN（416K对）、557K人类轨迹和278K DAgger合成数据。

## 6. 主要结论与发现

1. **精度与效率双SOTA**：MemVLN-8B达到R2R-CE SR 58.4%、RxR-CE SR 66.0%的领先水平；MemVLN-4B在R2R和RxR上较基线Qwen3-VL-4B分别提升5.8%和9.7%的SR。
2. **反向规模效应**：MemVLN-4B在RxR上（SR 66.5%）不降反升、优于8B版本，推测与更快的响应速度带来的“控制流畅度”增益有关，也可能反映指令细粒度信息在RxR中的重要作用。
3. **单目RGB即可匹敌多传感器**：仅用单目RGB输入便超过了诸多使用全景图、深度和里程计信息的模型，说明跨模态对齐的有效性可弥补低维感知输入的不足。
4. **实时推理可达**：通过原子动作Token化，推理帧率从2 FPS大幅提升至14 FPS（单次决策约70ms），满足实时控制的时间约束。
5. **注意力分布决定设计**：视觉注意力呈现强烈的近因效应，金字塔分辨率中赋予近期帧高分辨率是性能提升的关键。

## 8. 不足与局限

- **实验场景单一**：仅在Matterport3D的室内场景中测试，未验证在室外、动态场景或其他具身智能任务（如操纵、行走导航）中的泛化能力。
- **对训练数据的高度依赖**：在跨数据集泛化（仅R2R训练→RxR测试）中SR仅38.4%，虽然优于基线但距离高鲁棒性仍有差距；性能提升显著依赖于大规规模DAgger数据。
- **计算门槛高**：模型基于Qwen3-VL-4B/8B，训练需8×H200（140GB），推理仍依赖GPU加速。作者明确指出难以部署在低功耗边缘设备，实际物理机器人的“实时”控制效果存疑。
- **动作词表有限**：原子动作只支持固定步长（25/50/75cm）和固定转角（15°/30°/45°），缺乏连续动作空间或更细粒度的速度/转向调节，碰撞规避能力未测试。
- **潜在的评估偏差**：RxR上的显著优势部分源于其指令更详细（语义支撑更强），而R2R/标准测试集指令相对简短，模型在简洁指令场景下的稳健性可能被高估。
