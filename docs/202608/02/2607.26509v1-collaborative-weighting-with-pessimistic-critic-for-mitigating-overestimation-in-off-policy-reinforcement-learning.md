## 摘要
用于连续控制的深度离策略强化学习算法通常依赖神经值函数逼近来指导策略改进。然而，时序差分学习引入噪声目标，导致非平稳优化，而贪婪策略更新会放大早期估计误差。此类误差的递归传播会导致演员-评论家方法中出现持续的过估计偏差和训练稳定性下降。现有方法试图通过优先采样或修改值学习目标来缓解此问题，但往往过度强调由有限数据覆盖或自举误差引起的高不确定性转移，从而进一步放大偏差。本文提出协作加权演员-评论家，一种统一框架，明确考虑值估计中的预测不确定性。CWAC采用分布性评论家来建模回报不确定性，并引入协作加权机制，联合重新加权TD误差和不确定性，从而在抑制噪声更新的同时，从可靠样本中进行鲁棒学习。此外，我们通过从回报分布中采样，纳入随机悲观值估计方案，有效缓解策略改进过程中的误差传播。CWAC可以无缝集成到现有离策略算法框架中，如SAC、TD3和DDPG，且开销极小。实验结果表明，我们提出的方法在多种模拟任务上显著提升了性能。我们的代码公开于https://anonymous.4open.science/r/CWAC-348E。

## Abstract
Deep off-policy reinforcement learning algorithms for continuous control typically rely on neural value function approximation to guide policy improvement. However, temporal-difference (TD) learning introduces noisy targets, resulting in non-stationary optimization, while greedy policy updates amplify early-stage estimation errors. The recursive propagation of such errors leads to persistent overestimation bias and degraded training stability in actor-critic methods. Existing approaches attempt to alleviate this issue via prioritized sampling or modified value learning objectives, but often overemphasize high-uncertainty transitions caused by limited data coverage or bootstrapping errors, thereby further amplifying bias.In this paper, we propose Collaborative Weighting Actor-Critic (CWAC), a unified framework that explicitly accounts for predictive uncertainty in value estimation. CWAC employs distributional critic to model return uncertainty and introduces a collaborative weighting mechanism that jointly reweights TD-errors and uncertainty, enabling robust learning from reliable samples while suppressing noisy updates. In addition, we incorporate a stochastic pessimistic value estimation scheme via sampling from the return distribution, which effectively mitigates error propagation during policy improvement. CWAC can be seamlessly integrated into existing off-policy algorithm frameworks such as SAC, TD3, and DDPG with minimal overhead. Empirical results demonstrate that our proposed method significantly enhances performance across a diverse range of simulated tasks. Our code is publicly available at https://anonymous.4open.science/r/CWAC-348E.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：深度离策略强化学习（off-policy RL）在连续控制任务中依赖神经网络值函数逼近来进行策略改进，但存在两个根本性挑战：
  - **TD学习引入噪声**：时序差分（TD）学习产生的近似目标带有噪声，导致优化过程非平稳；
  - **贪婪更新放大误差**：策略改进中的贪婪算子 `max_a Q(s,a)` 天然偏好带有正估计误差的动作，早期估计误差被递归放大，形成自增强的正反馈循环，最终导致**系统性过估计偏差**（overestimation bias）和训练不稳定。
- **现有方法的不足**：
  - **悲观类方法**（如惩罚高不确定性动作）：过度保守会抑制探索，导致次优性能；
  - **加权采样方法**（如优先经验回放 PER、LAP）：仅基于 TD-error 大小加权，但 TD-error 往往与估计不确定性纠缠，容易过度强调高噪声/高不确定性样本，反而放大偏差。
- **论文提出的解决方案**：提出 **Collaborative Weighting Actor-Critic (CWAC)**——一个统一的不确定性感知框架，将**分布性评论家（distributional critic）**、**协作加权机制**和**随机悲观值估计**有机结合，在抑制过估计偏差的同时保持探索能力和样本效率。
- **整体意义**：提供了一种即插即用的通用增强模块，可无缝集成到 SAC、TD3、DDPG 等主流离策略算法中，显著改善训练稳定性和最终策略性能。

## 2. 论文提出的方法论

### 2.1 核心思想

CWAC 包含三大相互协作的组件：

| 组件 | 定位 | 作用 |
|------|------|------|
| 分布性评论家 | 不确定性建模 | 用均值 Qθ(s,a) 和标准差 σθ(s,a) 刻画回报分布的预测不确定性 |
| 协作加权机制 | 样本重加权 | 联合自适应调整 TD-error 和不确定性对 critic 更新的影响 |
| 随机悲观值估计 | 缓解过估计 | 从回报分布中随机采样构造悲观估值，抑制贪婪策略更新引起的误差放大 |

### 2.2 关键技术细节

**① 随机悲观值采样（Stochastic Pessimistic Value Sampling）**

定义悲观值估计器：

```
Zθ(s,a) = Qθ(s,a) - b(σθ(s,a))
```

其中 `b(σ) = |ε|·σ` 为随机采样值，`ε ~ N(0, μ·I)` 为零均值高斯噪声，μ 控制悲观扰动强度。直觉上，将 Q 值分解为真实值加近似误差后，适度悲观偏置可以中和 `max` 算子导致的正向误差放大；但过度悲观会反转动作偏好，抑制有益探索。

**② 协作加权值学习损失函数**

```
L(θ) = E[ ω(s,a) · Huber(Qθ(s,a) - y) + ξ(s,a) · σθ(s,a) ]
```

其中 TD 目标 y 采用双 critic 的最小悲观值：

```
y = r + γ[ min_{i=1,2} Zθ'_i(s',a') - α log πφ(a'|s') ]
```

两个权重定义如下：

```
ω(s,a) = ( E[σθ(s,a)] / (σθ(s,a) + c) )^βω
ξ(s,a) = ( E[|δ(s,a)|] / (|δ(s,a)| + c) )^βξ
```

- **不确定性感知权重 ω**：高不确定性样本（σθ↑）被降权（ω↓），抑制不可靠高方差样本对值函数的影响，阻止过估计的递归传播；
- **误差条件不确定性权重 ξ**：大 Bellman 残差样本（|δ|↑）被降权（ξ↓），防止过早最小化 σθ（避免不确定性崩溃），维持探索梯度；
- **梯度协同**：当学习收敛（|δ|↓, σθ↓）时，权重 ξ、ω 回升，促进值函数的精细精修，形成保守估计与主动探索之间的动态平衡。

**③ 演员目标**

```
Jπ(φ) = E[ Zθ(s,a) - α log πφ(a|s) ]
```

通过最大化悲观采样值来更新策略，直接减少贪婪更新带来的最大化偏差。

### 2.3 算法流程（文字说明）

1. 初始化 critic 网络 Qθ1、Qθ2，actor 网络 πφ，目标网络，经验回放缓冲；
2. 与环境交互收集经验存入缓冲；
3. 采样 mini-batch，通过双 critic 的最小悲观值构造 TD 目标 y；
4. 根据 Eq. (5) 计算协作加权损失，梯度下降更新 critic；
5. 通过 Eq. (4) 计算随机悲观值 Zθ，用于 Eq. (8) 更新 actor；
6. 软更新目标网络参数；
7. 循环直至收敛。
