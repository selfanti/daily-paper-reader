## 摘要
多智能体系统通过协作、工具使用、多模态推理和编排来解决问题，但每个智能体都在由其观察、上下文和资源所定义的知识边界内运行。记忆不仅要保存和传递结果，还要跨交互保留和传递证据、角色特定上下文、决策、流程和经验。向量记忆和图记忆将这些结构扁平化为嵌入或二元痕迹，掩盖了涉及智能体、工具、文档、错误和证据的事件。这限制了知识共享、追溯、复用、修订和编排。我们提出了MAGE，一种基于超图的多模态数据库，专为多智能体系统的记忆引擎而设计。MAGE将智能体、消息、工具、错误、流程、文档、实体、决策和证据存储在异构时间超图中，将高阶协作事件保留为可复用的记忆。它支持决策驱动的更新、角色感知检索、验证、生命周期管理和预算受限的上下文打包。通过向智能体和编排器传递知识，MAGE在不修改模型的情况下扩展了它们的知识边界。实验表明，MAGE在各种记忆基线上表现更优。

## Abstract
Multi-agent systems solve tasks through collaboration, tool use, multimodal reasoning, and orchestration, but each agent operates within a knowledge boundary defined by its observations, context, and resources. Memory must preserve and transfer evidence, role specific context, decisions, procedures, and experience across interactions, not only outcomes. Vector and graph memories flatten these structures into embeddings or dyadic traces, obscuring events involving agents, tools, documents, errors, and evidence. This limits knowledge sharing, tracing, reuse, revision, and orchestration. We present MAGE, a hypergraph based multimodal database designed as a memory engine for MAS. MAGE stores agents, messages, tools, errors, procedures, documents, entities, decisions, and evidence in a heterogeneous temporal hypergraph, preserving high order collaborative events as reusable memory. It supports decision driven updates, role aware retrieval, validation, lifecycle management, and budget bounded context packing. By delivering knowledge to agents and orchestrators, MAGE expands their knowledge boundaries without modifying the models. Experiments show MAGE outperforms on various memory baselines.

## 1. 核心问题与整体含义

- **研究背景**：多智能体系统（MAS）通过智能体协作、工具调用、多模态推理与编排来解决复杂任务，但每个智能体都受限于自身的知识边界（上下文、角色、观察、工具与历史）。系统的整体能力不仅取决于单个智能体与编排策略，还取决于能否在知识边界之间保存和传递证据、角色上下文、决策、流程和经验。
- **三个核心挑战**：
  1. **缺乏记忆以扩展知识边界**：信息往往停留在产生它的智能体内部，其他智能体无法访问证据、决策或经验；持续引入新知识若依赖模型后训练，则成本高且可能导致灾难性遗忘。
  2. **知识传递模式受限**：MAS 之间的知识传递多为纯文本消息、摘要或中间输出，容易丢失证据、压缩不确定性、剥离角色语义，并使结论与其行动/来源脱节，错误容易传播。
  3. **记忆结构表达不足**：向量记忆保存孤立片段，图/树记忆主要捕获层级或二元关系，无法表达涉及智能体、工具、文档、实体、中间状态和时序依赖的高阶协作事件；二元边会割裂共享上下文并模糊多方共同产生的决策。
- **论文含义**：提出 **MAGE（Multi-Agents Graph Engine）**——一个基于**异构时态超图**的多模态记忆引擎，作为 MAS 的外部共享记忆层。它不修改模型参数，而是通过结构化超图保存高阶协作事件、支持角色感知检索与生命周期管理，从而在不训练的代价下扩展智能体的知识边界。

## 2. 方法论

- **核心思想**：将多智能体的协作经验建模为**异构时态超图**，把“事件”作为一等公民存储，而不是退化为二元边；通过“写路径（摄取 + 决策更新）”和“读路径（角色感知检索 + 预算受限打包）”来支撑记忆的写入、修正、验证、淘汰和复用。
- **超图数据模型**：
  - 10 种节点类型：`Task, Agent, Message, Action, Error, Memory, Insight, Procedure, Modality, Entity`。
  - 5 种超边类型：`NaryFact, Collab, ErrCorr, Evidence, Procedure`，分别表示 n 元事实、协作事件、错误修正、证据绑定与流程绑定。
  - 每个节点/超边携带双时态戳（事务时间与有效时间）、置信度、嵌入、来源与生命周期状态（active / deprecated / archived / deleted）。
  - 采用二分图物化方法存储，便于复用标准图索引。
- **写流程（摄取与决策）**：
  - 三类提取器：文本提取器 Φtxt、多模态提取器 Φmm（以“模态指针 + 文本代理”记录图片/表格等，保留原始对象溯源）、痕迹提取器 Φtrc（将 MAS 执行轨迹转成任务/代理/消息/动作/错误节点，以及 Collaboration 和 ErrorCorrection 超边，并蒸馏出可复用 Memory 与 Procedure）。
  - 对新记忆执行**四路决策策略**：ADD / UPDATE / DELETE / NOOP，由 LLM 判断或确定性启发式完成，通过余弦相似度、极性翻转和阈值（τ_n、τ_c、τ_u）决定是新增、合并、软删除还是忽略，并将决策具体化为超图重写与 MVCC 版本链。
- **读流程（角色感知检索）**：
  - 查询先嵌入，按角色允许的类型范围取种子；再沿二元边和超边成员关系做多跳展开；然后对候选做多信号打分（语义、角色权重、置信度、来源支持、新鲜度、使用次数、生命周期惩罚、token 成本）；最后在 token 预算约束下做“0/1 背包”式贪心打包，渲染为带类型标注的上下文。
- **维护与自进化**：
  - 去重合并：对相似节点用 `merged_into` 链接，胜出者选择更置信、来源更多、更稳定的节点。
  - 艾宾浩斯式保留曲线：使用次数越多记忆衰减越慢；综合价值函数综合置信度、保留度、使用次数、下游收益、来源数、矛盾数、存储代价等，低于阈值则逐步降级直至删除。
  - 归纳更高层的 Insight、Community、Archetype、MetaProcedure 节点，支持更粗略的检索。
- **编排执行**：Orchestrator 基于 Planner 记忆生成 AOV 依赖 DAG，按拓扑层分发到 Planner / Retriever / Executor / Critic，Critic 判定后可在残差上重新编排，最终把完整轨迹回写超图，形成可复用程序性记忆。
- **复杂度**：读路径 O(|Σρ|·k·log n + L·Δ·|S| + |X|log|X|)，写路径 O(K + Δ)，维护 O(n log n)。

## 3. 实验设计

- **数据集（12 个 QA 基准）**：
  - 纯文本：HotpotQA（多跳）、NQ-Open、TriviaQA、WebQuestions；
  - 多模态/文档图表：FinMME、DocVQA、InfographicVQA、ChartQA；
  - 视觉问答：A-OKVQA、ScienceQA、TextVQA、VizWiz。
  - 按“源文档是否已索引进共享图”划分 **IND** 与 **OOD** 两类。
- **LLM 后端**：GPT-4.1-mini（主驱动）、Claude-4.5-Sonnet、Qwen2.5-VL-32B-Instruct，统一参数与策略，用于跨模型鲁棒性研究（RQ2）。
- **对比基线（11 种）**：向量记忆（Mem0、A-MEM、MemoryBank）、反思式记忆（Generative Agents）、技能库记忆（Voyager）、时序图记忆（Zep / Graphiti）、层级 MAS 记忆（G-Memory）、会话/拓扑中心 MAS 记忆（MetaGPT、ChatDev、MacNet），外加 NoMem 无记忆对照。
- **指标**：SQuAD 规范化后的 Exact Match（EM）与 token-level F1。
- **研究问题与对应实验**：
  - RQ1：12 个数据集上的全量记忆基线对比；
  - RQ2：三种异构 LLM 后端一致性；
  - RQ3：四个历时探针（修正传播、矛盾消解、陈旧率、跨智能体迁移），外加 10 集连续回放；
  - RQ4：组件消融（去掉超边、角色、衰减、合并等）+ 配对投影对照；
  - RQ5：将 MAGE 作为外挂记忆接入 8 个 MAS 框架（Direct、Self-Refine、ReAct、MAD、PEC、MetaGPT、ChatDev、MacNet）；
  - RQ6：系统级性能（CRUD 延迟、吞吐率、去重率）。
