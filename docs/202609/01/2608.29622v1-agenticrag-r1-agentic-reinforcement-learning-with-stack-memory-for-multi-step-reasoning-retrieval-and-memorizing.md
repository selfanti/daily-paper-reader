## 摘要
检索增强生成（RAG）提高了大语言模型（LLM）的事实性，然而现有的RAG系统在处理需要自适应检索和中间上下文持续修正的复杂多步推理时往往力不从心。最近的基于强化学习（RL）的智能体RAG方法在一定程度上缓解了这个问题，但通常依赖于粗粒度的动作空间和轨迹级奖励，导致奖励分配薄弱，并偏向于短视、刻板的推理模式。为了解决这一问题，我们提出了AgenticRag-R1，一个通过记忆栈和细粒度动作空间深度融合推理、检索与记忆的强化学习框架，并辅以层次化的动作感知奖励和信息感知的轨迹拒绝策略，以实现有效的长视界学习。在涵盖多种骨干模型规模的多跳、开放域和智能体推理基准上的实验表明，AgenticRag-R1始终优于强基线模型。此外，AgenticRag-R1学习到了更稳健、可解释和记忆感知的推理行为，凸显了细粒度动作建模与信息感知优化对长视界推理的效果。我们的代码匿名公开于 https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox。

## Abstract
Retrieval-Augmented Generation (RAG) improves the factuality of large language models (LLMs), yet existing RAG systems often struggle with complex, multi-step reasoning that requires adaptive retrieval and continuous revision of intermediate contexts. Recent reinforcement learning (RL)-based agentic RAG methods partially alleviate this issue, but typically rely on coarse-grained action spaces and trajectory-level rewards, resulting in weak reward assignment and a bias toward short-horizon, stereotyped reasoning template. To address, we propose AgenticRag-R1, a RL framework that deeply integrates reasoning, retrieval, and memory via a memory stack and fine-grained action space, supported by hierarchical action-aware rewards and an information-aware trajectory rejection strategy to enable effective long-horizon learning. Experiments across a diverse set of multi-hop, open-domain, and agentic reasoning benchmarks, spanning multiple backbone model sizes, demonstrate that AgenticRag-R1 consistently outperforms strong baselines. Moreover, AgenticRag-R1 learns more robust, interpretable, and memory-aware reasoning behaviors, highlighting the effect of fine-grained action modeling and information-aware optimization for long-horizon reasoning. Our code is anonymous available at https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox.

## 论文总结：AgenticRag-R1——基于栈记忆的智能体强化学习用于多步推理、检索与记忆

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：检索增强生成（RAG）通过引入外部知识提升了 LLM 的事实性，但真实世界的复杂决策任务往往需要**多步、相互依赖的推理**，要求模型在推理过程中动态决定“何时检索、检索什么”，并将检索结果持续融入内部状态，实现推理与检索的深度耦合。
- **现有方法的不足**：早期方法依赖手工提示或 SFT，容易过拟合固定推理模式；近期基于强化学习（RL）的智能体 RAG（如 Search-R1、AEPO、ARPO、Mem1）虽取得进展，但仍存在两个关键挑战：
  - **挑战 1（C1）**：动作空间粗粒度、记忆不可逆。现有方法将推理和检索压缩为单一的 `<think>`/`<search>` 模板并仅以“追加”方式写入记忆，无法检查、修正或丢弃中间噪声，导致错误累积；奖励仅在最终答案上评估，缺乏对中间动作的细粒度分配。
  - **挑战 2（C2）**：训练轨迹信息量不足。多跳任务中大部分样本只需一次检索或浅层推理即可解决，短视轨迹往往获得更高即时奖励，RL 因此偏向低信息模板化行为，难以探索长视界推理能力。
- **论文目标**：提出 **AgenticRag-R1** 框架，通过记忆栈与细粒度动作空间深度融合推理、检索与记忆，并配合分层动作感知奖励和信息感知轨迹拒绝策略，实现稳健的长视界学习。

### 2. 方法论：核心思想与关键技术

**整体框架**：由两大组件构成——①动作中心训练范式（多动作 rollout + 分层奖励建模）；②信息增益感知的动态轨迹拒绝策略。

**（1）记忆感知的多动作建模（解决 C1）**

- 引入 **LIFO 记忆栈**，每个栈元素是一个语义完整的推理单元，支持 push/pop 操作，使推理过程可逆、可解释。
- 定义六类组合动作：
  - `<Plan>`（push）：生成子目标或高层策略；
  - `<Think>`（push）：记录内部推理；
  - `<Search>`（push）：构造查询并调用外部检索；
  - `<Backtrack>`（pop 后 push）：检测到错误时回滚到先前有效状态；
  - `<Summary>`（pop 后 push）：压缩近期记忆条目；
  - `<Conclusion>`（push）：输出最终答案。

**（2）分层奖励建模**

每 token 奖励为：
\[
r^{(k)}_i = (1 - I^{(k)}_{mask,i}) \cdot r^{(k)}_{out} + I^{(k)}_{act,i} \cdot r^{(k)}_{proc,i}
\]

- **结果奖励** \(r_{out}\)：基于最终答案与标准答案的 EM/F1 匹配；
- **过程奖励** \(r_{proc} = r_{fmt} + r_{rag} + r_{mem}\)：
  - **格式奖励** \(r_{fmt}\)：动作语法的正确性（Conclusion 权重 1.0，其他有效动作 0.5）；
  - **检索奖励** \(r_{rag}\)：用通用奖励模型（GRM）评估查询-证据-任务上下文的相关性；
  - **记忆奖励** \(r_{mem}\)：用 GRM 评估 Backtrack/Summary 操作对当前推理状态的合理性与收益。
- **奖励预算与比例归一化**：设置过程奖励预算 \(B_{proc}\)，超出时按比例缩放，防止奖励黑客（通过过度调用动作刷分）。

**（3）信息感知轨迹拒绝（解决 C2）**

- 每个输入生成 K 条 rollout，计算同一输入下奖励的均值 \(\mu^{(b)}\) 与方差 \((\sigma^{(b)})^2\)；
- 定义 UCB 式信息感知分数：
  \[
  \tilde{r}^{(b,i)} = (\sigma^{(b)})^2 \cdot r^{(b,i)} + \mu^{(b)}
  \]
  方差项突出“同一输入存在多样非平凡解路径”的样本，奖励项区分同输入内的高质量轨迹；
- 在**批级（batch × rollout）全局排名**，仅保留前 p 比例的轨迹参与策略优化，丢弃低信息轨迹。

**（4）其他细节**

- **Pop 注意力掩码**：在标准因果掩码基础上，对被 pop 的 token 设置掩码，使其信息只能通过 summary token 间接访问，实现结构性的错误隔离；
- 训练采用 GRPO（群组相对策略优化），并配合 KL 正则与 SFT 初始化（可选）。

### 6. 主要结论与发现

1. **一致性超越基线**：AgenticRag-R1 在域内、域外基准上均达到最佳或次佳，例：3B 模型在 2Wiki 上 +3.02%、HotpotQA 上 +6.76%，7B 模型在 Bamboogle 上 +7.17%，1.5B 模型在 TriviaQA 上 +7.2%。
2. **记忆与拒绝机制缺一不可**：去掉记忆动作或轨迹拒绝均显著下降（Avg 从 33.55% 降至 27.37% / 25.43%），两者同时去掉降至 24.24%。
3. **过程奖励必要**：去掉检索奖励和记忆奖励后，平均 F1 从 33.55% 大幅降至 19.94%。
4. **长视界能力是设计的核心收益**：随着最大步数从 10 增至 30，模型性能单调提升（如 TriviaQA 上 37.53% → 55.28%），而 TC-RAG、Search-R1 在长视界下不稳定或退化，说明“增加步数”本身不够，必须配合细粒度记忆与奖励设计。
5. **训练动态健康**：`<think>`、`<summary>`、`<backtrack>` 等动作频率稳步上升，奖励上升、熵下降、响应长度先升后降，表明模型收敛到更高效、更一致的策略。
6. **小模型受益更大**：1.5B 提升 +54%，3B 提升 +50%，7B 提升 +20%，说明细粒度动作空间与记忆机制能有效弥补小模型参数容量的不足。

### 7. 优点

1. **问题定位精准**：明确指出现有 RL 智能体 RAG 的痛点——粗粒度动作、无记忆修正、稀疏奖励、短视偏差，并针对性地提出两阶段解决方案。
2. **技术设计新颖**：
   - 将记忆栈 + pop 注意力掩码引入 RL 训练，赋予模型可逆、可纠错的记忆管理能力，是区别于现有“append-only”范式的关键创新；
   - 层次化奖励（outcome + process）与奖励预算机制，缓解了奖励分配薄弱与奖励黑客问题；
   - 信息感知轨迹拒绝采用 UCB 式评分（方差×奖励+均值），在批级全局筛选，兼顾样本多样性与质量。
3. **理论支撑**：附录给出定理证明（outcome-only 奖励下的误差放大、pop 栈的结构隔离），为设计提供理论依据。
4. **实验全面性**：跨模型规模、跨任务类型、跨领域（医疗、报告、交互决策）的充分验证，并含训练动态、神经元重要性等深度分析，结论可信度较高。
5. **泛化能力强**：在域外基准（Bamboogle、TriviaQA、FRAMES）和垂直领域（MedQA、DeepResearch、WebShop）均表现提升，说明框架不是简单过拟合训练分布。

### 8. 不足与局限

1. **计算开销较高**：记忆栈管理、动态检索、GRM 评判均引入额外计算成本；训练期间记忆操作评估约消耗 3000–4000 input tokens/次调用，虽仅发生在训练阶段，但在大规模或实时场景下仍是瓶颈。
2. **超参数敏感**：拒绝阈值 p、奖励预算 \(B_{proc}\)、GRM 提示等需要仔细调整，不同配置性能差异明显，迁移到新任务时调参成本较高，框架的“开箱即用”性受限。
3. **奖励依赖外部评判模型**：\(r_{rag}\) 和 \(r_{mem}\) 依赖 GRM 的语义评估，GRM 本身的偏差会直接传导到训练信号中；论文未充分讨论 GRM 错误的鲁棒性。
4. **实验统计严谨性不足**：未见多次随机种子下的均值±方差或显著性检验；部分基线（AEPO、Mem1）在较大模型上性能异常，可能因训练不稳定或未充分调优，削弱了对比公平性。
