## 摘要
人工智能生成内容（AIGC）服务采用生成式人工智能（GenAI）模型自动生成多样化内容。移动AIGC网络在边缘部署的AIGC服务提供商（ASP）上托管GenAI模型，以向移动用户提供低延迟和个性化的AIGC服务。然而，AIGC推理任务通常在任务完成前持续占用GPU内存，导致服务ASP的GPU内存耗尽并触发内存不足故障，而不仅仅是增加服务延迟。现有关于AIGC任务编排的研究在很大程度上忽视了GPU内存可行性约束。为解决这一问题，我们开发了一个协作式多智能体编排框架，其中每个边缘节点配备一个调度智能体，将任务路由至本地ASP或相邻边缘节点。由于调度智能体仅基于局部观测做出决策，而对等卸载耦合了其资源状态与长期效用，我们将编排过程建模为协作式分散部分可观测马尔可夫决策过程（Dec-POMDP）。为解决该Dec-POMDP，我们提出了一种基于注意力引导的多智能体深度强化学习算法（A-MADiff），该算法采用扩散策略，并遵循集中训练与分散执行范式。A-MADiff利用基于扩散的分散行动者生成对可行编排动作的多模态偏好，并利用注意力引导的集中评论家从GPU内存异构性下的跨智能体状态中估计每个智能体的值。数值结果表明，A-MADiff相较于最先进的基线显著提升了累积奖励。

## Abstract
Artificial Intelligence-Generated Content (AIGC) services employ Generative AI (GenAI) models to automatically generate diverse content. Mobile AIGC networks host GenAI models on edge-located AIGC Service Providers (ASPs) to deliver low-latency and personalized AIGC services for mobile users. However, AIGC inference tasks typically occupy GPU memory until task completion, causing GPU memory exhaustion at serving ASPs and triggering out-of-memory failures rather than merely increasing service latency. Existing studies on AIGC task orchestration have largely overlooked GPU memory feasibility constraints. To address this issue, we develop a cooperative multi-agent orchestration framework, in which each edge node is equipped with a scheduling agent to route tasks to local ASPs or neighboring edge nodes. Since scheduling agents make decisions based only on local observations, while peer offloading couples their resource states and long-term utilities, we formulate the orchestration process as a cooperative Decentralized Partially Observable Markov Decision Process (Dec-POMDP). To solve the Dec-POMDP, we propose an \underline{A}ttention-guided \underline{M}ulti-\underline{A}gent deep reinforcement learning algorithm with \underline{Diff}usion policies (A-MADiff) under the centralized training with a decentralized execution paradigm. A-MADiff employs diffusion-based decentralized actors to generate multi-modal preferences over feasible orchestration actions, and an attention-guided centralized critic to estimate per-agent values from cross-agent states under GPU memory heterogeneity. Numerical results demonstrate that A-MADiff significantly improves the cumulative reward over the state-of-the-art baseline.

# A-MADiff 论文总结

## 1. 核心问题与整体含义

- **背景**：AIGC 服务依赖生成式 AI（GenAI）模型自动生成文本、图像、音视频等内容。移动 AIGC 网络将 GenAI 模型部署在边缘侧的 AIGC 服务提供商（ASP）上，以向移动用户提供低延迟、个性化服务。
- **关键痛点**：AIGC 推理任务在 GPU 上执行时会持续占用 GPU 内存（模型权重、KV cache、中间激活等），直至任务完成。若运行时可用的 GPU 内存不足，任务将直接触发 **OOM 失败（Out-of-Memory）**，而不仅仅是延迟增加。这是一种 **硬可行性约束**，与计算资源不足时的“软性降质”有本质区别。
- **研究缺口**：现有 AIGC 任务编排研究大多聚焦计算资源、带宽、缓存或服务质量，普遍忽略 GPU 内存可行性约束；且多数工作假设单一调度实体拥有全局可观测状态。
- **论文目标**：设计一个多智能体协作的任务编排框架，使各边缘节点调度智能体在部分可观测条件下，协同决定“本地执行、对等卸载、队列延后”，并显式考虑 GPU 内存约束，从而避免 OOM 失败并提升长期网络效用。

## 2. 方法论

- **系统建模**：
  - 每个边缘节点部署一个调度智能体（agent），管理多个本地 ASP；不同 ASP 具有异构推理速率、GPU 内存容量。
  - 每个智能体只能获取本地观测（当前任务特征、本地状态摘要、邻居状态摘要），邻居状态还包含噪声，模拟部分可观测性。
  - 任务有计算负载 `w_i`、内存需求 `m_i`、数据负载 `D_i`、已跳数 `h_i` 等属性；执行延迟由推理率决定，内存占用持续到任务完成。
- **问题形式化**：
  - 将动态编排过程建模为 **协作式 Dec-POMDP**，元组为 `<N, S, {O_n}, {A_n}, P, Ω, R, γ>`。
  - 动作空间为 `{本地执行, 对等卸载, 队列延后}`；每个动作受结构性可行集 `F_t` 约束（物理 GPU 容量、最大跳数、目标队列容量），运行时还需通过 **内存可用性准入检查**。
  - 奖励函数包括本地执行效用、卸载估计效用、延后成本、OOM 失败惩罚；整体采用合作式奖励 `r_t = Σ r_t^n`。
- **A-MADiff 算法**（核心创新）：
  - 遵循 **CTDE 范式**：集中训练、分散执行。
  - **扩散策略分散 Actor**：从高斯噪声出发，经过 `T_d` 步反向去噪，生成动作偏好向量，再经可行掩码归一化为离散动作分布。扩散过程的迭代结构可表达 **状态相关的多模态动作偏好**，优于单程高斯/分类策略网络。
  - **注意力引导的集中 Critic**：训练时利用所有智能体的局部观测，先经共享编码器，再使用 **多头自注意力（MHA）** 建模跨智能体影响，并拼接 agent ID，输出每个候选动作的边际价值。采用 **双 Critic** 降低过估计，并计算 soft state value。
  - **优化目标**：基于 SAC（Soft Actor-Critic）风格，包含评论家 TD 误差损失、Actor 熵正则化策略损失、熵系数自适应更新。
