## 摘要
本文研究了协作通信网络中的合作博弈问题，其中每个中继自主决策，并旨在实现最大化能效这一相同优化目标。我们考虑了非理想情况，即瞬时信道状态信息难以获取，仅能获得部分可观测的过时信道状态信息。为解决该博弈问题，我们定义了一种基于延迟奖励的状态-动作值函数，并提出了多智能体深度Q网络学习框架。随后，我们通过分析证明，采用瞬时信道状态信息的博弈论方法获得的效用值是我们所提方法的上界。仿真结果表明，我们的方法显著优于潜在的替代方案，且与最优解的差距仅为5.2%左右。

## Abstract
In this paper, we study a cooperative game in the cooperative communication network, where each relay makes decisions autonomously and aims to achieve the same optimization objective of maximizing energy efficiency. We consider the non-ideal situation where instantaneous channel state information (CSI) is difficult to obtain and only partially observable outdated CSI is available. To solve this game problem, we define a delayed reward-based state-action value function and propose a multi-agent deep Q network learning framework. Then, we prove analytically that utilities obtained by game-theoretic approaches with the instantaneous CSI serve as upper bounds for those of the proposed method. Simulation results reveal that our approach considerably outperforms its potential alternatives and is only about 5.2% away from the optimal solution.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：在两跳协作中继网络中，如何最大化系统的能量效率（EE），即端到端信道容量与总发射功率之比。
- **现有方法局限**：
  - 传统优化方法（如凸优化）通常假设理想信道状态信息（CSI）可用，且依赖中央控制器进行全局调度，不适用于分布式场景。
  - 已有基于多智能体强化学习（MARL）的工作大多假设瞬时CSI可获取，但在实际中信道状态快速变化，瞬时CSI难以获得，仅有部分可观测且过时的CSI可供使用。
- **研究目标**：在部分可观测、过时CSI的非理想条件下，设计分布式功率控制方案，使各中继节点独立决策但共同最大化系统能效。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：将问题建模为合作博弈，每个中继作为独立智能体，通过多智能体深度Q网络（DQN）学习最优功率选择策略，利用“延迟奖励”函数处理过时CSI带来的非马尔可夫性。
- **系统模型与博弈建模**：
  - 场景：源S、目的D和K个中继，采用放大转发（AF）协议、半双工模式。
  - 信道模型：高斯马尔可夫块衰落自回归模型，表征时间相关性（相关系数ρ）。
  - 能效定义：EE = I / (Ps + ∑Pk)，其中I为端到端信道容量。
  - 博弈G：玩家为中继，效用函数为全局能效，策略空间为离散功率水平 {0,1,…,L}·Pk_max/L。存在混合策略纳什均衡（定理1）。
- **非理想条件挑战**：过时CSI下博弈论方法无法直接应用（均衡不存在或不稳定），因此转向RL。
- **MDP设计**：
  - 状态（每个中继k）：s_k(t) = [h_sk(t-1), h_kd(t-1), Ps]（仅部分过时CSI）。
  - 动作：a_k(t) ∈ {0,1,…,L}，对应离散功率水平。
  - 奖励（延迟奖励）：r_k(t) = EE(a_t; s_{t+1}, p)，即依赖于下一时刻全局状态（瞬时CSI）和当前联合动作。这是关键创新：奖励基于“未来”真实状态，但智能体只能观察到过去状态。
- **延迟奖励状态-动作值函数**：
  - 定义˜Q(s_t, a_t; θ) = E_{s_{t+1}} [r_t(s_{t+1}, a_t)] + γ E_{s_{t+1}, a_{t+1}} [˜Q(s_{t+1}, a_{t+1}; θ)]。
  - 对于纯物理通信环境中的单步决策，˜Q(s_{t+1}, a_{t+1})可视为0，从而简化。
  - Bellman迭代：˜Q(s_t, a_t; θ) = E_{s_{t+1}} [r_t + γ max_{a_{t+1}} ˜Q(s_{t+1}, a_{t+1}; θ)]。
- **多智能体DQN算法**（Algorithm 1）：
  - 每个智能体独立维护经验回放缓冲区B_k、评估网络θ_k和目标网络θ'_k。
  - 采用ε-贪婪策略选择动作。
  - 训练时从缓冲区采样小批量，最小化TD误差平方的期望。
  - 使用RMSProp优化器，每C步更新目标网络。
- **理论分析（上界性能）**：
  - 利用瞬时CSI的博弈论最优策略π*_G能获得最大效用EE*，其满足：EE*(P*) = r_t(s_{t+1}, a*_t) ≥ r_t(s_{t+1}, ˜a_t)。
  - 进一步，对˜Q进行迭代，得到˜Q(s_t, ˜a_t; θ) ≤ E_{s_{t+1}} [Q_G(s_t, a*_t)]，即博弈论方法提供RL方法的上界。
  - 该结论对长期决策和单步决策均成立。

## 3. 实验设计

- **仿真场景**：基于高斯马尔可夫模型（ρ=0.1），源发射功率1.0 W，每个中继最大功率1.0 W，中继数K=5。每个智能体功率水平数L+1可变（2~8）。
- **超参数**：学习率0.001，经验池大小10000，mini-batch大小128，训练间隔1，训练episode数100，每个episode时隙1000，ε=0.9（训练），ε=1.0（测试，无探索）。
- **对比方法（Benchmarks）**：
  - **Optimal**：使用全局瞬时CSI的博弈论最优解（理论下界上界）。
  - **SADQN**（单智能体DQN）：中央控制器基于全局过时CSI学习联合策略，但动作空间维度为(L+1)^K。
  - **GOIBS**（全局过时信息方案）：使用全局过时CSI直接通过博弈论方法求解。
  - **POIBS**（部分过时信息方案）：每个中继仅利用自身过时CSI最大化单跳链路能效。
- **实验结果**：
  - **训练阶段**（L+1=4）：所提MADQN收敛更快（约40 episode），更稳定；SADQN收敛慢（约60 episode），波动大。最终能效MADQN约0.685 bit/J/Hz，SADQN约0.680 bit/J/Hz。
  - **测试阶段（不同功率水平数）**：
    - 所有方法中Optimal最高（如5个水平时0.823 bit/J/Hz）。
    - 所提MADQN约0.781 bit/J/Hz，与Optimal差距仅5.2%。
    - GOIBS约0.761 bit/J/Hz，低于MADQN（差距2.6%）。
    - POIBS仅0.409 bit/J/Hz，远差。
    - SADQN在水平增多时性能下降（动作空间爆炸），而所提方法持续提升。
