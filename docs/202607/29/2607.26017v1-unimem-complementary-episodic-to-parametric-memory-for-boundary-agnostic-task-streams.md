## 摘要
记忆对于大语言模型代理积累任务经验和复用特定任务执行策略至关重要。然而，在边界无关且不断演化的任务流中进行实际部署，会暴露出基本的稳定性-可塑性困境。基于外部检索的记忆可以快速吸收新证据，但往往难以内化重复的执行模式，并带来推理时的检索开销。参数化记忆一旦学习完成，能够实现稳定高效的执行，但通常依赖明确的任务边界和固定的参数预算。受人类大脑通过互补性情景存储和渐进巩固来平衡可塑性与稳定性的启发，我们提出了UniMem，一种用于自主记忆管理的自路由框架。UniMem使用可学习的路由令牌作为记忆控制器，实现互补记忆通路之间的自适应协调：新颖或稀疏的任务保留在情景缓冲区中以供检索增强执行，而重复且可靠的模式则巩固到可扩展的参数化记忆中。通过使用路由令牌和参数化记忆块将任务识别与任务执行解耦，UniMem在部署过程中无需任务标签即可按需扩展记忆，同时避免了参数的无控制增长。在长时流式任务序列上的实验表明，UniMem在保持执行保真度的同时 consistently 优于基线模型，在三种骨干模型上平均提升了4.0个EM点。

## Abstract
Memory is essential for LLM agents to accumulate task experience and reuse task-specific execution strategies. However, real-world deployment over boundary-agnostic and evolving task streams exposes a fundamental stability-plasticity dilemma. External retrieval-based memory can rapidly absorb new evidence, but it often fails to internalize recurring execution patterns and incurs inference-time retrieval overhead. Parametric memory enables stable and efficient execution once learned, but typically relies on explicit task boundaries and fixed parameter budgets. Inspired by the human brain, which balances plasticity and stability through complementary episodic storage and gradual consolidation, we propose UniMem, a self-routing framework for autonomous memory management. UniMem uses learnable routing tokens as memory controllers, enabling adaptive coordination between complementary memory pathways: novel or sparse tasks are retained in an episodic buffer for retrieval-augmented execution, while recurring and reliable patterns are consolidated into expandable parametric memory. By decoupling task identification from task execution with routing tokens and parametric memory blocks, UniMem expands memory on demand without task labels during deployment or uncontrolled parameter growth. Experiments on long-horizon streaming task sequences show that UniMem consistently outperforms baselines while maintaining execution fidelity, achieving an average gain of 4.0 EM points across three backbone models.

## 2. 论文提出的方法论

### 核心思想
UniMem 是一个自路由的统一记忆框架，通过**可学习路由令牌**作为记忆控制器，将新异或稀疏的任务导向**情景缓冲区**（检索增强执行），将重复可靠的模式巩固到**可扩展参数化记忆**中。路由令牌负责任务识别，与之关联的参数记忆块负责任务执行，两者解耦。

### 关键技术细节
- **路由令牌矩阵**：包含已知任务令牌 \(e_k\) 和新异哨兵令牌 \(e_{NOVEL}\)。输入查询经冻结LLM编码后，计算与路由令牌的匹配概率（基于隐藏状态点积）。只有当已知令牌概率超过哨兵令牌且高于阈值 \(\tau_{route}\) 时才激活对应参数记忆单元，否则进入新异路径。
- **参数化记忆块**：实例化为**程序性KV记忆**（Procedural KV Memory），包括每层可学习的键值对和注入门控 \(g^{(l)}\)。通过跨注意力将记忆输出融入冻结自注意力输出：\(H_{out}^{(l)} = H_{orig}^{(l)} + g^{(l)} \cdot \text{CrossAttn}(Q^{(l)}, K_k^{(l)}, V_k^{(l)})\)。
- **解耦优化目标**：路由损失 \(L_{route}\) 仅更新路由令牌；执行损失 \(L_{exec}^{(k)}\) 仅更新被选中的参数记忆块及其门控。
- **渐进式记忆扩展**：
  - **阶段一（路由空间初始化）**：为已知任务学习路由令牌，并基于已知令牌质心初始化新异哨兵令牌，再用保留的伪未见任务校准路由层。
  - **阶段二（自主发现与巩固）**：流式部署中，新异查询进入情景缓冲区；当缓冲达到容量 \(C\) 时触发无监督聚类（NCD距离 + HDBSCAN），只有通过质量门控（连贯性检验、嵌入异常值过滤）的簇才会被提升为新参数记忆单元（分配新路由令牌和KV记忆），并基于簇内样本进行SFT微调。

- UniMem在**所有设置下 consistently 优于基线**，在三个骨干上的EM平均提升4.0点（SNI）。

## 7. 优点

- **创新性**：首次将人脑互补学习系统原理系统引入LLM记忆管理，提出自路由情景-参数两阶段框架。
- **实用性**：无需显式任务标签即可在开放流中自主扩展记忆，参数增长受控（每个新任务仅约60k参数，远小于3B骨干）。
- **高效性**：推理时路由开销极低（一次点积比较），激活的参数记忆块仅用于匹配任务，不增加序列长度。
- **实验充分性**：在多个主流骨干和两个代表性基准上进行了详尽比较，消融实验设计合理，揭示了各组件的贡献。
- **可扩展性**：框架不耦合特定PEFT模块，未来可替换为其他参数高效记忆形式。

## 8. 不足与局限

- **保守的巩固策略**：当前采用保守聚类和低质量过滤（仅提升高置信簇），可能遗漏某些可巩固的模式，暂未探索更自适应的合并标准。
- **参数记忆实现单一**：仅实例化为程序性KV记忆，未尝试其他PEFT模块（如Adapter、Prefix-Tuning），不同模块可能带来不同容量/效率权衡。
- **潜在风险**：实际部署中，若记忆系统错误地巩固了有偏或不正确的策略，会导致重复利用这些错误。另外，用户敏感信息可能被无意保留在情景缓冲或参数记忆中，需要额外隐私过滤和审计机制。
- **实验覆盖**：虽然使用了多种模型，但任务类型主要为NLP理解和推理，未涉及多模态或更复杂的Agent交互场景。长尾分布的模拟（10 samples per sparse task）是固定的，未测试不同稀疏度或噪声干扰。
